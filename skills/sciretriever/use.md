# 使用文献库：HTTP 版 MCP

同一文献库地址的 `/mcp` 提供 Streamable HTTP。连接需要“读取”用途；提交任务还需要“操作”。只有“入库”用途时使用 [import.md](import.md) 的 HTTP 接口。

在支持 Streamable HTTP 的客户端中配置 `<文献库地址>/mcp`，从私有文件加载连接令牌作为请求头。具体配置方式以客户端为准；不把令牌粘贴进对话或示例配置。列出工具确认连通，实际工具和字段以服务端返回的定义为准，列表随连接用途变化。

- 查找与阅读：先检索文献库，再读文献详情与全文；按服务端分页读取，不一次请求整库内容。
- 入库后核对：读取批次状态、进度与报告，再按使用者要求检索新入库的文献。批次只读工具需要“读取”用途；只持“入库”用途时继续用入库 HTTP 接口。
- 提交任务：遵守使用者对范围、联网与费用的授权；缺少必要授权时先问。提交后按任务编号查询，不因等待而重复提交。

入库数据与文件使用 HTTP 入库接口，不通过 MCP 传输。完整接口说明仍在 `GET <地址>/api/v1/intake/instructions`。
