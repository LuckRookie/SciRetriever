# 使用文献库：HTTP 版 MCP

文献库在同一个地址的 `/mcp` 上提供 MCP（Streamable HTTP），工具与服务器上的 stdio 版相同。

## 配置

连接时用途要勾“读取”；还要发起会联网、会花费的任务（发现文献、获取 PDF、提交加工）时勾“操作”。“导入”和“收藏”用途不能用 MCP。

在支持 Streamable HTTP 的客户端里加一个服务，地址是 `<地址>/mcp`，请求头 `Authorization: Bearer <令牌>`。令牌从 `~/.config/sciretriever/curl.conf` 里取，由用户粘贴进客户端的配置，或由你直接写进只有用户能读的配置文件；不要在对话里显示它。常见写法：

```json
{
  "mcpServers": {
    "sciretriever": {
      "type": "http",
      "url": "http://localhost:4174/mcp",
      "headers": { "Authorization": "Bearer <令牌>" }
    }
  }
}
```

配置后重启客户端，列出工具确认连上。列表随用途变化：只有“读取”时看不到发起任务的工具。

## 常用流程

- **查找与阅读**：先检索文献库，再读文献详情与全文。全文按段落分页读，不要一次全取。
- **导入之后**：用导入会话的只读工具（状态、报告）核对结果，再按用户要求检索新导入的文献。
- **发起任务**（需要“操作”）：任务会联网或调用模型、产生费用。先把范围和要用的服务告诉用户，得到同意再提交；提交后按任务编号查看进度，不重复提交。

导入的数据和文件不经 MCP 传，走 [import.md](import.md) 的 HTTP 接口。
