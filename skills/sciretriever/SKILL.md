# SciRetriever 文献库

你与使用者的浏览器连接同一个 SciRetriever 地址。按连接码中的地址连接，不猜服务器地址或端口。

接口的请求、结果、格式、上限与错误码以连接后的 `GET <地址>/api/v1/intake/instructions` 为准。这里讲执行顺序与判断。Zotero 导入与单篇网页收藏使用浏览器扩展，不由 Agent 模拟扩展操作。

## 始终遵守

- **令牌直接写进私有文件**，不打印、不写进对话、网址、命令行参数或日志。请求从文件读请求头。
- **只做用户要求的范围。** 范围不明确（整库还是某个分组、要不要 PDF）先问。用户说要先看再导时，预览后停下，等用户确认。
- **以服务端的当前状态为准。** 中断或出错后先读批次状态和待交文件清单，再继续。确认返回只表示后台入库已启动，不能当作完成。
- 入库可以命中已有文献、补全未填写的字段；不替换已有主 PDF。只处理使用者指定的范围，冲突报告给使用者。
- 不读、不传用户的浏览器 Cookie、密码或其他服务的凭据。
