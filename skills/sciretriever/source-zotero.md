# 来源：Zotero

文献库不连 Zotero。由你在用户的电脑上从 Zotero 取出数据，再按 [import.md](import.md) 交给文献库。

## 现在可用：导出文件

1. 请用户在 Zotero 里右键要导入的分类（或“我的文库”），选“导出分类…”（整库为“文件 → 导出文库…”）。
2. 格式选 **BibTeX**，勾选 **导出文件**，保存到一个新文件夹。得到一个 `.bib` 文件和一个 `files/` 子文件夹，`.bib` 里每条的 `file` 字段写着 PDF 的相对路径。
3. 按 import.md 导入：`format` 为 `bibtex`，`library` 为 `null`，`file_name` 用 `.bib` 的文件名。
4. 确认后交文件时，把导出的那个文件夹交给 `scripts/upload_files.py`，它按 `file` 字段里的相对路径找 PDF。

这样导入的限制：

- 每次导入都是一个一次性来源。再导一次时，文献按 DOI 等标识去重，不会重复入库，但不会按 Zotero 的条目编号识别“同一条”。
- 分组层级、Zotero 标签不会变成文献库的文件夹。
- 只取每条的第一个 PDF，其他附件只计数。

## 以后：直接读 Zotero（未开放）

文献库的 Zotero 适配器还在开发中（计划 20 · 04）。上线后，你将从 Zotero 的本地接口读取库、分组、条目与附件，把原始数据原样交给导入会话，分组会变成文件夹，再次导入就是同步。在那之前不要自己把 Zotero 的接口数据改写成别的格式交给文献库。

库只在 Zotero 网站上、本机没有 Zotero 时，同样等适配器上线。到时会用用户自己的只读 key 读 Zotero 网络 API；key 留在用户电脑上，不交给文献库。
