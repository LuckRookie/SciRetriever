# 标签词表与文献标签

本目录拥有领域中立的词表、有序分配、人工锁定、整理和撤销。标签关联校订稿片段，问答标注算子的结果不进入词表。所有模型步骤通过共享 DSH 执行。

- `rules.ts`：名称、化合物、两层层级、锁定和排序规则。
- `vocabulary.ts`：通过同步事务端口制定创建、合并、变更与依赖撤销；不依赖 SQLite。
- `service.ts`：两步打标、证据核验、并发吸附、整理、定义复核及先预览后执行的回溯。
- `input.ts`：在完整校订片段边界限制章节输入，记录所读片段、各章节覆盖字节及未纳入原因；覆盖信息随打标回执和建档步骤结果保存。
- `model.ts`：打标、整理、回溯的 DSH 任务提示和封闭输出 schema。

SQLite 适配负责同一 catalog 的事务与索引；应用入口负责权限和协议转换。模型在事务之外执行；发布会检查标签、元数据和校订文档是否仍为对应版本。读取、筛选和回溯预览不会调用模型。
