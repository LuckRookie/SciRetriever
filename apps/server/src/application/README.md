# 应用任务控制

承接应用级任务执行、审计和只读过程投影。`jobs/` 管理持久任务；`operations.ts` 记录操作身份、允许的范围标识和固定任务目标的逐篇映射事件；`agent-traces.ts` 保存有界脱敏过程，并在会话结束满 7 天后清理。任务累计用量与结果独立保留。

## 下级目录

| 目录                    | 职责               |
| ----------------------- | ------------------ |
| [jobs/](jobs/README.md) | 持久任务与加工调度 |

`restart-admission.ts` 提供运行时的 intent/activity 共享与排他交接许可，覆盖提交、前台工作、探针和已登记任务的继续执行；准入不替代业务写锁，不以查询为空代替资源排空。

## 放置边界

生产对象图与应用生命周期组装在 bootstrap；用户操作编排在 entry；持久化执行记录在 storage/execution。

[上级目录](../README.md)

`conversation-record.ts` 约束原始可见会话记录：保留普通文本和工具 JSON 格式，排除凭据、图片字节与隐藏推理，明确标记截断；`agent-traces.ts` 仍负责持久化队列、2 MiB 会话上限和 7 天清理。
