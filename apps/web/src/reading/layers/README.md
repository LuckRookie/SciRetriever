# 阅读层

有阅读层的文献在阅读页上的四个视图（阅读体验第 3 节，ADR 0070、0073）：全文上的批语、脉络、概览、导图，以及层与层之间的过渡。阅读层按段写（文件版本 4）：每一段一条批语（带理由），每一节一句节旨；批语以它的段号为名（“¶41”，取全文左页边显示的段号，`model.ts` 的 `paragraphNo`），主干段的段号在实心朱圈里。框架无关：只生成 DOM、处理指针与滚动，由全文引擎 `../document.ts` 在正文排好之后挂上，React 一侧只经 `ReaderFrame` 的 `setLayer`、`layerWheel`、`setKeyTerms`、`foldLayers`、`onLayer`、`onLayers` 与它来往。界面上把要点叫“批语”，代码里沿用合同的名字 point。

- [read.ts](read.ts)：读一个版本的阅读层（`overview` 一次，`outline` 分页读完），用合同包的解析器；有译文部分时读 `bilingual`，换读法不再请求。[contract.ts](contract.ts) 只剩 409 拒绝的解析。
- [model.ts](model.ts)：四个视图共用的数据（各节带节旨）、各种文字取原文还是译文（批语、理由、节旨及其题的译文取读取结果的译文部分）、类别与关系的名字、段号、安全的行内渲染与重点词的标出（合同包的 `key-term-match-v1`），以及全文引擎要提供的 `LayersPort`。
- [notes.ts](notes.ts)：全文上的批语。把每条依据的句子在它所在的块里找出来（复用批注的 `mark-locate`；公式按 KaTeX 保留的 TeX 源码比对，整个公式作为一个整体标出），在文字节点外面包一层 `span.rl-ev`，重点词包 `b.rl-kt`；句末不标编号。批语所批的段（`unit_id` 的起点所在的块）带 `data-point`，主干段另带 `data-rl-main`（左页边的段号画成实心朱圈）。作者的文字不变，选中、复制、查找到的仍是原文；块的 `data-text-revision` 变化让批注重新建索引。找不到原句（公式写法不同）时不包，批语仍排在段落旁。`blockCopy` 是全文一块按读法的副本（去掉界面附加的东西），原地展开与脉络里没有批语的段共用。
- [leaf.ts](leaf.ts)：脉络与概览两页的内容与页边。脉络按全文的块依次排（`outlineItems`）：阅读层列出的一节排作者的标题与节旨，有批语的段排纲（批语接理由）与目（依据：一句或一句里的一段摘录，不相接的两处之间一个淡色“…”；摘录在一句中间起止时，那一头也有同样的“…”，按 `model.ts` 的 `quoteCut` 用合同包的分句规则与全文引擎给的单元原文判断，导图右栏同样），没有批语的段（段落、列表、图注）原样排；阅读层没有列出的一节（没有批语也没有节旨，例如参考文献）连同它的段不排。概览的“纲目”按节排节号、标题与节旨，下面是这一节的主干批语与所据的一行（它的第一条依据；读译文时是这条依据的译文摘录）。两页上是同一件东西的元素带同一个 `data-f`。
- [map.ts](map.ts)：导图。每段一个节点（段号加题，主干的段号在实心圈里、大一号），章节节点底线下一行节旨的题；按层分列、父节点对着子节点中间；每个比例都按真实尺寸重排；平移用 transform；右栏读一段：段号、类别、所在章节与节旨、批语与理由、关系、依据句、图。
- [change.ts](change.ts)：换层。新的一页照常排好，带同一个 `data-f` 的东西各从旧位置走到新位置；整个变化是 0 到 1 的一个值的函数，点击由时间推动，`Alt` 加滚轮由手推动。旧的一页是窗口附近内容的副本，放在纸页里。
- [view.ts](view.ts)：总控。在纸页里放栏线、朱笔、页边与另外两页，决定显示哪一层（纸页上的 `data-layer`），排页边（全文里每条批语对着它的段的第一行，相近的依次往下排）、处理点击与悬停（全文里批语与它的段一起亮）、起止换层。概览与脉络里的点击是原地展开（阅读体验 3.3.5）：原句展开成它所在的整段（全文块的一份副本，去掉界面附加的东西，用 `notes.ts` 的 `markSentence` 标出段里所有批语的句子，按读法留原文、译文或两者），出自这一段的其他原句一起收进来；动画逐词移动，原句的词按字面配对后以副本（`.rl-ghost`，放在 `stage` 里）飞到段落里的位置；`fold()` 全部收回，`keepPlace` 每一帧保持点的那一处的高度。

样式在 `../../app/features/reader/layers.css`，类名都以 `rl-` 开头。页面测试是 `apps/web/test/next-reader-layers.test.ts`，夹具 `stored-layers.ts` 是一篇合成文献。
