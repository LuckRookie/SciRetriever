# 连续阅读与固定证据

面向工作台阅读标签的 PDF、解析全文和辅助知识呈现。材料、文档与证据继续由现有查询 owner 校验；这里不生成分析结果、不访问任意文件或远程图片。

`state.ts` 保存按库、文献及固定材料版本隔离的临时位置与布局；关闭标签即释放对应状态。渲染模块及 PDF worker、字体与数学样式由正式静态资源构建交付，按阅读入口装载。

全文首先读取一页片段对应的连续范围，再随续读推进片段游标；不等全部片段和目录枚举完成才显示正文。接近已加载末尾时自动续读；失败停止并显示重试，已渲染的稳定段落和图片不重建。每次续读仍固定文档身份与实际 UTF-8 连续范围，位置恢复保留原先已加载范围。

正文和表格内的图片接近可视区域时自动读取，分段核验固定资源与 hash 后解码、显示；加载期间只显示中文状态，不把资源路径当作正文。支持点击或键盘放大，缺失、读取失败和无法解码分别保留说明；不会加载任意外部图片。

目录异步返回时，初始位置恢复不能抢占已经打开的文内引用预览或导航操作。初始恢复直接定位，不遗留平滑滚动；用户主动导航仍按动效偏好执行。

PDF 按段读取：`pdf-bytes.ts` 为每份固定 PDF（按资产 SHA-256）维护一个共用的读取器，PDF.js 经 `pdf.ts` 的范围传输只取它需要的 64 KB 块，第一页先显示；首屏画出后，其余部分在后台按每次至多 2 MB 补齐（有阅读请求时让路），收齐后整份计算一次 SHA-256。块不重复下载，同一份 PDF 的多个读者共用下载与校验；最后一个读者关闭时取消未完成的请求。每个响应核对内容类型、`X-Sciretriever-*` 身份头、ETag 与所请求的范围。校验通过后字节进入会话缓存（256 MB，最近使用优先），“下载 PDF”此时才可用；校验或响应核对不通过时，所有读者停止显示并释放页面，会话缓存作废，这份 PDF 记入本机的“绕过缓存”名单，下次打开以 `cache: "reload"` 重新取，校验通过后移出名单。

PDF 页码输入保留尚未提交的编辑值，滚动通知不回写覆盖；确认页码后更新实际位置，切换文献继续按各自固定材料恢复。

React 阅读入口通过 `contract.ts` 的 `ReadingContext` / `ReaderFrame` 接入；`source.ts` 是固定来源 URL 与身份解析。`dom.ts` 提供引擎内部的安全 DOM 控件。旧 DOM 入口 `entry.ts` / `frame.ts` 已删除，正式阅读引擎由 Vite 按需 chunk 装载。框架卸载后不再读取已脱离布局的滚动几何，避免把有效页码覆盖成末页。

全文的显式片段链接仅对已加载、可匹配的 Markdown 标题提供预览和定位，不推测裸引用编号与 PDF 页码；标题显示层级可位于元数据文献标题之下，但原文字节、hash、UTF-8 范围和科学内容不改写。

`table.ts` 从 inert template 重建 MinerU HTML 表格，只保留表格结构、有限排版和跨行/跨列属性；事件、样式、脚本与远程图片不进入页面。表内本地图片仍由固定文档资源 owner 读取，原文和证据字节不变。

批注的重新定位（用户整理 9.4）：`mark-relocate.ts` 是纯函数，决定在另一份 PDF 或另一个文本版本上要不要找（只找同一部分的高亮，框选从不找）、读出当前方法 `mark-locate-v1` 下记下的位置、按 `mark-locate.ts` 的比对与阈值分档。`marks.ts` 在 PDF 上逐页、在全文上按已载入的文本查找，同一会话里找不到的不重复找；找到的经 `place` 记一次，以后打开直接读记录，批注自己的锚点从不改写。
