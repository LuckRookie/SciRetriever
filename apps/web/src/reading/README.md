# 连续阅读与固定证据

面向工作台阅读标签的 PDF、解析全文和辅助知识呈现。材料、文档与证据继续由现有查询 owner 校验；这里不生成分析结果、不访问任意文件或远程图片。

`state.ts` 保存按库、文献及固定材料版本隔离的临时位置与布局；关闭标签即释放对应状态。渲染模块及 PDF worker、字体与数学样式由正式静态资源构建交付，按阅读入口装载。

全文首先读取一页片段对应的连续范围，再随续读推进片段游标；不等全部片段和目录枚举完成才显示正文。接近已加载末尾时自动续读；失败停止并显示重试，已渲染的稳定段落和图片不重建。每次续读仍固定文档身份与实际 UTF-8 连续范围，位置恢复保留原先已加载范围。

PDF 页码输入保留尚未提交的编辑值，滚动通知不回写覆盖；确认页码后更新实际位置，切换文献继续按各自固定材料恢复。

[上级源码目录](../README.md)

React 阅读入口通过 `contract.ts` 的 `ReadingContext` / `ReaderFrame` 接入；`source.ts` 是固定来源 URL 与身份解析。`dom.ts` 提供引擎内部的安全 DOM 控件。旧 DOM 入口 `entry.ts` / `frame.ts` 已删除，正式阅读引擎由 Vite 按需 chunk 装载。框架卸载后不再读取已脱离布局的滚动几何，避免把有效页码覆盖成末页。

全文的显式片段链接仅对已加载、可匹配的 Markdown 标题提供预览和定位，不推测裸引用编号与 PDF 页码；标题显示层级可位于元数据文献标题之下，但原文字节、hash、UTF-8 范围和科学内容不改写。
