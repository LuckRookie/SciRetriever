# 任务

React 任务列表使用查询缓存管理分页、刷新和取消；`TaskRun.tsx` 提供独立任务运行页，显示本次运行的逐篇步骤、用量、发起身份、失败恢复及文献/Agent/结果入口。建档任务按六步显示页进度、实际用量与停下原因。原始事件折叠到技术详情。
任务页由 `TaskPage.tsx` 组成五个下划线式标签页：任务、需处理、浏览器、Agent 会话、来源统计。每个标签页仍是自己的 `view`（`task`、`archive`、`web`、`agent`、`stats`），所以旧地址直接落到对应标签页，切换标签页也是一条可后退的历史记录。

任务控制只由用户显式触发，失败仍保留已经加载的回执。纯任务解析沿用 `src/task-view.ts`。

活动抽屉分别查询进行中、待处理和最近结束的任务；重新打开立即刷新，历史结束任务不会遮住较早的活跃任务。列表状态筛选、搜索、续页和迟到请求分别由查询键与取消信号隔离。

综合任务按成员分页显示新算、复用、部分完成、失败或中断，以及本次任务中该篇的累计用量；历史没有逐篇事件时明确说明，不从当前缓存猜测过去执行状态。
