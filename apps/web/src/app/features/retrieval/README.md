# 检索与上下文

读取既有材料与知识，显式提交检索条件，通过 Query 的有界请求及合同校验接纳结果。会话内保留草稿、结果和上下文篮子；导航会取消在途查询，旧响应不能覆盖新结果。命中按文献分组，写出所在章节（检索结果带页码时写页码），同一篇超过 3 条时折叠；“上下文”栏在选了第一个片段后才出现。“记下出处”按版本及连续字节范围核对，界面不自动翻译或重建索引。

命中库中译文的结果（`matched: "translation"`，文档与证据 9.7）在位置后标“译文”，摘录是译文，用无衬线、`--fg2`；原文摘录用衬线（`data-origin`）。出处、证据与“在全文中查看”都是原文那一段。索引状态行（`IndexLine.tsx`）读 `rule_current`、`rule_reason` 与 `library_search_rule_current`：规则或译文语言过时时说明并给“重建索引”；书目检索按旧规则时另一行给“重写书目检索”（`POST /api/v1/maintenance/rebuild-library-search`，答复在全部重写之后才回来）。两项都只在使用者点了之后执行。
