# 阅读界面

这里拥有阅读页顶栏里的阅读控件（视图、查找、排版、侧栏、“更多”，经外壳给出的插槽放进顶栏；导航按钮与标签页属外壳）、纸页的页眉（`ReaderPageHeader.tsx`）、纸页上的加载骨架（`ReaderPreparing.tsx`）、案头几何、PDF 页列与顶栏收起（`geometry.ts`）、专注模式（状态在外壳，顶栏由外壳收起）、初稿的疑点浮层（`DraftDoubt.tsx`，读取已保存的 `draft-differences`）、可收起的信息栏、总结分组和证据预览。`Reader.tsx` 根据既有 URL、固定材料与文档来源创建生命周期；`ReaderInformation.tsx` 呈现书目摘要、来源、已保存引用与处理入口；`SummaryView.tsx` 验证并展示当前单篇算子结果，以短证据编号打开原文。

PDF.js、连续 Markdown/KaTeX 与字节校验保留在 [reading](../../../reading/README.md) 的框架无关引擎中。React 通过 `ReaderFrame` 接收页码、目录、查找、可重试错误与图片/文内链接预览，不接管已稳定渲染的正文节点。切换材料会取消旧请求并释放 worker、canvas 和对象 URL。阅读位置按库、文献、模式及不可变材料隔离；关闭标签释放会话状态。

总结按已保存的报告条目呈现，不编造研究背景、不翻译或重新生成内容。模型正文中 `【片段 ID】` 与同条结构化证据完全对应时，仅在显示层移除重复标记，使用条目下方的短编号；不删除未对应的编号，不改变保存的结果或原文。证据短编号使用固定版本查询后展示原文；无法映射 PDF 页码时只定位到正文段落。全文中的显式 `#heading` 链接只在目标标题已加载且能确定匹配时提供预览；裸 `[1]`、原始 HTML 锚点和未加载目标不被猜测成参考文献。

`reading.css` 位于 `pages` 层，定义案头与纸页、正文（阅读字号 16–32 px，本机一个值）、视图切换与侧栏的过渡和窄屏布局；共用的控件与浮层继续由 [components](../../components/README.md) 提供。加工按钮进入既有 `OperationDialog` 确认，不由阅读组件调用解析器或模型。

计划 25 的 30 块：没有 PDF 的文献打开为书目页（`ReaderBibliography.tsx`，复用 `BibliographyContent`），不显示视图切换与书脊；“排版”是面板（`ReaderTypePanel.tsx`：字号或比例、行宽、行距、主题色块、两个开关），行宽与行距存本机偏好（`input/reading-layout.ts`），主题与“设置 → 外观”同一偏好；总结与结果是视图切换里临时多出的一格，排在案头的纸页上。翻译是否可用读 `GET /api/translation` 的模型列表，选中文字只填原文框，点“翻译”才出浮框。

小球（阅读体验 1.9，ADR 0071）：有 PDF 的文献打开先到 PDF。案头右下角“读”“译”两个小球（`ReaderBalls.tsx`），单击换、双击并（纯规则在 `input/balls.ts`，单击立即生效，400 ms 内的第二下变成并排；悬停时左边的“并排”小签等于双击）。“读”在 PDF 与读本之间换，并排时案头分左右两页：左页是另一组引擎（`companion`，`createReaderEngines` 的精简绑定，没有批注），在自己的滚动区 `.reader-beside` 里显示同一材料的 PDF；中间的分界可拖，宽度存本机偏好 `sciretriever:reader:pair-left:v1`；并排与否按文献记在阅读记忆的 `pair`。两页互相跟随：指针、滚轮或键盘最后在哪一页，那一页领着另一页走（读本在概览或脉络时，PDF 跟着正在读的那条批语的第一条依据，经引擎的 `layerStart` 与 `anchorAt`）；点读本里的批语或原句，PDF 翻到那一处并画出定位线（`frame.onPick`）；点 PDF 的一页，读本到那一段。“译”在原文、译文之间换，双击是对照，读本的读法与 PDF 的译文页共用这一个选择。读本在场时它下方浮着程度条“概览 · 脉络 · 全文”。顶栏只剩“导图”一个按钮。“更多”的第一项“阅读方式”是一个子菜单，各有快捷键（`input/commands.ts` 的 `view-pair`、`view-map`、`text-translate`、`text-pair`）。

阅读层（阅读体验第 3 节，ADR 0070）：有阅读层的文献，视图切换是“导图｜概览 · 脉络 · 全文｜PDF”，层写在地址的 `layer` 参数里（`map`、`overview`、`outline`，没有就是全文；它不是引擎的建造条件，换层不重建引擎）。`Reader.tsx` 从 `describe` 的 `layers` 得知有没有阅读层，把地址里的层交给引擎的 `frame.setLayer`，引擎自己换了层（点一条批语、`Alt` 加滚轮）经 `layerChanged` 写回地址。纸页的几何多一档“带批语”（`geometry.ts` 的 `annotated`：栏线所在的间隔与批语的宽写进 `--sheet-gutter`、`--sheet-note-width`）。`layers.css` 是四个视图与换层的样式；DOM 由 [reading/layers](../../../reading/layers/README.md) 的框架无关模块生成。“排版 → 标出重点词”存本机偏好 `sciretriever:reader:key-terms:v1`，默认打开。读者的页边批注在带批语的纸页上与机器的批语同宽，并排在挡路的批语下方（`marks/margin.ts` 的 `taken`）。

证据预览复用安全 Markdown/公式渲染，在阅读区边界内采用浮层；窄屏保留核对依据与校订入口。总结的逐值核对以折叠标记呈现，原因由共享 strings 映射为中文，展开后可查看每个来源的固定原文。

`ProofreadEditor.tsx` 提供完整校订稿编辑、公式/表格预览与页同步。桌面左 PDF 右编辑，窄屏上下对照；保存前保留草稿、离开需确认。

- `proofread-text.ts` 读取整份固定校订稿，按叶块所在页切成可编辑的片段；同一页被合并或图表打断时会出现“续”。
- 只能改已有段落里的文字。保存时整份提交，带整理版本与人工修订号；对应不到原文区块时返回映射冲突，草稿保留。
- “显示已删除”由 `dropped-leaves.tsx` 按页列出被删掉的内容与理由。“恢复”把它放回相邻保留内容所在的章节并锁定；需要重新校订的页由用户显式发起。
- 旧流程的校订稿只读。

`translation/` 提供阅读页翻译（ADR 0049、0050）：`use-translation.ts` 持有浏览器偏好（模型、目标语言、自动翻译、划词浮框）、原文框内容、当前译文与浮框的打开状态和拖动位置；选区立即填入原文框，开启自动翻译时浮框先显示“翻译中”，选区停下 150 ms 再发请求，新请求取消旧请求。`TranslationViews.tsx` 是可拖动的划词浮框与信息栏的原文/译文对照页。划词翻译只在选择工具下由批注表面的选区事件触发，高亮笔不翻译。

全文的三种读法（阅读体验第 9 节，ADR 0068）：由“译”小球选（见下面“小球”一段；原文 · 译文 · 对照），选择存本机偏好 `sciretriever:reader:text-mode:v1`（`input/text-mode.ts`），所有资料共用。`Reader.tsx` 每次打开重新读 `describe` 的 `translation`：只有 `complete`、`partial` 时“译”小球可按，否则变淡并悬停说明（`none` 按文本等级分两句：没有全文或未校对时“译文在解析全文时产生”，已校对时“解析全文时还没有翻译”；另有 `same-language`、`stale`；文字在 `strings.ts` 的 `translationUnavailable`，PDF 的译文页用同一句），这篇按原文显示，不改记住的选择。引擎（`reading/document.ts`）经 `document-translation` 读出全部单元，按单元首片段落在哪个块里挂到块上：块内加一段 `.reading-translation`（无衬线、`--fg2`，标题译文用 `role="heading"` 的段落，不用 h 标签），缺译的块左页边标“未译”；读法写在 `article[data-text-mode]`，CSS 决定显示哪一种。切换前后由锚点机制保持阅读线处的块；查找只找当前读法显示的文字；批注只落在原文上（译文读法不收选区，对照里涉及译文的选区也不收），译文读法里有批注的段右页边写“批注 n”，点它或从批注列表打开这样一条，都切到对照并定位。“复制为引用”和“翻译本段”取块的原文（`reading/block-text.ts`），有库里的译文时“翻译本段”直接显示它。“翻译”标签页在配置了翻译服务、或这篇有库里的译文时出现；没有翻译服务时它只有“翻译本段”的结果和一句说明，不显示模型、语言与划词选项（`TranslationPanel` 的 `service`）。“更多 → 下载全文”有译文时给原文、译文、对照三种（`slice` 的 `text`），否则只有原文。

PDF 视图的译文页（ADR 0051、0068、0071）：`use-fulltext.ts` 持有视图模式（关、对照、只看译文），`Reader.tsx` 按“译”小球的选择设它（原文为关，译文为只看译文，原/译为对照）、按页的译文与进度；页面读的是库里的译文，不请求模型，所以不先确认、也不重翻，语言取 `describe` 给出的译文语言；没有译文时“译”小球变淡并写出原因；读译文页的进度与失败后的重试写在小球左边。按页请求、最多 3 页同时进行。`fulltext-layer.ts` 是框架无关的 DOM 层，挂在 PDF 引擎的 `onPdfPage` 上：在每个已绘制页内放一个 `.ft-twin`，复制该页画布作底，在叶块区域盖上不透明底色和译文（行内 Markdown 与 KaTeX），字号从页宽决定的起点逐步缩小到放下为止，下限约为页面 6 磅。`text-layer` 定位取文字层中字母全部落在该块原文里的最长连续片段，覆盖不到原文 40% 时不放置，在页角标“N 段未放置”。批注按行框中心落在哪个块来判定，块显示最新一条的颜色，点击在原文中打开该批注；框选批注在译文页画同色框。对照时 `frame.pdfColumns` 为 2，适宽时两栏分用案头（减去书脊的位置），不按纸页宽；只看译文时译文页盖在原页上。

键盘与鼠标（阅读体验第 1.8 节）在 `input/`：`commands.ts` 是操作登记表（名称、快捷键、作用范围），“更多”“排版”、右键菜单、按键处理与快捷键一览都从它读；`scale.ts` 是阅读比例的换算（滚轮、捏合、PDF 的整十对齐），`use-reading-scale.ts` 把 Ctrl+滚轮与捏合挂在案头上，经引擎的 `holdPoint` 保持指针下的点；`context-menu.ts` 判定右键目标并组成三段，`ContextMenu.tsx` 在一个点上打开菜单；`use-reader-input.tsx` 处理按键、键盘滚动、Esc 的层次、鼠标侧键与右键菜单的对象操作；`reading-font.ts` 存本机的阅读字号。标签页的关闭、关闭记录与会话存储在 `shell/paper-tabs.ts`。

右侧面板（阅读体验第 1.4 节）默认收起；窗口不小于 1440 px 时停靠在案头右侧（`SplitPane`，宽 352 px，把手仍可调），更窄时浮在案头之上，不移动纸页。四个标签页：信息（`ReaderInformation`，原信息栏的各项，“档案”改名“材料”）、批注（`MarksPanel`）、关联（`ReaderRelations`，库内概况的被引用与引用两行）、翻译（`TranslationPanel`，划词与粘贴的文字；没有“翻译当前所在的节”，全文的译文在读法里看）。打开状态与当前标签页按资料记住。

书脊（阅读体验第 1.5 节）是 `ReaderSpine.tsx`，画在纸页右边缘外 8 px，高度等于纸页的可见部分，取代原来只在 PDF 上出现的批注刻度条。`spine.ts` 是纯函数：章节段按一级标题（摘要单列）和文档大纲给出的 UTF-8 字节数分段，PDF 按页数；视窗按屏幕上首尾可见块的字节换算；批注与查找命中的刻度相距不足 3 px 时合并。目录（第 1.6 节）是从书脊旁弹出的浮层，选中一项或按 Esc 即关闭。

排版与标记（阅读体验第 2 节）：原文的字号都是阅读字号的倍数，`document.ts` 的 `typeset` 只加标记不改文字（标题编号、“表 1”“图 2”、表格里的数值、拉丁段落、不可断开的数值与单位、`data-origin`）。查找用 CSS highlight 只标命中的词。批注在原文里是该颜色标签文字色的下划线（近似位置为虚线），笔记由 `marks/MarginNotes.tsx` 排在右页边（避让规则在 `marks/margin.ts`），窄档落到段落下方；PDF 上是同色下划线、墨蓝框选与编号圆点。
