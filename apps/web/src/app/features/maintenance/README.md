# 高级维护与规范交付

本模块复用正式维护合同，提供已有材料准备、提取 operation 与候选交付、回执、到期清理、索引重建和原始任务请求。主工作台通过持久任务执行分析与解析；独立维护入口使用已支持的维护接口。

`delivery.ts` 保留严格 JSON、响应上限、manifest/hash 与固定输入的回执校验；`transport.ts` 统一现有 CSRF/协议包络。查询入口只显示准备已有材料这一只读部分。设置页内的维护工具不带页头，按节排列；文献从文献库搜索选择（`LiteraturePicker.tsx`，粘贴的文献编号也能找到），文件用本站的按钮选择。

`SynthesisMaintenance.tsx` 保留独立维护入口的显式文档/知识来源 JSON、覆盖策略、固定输入与确认执行。准备为只读，提交仍使用现有综合维护合同；来源变化会撤销旧准备结果。
