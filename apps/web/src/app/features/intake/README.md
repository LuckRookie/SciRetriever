# 文献入库

入库页与批次页（页面规格“入库”“批次页”）。`Intake.tsx` 按文献从哪里来分为检索、文件、Zotero、网页四个标签页，下面是入库记录；地址带批次编号时显示这个批次。

- `Discovery.tsx`：主题发现与引用扩展，提交前确认范围与服务，不自动获取 PDF。
- `Dropzone.tsx`：放置区。识别 PDF、文件夹与导出文件（规则在 `data/intake-drop.ts`），一次放入形成一个批次：交导出内容与 PDF（带文件夹内的相对路径，由服务端配对），不写文献库；识别不了的文件不交。
- `Extension.tsx`：Zotero 与网页两个标签页，按设备连接的 `kind` 写扩展是否已连接，没有时给出连接的三步。
- `IntakeRecords.tsx`：全部批次，一种行，发起者按连接的类型写“扩展”“Agent”或“设备”。
- `Batch.tsx`：批次页。状态、计数、待决定的条目、报告都来自入库接口（`/api/v1/intake/batches`），刷新后照原样显示；逐条决定、确认、续传文件、结束与取消都由使用者发起。
- `ParseDialog.tsx`：“解析并形成初稿”的对话框，范围为这一批，篇数取批次的预估；“获取全文”沿用文献库的获取 PDF 对话框。两者只在点按钮后才提交任务。

- `Withdrawal.tsx`：撤回与整批恢复。撤回先读预估（将移除、将保留及原因），确认后才执行；已撤回的批次显示撤回报告与“恢复这一批”。只接受网页登录，页面上没有绕过预估的入口。
