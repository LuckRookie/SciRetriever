# 文献来源

[功能页面](../README.md)

- `SourceDirectory.tsx`：设置页的来源目录。
  - 元数据与 PDF 各自的选源方式，PDF 获取顺序五级，每个来源一行：用途四列、配置、测试。
  - 自定义模式下，用途标记变成开关。
  - 展开一行可修改这一个来源的配置：凭据只替换或清除，不回显；保存后自动测试一次。
  - 配置被其他操作改过时，重新读取并保留其余未改动的状态。
- `ApplyConfiguration.tsx`：页头的“应用配置”。有任务在跑时等任务结束，等待期间可以取消；重启后需要重新登录。
- `problem.tsx`：错误的共用呈现，供任务详情、来源统计与浏览器页复用。
  - 一律显示“错误”，只单独写出未配置、凭据无效、无全文权限三种可处理的情况；
  - 原因码只放进技术详情。

接口见 `packages/contracts/src/source-configuration.ts`。
