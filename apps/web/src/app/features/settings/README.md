# 配置与外观

通过既有配置 owner 的读取、按分区发布、凭据和显式探测接口操作。配置冲突保留草稿，分区保存不覆盖其他未保存的编辑；凭据只存在输入控件与当次请求中，提交立即清除。配置保存与运行时生效分别显示。外观偏好仅在浏览器内保存。

分区按要做的事排列（`sections.ts`）：外观、模型服务、获取 PDF、生成全文、设备连接、网络、文献库文件、运行状态、高级；旧的分区地址（`setting=sources`、`cred` 等）落到新的对应分区。模型服务每个服务一组，地址、密钥、模型与测试在一处；密钥经凭据接口按服务保存（`SecretField.tsx`），只显示“已保存”或“未填”。“获取 PDF”含 [来源目录](../sources/README.md)（来源的密钥在行内）与受控浏览器；“生成全文”含解析服务与参数。运行配置按块保存，每块只发布自己的字段；保存按钮在块的右下角，有改动时旁边写“有未保存的改动”。“退出登录”在页面最下方。“网络”分区设置代理地址、只写的代理认证与各服务是否走代理（ADR 0056），“代理”与“走代理”两节分别保存。“设备连接”分区（`Devices.tsx`）生成一次性连接码、列出、改名与撤销设备连接（ADR 0058）；连接码只留在对话框里，不进地址、存储或日志。“高级”只放“重新读取配置”与维护工具。
