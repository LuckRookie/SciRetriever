# 配置与外观

通过既有配置 owner 的读取、按分区发布、凭据和显式探测接口操作。配置冲突保留草稿，分区保存不覆盖其他未保存的编辑；凭据只存在输入控件与当次请求中，提交立即清除。配置保存与运行时生效分别显示。外观偏好仅在浏览器内保存。

“文献来源”分区由 [来源目录](../sources/README.md) 提供；页头的“应用配置”也在那里。“凭据”分区只管模型服务与 MinerU。“网络”分区设置代理地址、只写的代理认证与各服务是否走代理（ADR 0056），“代理”与“走代理”两节分别保存。“设备连接”分区（`Devices.tsx`）生成一次性连接码、列出、改名与撤销设备连接（ADR 0058）；连接码只留在对话框里，不进地址、存储或日志。
