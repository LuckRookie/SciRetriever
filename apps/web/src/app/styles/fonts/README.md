# 离线拉丁字体

Source Sans 3 与 Source Serif 4 的可变字重拉丁子集，正常/斜体各一份。来源为 npm `@fontsource-variable/source-sans-3@5.3.0` 和 `@fontsource-variable/source-serif-4@5.3.0`（2026-07-19 发布），原始字体由 Adobe 发布，SIL OFL 1.1 许可证全文分别保留于同目录。

字体仅作为静态资产交付，不新增运行时包依赖。`tokens.css` 使用 font-display swap，Vite 对字体生成带hash文件；中文仍使用系统字体。下载记录位于本机运行材料，不把字体包或缓存提交仓库。
