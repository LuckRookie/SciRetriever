# 07 · 统计与发表分析

类型：计划（结果块）
负责：`statistics` 产出类型与三样交付、派生形态、发表统计、记录表统计
状态：Pending

## Outcome

1. 人在 Web 上，或 Agent 经 CLI、MCP，选一个快照，即可得到发表统计，无模型费用。预置维度是发表年份、出版形式、发表载体、文章性质、语言、作者、机构，定义见规格 8.7；不假定文献都发表在期刊上；只有书目的文献同样计入；
2. 也可以对一份记录表做统计（按字段计数、取值分布）；
3. 每个统计格记录公式、分母与成员，可以展开到具体文献或记录；元数据缺失的成员计入“缺失”格；
4. 派生执行器是平台内置确定性函数的公共底座，12 的页面清单组装与 06 的覆盖合计复用它。

`statistics` 类型的三样交付（规格 8.12）：

| 交付           | 内容                                                                 |
| -------------- | -------------------------------------------------------------------- |
| 人读的页面     | 统计表，加上由使用者选择维度的图表；每格可以展开到成员列表           |
| Agent 按层读取 | 外框 → `dimensions`、`measures` 一次读取，`cells` 分页，成员按格分页 |
| 带出处的导出   | CSV（含公式与分母），附成员清单与成员的书目                          |

规格见[知识加工规格](../../architecture/technical/05-knowledge-processing.md) 8.2、8.3、8.7、8.12。

## 集成与影响

- 调用方：Web 快照页与结果页、MCP 与 CLI 的 `estimate`、`run`、`get_result`；12 的页面清单、06 的覆盖合计。
- 存储：结果沿用现有结果外壳；不改写历史结果。
- 用户可见变化：快照可直接生成发表统计；记录表可生成统计。

## 验证

命令按根 README 的验证路线；新增 `processor-statistics.test.ts`。

- 同一冻结输入重算，统计内容的规范化 hash 相同（不含结果 ID 与时间）；分母与成员一致；缺失元数据计入“缺失”格且不从分母去掉；
- 合成快照混合期刊文章、会议论文、学位论文、专利、报告与数据集：出版形式与载体分开计数，没有载体的成员计入载体“缺失”，不被当作期刊；
- 派生运行不产生模型调用；元数据之后变化不改变已发布统计；
- 作者、机构同名不同写法按原样分开；多值维度的各格之和可以大于分母，结果写明；
- 分层读取与导出：`cells` 分页无重复无遗漏；CSV 的公式与分母与结果一致。
