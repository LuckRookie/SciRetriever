# 14 · 概览与脉络

类型：计划（结果块）
负责：概览与脉络两个视图、就地展开、出处角标；原文页边的要点标签与关键句；视图之间的位置；第一次打开进入概览
状态：Pending

## Outcome

- “概览”一屏放下：性质与范围、要点、依据（含关键数据三线表）、局限与未决事项、精读建议，以及一两张关键图表与它们支撑的要点。
- “脉络”是悬挂式的提纲：作者的标题分组，要点编号在左页边，每条要点下面是五类依据。
- 机器写的每一句后面有“¶段·句”出处角标；点开可就地看到原句；要点可以就地展开到全部原句，图可以就地展开到整幅图；原句可以在原文中定位并返回。
- 原文的左页边写这段支撑哪些要点，关键句旁有竖线。
- 在原文与脉络之间切换落在对应的位置；书脊在脉络里有视窗，在概览里没有。
- 没有做过加工、加工进行中、结果过时的资料按规格显示；第一次打开已经有概览的资料时进入概览。

规格：[3.1 共同规则](../../architecture/web/reading-experience.md#31-共同规则)、[3.2 概览](../../architecture/web/reading-experience.md#32-概览)、[3.3 脉络](../../architecture/web/reading-experience.md#33-脉络)、[3.4 原文](../../architecture/web/reading-experience.md#34-原文)（要点标签）、[3.9 没有加工或材料不全](../../architecture/web/reading-experience.md#39-没有加工或材料不全)、[4.3 视图之间共用一个位置](../../architecture/web/reading-experience.md#43-视图之间共用一个位置)（脉络与概览三条）、[6.4 打开哪个视图](../../architecture/web/reading-experience.md#64-打开哪个视图)（第二条）、[1.5 书脊](../../architecture/web/reading-experience.md#15-书脊)（脉络的视窗、概览无视窗）。

## Tasks

- [ ] **14.1 概览视图**：数据取 `material-layers` 的 `overview`（`refs[]` 已展开为编号、短文本与类别，关键图表带它支撑的要点）；规格第 3.2 节的两栏版面、五个栏目、条数上限与“另 n 项，见脉络”、关键图表栏；没有图表时一栏；在 1440×900、20 px 时一屏放下。
- [ ] **14.2 脉络视图**：数据取 `material-points`，按 `next_cursor` 续读、按编号排列，`heading` 给出作者的标题分组；规格第 3.3 节的分组、要点、五类依据；与原文不符的数字带所引片段的原文（响应里给出，截断时标明）；引用依据按“库内”“不在库内”“初稿上无法解析”三种显示；与原文不符的数字按第 2.5 节（11 的 11.7）。
- [ ] **14.3 出处角标与就地展开**：规格第 3.1 节；角标取响应里的 `mark`，`sentences` 为 `null` 时只写段号；展开的层级（概览要点 → 脉络依据 → 原句 → 在原文中定位）；展开与收起的过渡（规格第 6.1 节）；“在原文中定位”记入跳转记录。
- [ ] **14.4 原文页边与关键句**：数据取 `material-marks`（按文档顺序分页：段号、对应的要点编号、关键句的位置与句号）；左页边“要点 n”标签与段落编号（11 的 11.10 的位置）；关键句竖线（11 的 11.5）；脉络建在别的版本上（`on_read_version` 为 `false`，`material-marks` 返回 `marks-version-mismatch`）时，不画要点标签与关键句竖线，页眉下方一行说明（规格第 3.1、3.4 节）；右页边的“批注 n”“证据 n”记号在概览与脉络中显示（规格第 2.5 节“记号”）。
- [ ] **14.5 视图之间的位置**：规格第 4.3 节第三至五条（原文 → 脉络、脉络 → 原文、概览不改变记住的位置）；脉络的锚点为要点标识（04 的 4.1）。
- [ ] **14.6 书脊**：脉络的视窗按可见要点所引原句的范围计算；概览不显示视窗，点一段打开原文的该节（10 的 10.3）。
- [ ] **14.7 打开与状态**：两格随 `reading_layers.available` 出现与消失（不显示停用的控件）；第一次打开、`material-layers` 有概览的资料进入概览（规格第 6.4 节第二条）；第 3.9 节“未做过加工”（`spine` 为 `null`）与“加工进行中”（`pending` 不空；进度用 `material-progress`，只在有 `pending` 时轮询）两行；第 3.1 节“过时”（`freshness` 为 `outdated`）与“建在别的版本上”（页眉与一行说明写明所依据的版本与文本等级，能发起时给“重新加工…”；出处角标展开时显示原版本的原句并标明版本，按批注的重新定位规则找到位置才给“在原文中定位最近处”，否则写“在这一版本中无法定位”）；只能读、不能发起时（`can_start` 为假）所有“发起加工…”不出现，第 3.9 节写“这个部署只读取已有的结果，不能发起加工。”；“发起加工…”打开现有的四步运行对话框，组合为 `reading-layers`，先估算后确认（显示真实估算等计划 16 的 2.9）。
