# 05 · 声明式算子

类型：计划（结果块）
负责：人与 Agent 自制算子的定义、确认、发布与通用执行
状态：Pending

## Outcome

1. 人在 Web 上，或 Agent 经 CLI、MCP，可以用一份声明（提示词、规范格式、产出类型、读取范围、所需材料）做出新的单篇算子，不写代码；
2. 新算子由通用执行器经公共会话运行，自动具备批量运行、组合、对照表、核对与导出；
3. 新算子先是草稿，只有创建者能运行；经所有者确认后发布（三端在所有者授权下都可执行），发布版本不可修改；
4. 声明不能扩大读取范围、使用白名单外的工具或绕过平台校验。

声明式算子只产出 `report`、`answer`、`records`，经类型注册表自动获得这三种类型已有的三样交付（规格 8.12）：人读的页面（02、03 的视图）、Agent 的分层读取（02 的 2.10）、带出处的导出（02 的 2.11）。本块不新增视图。

规格见[知识加工规格](../../architecture/technical/05-knowledge-processing.md) 8.4、8.12、8.14。

## 进入条件

- 01、02、03 退出：三种单篇产出类型都已由内置算子验证插件合同；
- 04 的 4.2 合入（5.2 按 `requires` 准入依赖它）；
- E1a、E1b 通过；
- 5.3 的发布是所有者操作，只在规格 8.6“所有者操作”列出的入口上执行。

## 责任边界

worker：定义存储、通用执行器、注册表合并内置与声明式算子、机器接口。总设计师：Web 定义编辑、预览与确认页面。

## Tasks

- [ ] **5.1 定义存储**〔worker〕
  - 定义是库数据，按内容 hash 与版本保存；状态为草稿或已发布；发布后不可修改，修改即新版本。需要新表时停下交 Owner（G-schema）。
  - 保存时校验 `spec_schema` 属于规格 8.14 的表单封闭子集，超出的拒绝，不降级为手写 JSON。
  - 声明式算子不能按章读取，也不能使用阅读层的补丁（规格 8.16）；声明这两项的定义在保存时拒绝。
- [ ] **5.2 通用执行器**〔worker〕
  - 按声明经公共会话运行；工具白名单固定；读取范围、`requires` 与文本等级由平台执行（04）；产出按 `output_kind`（`report`、`answer`、`records`）由平台校验，并经类型注册表自动获得视图。定义 hash 计入复用键。付费运行走 02 的运行流程。
- [ ] **5.3 生命周期与权限**〔worker〕
  - 三端都可以创建与修改草稿、在指定文献上试运行草稿（经运行流程确认）；发布是所有者操作，三端在所有者授权下都可执行（ADR 0033），Agent 的任务授权不包含发布；发布表示可见，不授权全库执行。
- [ ] **5.4 Web**〔前端〕
  - 页面规格草案后实现：定义编辑（按声明字段的表单与预览）、在样例文献上试运行、所有者确认发布；运行表单按 `spec_schema` 自动生成（只覆盖封闭子集），结果视图按产出类型复用。
- [ ] **5.5 验证与审阅点 C 审阅包**
  - 运行下节测试；审阅包含定义编辑、试运行与发布确认的截图及越权负例说明。

## 集成与影响

- 调用方：Web 算子管理页、运行页（新算子出现在可运行列表）、MCP 与 CLI 的定义与运行操作。
- 存储：定义作为库数据保存，需要新表时走 G-schema；历史结果按定义 hash 解析。
- 用户可见变化：已发布的声明式算子与内置算子并列，结果按产出类型使用同一视图。

## 验证

命令按根 README 的验证路线；新增 `processor-declarative.test.ts`。

- 草稿不能绕过确认被他人运行或批量运行；无所有者授权的发布在三端都被拒；发布版本不可修改；
- 提示词要求读取声明范围外内容时，工具调用被拒并计入覆盖；白名单外工具不可用；
- 非法 `output_kind`、`requires` 或 schema 在保存时拒绝；
- 同一定义同输入复用，定义改动后重新计算；
- 声明式算子可作为 02、03 组合的逐篇一段，产出进入问题综合与对照表，页面、分层读取与导出与内置算子一致；
- 同一草稿分别由 Web 与 CLI 创建并试运行，经过同一组检查点。

## 退出条件

声明式算子可创建、确认、发布与运行，越权负例全部被拒；审阅点 C（本块部分）获确认。

## 恢复与交接

5.1–5.3 可先以机器接口交付草稿与试运行；所有者的发布确认在三端都未就绪前，只在 Web 上开放发布。
