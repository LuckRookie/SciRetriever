# 10 · 关系与知识图谱

类型：计划（结果块）
负责：`relations` 产出类型、候选对生成、成对运行、边的确认、关系图视图、维基中的实体链接
状态：Pending

## Outcome

1. 人在 Web 上，或 Agent 经 CLI、MCP，选定关系类型，平台按冻结规则生成候选对，显示候选数与估算，确认后逐对判定；
2. 每条边有关系类型、方向、条件、极性与证据；相同端点不同条件或相反极性的边分别保存；
3. 成对运行只产出候选边；边的确认与实体确认分开，确认、撤销产生新版本；
4. 维基页面（12、08）链接到已确认实体与边；结果写明候选规则与漏召回风险。

`relations` 类型的三样交付（规格 8.12）：

| 交付           | 内容                                                                             |
| -------------- | -------------------------------------------------------------------------------- |
| 人读的页面     | 边列表，可按端点、关系类型、极性、候选或已确认筛选；可选的关系图；证据展开到原文 |
| Agent 按层读取 | 外框 → 按端点、关系类型或状态分页读取边 → 证据 → 原文                            |
| 带出处的导出   | CSV、JSON，附书目                                                                |

规格见[知识加工规格](../../architecture/technical/05-knowledge-processing.md) 8.2、8.3、8.7、8.8、8.12。

## 验证

命令按根 README 的验证路线；新增 `processor-relations.test.ts`。

- 候选集可重放；候选数与估算一致；没有候选的对不被调用；
- 相同端点不同条件、相反极性的边分别保存，不合并；
- 候选边不显示为已确认；实体确认不改变边状态；边撤销产生新版本，旧引用按旧版本解析；
- 归一决定或候选规则变化后，依赖的边标记过时，不自动重算；
- 结果覆盖如实写明候选集范围；
- 维基页面只链接已确认的实体与边，未确认实体显示为歧义。

未覆盖：真实语料上的关系判定质量与漏召回（11 的成套效果评估）。
