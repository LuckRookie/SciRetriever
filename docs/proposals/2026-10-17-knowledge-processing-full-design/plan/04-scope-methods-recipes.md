# 04 · 范围、默认方法与配方

状态：Pending。

## Outcome 与进入条件

02、03 已完成。用户或 Agent 提交范围定义与任务规范后，系统形成文献集合，并用默认方法完成首版五类任务。每个产物都带结果卡、证据和覆盖；支持小样预览和全量成本估算。

## 责任与 Tasks

- [ ] 4.1 范围执行：实现 `where`（元数据，即时）、`search`（混合检索，按阈值截断）、`follow`（库内引用关系）、`judge`（逐项筛选形状，`read: abstract_then_fulltext` 先读摘要，“不确定”再读全文）、`keep`。产出 Collection：规则、快照、漏斗统计、每篇纳入理由与证据，“无法判断（缺全文等）”单独列出。
- [ ] 4.2 逐篇提问与打标签（逐项变换）：问题 + 答案类型 → 文献表上的一列；每个值带证据；状态区分完成与失败。
- [ ] 4.3 记录提取（逐项展开）：先用字段说明在文献内部定位相关 Unit（优先表格、图注、SI），再联合抽取整组字段；程序校验数值确实出现在所引 Unit 中、单位可解析、取值在合理范围；记录保留原文写法、规范值、推算标记。状态区分“有记录 / 零记录（读完确实没有）/ 失败”，并写明已处理的材料范围。粒度默认 `as_reported`，不合并重复测量。
- [ ] 4.4 程序方法：数值解析（±、<、~、区间）与单位换算；分组统计（按组处理），输出中位数、范围、计数与成员引用。
- [ ] 4.5 整集综合（整集合成）：输入为集合或上游产物，输出论断文档。每个论断标明“原文报告/汇总”或“推断”，引用记录、汇总或 Unit；文档末尾列出知识缺口与覆盖。
- [ ] 4.6 配方：有序步骤，步骤引用前序输出或既有资产版本；四类模板（提问、提取、统计、综合），模板只是预填的配方。配方提交前做程序检查：类型匹配、字段存在、形状与方法兼容、所需材料可用、写入范围合法。
- [ ] 4.7 规范起草（可选）：模型根据用户描述起草任务规范草稿，用户确认后才生效；不起草配方，不生成代码。
- [ ] 4.8 小样与估算：在指定的 N 篇上试跑并生成独立的小样产物；全量估算 = 预计未命中的工作项数 × 方法单位成本，并说明估算依据。

## 验证与退出条件

- fake 模型 + 合成文档覆盖：漏斗统计、无法判断清单、两级读取、联合提取与证据校验（伪造证据会被拒）、零记录与失败的区分、单位换算、分组统计、论断引用与缺口、配方检查拒绝非法组合、小样不触发全量。
- 同一批合成文献同时完成“提问 + 综合”和“提取 + 统计”，二者共用读取、证据和执行。
- 定向测试与 Quick 通过。
