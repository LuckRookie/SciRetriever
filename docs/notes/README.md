# 注意事项

本目录保存外部供应商和工具随时间变化、但又需要集中维护的事实。它们帮助配置和排障，不重新定义产品架构或当前命令。

- [Provider 接入注意事项](providers.md)：各 metadata/acquisition Provider 的凭据、限流、能力、已知限制和检查重点。
- [MinerU 接入注意事项](mineru.md)：外部 MinerU 服务的固定版本、连接、安全、恢复和升级注意事项。
- [工具中立性声明](tool-neutrality.md)：项目对来源和工具的中立立场及工程安全边界。

任何秘密值、私有 endpoint、Cookie、用户身份或受限正文都不得写入本目录。
