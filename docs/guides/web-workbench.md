# Web 任务工作台

正式 Web 使用蓝白工具界面，主导航为工作台、任务、文献库、设置。它与 CLI/MCP 使用同一套文献、资产和持久任务服务。页面不保存另一份业务数据库；刷新或关闭浏览器不会清空任务记录。

## 启动与数据库绑定

在源码工作区完成构建后运行：

```bash
pnpm build
node apps/server/dist/cli/main.js web --port 4174
```

已安装的 console script 对应 `sciretriever web --port 4174`。默认端口为 4174；`--port 0` 让系统分配端口，终端输出实际 `url`。仅监听 `127.0.0.1`，通过同源 Cookie、客户端令牌与 CSRF 校验处理操作。Ctrl+C/SIGTERM 关闭服务并清理本进程资源。

普通启动固定读取用户 home 下的 `.sciretriever/config.toml`，不接受 `--home`、`--config`，不随工作目录切换。先按[配置手册](configuration.md)设置 `paths.catalog_path` 与 `paths.artifact_root`，再按[初始化与升级指南](upgrade.md)显式准备支持的 catalog。Web 不自动创建、升级或迁移真实数据库；未准备好时启动拒绝。程序 API 的 `home` 参数是显式组装/隔离入口。

首页和设置显示**当前进程实际使用的** catalog 与资产目录。设置中可以保存新的路径，但当前进程继续绑定原库，重启后才按新配置打开；保存路径不搬动资产、不复制数据库。配置显示的已保存 revision 和运行快照分别呈现。

无需预选文献，启动也不会打开 Browser 或访问外部来源。程序入口为 `startProductionWorkbench({ home, port? })`；已有 `literature_id` 参数仍可用于预选目标。调用方最终须 `await workbench.close()`。

## 工作台与任务

首页展示最近任务中的活动任务、需要处理的失败/暂停/人工协助和最近结束任务。新建任务明确区分：

- **获取 PDF**：选择已存在文献、库内查询范围或全部待处理文献，确认人工协助策略和尝试预算。只获取 PDF，不自动解析和分析。
- **固定材料加工**：解析、文章身份核验、单篇分析、长文分段分析和集合综合使用已有严格输入合同。可从文献详情进入加工表单，或提交高级 `ProcessingTaskRequest` JSON。

创建任务返回持久 ID，点击运行才开始；加工工具表单的“提交”明确创建并启动对应操作。任务详情按执行、结果、活动记录组织，分别呈现成功结果、跳过和失败。部分失败的任务仍可读取已提交结果，重试只处理符合原有恢复规则的项目。

暂停、继续、取消和重试调用同一 `ProcessingTaskService`。取消不是回滚，已入库 PDF、文档或知识不会被撤销。关闭页面后，本地服务继续执行；停止服务后不会有独立后台守护进程继续工作。重启后读取持久记录，并显式恢复未完成任务。

Browser 是任务目标的二级视图。打开目标会话可观看真实页面、提交指导、人工接管、输入和交还；控制绑定文章、会话和控制版本，旧动作不能跨文章执行。自动获取使用同一生产 Browser flow。页面会如实显示无画面、排队、下载、失败和结束；不能把文件接纳推断成文章身份已经核验。

## 文献、材料与知识

文献库支持搜索、排序、引用分页、书目导出以及 PDF/Markdown 下载。打开详情和证据是只读操作，不触发扩库。

“阅读原始 PDF”按固定资产 ID/hash 获取字节并验证 SHA-256 后预览；“阅读材料与文档”打开固定解析版本、目录、片段和资源。任务结果中的文档/知识/综合链接保留产物 ID，避免后来默认版本改变时打开错误结果。没有可读材料时展示缺口。

选中文献会预填 PDF 接纳、解析、知识阅读和上下文范围。解析前读取实际 PDF 与默认 revision；单篇分析前固定材料清单和解析版本。首次解析需选择调用解析服务，复用模式只使用已保存的解析结果。材料不足时不会自动下载。知识阅读展示用途、覆盖、缺口和证据；证据回到其原始固定版本。

“知识与材料检索”提供材料/知识上下文、提取输入准备、已保存知识和集合综合阅读。“材料加工与交付”提供解析、分析、综合、索引重建和提取操作/候选提交/回执/关闭等高级操作。提取仍是调用方定义的候选交付协议，Web 不代替领域提取算法。索引重建和生成均由明确点击启动。

“添加文献与材料”提供三类独立操作：外部主题发现、BibTeX/BibLaTeX/RIS/CSL JSON 书目导入、为已存在文献接纳所选 PDF。发现使用配置的来源和明确扫描上限，返回各来源结果；导入显示逐项回执。二者都不会自动获取 PDF。当前发现和导入通过请求返回报告，未包装为持久加工任务。

## 设置与安全

设置保留来源 Auto/Custom、Provider/Model 注册、Browser/Parser/Analyze 角色、凭据与显式探测。保存经过 Configuration owner 校验与 revision CAS；冲突时保留草稿，不覆盖他人的保存。普通配置需要重启已组装运行对象时有明确反馈。凭据不回显；首页/readiness 不发真实服务探测请求。

Web 只接收用户选择的文件字节，不允许用 HTTP 参数读取任意服务器文件路径。真实 Provider、模型、MinerU 和 Publisher 能否成功仍取决于配置、安装、网络和权限；离线测试不构成对这些真实服务质量的证明。

独立只读入口 `startQueryOnlyWorkbench` 与独立维护入口 `startMaintenanceWorkbench` 继续保留。正式加工表单返回持久任务链接，独立维护页保留同步请求行为。只读部署不因统一工作台加入维护功能而取得写入能力，详见[独立阅读指南](library-query.md)。`pnpm preview:browser` 和 `pnpm preview:workbench` 继续是合成预览，不能用来存放真实资料。
