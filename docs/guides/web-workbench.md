# Web 文献库工作空间

正式 Web 使用React实现[定稿原型](../architecture/web/README.md)的库中心布局，并采用已确认的公共组件、四主题与动效，以文献库为首页。侧栏分为资料（文献库、发现）、使用（洞察、检索、综合、提取）、运行（任务、浏览器），设置固定在底部。它与 CLI/MCP 使用同一套文献、资产和持久任务服务，页面不保存另一份业务数据库。

默认地址为 `/`，维护服务的独立查询页为 `/query`。请直接打开正式地址；迁移期 `/next` 地址与旧 `workspace` URL 别名已撤销。主题、栏宽、阅读设置与保存筛选只使用当前 React 界面的本机偏好；旧前端设置不会自动导入。文献、PDF、解析材料和历史结果的读取合同不受这项界面清理影响。当前版本的最终测试和安装验收记录见[实施计划](../archive/2026-10-19-web-experience/README.md)。

## 启动与数据库绑定

在源码工作区完成构建后运行：

```bash
pnpm build
node apps/server/dist/cli/main.js web --port 4174
```

已安装版本使用 `sciretriever web --port 4174`，源码工作区也可运行 `pnpm sciretriever web --port 4174`。默认监听 `0.0.0.0:4174`，其他电脑可以直接连接。`--port 0` 让系统分配端口，启动输出包含实际监听地址、可用访问 URL；`0.0.0.0` 是监听地址，不是浏览器访问地址。Ctrl+C/SIGTERM 关闭服务并清理本进程资源。

### 在服务器运行，从自己的电脑访问

启动命令与本机使用完全相同，无需设置 `--host` 或 `--origin`：

```bash
pnpm sciretriever web --port 4174
```

未指定密码时，服务自动生成访问密钥，在启动终端输出的 `api_key` 中显示。在自己的电脑打开 `http://服务器IP:4174/`，将这个密钥粘贴到登录框即可；本机访问也须登录。服务端防火墙须允许该端口；经 NAT 访问时使用实际映射地址和端口，无需向 SciRetriever 登记 origin。启动输出列出本机网卡地址，无法推断网关的公网映射。

需要固定密码时，在启动环境中设置 `SCIRETRIEVER_WEB_PASSWORD`。例如在 zsh 中隐藏输入、启动并在退出后清除：

```zsh
read -rs 'SCIRETRIEVER_WEB_PASSWORD?访问密码: '
export SCIRETRIEVER_WEB_PASSWORD
pnpm sciretriever web --port 4174
unset SCIRETRIEVER_WEB_PASSWORD
```

指定密码至少 12 个字符（长度校验不计首尾空白）、最多 1024 UTF-8 字节，不回显；未指定则生成 256 位随机 API key，不暂停等待输入。API key 和密码使用同一登录流程。自动密钥在每次重启时变化；固定密码须在重启时继续提供。指定了无效密码则在打开数据库前拒绝，不静默改用自动密钥。

密码和密钥不写入普通配置或数据库；自动密钥仅在成功启动的终端输出中展示，程序不会额外创建密钥文件。Web CLI 消费后从服务进程环境中移除密码，避免传给 Agent 子进程。不要将访问凭据放进命令行参数或 URL。可选 `--host IPv4` 仅限制监听网卡，即使指定 `127.0.0.1` 也必须登录；不再支持 `--origin`。

登录有效期为 12 小时，重启后失效。设置 → 文献库位置 → 当前登录可退出；退出释放该浏览器登录下的观看/控制连接，已经提交的后台任务继续运行。有效会话最多 64 个；每个连接 IP 每分钟最多 10 次登录尝试，全进程每分钟 60 次、同时最多 2 次校验，超额返回可重试提示。普通操作继续校验 tab grant、CSRF 和同源 Origin；未登录不能读取文献、文件、任务或配置。Host 只接受 IPv4 字面地址或 localhost，不信任 `Forwarded`/`X-Forwarded-*`。CLI/MCP 连接同一服务也须登录，见 [Agent 指南](agent-interface.md#连接正在运行的-web-服务)。

当前支持 IPv4 和普通 HTTP，HTTP 中密码和资料不加密；HTTPS、域名与反向代理部署暂未实现。HTTP 下的任务标识使用浏览器安全随机数，复制上下文支持普通 HTTP 的选择复制；浏览器仍拒绝复制时可导出 JSON。

启动无需配置向导或先运行初始化命令，打开浏览器登录后进入工作台。普通启动固定使用用户 home 下的 `.sciretriever/config.toml`，不接受 `--home`、`--config`，不随工作目录切换。未配置的存储路径由 Configuration owner 补齐并保存为：

```text
~/.sciretriever/config.toml       # 共享普通配置
~/.sciretriever/catalog.sqlite   # 默认文献数据库
~/.sciretriever/artifacts/       # 默认文献资产目录
```

已有 `paths.catalog_path`、`paths.artifact_root` 优先使用；只补齐缺失项，保留其它设置。Web、CLI、MCP 后续读取同一份配置和文献库。目标数据库不存在时，Web 通过 Storage 的 create-if-absent 初始化建立当前完整空库；自定义数据库文件的父目录须已存在。已有库保持其版本与数据，损坏、不安全或不兼容目标会拒绝启动，不会覆盖或自动升级；升级按[初始化与升级指南](upgrade.md)显式处理。程序 API 的 `home` 参数仍是组装/隔离入口，不扫描或搬迁旧目录。

设置的“文献库位置”显示**当前进程实际使用的** catalog 与资产目录。设置中可以保存新的路径，但当前进程继续绑定原库，重启后才按新配置打开；新目标不存在时创建空库，已有资料不会自动搬迁。使用已有库时须同时选取其对应资产目录。配置显示的已保存 revision 和运行快照分别呈现，详见[配置手册](configuration.md)。

无需预选文献，启动也不会打开 Browser 或访问外部来源。程序入口为 `startProductionWorkbench({ home, port?, access? })`；`access` 接受 `{ host?, password? }`，默认监听所有 IPv4 网卡、始终认证；未提供密码时返回自动生成的 `apiKey`，供启动调用方显示。返回值还包括 `listenAddress`、`urls` 和可供进程内连接的 `origin`；不得将完整返回值写入业务日志。已有 `literature_id` 参数仍可用于预选目标。调用方最终须 `await workbench.close()`。

## 文献库与阅读

首页使用参考文献式列表。搜索、排序与状态筛选在列表上方；“筛选”展开作者、年份、期刊、关键词和 DOI。点击文献打开顶部阅读标签，预览按钮才展开右侧摘要；多选后显示获取 PDF、解析、分析和“用这些文献做…”操作。批量操作固定所选 ID；当前筛选范围按页读取，超过 1000 篇时要求缩小范围。

同一工作区内从阅读返回库或浏览器后退，会保留选择、已加载页数和滚动位置；材料发布或重连后更新相应查询，Browser心跳不会重复刷新全库。改变查询或排序时重置列表。标题中的书目格式实体仅在纯文本展示时解码，不修改来源记录。阅读标签可以用键盘切换和关闭，弹窗会管理焦点并在关闭后返回触发位置；等待写操作回执时仍禁止关闭。

阅读标签使用 PDF / 全文 / 总结切换，右侧保留元数据、材料状态、上传与加工入口。PDF 按固定资产 ID/hash 校验完整字节后用本地 PDF.js 呈现，支持页码、缩放/适宽、内嵌目录、可选择文字与文字层查找，只渲染可见及邻近页；扫描文件没有文字层时明确提示。全文按固定版本分段续读，排版标题、表格和公式，图片只取已保存且通过完整性核验的文档资源，失败时保留正文。总结展示已发布知识及证据，右侧可展开与当前文献有关的已有处理结果。身份状态、引用来源与其他版本按实际事实展示。引用和被引支持分页与来源证据。任务结果链接保留文档或知识产物 ID，不依赖后来变化的默认版本。打开、筛选、阅读与展开证据均不启动加工。

每篇文献的阅读位置、缩放、临时字号/行宽和侧栏开合按库与固定版本隔离，仅在当前工作区会话内保留；关闭文献标签释放该篇状态，刷新后不恢复位置。设置中的默认字号/行宽与两侧栏宽属于本机偏好，可跨刷新延续。正文查找明确限定“已加载范围”，可继续加载后重查。来源证据定位为解析全文中的原文块；没有可靠PDF页码或坐标时不伪造PDF高亮。图片或文档读取失败可重试，密码PDF仍由既有入库边界拒绝，不自动解密。

从文献行或阅读页拖入/选择 PDF 后，确认目标文献再上传；单文件不超过 16 MiB，不能覆盖已接纳主 PDF。解析入口明确调用解析服务；单篇分析和身份核验只使用已有固定材料，缺少前序输入时逐项说明。“用这些文献做…”可进入综合、检索、提取、洞察或导出 BibTeX/RIS。

查询条件与排序保留在 URL 中，支持刷新、前进与后退。保存视图是按当前 catalog 路径隔离、有版本的浏览器偏好，最多保留50项；可应用或删除，刷新后延续。主题为浅色、深色、墨绿、暖白或跟随系统。设置 → 外观可保存主题、默认阅读字号/行宽和减少动效；系统的减少动效偏好同样生效。偏好不成为文献事实，也不保证跨浏览器同步。Source Sans 3 / Source Serif 4拉丁字体随包提供，中文使用本机回退字体，不请求CDN或外部字体服务。

默认采用较舒展的字号和控件尺寸：浏览器默认根字号 16px 时，导航与界面正文为 18px、文献标题和全文正文为 20px、书目信息为 17px、辅助标签为 16px，常规按钮高 40px。外框尺寸使用 `rem` 跟随浏览器根字号；新阅读器单独提供 18/20/22/24 px 正文字号选项，PDF 内部文字由阅读器缩放控制。

## 发现、检索与综合

“发现”提供主题发现、引用扩展、BibTeX/BibLaTeX/RIS/CSL JSON 导入和人工 PDF 接纳。引用扩展固定种子、方向和扫描上限，调用已有 CitationDiscovery；主题发现使用配置的来源。发现和导入显示真实逐项报告，不自动获取 PDF，也不伪装为持久加工任务。本次会话保留最新30份报告，跨页面返回仍可查看，刷新后清空；它们不等于永久批次历史。有真实发现批次 ID 时可以筛选返回文献库。

“检索”提供原文与知识查询、范围、数量和字节预算、继续查找，以及上下文篮子的 Markdown 复制和 JSON 导出。固定来源按实际文档或产物及其 hash 核对；知识可展开证据。“综合”读取已有产物，或从所选文献/当前范围准备固定输入，确认问题与覆盖策略后提交综合任务。

综合问题、覆盖策略与输入范围在当前会话内保留；离开再返回须重新固定输入，范围变化不会删除问题。检索与普通库读取使用各自的只读执行队列，首次索引完整性检查仍可能耗时，但不会阻塞文献库列表；取消页面请求不承诺中断已经进入 SQLite 的同步校验。

三种内容模式分别检索原文与知识、仅原文、仅知识；含知识的模式覆盖已保存的概览、详细分析、问题分析和综合。当前为词法匹配，多关键词需同时命中，不自动翻译或扩展同义词。输入汉字时显示原文关键词提示，但仍正常提交原查询；独立中文词串可以命中，连续长串中的子词和跨语言含义不保证命中。只有索引可用时，零结果才表示没有匹配当前关键词；不表示库中没有相关知识。索引未建立、过期或不可用时会明确提示，用户可从设置 → 高级显式重建对应材料／知识索引，普通查询不会自动维护。

点击检索命中会携带固定文档版本、hash 与 UTF-8 片段范围，或固定知识／综合产物及断言 hash；阅读前重新核对。后来发布新默认文档，不会替换旧命中的来源；元数据命中若已变化则提示重新检索。页面内返回检索和浏览器后退保留当前问题、范围、结果与上下文篮子，离开页面会取消尚在等待的检索。固定来源链接支持刷新；检索结果和篮子只在本次页面会话中保留，刷新整个页面不会恢复它们，也不会自动重新发起查询。

“洞察”按当前范围读取年份、期刊、关键词与材料统计；统计最多覆盖 1000 篇，引用图最多展开 40 篇各 100 条关系，页面明确显示这些边界。没有将原型里的示例统计、分析标签或模拟数据移入生产。

“提取 → 新建处理”提供记录提取和文献标签表单，可从单篇、选中文献或全部当前筛选结果发起。记录配置含义、纳入条件及字段名/描述/类型/单位；标签配置问题和是非、文字或指定选项。默认读取全部可读正文，也可显式选择关键词片段，此时结果为部分覆盖。范围预览只读已有材料；缺正文保留缺口，不会自动获取或解析。

范围预读失败时可“重新读取范围”，此时尚未提交任务。结果表逐行显示固定记录的已验证证据来源，整份产物的关联范围单独显示；没有证据的记录不会把整份输入冒充来源。选择无证据记录后仍可选择其关联输入文献，选择条会说明区别。数值子字段的“空值／有值”同时覆盖父对象为空和路径缺失；零、否和空字符串属于有值。宽屏证据栏可独立滚动，长表中展开证据无需返回表头。

提交先保存持久任务，再请求启动；草稿在当前工作区会话中保留，重试同一请求复用幂等标识。保存成功但启动回执未确认时，可从“查看任务”核对并继续。任务按实际集合显示新生成、复用、partial 和失败，提供固定结果/集合摘要；记录预览保留原数值、单位和缺失理由，产物生成信息可展开，复用历史用量不计为本次调用。从“已有结果”进入集合或完整结果，按字段筛选、排序和分页；标签区分“否”和“无法判断”。跨页选择保留记录 ID，来源文献数按实际 ID 去重。字段旁可展开证据、逐层查看上游记录/知识、打开固定全文，再返回原表的筛选与选择。选中记录可显式发起综合，确认面板固定提交范围。

“规范与外部交付”保留原有规范、材料准备、候选提交/回执/关闭/清理；高级工具保留解析/分析/综合、索引重建和原始 ProcessingTaskRequest 提交。领域规范和最终接纳仍由调用方拥有。

“导出这份完整结果”下载整份已保存产物，不受当前页、筛选和选择影响。JSON 保留固定引用与完整结果；CSV/Markdown 使用 ZIP 同时交付正文和 `metadata.json` 中的输入、coverage、provenance。超过单次响应预算时自动有界续读并校验最终 hash。索引过期只影响表格/检索，完整结果仍能下载；重建索引由 CLI/MCP 显式执行。

## 任务与 Browser

获取、解析、分析、身份核验和综合均通过显式确认提交任务。获取默认自动处理，已有材料保留；获取策略可选通知或暂停，尝试与重试上限可调整，也可只保存暂不执行。高级原始加工请求默认只保存，可选择立即执行。任务页支持筛选、分页、刷新、暂停、继续、取消和重试，展示逐项结果、失败与活动记录；顶部活动抽屉用于快速进入任务。

取消不是回滚，已入库 PDF、文档或知识不会被撤销；重试遵循原有恢复规则。关闭 Web 页面后，本地服务仍可执行任务；停止服务后没有独立守护进程继续工作。重启后可读取持久记录并显式恢复。

普通解析从所选 PDF 读取默认 revision 后提交，任务会区分“解析版本已保存”和“默认全文已切换”；版本冲突时仍可打开此次固定结果，旧默认不会被强制覆盖。分析模型缺失或不可用时，任务提供模型设置入口和保存、重启、显式重试的恢复指引，同时保留机器错误码。

“浏览器”显示当前服务持有的文章会话。打开画面仅观看，直接点击时先取得控制权，再校验文章、会话、页面观察版本和视口；接手期间画面改变时提示重试，不重放旧点击。人工控制时可输入文字、按键、滚动，并交还 Agent。页面文字、指导及额外控制收在可选详情中。生产 PDF 接纳仍由获取流程完成，不增加人工审核门。

主动关闭画面或导航离开时，先确认交还成功再关闭；失败则保留界面并提示重试。意外断线不会由页面自动交还；服务端按既有三分钟 grant 过期策略撤销租约，生产会话随后暂停。这里只显示同一服务的活会话，共享数据库不意味着另一个 CLI/MCP 进程的 Browser 自动可见。Agent 可用 `--workbench-url` 显式连接当前服务，观察/控制同一 Browser，或把任务交给当前服务执行；详情见 [Agent 指南](agent-interface.md#连接正在运行的-web-服务)。

## 设置与安全

设置保留来源 Auto/Custom、Provider/Model 注册、Browser/Parser/Analyze 角色、凭据与显式探测。保存经过 Configuration owner 校验与 revision CAS；冲突时保留草稿，不覆盖他人的保存。普通配置需要重启已组装运行对象时有明确反馈。凭据不回显；首页/readiness 不发真实服务探测请求。

Web 只接收用户选择的文件字节，不允许用 HTTP 参数读取任意服务器文件路径。真实 Provider、模型、MinerU 和 Publisher 能否成功仍取决于配置、安装、网络和权限；离线测试不构成对这些真实服务质量的证明。

独立只读入口 `startQueryOnlyWorkbench` 与独立维护入口 `startMaintenanceWorkbench` 继续保留。正式加工表单返回持久任务链接，独立维护页保留同步请求行为。只读部署不因统一工作台加入维护功能而取得写入能力，详见[独立阅读指南](library-query.md)。`pnpm preview:browser` 和 `pnpm preview:workbench` 继续是合成预览，不能用来存放真实资料。

## 阅读与界面调整

全文接近已加载末尾时自动续读，每次仍核验固定版本与连续范围；加载失败会保留已读正文并显示“重试加载正文”，不自动重跑解析。来自解析产物的标题和正文保持原义；解析错误不会由页面静默改写。

桌面导航栏右边界、阅读信息栏左边界可拖动；聚焦分隔线后用左右方向键调整，Home/End 到最小/最大宽度，双击恢复默认。宽度保存在当前浏览器的本机偏好中，不改变文献数据库。窄屏使用堆叠/抽屉布局，不显示拖动手柄，摘要和来源仍可展开。

阅读信息中“摘要”展示元数据原文；“元数据来源”按来源列出采集时间、来源记录及书目字段，不是 Agent 总结。来源摘要可另行展开。

洞察说明当前使用的是筛选、选择还是全库范围；“查看全部文献库”仅改变本次洞察范围，保留库里的筛选。统计最多读取 1000 篇；引用网络只读取前 40 篇每篇最多 100 条参考关系，并仅显示两端都在样本内的边。无连线会给出取样说明，不代表全库没有引用，也不要求文献先完成解析/分析。
