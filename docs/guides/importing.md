# 导入文献

类型：指南
负责：把文献放进文献库的几种办法与选择
状态：现行

文献进库有四个入口，都在侧栏的“找文献”页，各占一个标签页。另有命令行和 Agent 两条路。先按你手上有什么选一种：

| 你手上有                             | 用哪种                            |
| ------------------------------------ | --------------------------------- |
| 一堆 PDF                             | [文件](#文件pdf-与导出文件)       |
| 文献管理软件导出的 `.bib`、`.ris` 等 | [文件](#文件pdf-与导出文件)       |
| 一个 Zotero 库，想连 PDF、批注一起搬 | [Zotero](#zotero)                 |
| 正在浏览器里看的一篇文章             | [网页收藏](#网页收藏)             |
| 只有一个主题，或一篇种子文献         | [检索](#检索按主题找或沿引用扩展) |
| 想让 Agent 或脚本来做                | [命令行与 Agent](#命令行与-agent) |

不论哪种，每次导入都是一个**批次**，列在“找文献”页下方的批次记录里。导入不会自动联网取 PDF，也不会自动解析；这两件事要你另外发起。

## 文件：PDF 与导出文件

打开“找文献 → 文件”，把文件或文件夹拖进放置区，或点“选择文件”“选择文件夹”。

**只放 PDF**

1. 拖入后立即建一个批次并打开它。每个 PDF 是一条只有文件的条目。
2. 系统先识别每个 PDF 是哪一篇，页面写“正在识别文件 n / 总数”。
3. 识别完，看一眼“需要决定”的条目（见下），点“确认入库”。

**放导出文件（可以同时放 PDF）**

1. 支持 BibTeX、BibLaTeX、RIS、CSL JSON，一次一个导出文件，不超过 7 MiB。放置区下方会写出识别到的格式，识别不了时自己选一个。
2. 同一次拖入的 PDF 会按导出文件里写的路径和条目配对。从 Zotero、EndNote 等导出时，如果想连 PDF 一起带上，把导出文件和存 PDF 的文件夹一起拖进来。
3. 点“继续”建批次，核对后“确认入库”。

**没认出来的 PDF**

系统靠 PDF 里的 DOI 和标题去 Crossref、OpenAlex 查它是哪一篇。查不到的照样入库，标题用 PDF 里的标题或文件名，行末写“书目不全”。批次页会写出有多少个 PDF 的内容没读出来以及原因（扫描件、加密等）。之后可以在文献库里选中它们，用“更多 → 识别书目”再认一次，进度在“任务”里；扫描件要先解析全文，解析完成后系统会自动再认。中文期刊的文章这两个来源大多查不到，需要在阅读页的“编辑元数据”里手工补。

**需要你决定的条目**

- 可能重复：选“并入”库里已有的那一篇，或“新增”。
- 可能是这一篇：系统给出候选，选“采用”其中一个，或“都不是”。
- 未配对的文件：选“作为单独的文献入库”或“不入库”。

没做决定的条目不会入库，入库结束后还可以回来处理。确认入库只新增，不删除、不替换库里已有的 PDF。

文件很多时，确认后导入在后台进行。浏览器没传完就关了，回到这个批次点“选择文件夹”续传，已经交过的不会重传。

## Zotero

在装了 Zotero 的电脑上，可以让 Agent 代你运行 skill 里的 Zotero 导入程序（`scripts/zotero_import.py`），也可以自己运行：它读 Zotero 的本地接口，把一个库或其中几个分类连同分类、标签和 PDF 交给文献库的一个批次，你在“找文献”的批次记录里预览、确认，之后它把 PDF 传上来。要先在 Zotero 的设置 → 高级里允许其他应用程序与 Zotero 通讯。批注现在带不过来，只计数。扩展里的“从 Zotero 导入”一项还是停用的。

也可以在 Zotero 里把要的条目导出成 BibTeX 或 RIS（勾选导出文件），再按上面“文件”一节把导出文件和附件文件夹一起拖进来。分组、标签带得过来的程度取决于导出格式，批注带不过来。

扩展的安装与连接见[浏览器扩展指南](browser-extension.md)。只想搬书目和 PDF、不要批注时，从 Zotero 导出 BibTeX 或 RIS 再走上面的“文件”也可以。

## 网页收藏

装好并连接浏览器扩展后，在出版社或预印本的文章页面上点工具栏里的扩展按钮：

- 不在库的文章：显示标题、作者与年份，可以选一个文件夹，点“收藏”。
- 已在库但没有 PDF、而页面上有 PDF 时：可以“补上 PDF”。

PDF 用你浏览器自己的网络和登录状态下载，所以学校或机构订阅的文章也取得到；Cookie 和登录信息不会离开你的浏览器。每台设备每天的收藏合成一个批次。细节与限制见[浏览器扩展指南](browser-extension.md#收藏)。

## 检索：按主题找，或沿引用扩展

打开“找文献 → 检索”。

- **主题发现**：填主题或检索式，可以限定出版年份和每个来源最多扫描多少条（默认 200）。确认对话框会写明会查哪些来源。
- **引用扩展**：填一篇种子文献，选方向（它引用的，或引用它的）和层数。需要先配置模型。

检索只带回书目，不取 PDF。带回来的文献是**候选**，不直接进你的文献库：在批次页或搜索结果里点“加入文献库”，或把它们放进文件夹，才算你的。这样一次检索带回几千篇也不会把文献库淹掉。

来源的选择在“设置 → 获取 PDF”，见[配置手册](configuration.md)。

## 命令行与 Agent

在运行服务的机器上，命令行直接读写同一个文献库：

```bash
pnpm sciretriever import metadata bibtex /absolute/path/library.bib
pnpm sciretriever import pdf <literature_id> /absolute/path/paper.pdf
pnpm sciretriever discover topic "your topic"
```

完整的命令和参数用 `pnpm sciretriever --help` 查看。

自己电脑上的 Agent 经“设置 → 设备连接 → 连接 Agent”连上后，可以替你整理本地的 PDF 和书目并导入；它发起的导入同样是一个批次，你可以在“找文献”页实时看到，并在那里确认或取消。见 [Agent 接口](agent-interface.md#从自己的电脑连接设备连接与-skill)。

## 导入之后

打开批次页（在批次记录里点名称），页面下方有“接着做什么”：

- **获取全文 n 篇**：为这一批里还没有 PDF 的文献找 PDF。
- **解析并形成未校对的全文 n 篇**：把这一批的 PDF 交给解析服务。

两者都会联网，可能产生费用，所以不会自动开始。

导错了可以**撤回**：批次页页眉的“更多 → 撤回这一批”。撤回前会列出将移除和将保留的文献及原因（例如入库前已经在库、你读过或批注过的会保留）。撤回只是从文献库移除，文件不会被删除，之后可以“恢复这一批”。

批次页每一块的完整说明见 [Web 指南](web-workbench.md#找文献检索与综合)。
