# 上手指南

类型：指南
负责：新用户从安装到读上第一篇的路线
状态：现行

这一页带你从零走到“库里有文献、能读、能搜”。每一步只写要做什么；细节在各步末尾链接的指南里。

## 1. 安装并启动

需要 Linux x64、Node 22.19.0 和 pnpm。系统里还要有 `flock`、`prlimit`、`pdfinfo`（poppler-utils）、`Xvfb`，以及编译用的 `gcc` 和 `make`，大多数发行版自带或一条命令可装。

```bash
git clone https://github.com/LuckRookie/SciRetriever.git
cd SciRetriever
corepack enable
pnpm install --frozen-lockfile
pnpm build
pnpm sciretriever web --port 4174
```

- 想让 AI 替你做这些，用[给 AI 的配置提示词](setup-with-ai.md)。
- 第一次 `pnpm build` 会下载并编译读取 PDF 用的工具 MuPDF（需要联网、gcc 和 make，几分钟）。取不到时构建会失败并写明原因，不会装出一个读不了 PDF 的程序。
- 服务启动时会核对 MuPDF、`flock`、`prlimit`，缺了哪一样就拒绝启动，并写明怎么补。
- 装好后可以运行 `pnpm sciretriever doctor --json` 检查系统依赖。其中 `cloakbrowser` 一项显示 blocked 是正常的，它只影响“用受控浏览器取 PDF”。
- 服务在前台运行，关掉终端就停。要长期开着，放进 `tmux` 或 `screen`。

完整的安装条件见[安装指南](installation.md)。

## 2. 登录

终端会打印访问地址和一个 `api_key`。浏览器打开地址，把 `api_key` 粘贴到登录框。

- `api_key` 每次重启都会变。想用固定密码，启动前设置环境变量 `SCIRETRIEVER_WEB_PASSWORD`（至少 12 个字符）。
- 服务在服务器上、人在自己电脑上时，直接访问 `http://服务器IP:4174/`；或者用 SSH 端口映射：`ssh -L 4174:localhost:4174 <服务器>`，然后打开 `http://localhost:4174/`。
- 目前只有普通 HTTP，密码和文献在网络上不加密。请只在可信网络里用，或走 SSH 端口映射。
- 登录 12 小时后过期，服务重启后也要重新登录。

第一次启动会自动建好空库，数据都在 `~/.sciretriever/` 下：`catalog.sqlite` 是文献数据库，`artifacts/` 是 PDF 等文件，`config.toml` 是配置。备份时这三样要一起备份。

远程访问与密码的细节见 [Web 指南](web-workbench.md#启动与数据库绑定)。

## 3. 认识界面

- **顶栏**：左边是开合侧栏的按钮；阅读页的工具在右边。
- **侧栏上半**：文献库、最近读过，以及你的文件夹。
- **侧栏底部**：找文献、全文检索、任务、加工、设置。
- **文献库页**：中间是列表，右边一栏是当前这一篇的书目、材料和摘要。单击一行是选中，双击（或回车、右栏的“打开阅读”）才打开阅读页。

两个词要先知道：

- **文献库**是你自己的文献：导入的、收藏的、放进文件夹的、读过的。
- **候选**是检索任务找到、你还没有要的文献。搜索时它们列在文献库的结果下面，点“加入文献库”才算你的。

每篇文献的材料状态有三种常见的：**只有书目**、**有 PDF**、**有全文**。后两步分别靠“获取 PDF”和“生成全文”得到。

## 4. 放进第一批文献

最快的办法：打开侧栏的“找文献 → 文件”，把电脑里的 PDF 或一个文件夹拖进去。也可以从 Zotero 导入、在网页上收藏，或按主题检索。四种办法和各自的步骤见[导入文献](importing.md)。

这一步不需要任何配置。

## 5. 获取 PDF

只有书目的文献，可以让系统去找 PDF：

1. 在文献库里勾选文献（或者不勾，对当前筛选出的全部文献操作）。
2. 点选择栏里的“获取 PDF”，对话框会写明范围和会查的来源，确认后提交。
3. 进度在侧栏的“任务”里看。取到的变成“有 PDF”，各条路都试过仍没有的标为“没找到 PDF”，这时可以在阅读页手动上传。

不配置时只用几个开放来源（如 arXiv、Europe PMC），所以命中有限。要提高命中，在“设置 → 获取 PDF”里加来源、填出版社接口的密钥，或启用受控浏览器。来源与顺序见 [PDF 获取](pdf-acquisition.md)。

## 6. 生成全文

“生成全文”把 PDF 解析成分章节、带页码出处的全文，之后才能全文检索、翻译、打标签和加工。它需要两样东西，都在“设置”里配：

- **解析服务**（设置 → 生成全文）：一个你自己部署或有权使用的 MinerU 服务的地址。
- **模型**（设置 → 模型服务）：一个大模型服务的地址、密钥和模型名，用于校订和总结。

配好后，在文献库勾选“有 PDF”的文献，点“生成全文”。任务在后台运行，可以关掉页面；失败的条目在“任务 → 需处理”里，写着原因和可做的处理。

这一步会把 PDF 交给解析服务、把文本交给模型，可能产生费用。系统不会自动做这件事，每次都要你确认。流程与状态见[文献建档](literature-archive.md)和[文档处理](document-processing.md)。

## 7. 阅读

双击文献打开阅读页：

- 有全文时看全文，可以和 PDF 原页对照；只有 PDF 时直接看 PDF。
- 选中文字可以高亮、写批注。
- 配了模型后可以翻译选中的段落或全文对照翻译。
- 外观（字号、行距、阅读主题）在“设置 → 外观”和阅读页的工具里调。

阅读页的全部功能见 [Web 指南](web-workbench.md#文献库与阅读)。

## 8. 检索与加工

- **搜书目**：文献库页顶部的搜索框，搜标题、作者、摘要等；旁边的“筛选”按年份、期刊、标签等条件收窄。
- **全文检索**（侧栏）：在已生成的全文和已保存的知识里按关键词找，命中带章节和页码，可以跳到原文。目前是按词匹配，不会自动翻译或扩展同义词。
- **加工**（侧栏）：对一批文献运行“算子”，例如总结、按你定义的问题做标注、按你定义的字段提取记录、多篇综合。每条结果都能展开看依据。需要模型。

见[独立文献库阅读](library-query.md)与[知识加工](knowledge-processors.md)。

## 9. 让 Agent 用

自己电脑上的 Agent（Claude Code、Codex 等）不用装本仓库：

1. 在“设置 → 设备连接”点“连接 Agent”，勾选它能做的事（入库、读取，需要时再勾操作），生成连接码。
2. 把对话框里“复制给 Agent 的话”整段发给 Agent。

之后 Agent 就能检索、阅读你的文献库，按你给的权限导入文献或发起任务。连接可以随时在同一页撤销。见 [Agent 接口](agent-interface.md#从自己的电脑连接设备连接与-skill)。

## 哪些功能要先配置

| 功能                           | 需要先配什么                                                 | 在哪里配                  |
| ------------------------------ | ------------------------------------------------------------ | ------------------------- |
| 导入文件、看 PDF、文件夹、批注 | 不需要（导入 PDF 时识别书目要联网查 Crossref、OpenAlex）     |                           |
| 网页收藏、从 Zotero 导入       | 装浏览器扩展并连接                                           | 设置 → 设备连接           |
| 按主题找文献                   | 不需要（默认来源可用）；个别来源要密钥                       | 设置 → 获取 PDF           |
| 沿引用扩展                     | 模型                                                         | 设置 → 模型服务           |
| 获取 PDF                       | 不需要（只查开放来源）；更多来源要联系邮箱、密钥或受控浏览器 | 设置 → 获取 PDF           |
| 生成全文                       | MinerU 解析服务和模型                                        | 设置 → 生成全文、模型服务 |
| 翻译、标签、加工、综合         | 模型                                                         | 设置 → 模型服务           |
| 全文检索                       | 不需要，但只搜得到已经生成全文的文献                         |                           |

密钥只在“设置”页或命令行的 `sciretriever config` 里填，它们单独存在 `~/.sciretriever/credentials.toml`，不要写进 `config.toml`。每个配置项的含义与默认值以[配置手册](configuration.md)为准。

## 常见问题

- **重启后登录不上**：没设固定密码时，`api_key` 每次启动都变，看启动终端里最新的那一个。
- **换了机器或想搬库**：把 `~/.sciretriever/` 整个目录搬过去。数据库和文件目录必须是同一套。
- **升级后启动被拒绝**：库结构变了。旧库不会被自动转换，按[初始化与恢复](upgrade.md)处理，先备份。
- **搜不到刚生成全文的文献**：全文索引在后台更新，“全文检索”页的搜索框下方会写索引的状态和可做的操作。
- **导入的 PDF 只有文件名，作者、期刊、年份都是“未提供”**：较早的版本在没有编译 MuPDF 时也能启动，那时导入的 PDF 读不出内容。更新到最新代码后重新 `pnpm build` 并重启服务。服务器不能访问外网时也会认不出，因为识别书目要查 Crossref 和 OpenAlex。已经这样入库的文献不用重新导入：在文献库里用“筛选 → 更多条件 → 书目不全”找出它们，全选后点“更多 → 识别书目”。
- **取不到 PDF**：先看这篇的“任务”记录里各来源的结果；需要机构权限的文章，考虑启用受控浏览器或手动上传。
