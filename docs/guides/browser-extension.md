# 浏览器扩展：网页收藏

类型：用户指南
负责：浏览器扩展的安装、连接与使用
状态：现行（真实出版社页面的试用待 Owner 进行）

在出版社或预印本网站看到一篇文献，点扩展按钮就能看它在不在库，不在就连同 PDF 收进文献库。决定见 [ADR 0057](../architecture/decisions/0057-zotero-import-and-browser-capture.md) 第 5 节与 [ADR 0058](../architecture/decisions/0058-import-system-and-agent-access.md) 第 1、2 节；弹窗的各状态见[页面规格](../architecture/web/page-specs.md#浏览器扩展弹窗)。

## 安装

扩展用于 Chrome 和 Edge（116 及以上），不在商店上架，以开发者模式加载：

1. 在文献库“设置 → 设备连接”点“下载扩展安装包”，解压到一个固定的文件夹。
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），打开“开发者模式”，点“加载已解压的扩展程序”，选那个文件夹。
3. 升级时下载新的安装包，覆盖原文件夹，再在扩展管理页点刷新。

## 连接

1. 在“设置 → 设备连接”点“连接浏览器扩展”，用途默认勾“收藏”，生成连接码。
2. 点浏览器工具栏上的扩展按钮，粘贴连接码，点“连接”。浏览器会询问是否允许扩展访问文献库的地址，选允许。
3. 连接码 10 分钟内有效、只能用一次。连接成功后，扩展记住地址和自己的令牌。

扩展只连你在浏览器里打开文献库用的地址。文献库在服务器上时，这个地址是你的端口映射（例如 `ssh -L 4174:localhost:4174 <服务器>`）映射出的本机地址；连不上时，扩展会写出所连的地址，请先检查端口映射是否开着。端口变了时在扩展的“设置”里改地址，不需要重新连接。

## 收藏

- 只在你点扩展按钮时读一次当前页：DOI、arXiv 号和书目标签（`citation_*`、Dublin Core、`prism.*`），以及网址里的 DOI 或 arXiv 号。
- 已在库：显示是否已有 PDF；还没有 PDF 而页面上有时，可以“补上 PDF”。
- 不在库：显示标题、作者与年份，可选一个文件夹，点“收藏”。页面上读不到 DOI 或 arXiv 号时，要手动填写，否则不保存。
- PDF 取页面的 `citation_pdf_url`，当前就是 PDF 页面时取这个页面。扩展用你浏览器自己的网络和登录状态下载，再把文件交给文献库；Cookie 和登录信息不离开浏览器。第一次从某个网站下载时，浏览器会询问是否允许扩展访问该网站。
- 书目作为“网页收藏”来源保存，并照常用标识向已配置的元数据来源补全。PDF 按 ADR 0029 验收，标为“文章身份未验证”；库里已有 PDF 时不替换，文件不同就记为冲突。
- 每台设备每天的收藏合成一个入库批次，名为“网页收藏 YYYY-MM-DD”（按 UTC 日期），在入库记录里可以改名。

## 断开与撤销

扩展的“设置 → 断开连接”删除本机保存的令牌；要让这个令牌彻底失效，再到文献库“设置 → 设备连接”撤销这个设备。撤销后扩展的请求立即被拒绝，要再用需重新连接。

## 已知限制

- 只读通用书目标签，不使用 Zotero 翻译器。标签不全的网站可能读不到 DOI 或 PDF 地址，这类站点以后按站点补规则。
- 需要先在网站上登录或点一次“同意”的 PDF，扩展可能下载到网页而不是 PDF，此时只保存书目，并写明 PDF 没有收进来。
