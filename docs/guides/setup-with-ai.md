# 让 AI 帮你安装和配置

类型：指南
负责：交给编程 Agent 的安装与配置提示词
状态：现行

不想自己读安装和配置文档时，可以把下面的提示词交给一个能在你机器上执行命令的编程 Agent（Claude Code、Codex 等），让它替你装好、检查环境、写好不含密钥的配置，并告诉你最后要亲手做的几步。

## 怎么用

1. 在要运行 SciRetriever 的 Linux 机器上打开编程 Agent。已经把仓库克隆下来的话，在仓库目录里打开；没有也行，提示词会让它克隆。
2. 把下面“提示词”一节的整段文字复制给它。
3. 它会先问你几个问题（见“它会问你什么”），按你的回答去做。
4. 最后它会给你一条启动命令和几件要你亲手做的事：启动服务、登录、在“设置”页填密钥。

密钥和密码始终由你自己填，不要发到对话里。提示词里已经要求 Agent 不索要、不读取、不保存它们。

## 提示词

```text
请帮我安装并配置 SciRetriever（一个文献知识库，Node/pnpm 项目）。
仓库：https://github.com/LuckRookie/SciRetriever

先读这几份文档再动手，以它们为准，不要凭印象：
- README.md
- docs/guides/installation.md（安装条件）
- docs/guides/getting-started.md（上手路线，尤其“哪些功能要先配置”）
- docs/guides/configuration.md（配置项；只在要写某一项时查对应小节）
- example/config.example.toml（不含密钥的配置模板）

规则（必须遵守）：
1. 不要向我索要任何密钥、令牌、密码，也不要让我把它们贴到对话里。
   需要密钥的地方，只告诉我在 Web 的“设置”页哪一块填，或让我自己运行
   `pnpm sciretriever config`。
2. 不要读取、打印或修改 ~/.sciretriever/credentials.toml。
3. ~/.sciretriever/config.toml 已经存在时，先给我看你打算改哪几行，
   我同意后再改；不要用模板覆盖它。新建时目录权限设为 0700，文件 0600。
   config.toml 里不写任何密钥。
4. 不要自己启动 Web 服务：启动时终端会打印登录用的 api_key，应当只有我
   看到。你准备好一切后，把启动命令给我，由我在自己的终端里运行。
5. 不要调用会联网取文献、解析 PDF 或调用模型的命令（discover、complete、
   archive build、document parse 等），这些可能产生费用，由我自己在界面里发起。
6. 每一步失败时，先把原始报错给我看，再说你打算怎么处理；不要跳过。
7. 不要用 sudo。缺系统软件包时，把要我执行的安装命令列给我。

请按这个顺序做：

A. 先问我下面这些问题，一次问完，等我回答：
   1) 仓库放在哪个目录（已经克隆了就告诉你路径）？
   2) 服务用哪个端口（默认 4174）？我是在本机用，还是服务在服务器上、
      我从自己电脑访问？
   3) 文献数据库和文件放在哪里（默认 ~/.sciretriever/ 下）？
   4) 我打算用哪些功能：只导入和阅读 PDF；按主题找文献；自动获取 PDF；
      解析全文（需要我有 MinerU 解析服务和一个大模型服务）；翻译、标签、
      加工（需要大模型服务）。
   5) 如果要解析全文或用模型：MinerU 服务的地址是什么？模型服务的地址、
      接口类型（OpenAI 兼容等）和模型名是什么？（只要地址和名字，不要密钥。）
   6) 获取 PDF 时要不要启用 Unpaywall（需要一个联系邮箱，不是密钥）？

B. 检查环境并报告结果：
   - 系统是否 Linux x64；`node --version` 是否 22.19.0（不是的话告诉我
     怎么装这个版本，例如用 nvm 或 fnm，不要替我改系统级的 Node）；
   - `corepack enable` 后 pnpm 是否可用；
   - `flock`、`prlimit`、`pdfinfo`、`Xvfb` 是否存在；
   - `gcc`、`make` 是否存在（编译读取 PDF 的工具要用）。

C. 安装与构建（在仓库目录里）：
   - 没有仓库就克隆；
   - `pnpm install --frozen-lockfile`
   - `pnpm build`（第一次会下载并编译读取 PDF 的工具 MuPDF，要联网，
     几分钟；它失败时构建会失败并写明原因，把原因给我看）。
   - `pnpm sciretriever doctor --json`，把结果解释给我。
     其中 cloakbrowser 为 blocked 是正常的，除非我要用受控浏览器取 PDF。

D. 写不含密钥的配置（只写我在 A 里要的功能涉及的项）：
   - 我选了非默认的存放位置时写 [paths]；用默认位置就不写，首次启动会自动建。
   - 按我的回答写文献来源、Unpaywall 联系邮箱、[parsing] 的 MinerU 地址、
     [providers] 与 [models] 里的模型服务地址和模型名、以及引用它们的角色。
     每一项的字段名和取值去 docs/guides/configuration.md 对应小节查，
     拿不准的项不要写，改为告诉我在“设置”页哪一块可以配。
   - 写完把你新增或改动的内容（不含任何密钥）列给我。

E. 交给我收尾。请给我一份清单，包含：
   1) 启动命令。建议我放在 tmux 里运行：
        cd <仓库目录> && pnpm sciretriever web --port <端口>
      并说明：想用固定密码，就在启动前自己设置环境变量
      SCIRETRIEVER_WEB_PASSWORD（至少 12 个字符）；不设则每次启动
      终端会打印一个新的 api_key。
   2) 访问地址。服务在服务器上时，给出两种访问办法：直接访问服务器 IP，
      或 `ssh -L <端口>:localhost:<端口> <服务器>` 后访问 localhost；
      并提醒我目前只有普通 HTTP，只在可信网络里用。
   3) 登录后要我亲手在“设置”页填的密钥：逐条写明在哪个分区、哪一行、
      填什么（例如“设置 → 模型服务 → 某某服务 → 密钥”），以及填完后
      点哪里的“测试”验证。
   4) 第一次用的三步：在“找文献 → 文件”拖入几个 PDF；选中后“获取 PDF”
      或“解析全文”；双击打开阅读。并附上 docs/guides/getting-started.md
      和 docs/guides/importing.md 的路径。
   5) 这次你没做或没能验证的事。

全程用中文和我交流。
```

## 它会问你什么

提前想好这几件事，能省一轮来回：

- **端口与访问方式**：本机用，还是服务在服务器上、从自己电脑访问。
- **数据放哪里**：默认在 `~/.sciretriever/`。文献多时 PDF 会占不少空间，可以指到大一点的盘。
- **要哪些功能**：只导入和阅读不需要任何外部服务。解析全文需要一个 MinerU 解析服务和一个大模型服务；翻译、标签、加工需要大模型服务。
- **服务的地址和模型名**：只要地址和名字。密钥等启动后你自己在“设置”页填。

## 之后

Agent 做完后，照它给的清单启动、登录、填密钥。接下来怎么用，看[上手指南](getting-started.md)；怎么把已有的文献放进来，看[导入文献](importing.md)。

配置之后想改，不必再找 Agent：Web 的“设置”页每一块都能直接改，改动保存后按页面提示应用。所有配置项的含义见[配置手册](configuration.md)。
