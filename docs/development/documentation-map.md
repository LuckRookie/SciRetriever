本文件是代码变化时的影响分析索引，不是把目标设计当作当前实现的证据。当前公开行为以 README、用户指南、活动源码和直接测试为准；目标合同以 requirements、Accepted ADR、design 和 technical 文档为准；Python、wheel 与旧 Harness 只在明确标记的历史材料中出现。

## 4. 变更后的最小检查

1. 读取适用 requirements、Accepted ADR、design/technical 和当前直接调用方。
2. 对共享合同核对生产者、消费者、解析/序列化、持久化和错误边界。
3. 更新当前行为文档与目标/历史标记，不把计划完成状态当作实现证据。
4. 运行与变更直接相关的测试；代码变更再按需要运行 `pnpm quick`、`pnpm test` 或 `pnpm full`。
5. 文档变更检查本地链接/锚点、命令事实、术语一致性和 `git diff --check`。
6. 交付时列出实际命令、退出码、跳过/未运行项、changed paths 和残余风险；不读取或提交凭据、真实数据、构建产物或无关改动。
