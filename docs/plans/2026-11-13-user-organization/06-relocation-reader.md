# 06 · 阅读器里的重新定位

类型：计划（结果块）
负责：PDF 不同、文本版本不同时，阅读器按原文重新定位批注并按规格记录结果
状态：Pending

## Outcome

- 一篇文献的 PDF 换了（sha256 不同）时，旧 PDF 上做的高亮按原文和前后文在当前 PDF 上重新查找，规则与相似度分档同规格 5.3；对不上的按 1.3 标注，不放到别处（规格 9.5）。现在这些批注既不显示也不查找。
- 带旧文档版本锚点的批注，在当前版本上找到位置后按 1.3 记下，下次打开直接使用；不再每次打开都重新查找（ADR 0046 第 5 条）。
- 框选在 PDF 不同时按 1.3 处理。
- 初稿升级为校订稿时同样适用（规格 9.2，不另设规则）。
- 批注画成什么样、批注标签页里怎样标注，按阅读体验第 1.4、2.5 节，由计划 24 实现。

规格：[用户整理 5.3](../../architecture/technical/09-user-organization.md#53-两种材料之间对位)、[5.4](../../architecture/technical/09-user-organization.md#54-文本变化时)、[9.5](../../architecture/technical/09-user-organization.md#95-pdf-文件不同时重新定位)，经 01 的 1.3 补齐；[阅读体验](../../architecture/web/reading-experience.md)第 1.4、2.5、4.3、5.2 节。

- 6.3 起：05 完成（若 1.3 决定记录）；C2 允许（计划 README“与其他计划的关系”）。

## 责任边界

- 负责：前端实施者。
- 拥有：新文件（建议 `apps/web/src/reading/mark-relocate.ts`）中的重新定位纯函数。
- 触达（6.3 起，受 C2 约束）：`apps/web/src/reading/marks.ts`（`createPdfMarkSurface` 现在用 `onPage = m.pdf?.sha256 === sha256` 只画同一 sha256 的批注，`placeMissing` 只为没有 PDF 锚点的批注查找；全文一侧对旧版本锚点每次查找、从不保存）；`apps/web/src/app/features/reader/marks/`（调用 05 的记录操作）。
- 不改：`apps/web/src/reading/mark-locate.ts` 的比对规则与阈值；批注的画法与批注标签页的样子（计划 24 的 09、10、11）。

## Tasks

- [ ] **6.1 纯函数**：在新文件里写重新定位：输入一条批注与当前材料（PDF 各页文字层或文档区块），复用 `mark-locate.ts` 的 `canon`、`indexText`、`locate`、`PLACE`、`APPROXIMATE`，按 1.3 选候选 PDF 与查找范围，输出位置与档次（按位置、近似、对不上）。不碰 DOM 以外的状态，不发请求。
- [ ] **6.2 纯函数的测试**：见“验证”第一项。
- [ ] **6.3 接入 PDF 一侧**（C2）：sha256 不同的批注交给 6.1；找到的按档次显示，按 1.3 记录；对不上的按 1.3 标注。
- [ ] **6.4 接入全文一侧**（C2）：旧版本锚点的批注交给 6.1；找到后按 1.3 记录，之后读取已记录的位置。
- [ ] **6.5 不推动正文**：记录结果后刷新批注列表时，阅读位置不变（阅读体验第 5.2 节）；不重建阅读器（计划 24 的 03 之后，阅读器常驻）。
- [ ] **6.6 性能**：长文档上按页面绘制时逐页查找，不在打开时整篇比对；已记录的位置不再查找。

## 集成与影响

用户可见：换过 PDF 或文本出了新版本的文献，旧批注重新出现在对得上的地方；对不上的如实标明。打开次数多的文献不再每次重新查找。

## 验证

- 新增 `apps/web/test/mark-relocate.test.ts`（纯函数，合成文字），证明：
  - 另一版 PDF 的文字层与原文一致：按位置；有小改动：近似；删去了这段：对不上；
  - 前后文能区分同一句话的两次出现；
  - 1.3 规定的候选 PDF 范围（主 PDF 与补充材料）；
  - 框选按 1.3 处理；
  - 旧文档版本与新版本、初稿与校订稿两种情形。
- 扩展 `apps/web/test/next-reader-marks.test.ts`（6.3 起）：
  - sha256 不同的批注被重新定位并显示，原锚点不变；
  - 找到的位置记录一次，第二次打开不再查找（计数断言）；
  - 对不上的不画在页面上，标注按 1.3；
  - 记录结果后阅读位置不变；
  - 现有断言不变。
- `next-reader-boundaries.test.ts` 照常通过（PDF 的画布与文字层上限不变）。
