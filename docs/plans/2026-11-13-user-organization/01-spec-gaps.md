## Tasks

每项写清：要回答的问题，写进哪一节。规则写在规格里，不写在本计划里。

- [ ] **1.1 补规格：保存的筛选的合同与存储**（09 §9.1；07 第 7 节）
  - 规格 9.1 只说“读取、新建、改名、删除在 Web、CLI、MCP 上都提供”，没有写：
    - 操作名与请求、结果（参照 `FolderOperation` 的写法）；是否有“改条件”（现在 Web 的“保存当前筛选”是新建，规格没有改条件的操作）；
    - 每项的字段：编号的生成、名称、`LibraryQuery`、`LibrarySort`、创建与修改时间、操作人；
    - 上限：最多几项（浏览器版是 50 项）；名称上限规格写 128 字符，浏览器版是 100，导入时怎样对待；
    - 列表的顺序；
    - “说明文件夹已不存在”在结果里怎样表达（字段名、何时给出）；
    - CLI 命令名、MCP 工具名（参照 `folders_query` 与 `folders_manage`）、HTTP 路径；
    - 表名与列，以及它是否进入文献状态投影的输入表（规格 6.1 要求不进入）。
- [ ] **1.2 补规格：浏览器中已有筛选的导入**（09 §9.1、§4；页面规格“文献库”）
  - 规格只说“由使用者在 Web 上明确导入，不自动搬迁”。要写明：
    - 入口放在哪里、提示什么（排布归页面规格）；
    - 名称与已有的重名时怎样处理（跳过、加序号、或让使用者选）；
    - 浏览器里有不合法的项时：现在 `loadViews` 遇到任一项不合法就整份按空处理；导入是逐项判断还是整份拒绝，报告怎样列出没导入的项；
    - 名称超过新上限时怎样处理；
    - 导入之后浏览器里的旧数据怎样处理（保留、清除、或只标为已导入），Web 是否还读写 `localStorage`；
    - 同一份浏览器数据再次导入时是否重复建立。
- [ ] **1.3 补规格：重新定位的结果记不记、记在哪里**（09 §5.4、§9.5；ADR 0046 第 4、5 条）
  - 矛盾：规格 5.4 写“在新版本上找到位置后不另存新锚点，每次打开时重新查找”；ADR 0046 第 5 条写“第二个锚点在对位成功后补存，不在打开文献时重算”，第 4 条写“材料换了版本时用它们（原文与前后文）重新定位”。规格 9.5 写“旧的 PDF 锚点不改写”，没有说找到的位置记不记。
  - 现状的约束：批注表每条只有一组 PDF 锚点列和一组全文锚点列；`update` 会覆盖它们（`marks-engine.ts`）。“旧锚点不改写”与“记下新位置”同时成立，只能另设存放处。
  - 要写明：
    - 对旧文档版本与不同 sha256 的 PDF，找到的位置是否记下；
    - 若记下：存放在哪里（新列、新表，按批注与材料版本或 sha256 区分）；读取时以哪个为准；列表与导出（规格 5.6）怎样给出；相似度在 0.7–0.85 之间（近似位置）时记不记；同一材料再次打开时是否还查找；
    - 一篇文献有多个 PDF（主 PDF 与补充材料）时，在哪些 PDF 上查找；
    - 框选没有原文，PDF 不同时无法按文字查找：怎样显示与标注（规格 9.5 写“对不上标为仅全文”，但框选没有全文锚点）；
    - 阅读器里怎样标明“这条批注是在另一版材料上做的”：新的标注文字写进阅读体验第 1.4、2.5 节，还是沿用“近似位置”等现有标注。
- [ ] **1.4 补规格：分组与筛选的导出**（09 §9.6）
  - 规格 9.6 只给了内容。要写明：
    - 操作名、入口（Web 是否有下载按钮，CLI、MCP、HTTP）、设备用途；
    - JSON 的结构与版本号：文件夹树（编号、名称、上级、顺序）、成员、保存的筛选；
    - 成员写出哪些稳定标识（DOI、arXiv 号等的取法与顺序；没有标识的成员怎样写）；
    - 规模：全库文件夹成员可能有数万行，是一次返回、分页，还是 CLI 直接写文件；
    - 03 尚未交付时（保存的筛选还在浏览器里），导出里的保存筛选怎样处理。
- [ ] **1.5 三处文档的小修正**（不卡任何块）
  - 查询技术篇 2.1.1 的 `LibraryQuery` 补上 `folder` 与 `recently_opened`，链接到用户整理 2.4 与第 3 节。
  - 技术文档 01–08 开头的导航行“八模块技术导航”改为与 09 一致的“九模块技术导航”。`docs/architecture/README.md` 中同样的字样一并核对。
  - 用户整理第 7 节末尾“CLI 的 `--help` 当前没有列出……”一句，在 02 合入后删除（放在 08 的 8.1 一起做也可以）。
