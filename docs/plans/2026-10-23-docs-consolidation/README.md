# 计划 15：文档体系整理

类型：导航
负责：文档归属、去重、退役与检查器交付
状态：整理完成，待统一审阅与提交（2026-10-24）；9/9 Task 已勾选，未提交、未归档

## 目标

让现行文档符合[文档导航](../../README.md)中的文档类型、主题归属表与维护规则：

- 每个主题只有一个归属文档，其它文档只链接；
- 规格、指南和需求只写现在，不再夹带修订日志；
- 被取代的内容改掉或移走，不在原处加注；
- 每份现行文档开头写明类型、负责的主题和状态。

## 背景

2026-10-23 Owner 指出文档很乱：同一件事在多份文档里各说一遍，旧文档也没有退役或修改。当天以 Web 主题为例核实：

- 侧栏分组在 6 份文档里描述，有三个互相矛盾的版本；字号在 6 份文档里描述，Web 指南还写着已经废弃的 18 px；
- ADR 0032 修订 11 次、ADR 0037 修订 20 次，页面细节写进了 ADR；15 份 ADR 正文开头挂着“某日被某 ADR 修订”的引用块；
- `design.md` 末尾追加了“ADR 0034 补充”节；根 `README.md` 557 行，与指南有重叠。

Web 主题已在 2026-10-23 先行整理（ADR 0038、设计内核、页面规格、Web 设计目录、Web 指南的侧栏与字号）。本计划处理其余部分。

## 不变量

- **不丢内容**：删除的每段文字，要么已在归属文档中有等价表述，要么属于历史（在 Git 或归档中可找回）。每批 diff 附“删除段落 → 去向”对照表。
- **ADR 正文不改写**：已接受的 ADR 只改状态行和失效链接；被取代的细节在规格中维护。
- 不改源码行为，不改测试；`src/` 内 README 仍须自包含。
- 计划 14 进行期间，不动 `docs/architecture/web/`、`docs/guides/web-workbench.md` 和 ADR 0038，由计划 14 负责。
