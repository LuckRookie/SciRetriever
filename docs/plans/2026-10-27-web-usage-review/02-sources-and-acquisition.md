# 02 · 来源在 Web 上配齐、一键生效

类型：计划（结果块）
负责：P7、P8、P13、P14、P15、P16，以及 P20 在设置页的部分
状态：Ready

## Outcome

- 用户在设置页的“文献来源”里，能看清每个来源能做什么、在不在用、缺什么配置。
- 全部来源的配置都能在 Web 上填写、保存、测试，不用编辑配置文件。
- 改完点“应用配置”即可生效，不用回终端重启。
- 自动模式会用上所有配置齐全的来源，包括 Sci-Hub。
- 面对直接 PDF 与网页阅读器两个入口时，Agent 优先点直接 PDF。

验收口径以问题清单 P7、P8、P13–P16 的“怎样检验”为准。界面以[页面规格草案·来源目录](../../architecture/web/page-specs.md#草案文献来源设置与获取任务详情计划-17待确认)和其中“错误的呈现”为准。

## 责任边界

- worker 负责：
  - 来源配置的读写与校验，凭据只报“已配置”，可替换、可清除，不回显值；
  - 每个来源的测试接口；
  - 自动模式的选源；
  - “应用配置”与平稳重启；
  - Agent 提示词；
  - 配置指南与 [PDF 获取指南](../../guides/pdf-acquisition.md) 的同步。
- Claude 负责来源目录界面、错误呈现的共用组件，以及页面规格草案并入正文。

## Tasks

- [ ] **2.1 合同先行**（worker）
  - 给出每个来源的合同字段：
    - 用途四列：主题检索、补全书目、引用关系、PDF；
    - 状态：在用、能用未启用、不提供；
    - 配置项清单与填写状态：缺、已配置、可选增强、无需配置；
    - 测试结果：可用；错误；或三种可处理的情况——未配置、凭据无效、无全文权限。
  - 给出单个来源配置的保存接口。
  - 原因码只放在技术详情字段里。
  - 交 Claude 核对。
- [ ] **2.2 全部来源可在 Web 配置**（worker）
  - 15 个来源的全部配置项都能经 Web 保存，包括联系邮箱、Web of Science 的产品与数据库、Sci-Hub 镜像。
  - 来源凭据从“凭据”分区移到来源目录，“凭据”分区只留模型服务。
  - 保存只作用于这一个来源。
  - 写配置沿用现有的原子写入与权限规则。
- [ ] **2.3 来源测试**（worker）
  - 测试按草案规定做最小的真实请求，不写入文献库：
    - 元数据来源：用固定公开 DOI 补全一次；
    - PDF 来源：对一篇固定开放获取文章请求一次 PDF，只校验响应；
    - 出版社 API：区分“无全文权限”；
    - Browser Agent：只检查运行时能否启动。
  - 自动测试一律用 fake。生产环境里由用户点“测试”触发真实请求。
- [ ] **2.4 自动模式用上所有来源**（worker，P15）
  - 自动模式下，配置齐全的来源全部启用。
  - Sci-Hub 用内置镜像，位于 DOI 落地页之后、Browser 之前，按 ADR 0040 执行。
  - 自定义模式保持精确。
- [ ] **2.5 应用配置**（worker，P7）
  - 页头显示“应用配置”：
    - 没有任务在跑时，立即平稳重启；
    - 有任务在跑时，等其结束后重启；
    - 等待期间显示“将在任务结束后生效”，可以取消。
  - 现在 4174 是由 `sh -c node … web` 直接启动的，没有托管进程。需要由 `web` 命令自带守护，用父进程重启子进程，不依赖 systemd。
  - 重启前后的端口、令牌与会话按现有规则处理。
  - 首次切换到新启动方式时需要 G-deploy。
- [ ] **2.6 Agent 优先点直接 PDF**（worker，P8）
  - 提示词加通用偏好：“有直接 PDF / 下载链接时优先点它”，不点名出版社。
  - 合成页同时放 PDF 与 ePDF 两个入口，直接测试 Agent 的选择。测试用录制的模型回放或 fake，不调用真实模型。
- [ ] **2.7 界面**（Claude）
  - 按草案实现来源目录：
    - 选源方式；
    - PDF 获取顺序五级；
    - 来源表；
    - 展开配置；
    - 测试与全部测试；
    - 窄屏布局；
    - “应用配置”的页头状态。
  - 错误呈现做成共用组件，供 03 复用：一律显示“错误”，只单独写出三种可处理的情况，原因码放进技术详情。
  - 设计样例库补齐各状态，截图后交 R-02。
- [ ] **2.8 真实来源测试**〔须 G-real〕
  - 在 4174 或只读副本上，对已配置的来源各点一次“测试”，逐个记录结果。
  - 由 Owner 抽查一篇真实 Wiley 文章，确认 Agent 先点直接 PDF。
