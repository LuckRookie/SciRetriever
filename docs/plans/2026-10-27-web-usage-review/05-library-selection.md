# 05 · 文献库连续选择与批量操作

类型：计划（结果块）
负责：P21、P22（不含运行算子对话框）
状态：Done（2026-10-28，`02c6e96`）

## Outcome

- 文献库能连续选取多篇：拖动勾选列、Shift + 点击、Esc 取消；拖到边缘时自动滚动；可以切到“全部 N 篇符合条件的文献”。
- 选择栏写出所选文献的组成，每个按钮写出实际会处理的篇数。
- 点“获取 PDF”只处理无 PDF 的，点“建档”只处理有 PDF 未建档的。

界面以[页面规格草案·连续选择与批量操作](../../architecture/web/page-specs.md#草案文献库的连续选择与批量操作计划-17待确认)为准。

**不在本块**：草案中“运行算子遇到混合选择”一节，包括“补齐材料”。原因是计划 17 的范围约定“算子相关界面不改”，而“能运行”的判定要随计划 16 变化。所以本块里选择栏的“运行算子”只统计并提交“已就绪”的篇数，对话框保持现状。这一节留在页面规格草案中，随计划 16 再定。

无。可以立即开始。

## Tasks

- [x] **5.1 服务端计数**（worker；先由 Claude 确认现有接口是否已够）
  - 给定筛选条件，返回按状态（无 PDF、有 PDF 未建档、已就绪）的篇数。
  - 批量操作在服务端按同一口径过滤，提交的范围与显示的数字一致。
  - 2026-10-28 Claude 核对：不需要新接口。选择只能从已加载的行或“选择全部”产生，状态都在 `LiteratureSearchItem` 里；“选择全部”改用新的 `scopeItems` 一次取回范围内各篇及其状态（上限 1,000 篇）。各按钮只提交本组的 id，所以提交范围就是按钮上的数字。
- [x] **5.2 连续选择**（Claude）
  - 拖动选中与取消、Shift 选整段、边缘自动滚动、Esc；在虚拟滚动下正确。
  - 2026-10-28 实现：`features/library/selection.ts` 的 `useRangeSelection`。
    - 在勾选列按下即决定：从起点到指针所在行整段设为同一状态，按行序号计算，不依赖逐行进入事件，所以虚拟滚动和快速移动不会漏行；
    - 指针停在滚动区上下 56 px 内时自动滚动；
    - 按下时不会触发行的拖入文件夹；
    - 键盘 Space 仍走复选框本身。
  - 实施中修了两处：React 受控复选框在点击被取消后仍会报告变化，所以切换函数改为询问这次按下是否已处理；点过勾选框后焦点停在复选框上时，Esc 也能清空选择。
- [x] **5.3 选择栏**（Claude）
  - 显示组成标签，点标签把选择缩小到该类。
  - 按钮带篇数；数字为 0 时停用，悬停说明原因。
  - 主次按钮与“更多”按草案排布。
  - 2026-10-28 实现：
    - 组成标签为无 PDF、有 PDF 未建档、已就绪、其他；
    - 按钮为获取 PDF n（页面唯一的主按钮）、运行算子 n、建档 n、加入文件夹；更多里是解析 PDF、核验文章身份、生成快照、导出书目和移出文件夹；
    - 窄屏下选择栏占满宽度，折成两行。
  - 单篇文献的行菜单不受分组限制，仍可以重新获取 PDF。
