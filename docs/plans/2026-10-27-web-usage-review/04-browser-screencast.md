# 04 · 浏览器实时观看与直接操作

类型：计划（结果块）
负责：P25 的实施与验收
状态：Ready（ADR 0042 已 Accepted）

## Outcome

- 观看页的画面改用页面投屏，Agent 推理期间也持续更新。
- 人在画面上的鼠标、拖动、滚轮、键盘操作（含中文输入）直接作用到页面，第一次操作即暂停 Agent。
- 不再出现“点不上”。
- Agent 的观察截图照旧，但不再往页面里插遮挡层。

方案、实测数字与验收口径以问题清单 P25 为准。

## 进入条件

- **G-adr**：新 ADR（编号 0042）Accepted。它部分取代两处决定：
  - ADR 0026 中“直接点击或输入不能省略页面版本校验”；
  - ADR 0032 第 5 节第 2 条“输入绑定实际看到的页面 revision”。
- 4.1 由 Claude 起草，Owner 确认后，本块其余 Task 才开工。
- 实测装置可作参考：本机 `sandbox/cases/2026-10-27-browser-screencast/` 及其中的 `real-network/`。

## Tasks

- [x] **4.1 ADR 0042**（Claude）
  - 写清以下决定：
    - 观看与 Agent 观察分开；
    - 取得控制权的第一次操作如何防止落到已经变化的页面：输入带上它所在的投屏帧，服务端只校验文档没有换，不校验观察 revision；
    - 取得控制权后，输入直接转发；
    - 交还后 Agent 重新观察；
    - 投屏帧只发给已认证的观看者；
    - 投屏不遮挡密码框，因为观看者就是控制者本人，页面也只显示圆点；
    - 观察截图仍按 ADR 0030 遮挡。
  - 交 Owner 确认（G-adr）。
- [x] **4.2 投屏转发**（worker）
  - 用 `Page.startScreencast`，逐帧 ACK，`everyNthFrame` 为 1。
  - 待发只留最新一张，经已认证的 WebSocket 发送二进制帧。
  - 有观看者才开投屏，最后一个观看者离开即停。
  - 默认 1280 宽、JPEG 质量 60。
  - 按实测带宽自适应降到 960 宽或更低质量。
  - 在途帧数从 1 放宽到 2 的效果，在 4.6 实测后定。
  - 证据（2026-10-28）：`packages/contracts/src/screencast.ts` 与 `screencast-relay.ts` 已接入认证、二进制帧、stream_epoch、逐帧 ACK 和最新待发槽；参数沿用实验，默认在途 1、1280/Q60/N1、最大高 1080，带宽逐档降级。`test-acceptance.log` 6 文件 37 项通过。
- [x] **4.3 直接输入与控制权**（worker）
  - 鼠标移动、按下与抬起、拖动、滚轮、键盘、文本插入（输入法）都经 CDP `Input.*` 转发，坐标按投屏帧换算。
  - 第一次操作申请控制权并暂停 Agent；尚未派发的 Agent 决定作废。
  - 交还后 Agent 重新观察。
  - 多窗口竞争按 ADR 0032 第 5 节第 4 条，与 ADR 0042 一并执行。
  - 证据（2026-10-28）：首次输入只复核帧文档及控制 epoch；已控制后直接经 Host FIFO/CDP 派发。直接测试覆盖旧决定作废、竞争 CAS、交还新观察、断线暂停、输入法和粘贴；HTTP/CLI/MCP 观察及控制回归通过。
- [x] **4.4 截图遮挡改为画在图上**（worker）
  - 观察截图截好后，再在图上涂抹敏感输入的区域，不再往页面 DOM 插入覆盖层。
  - 遮挡范围与现行一致：password、one-time-code。
  - 证据（2026-10-28）：surface capture 后像素遮挡，检测失败返回无图。`mask-verification.json`：1010 帧遮挡色为 0；40 张 Agent 图敏感区域覆盖率 100%；停止完成后 500 ms 原始帧为 0。
- [x] **4.5 标签页与页面切换**（worker）
  - 刷新和页内跳转时，投屏保持不断。
  - Agent 切换到新标签页或弹窗时，停掉旧订阅，在新页上重新订阅。
  - 证据（2026-10-28）：Cloak 回环验证刷新/页内导航继续出帧、弹窗新建订阅；服务层验证生产 automatic observation hook 换到新源、拒绝跨文章绑定。静止页 8 次新订阅均在 2.5 秒内出首帧，不用短动画；停止等原生 stop/detach 回执。
- [x] **4.6 实测与直接测试**（worker）
  - 直接测试：

    - 投屏中没有遮挡层闪现；
    - 新标签页后画面跟过去；
    - 第一次操作暂停 Agent。
