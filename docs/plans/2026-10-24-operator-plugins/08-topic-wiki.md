# 08 · 主题分组与维基

类型：计划（结果块）
负责：`groups`（`topic` 变体）与 `pages` 产出类型、主题分组、按组汇总、维基页面集与增量更新
状态：Pending（须 G-adr）

## Outcome

1. 一批论文可以组织成维基：论文卡片、主题页、方法页、论断页、研究空白页，页面互相链接，每个陈述可回到证据根；
2. 各类页面由各自的规范驱动逐篇采集；研究空白页区分草案 8.9 的三种来源；
3. 主题分组可多归属，组定义冻结；变化发生时平台列出受影响范围，经授权后更新；
4. 每次更新发布新的页面清单，条件切换入口，旧页面和链接仍可访问。

规格见[知识加工规格](../../architecture/technical/05-knowledge-processing.md) 8.2、8.3、8.7–8.9、8.12。新增产出类型与分组形态属草案冲突表条目，须 G-adr。

## 进入条件

02、03、06 退出；07 的 7.2 合入；G-adr 通过。

## 责任边界

worker：`groups`（`topic`）与 `pages` 合同，分组执行，`per-group` 汇总，页面清单的组装（复用 07 的派生执行）、发布与条件切换，受影响范围计算，机器接口。Claude：页面类型规范的内置模板、维基视图与更新流程页面。

## 集成与影响

- 调用方：Web 新增维基区域；MCP 与 CLI 的 `run`、`get_result` 与页面清单读取。
- 存储：页面清单与入口指针；需要新表时走 G-schema。
- 用户可见变化：可以生成并浏览维基，显式更新。

## 验证

命令按根 README 的验证路线；新增 `processor-grouping.test.ts`、`wiki-pages.test.ts`。

- 多归属、组定义冻结、重新分组生成新结果而不改旧组；
- 页面陈述的证据链在合成样例上可回到证据根；研究空白三种来源分开呈现（只证明信息传递，不证明真实质量）；
- 受影响范围：分别改变新增论文、文档版本、规范或模型、组定义、交叉链接，断言受影响集合与预期完全一致；
- 条件切换：两个并发更新基于同一入口版本时只有一个切换成功；发布失败不换入口；旧页面与旧链接持续可读；
- 重建检索索引不使任何页面过时；
- 未经确认或授权不产生调用；变化事件与页面访问不触发更新。

未覆盖：真实文献集上的分组与页面质量（11 的成套效果评估）。
