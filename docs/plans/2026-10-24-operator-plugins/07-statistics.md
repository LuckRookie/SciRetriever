# 07 · 统计与发表分析

类型：计划（结果块）
负责：`statistics` 产出类型与视图、派生形态、发表统计
状态：Pending（须 G-adr）

## Outcome

1. 用户选一个快照，即可得到发表统计（年份、期刊、作者、机构等维度的分布），无模型费用；
2. 也可以对一份记录表做统计（按字段计数、取值分布）；
3. 每个统计格记录公式、分母与成员，可以展开到具体文献或记录；元数据缺失的成员单独计数；
4. 统计结果在 Web 有表格与图表视图，经机器接口可取用。

规格见[知识加工规格](../../architecture/technical/05-knowledge-processing.md) 8.2、8.3、8.7、8.12。新增产出类型与派生形态属草案冲突表条目，须 G-adr。

## 进入条件

01 退出；G-adr 通过。7.2 需要 02 的 2.5（运行流程）与 2.5b（机器接口）；对记录表的统计需要 03 的 3.1。

## 责任边界

worker：`statistics` 合同与校验、派生执行（平台内置的确定性函数，08 复用）、机器接口。Claude：统计视图与发表统计入口。

- [ ] **7.1 类型**〔worker〕
  - 落实草案 8.2 的 `statistics`；在类型注册表登记校验器、判断取值与视图标识。
  - 输出：合同、parser、合同测试（公式、分母、成员引用、缺失计数）。

  - 输出：派生执行器与内置函数集合（计数、分组计数、分布）；08 的页面清单组装复用本执行器。
- [ ] **7.3 命名组合 `publication-statistics`**〔worker〕

- [ ] **7.4 Web**〔Claude〕
  - 页面规格草案后实现：在结果页外框内登记统计视图（表格；用户选择维度的柱状图或折线图）、成员展开、缺失计数说明。
- [ ] **7.5 验证与 R3 审阅包**
  - 运行下节测试；R3 审阅包含发表统计与记录表统计的截图及行为说明。

## 集成与影响

- 调用方：Web 快照页与结果页、MCP 与 CLI 的 `estimate`、`run`、`get_result`。
- 存储：结果沿用现有结果外壳；不改写历史结果。
- 用户可见变化：快照可直接生成发表统计；记录表可生成统计。

## 验证

命令按根 README 的验证路线；新增 `processor-statistics.test.ts`。

- 同一冻结输入重算，统计内容的规范化 hash 相同（不含结果 ID 与时间）；分母与成员一致；缺失元数据单独计数；
- 派生运行不产生模型调用；元数据之后变化不改变已发布统计；
- 作者、机构同名不同写法按原样分开。
