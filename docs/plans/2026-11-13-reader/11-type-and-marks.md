# 11 · 排版与标记

类型：计划（结果块）
负责：阅读区的字号与段落、期刊排法、作者与机器的字体规则；关键句竖线、读者的划线、页边批注、证据、查找命中、与原文不符的引用；PDF 上的批注
状态：Pending

## Outcome

- 标题明显大于正文；中文与拉丁段落按规格排；摘要上下细线、三线表、编号的图表与公式。
- 作者的文字只有一种墨色；关键句在左页边有一条蓝色竖线（“排版 → 标出关键句”可关）。
- 读者的划线是该批注颜色的笔线；批注写在右页边，用细线连到被划线的那一行；窗口窄了落到段落下方。
- 证据是荧光黄打底加页边的黄色刻度；查找只标命中的词，不再标整段。
- 与原文不符的引用用警示色标出，点开可以看到被引用的那段原文。
- PDF 上：划线与框选画在页面上，批注在页面右边缘内侧用编号圆点表示。

规格：[2.1 字号](../../architecture/web/reading-experience.md#21-字号)、[2.2 段落](../../architecture/web/reading-experience.md#22-段落)、[2.3 期刊排法](../../architecture/web/reading-experience.md#23-期刊排法)、[2.4 作者与机器](../../architecture/web/reading-experience.md#24-作者与机器)、[2.5 标记](../../architecture/web/reading-experience.md#25-标记)、[3.4 原文](../../architecture/web/reading-experience.md#34-原文)（页边部分；要点标签在 14）、[3.5 PDF](../../architecture/web/reading-experience.md#35-pdf)（批注部分）。

08 的 8.1–8.3。

## Tasks

- [ ] **11.1 字号与段落**：规格第 2.1 节的表，全部以阅读字号的倍数表示；第 2.2 节的中文与拉丁段落设置与不可断开的单元。
- [ ] **11.2 期刊排法**：规格第 2.3 节：编号标题、摘要细线、文章信息收起、三线表、图与图注、组图、公式、页脚注。现有的表格与公式渲染只改样式。
- [ ] **11.3 作者与机器**：正文元素按来源标 `data-origin="author"` 或 `"machine"`；字体按规格第 2.4 节。
- [ ] **11.4 字号规则测试**：`design-rules.test.ts` 对阅读区（以容器标记识别）改为检查规格第 2.1 节的字号集合，阅读区以外照旧检查七种字号；增加“作者的文字用衬线、机器与界面用无衬线”的检查；`--reader-check-fail` 在两种主题纸页上的对比度 ≥ 4.5:1。
- [ ] **11.5 关键句竖线**：在原文的左页边按规格画竖线；“排版 → 标出关键句”开关；关键句的数据在第三次交付才有（14），本块用合成数据实现与验证。
- [ ] **11.6 读者的划线与页边批注**：划线颜色取该批注颜色的标签文字色；近似位置用虚线；页边批注、颜色方块与引线；避让规则（相隔 10 px、挤离超过 120 px 时只显示第一行）；窄档落到段落下方。
- [ ] **11.7 证据与与原文不符的引用**：证据标记的真实数据从哪个读取来，等 01 的 1.8；与原文不符的引用取 `material-points` 依据里的核对结果（14 接上）；证据的荧光黄与页边刻度；与原文不符的引用按规格（波浪线、“与原文不符”、点开显示被引用的原文）；数据在第三次交付才有，先用合成数据。
- [ ] **11.8 查找只标命中的词**：替换 `document.ts` 中整块加 `reading-match` 的做法，命中用 `--hl`，当前命中用 `--hl-current`；PDF 照现有的词级高亮；查找栏打开时书脊刻度标出命中（10 的 10.4）。
- [ ] **11.9 PDF 上的批注**：划线与框选画在页面上；页面右边缘内侧的编号圆点，悬停或点击以浮层显示笔记。
- [ ] **11.10 左页边的位置**：段落编号“¶n”；为要点标签（14）与疑点（计划 21 的 10.4）留出位置与样式。
