# 04 · 阅读位置

类型：计划（结果块）
负责：锚点、版面变化中的位置保持、PDF 与全文共用位置、跳转后返回、按资料记住
状态：Completed（2026-11-15）

## Outcome

- 改字号、开合信息栏、改窗口大小、图片与公式载入、后台刷新、打开或关闭查找时，读者正在读的那一段留在原处。
- 从全文切到 PDF 或反过来，落在同一段；对应不上时停在最接近处，并用一行说明告诉读者。
- 点出处、目录、批注等跳转之后，可以回到原处（Alt+← / Alt+→）。
- 关掉再打开同一份资料，回到上次的视图和位置；文本换了版本时尽量找到最近的位置。

规格：[4.1 锚点](../../architecture/web/reading-experience.md#41-锚点)、[4.2 必须保持锚点的变化](../../architecture/web/reading-experience.md#42-必须保持锚点的变化)、[4.3 视图之间共用一个位置](../../architecture/web/reading-experience.md#43-视图之间共用一个位置)（本块只做原文与 PDF 两条；脉络与概览在 14）、[4.4 跳转后返回](../../architecture/web/reading-experience.md#44-跳转后返回)、[4.5 按资料记住](../../architecture/web/reading-experience.md#45-按资料记住)。

## Tasks

- [x] **4.1 锚点模型**
  - 按规格第 4.1 节实现锚点块的选取和锚点记录（全文：文档版本加块的起始字节；PDF：页码加文字块，没有结构信息时页码加纵向比例）。
  - 阅读线在第一次交付期间按[规格第 10 节](../../architecture/web/reading-experience.md#10-新版面之前的规则)：可见滚动区高度的 28%，从上沿量起。第二次交付时上沿改为页眉细线（08 的 8.3）。两者只差上沿，写成同一个参数。
  - 纯计算部分写成不依赖 DOM 的函数，便于直接测试。
- [x] **4.2 版面变化中保持锚点**
  - 规格第 4.2 节列出的每一种变化：变化前测量，变化后同一帧、绘制之前恢复。
  - 锚点上方的块尺寸变化（图片、公式、表格、续载）用 `ResizeObserver` 在同一帧补偿；不依赖浏览器的 `overflow-anchor`。
  - 分批载入的长文档上，续载发生在锚点下方时不移动；发生在上方时补偿。
- [x] **4.3 原文与 PDF 共用位置**
  - 切换视图时，按规格第 4.3 节的前两条换算锚点：原文 → PDF 用块的页码与区域，再用 `mark-locate.ts` 的文字比对确认；PDF → 原文反向查找。
  - 对应不上时停在之前最近的有对应的块，显示规格给出的说明（第一次交付期间在状态栏里，规格第 10 节）。
- [x] **4.4 跳转记录**
  - 规格第 4.4 节列出的跳转之前压入记录（每份资料最多 20 条）；“↩ 回到 ¶n”在第一次交付期间按规格第 10 节是浮在内容区右上角的小按钮，不占一行；Alt+← 后退、Alt+→ 前进。
  - 一屏以内的跳转平滑滚动，更远的直接到位并闪一次底色（时长取现有令牌）；减少动效时一律直接到位。
- [x] **4.5 按资料记住**
  - 用 `localStorage` 按规格第 4.5 节保存与恢复：键包含文献库标识与文献标识，最多 300 份，最近使用淘汰；读写都包在异常处理里，浏览器禁止存储时照常工作，只是不记住。
  - 文档版本变化时按起始字节找最近的块；找不到时从开头打开并显示规格给出的说明。
  - `state.ts` 现有的会话内状态并入这里，不保留两套。

## 集成与影响

- 用户可见：阅读位置不再丢；关闭再打开回到原处。
- `localStorage` 是本机浏览器的数据，不进服务端，不导出；文献删除时不主动清理，按 300 份淘汰。
