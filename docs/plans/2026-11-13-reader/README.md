# 计划 24：阅读页

类型：计划
负责：ADR 0061 与 ADR 0062 在 Web 阅读页的落地，按阅读体验规格交付
状态：Pending（2026-11-13 计划编写完成；01 的 1.1、1.2、1.3、1.5、1.6 已写进规格，1.4 未完成；02–18 未开工；技术可行性未验证；功能未交付）

## 目标

按[阅读体验](../../architecture/web/reading-experience.md)（下文简称“规格”）重做 Web 阅读页，分三次交付，次序按 [ADR 0061](../../architecture/decisions/0061-reading-first-reader-and-layered-reading.md) 的“后果”：

1. **第一次交付：读起来顺**（03–07）。样子不变。阅读位置在每一种版面变化中保持；PDF 与全文共用一个位置；切换视图或资料不拆掉阅读器；PDF 缩放与滚动不露空白；加载有骨架和进度；后台刷新不推动正文；打开资料时进入它实际具备的视图。
2. **第二次交付：新的样子**（08–12）。案头、纸页、页眉、顶栏、右侧面板、书脊、排版与标记、专注模式（[ADR 0062](../../architecture/decisions/0062-reader-visual-manuscript-on-a-desk.md)）。
3. **第三次交付：按理解的过程读**（13–18）。概览、脉络、按问题阅读的回答块、关联标签页、长资料的按章视图。

### 为什么这样分

- **01 单独一块、由总设计师负责**：规格里写不清的地方必须先补进规格，实施者不自行决定。
- **02 放在最前面**：每一块的验收都要截图和数字，截图脚本现在起不来，数字现在没有基线。
- **第一次交付拆成 03–06**：拆掉阅读器、位置、PDF 画面、打开与加载是四个独立可见的结果，各有自己的检查（规格第 8.2 节的不同行），任一块失败不影响其余块合入。03 在最前面：位置、PDF 画面和不出现空白都以“不拆掉”为前提。
- **第二次交付拆成 08–11**：骨架（纸页与顶栏）、右侧面板、书脊、排版与标记分别可以截图验收。后三块只依赖骨架。
- **第三次交付按加工结果的来源拆**：13 是读取层与合成结果；14、15、16、17 分别等计划 16 的不同块（见下节），能各自在合成结果上验收、在真实结果到来时各自接上。
- **每次交付一个验收块（07、12、18）**：交付是 Owner 看效果的单位，审阅的材料、数字和部署都在那里汇合，不散在各块。
