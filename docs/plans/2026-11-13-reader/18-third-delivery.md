# 18 · 第三次交付：验收与收尾

类型：计划（结果块）
负责：第三次交付的汇合检查与 R3；全量；规格改为现状；指南；可选的部署
状态：Pending

- Owner 看到概览、脉络、按问题阅读与库内关联、长资料按章阅读，在合成结果上完整可用；计划 16 已交付的部分在真实结果上可用。

- 前端实施者：汇合检查、全量、截图、审阅材料、指南。
- 总设计师：R3；把规格第 9 节改为现状，并删去已经实现的“目标”说法；检查页面规格与设计内核与实现一致。

- [ ] **18.1 汇合检查**：测量工具的全部检查与规格第 8.1 节的全部直接测试；与 07、12 的数字对比，不退步。
- [ ] **18.2 截图**：规格第 8.2 节“截图”一行的全部页面，三种尺寸、两种主题；另加 13 的 13.3 列出的状态：能力不可用、只有阅读层可用、只读部署（含提问框的已答问题列表与“不能发起新的回答”）、脉络建在别的版本上（概览、脉络、原文各一张，含出处角标展开显示原版本原句）、阅读层加工进行中与等待确认。

- [ ] **18.7 可选：部署**（须 G-deploy）。
- [ ] **18.8 计划收尾**：根 README 记录最终版本、残余风险与未接真实结果的部分；计划状态改为 Completed，或在计划 16 未交付部分上改为 Partial 并写明剩余的退出条件。
