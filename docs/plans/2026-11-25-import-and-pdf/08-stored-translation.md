# 08 全文的译文：解析时翻好，存进文献库

类型：计划（结果块）
负责：把全文翻译做成解析全文的一步并存进文献库；阅读页“全文”的原文、译文、对照三种读法；译文的导出、检索与 Agent 读取
状态：Pending（ADR 0068 已接受，可以开工；先写 8.2 的规格）

## Outcome

解析全文之后，一篇文献同时有原文和译文，块与块一一对应。阅读页的“全文”可以读原文、译文或上下对照；Markdown 可以导出三种；用译文的语言能搜到它；Agent 能读到译文。

## 进入条件

- [ADR 0068](../../architecture/decisions/0068-stored-full-text-translation.md)：Accepted，8.2 起以它为准。
- 现状：`apps/server/src/translation/` 已有逐页分块翻译（`fulltext.ts`）与译文缓存；块的编号、类型与章节角色由 document 模块给出。阅读页视图切换现在写“原文 · PDF”。
- 库结构要加表：部署时在正式库上执行须经 Owner 同意（他 2026-11-25 说“库结构改就改呗”，执行前仍确认一次）。
- 真实的质量与花费实测等 G-parse。
- 模型并发：整个进程同时发出的模型请求默认只有 3 个，校订、元数据、标签都在用（[05](05-parse-throughput.md) 的 5.1）。翻译加进来会抢同一组名额，8.3 要定翻译用多少并发、名额是否随之调整，8.8 要量解析全文因此慢了多少。

## 责任边界

复用现有的分块翻译逻辑与提示词；不改校订稿、块的编号与证据定位。划词翻译与它的缓存不动。分层阅读（概览与脉络）不在本块。

## Tasks

- [x] 8.1 审定：Owner 2026-11-25 接受 ADR 0068（“其他的都依你的想法即可”）。
- [ ] 8.2 规格（总设计师）：
  - 文档与证据、存储两篇技术篇：译文怎样按文献、全文版本、块与语言记录；全文改动后哪些块重翻；“译文语言”设置；怎样判断全文已经是译文语言；表格怎样处理。
  - 任务协调：翻译作为解析全文的一步，进度、失败与重试，用量估算。
  - [阅读体验](../../architecture/web/reading-experience.md)与[页面规格](../../architecture/web/page-specs.md)：视图“全文 · PDF”，全文的三种读法在哪里切换、对照怎样排版、没有译文时怎样说明；界面用词表里“原文”的含义。
- [ ] 8.3 后端：存储与翻译步骤。译文的表（一次库结构追加）；解析全文加入翻译一步，排在渲染之后、元数据之前；失败不使解析全文失败，记进需处理；已有全文没有译文的文献，再次解析全文只补这一步；用量估算包含翻译。
- [ ] 8.4 后端：读取与导出。读取全文的接口加“原文、译文、对照”；Markdown 导出三种；CLI 与 MCP 同步；PDF 视图的对照翻译改读文献库里的译文。
- [ ] 8.5 前端：阅读页。“原文”视图改称“全文”；三种读法的切换与记住选择；对照的排版；没有译文时的说明；页眉右侧的文字随之改。
- [ ] 8.6 后端：检索。全文检索的索引加入译文，命中回到对应的原文块；结果里标明命中的是译文。
- [ ] 8.7 Skill 与指南：`skills/sciretriever/use.md`、[代理接口指南](../../guides/agent-interface.md)、建档指南、Web 指南。
- [ ] 8.8 实测（G-parse）：选 6 到 10 篇不同学科、长短不一的文献解析一遍，记录翻译这一步的花费与耗时、缺译的块数；抽查术语前后是否一致、公式与图注的质量。结论决定要不要按章节给上下文或加术语表。
- [ ] 8.9 部署：库结构追加经 Owner 同意后执行；部署后在一篇已有全文的文献上补译文并在页面上看三种读法。

## 集成与影响

解析全文多一步，花费与耗时增加；库结构加表；阅读页的视图名称变化；ADR 0051 的全文译文缓存文件退役。

## 验证

- 离线：假模型下，翻译步骤的成功、部分缺译、失败不挡全文、只补缺的一步、全文改动后只重翻变了的块，各一条服务端测试；读取与导出三种各一条；检索用译文语言命中并回到原文块一条。
- 页面：三种读法切换、对照排版、没有译文的说明；在样例库上截图看一遍。
- 真实：8.8。

## 退出条件

新解析的文献自带译文；三种读法、三种导出、译文检索、Agent 读取都可用；规格、指南与 Skill 同步；已部署。

## 恢复与交接

翻译步骤按块记录进度，中断后从没翻的块继续。8.3 完成而 8.5 未完成时，译文已在库里，阅读页仍按旧的对照翻译显示，不影响使用。
