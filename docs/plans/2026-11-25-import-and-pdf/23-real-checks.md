## 进入条件

## 责任边界

- 负责：总设计师确定口径、核对结论；后端实施者按授权运行；Owner 在自己的电脑上试用。
- 不改：代码与规格。发现缺陷时记录，交回对应的块或作为新问题处理（先分清是缺陷还是设计问题）。
- 只读副本：结束后核对正式库的修改时间与大小没有变化。

## Tasks

- [ ] **23.1 入库试用**（G-trial；原 20 的 11.3）
  - 动作：Owner 在自己的电脑上试用：网页上传一份导出文件连同 PDF 文件夹；用扩展收藏 3–5 个页面；让 Agent 经入库接口导入一小批，并经 HTTP 版 MCP 查一篇文献。
  - 输出：实施者只看批次与报告，核对篇数、文件、冲突，以及再入库一次的幂等；经真实 SSH 隧道上传一个大文件，补验上传不被请求超时掐断（原 20 的 13.1）。
- [ ] **23.2 文件直接入库试用**（G-deploy、G-trial；原 20 的 11.4；等 12）：放置区直接放入 PDF 与文件夹，核对认篇与可能重复的结果。
- [ ] **23.3 真实文件上认出的比例**（并入本计划 [02](02-pdf-only-metadata.md) 的 2.1–2.3，在那里做，这里不重复）（G-files；原 20 的 15.9；ADR 0063“还没有验证的前提”第 2 条）
  - 动作：在 Owner 授权的一组真实 PDF（建议 50–100 篇，包括中文期刊和扫描件）的副本上运行认篇，只在本机进行，不写正式库。
  - 输出：分别统计四步各认出多少、认错多少，以及首页标识被引文献干扰的次数。
  - 验收：结论交总设计师。认错率高到不能接受时，按 ADR 0063 回到决定本身修改，不在实现里自行放宽。
- [ ] **23.4 可能重复的误报与漏报**（G-lib；原 20 的 16.6；ADR 0063“还没有验证的前提”第 3 条）
  - 已有：合成库上误报、漏报各 1/21，阈值不变（原 20 的 16.6）。
  - 动作：在正式库的只读副本上，对一份已知答案的条目集运行判断，统计误报与漏报。
  - 验收：结论交总设计师；不能接受时按 ADR 0063 回到决定修改。
- [ ] **23.5 Agent 重新试跑**（无门槛；原 20 的 6.12）
  - 动作：起一个全新的 Agent，只给“复制给 Agent 的话”，对合成的文献库完成一次入库，包括后台确认与交文件；再用 HTTP 版 MCP 查一篇文献。
  - 输出：试跑记录追加到原 20 的 06 的“试跑记录”表的后面（写在本块）。
  - 验收：一次通过；令牌没有出现在输出里。
- [ ] **23.6 撤回试用**（G-deploy、G-trial；原 20 的 11.6；等 12.7、13）：Owner 撤回一个试用批次，核对移除与保留的内容。
- [ ] **23.7 初稿的疑点（E1）**（G-lib，不调用模型；原 21 的 11.1、11.2）
  - 样本：从副本里有文字层、已有初稿的文献中分层抽样，写明抽样规则：至少两个差别明显的学科；出版社、年代不同；含表格多的、公式多的、有扫描页的、超过 50 页的长文档各有一些。建议约 30 篇，篇数由 Owner 在授权时确定。
  - 前提：现在正式库只有 3 篇有初稿；其余有原始解析的 70 篇要重新解析才能形成初稿（会调用 MinerU，Owner 决定）。样本不足 30 篇时，先用已有的，报告写明。
  - 测量：形成成功率与失败原因；每页耗时；每篇疑点片段占有文字层片段的比例，每页差异处数（中位数、P90）；`no-text-layer` 片段与扫描页的比例；按区块类型（正文、表格、公式、图注）分别统计，表格单列。
  - 人工抽查：随机取疑点片段，对照 PDF 原图，分为真错误与写法噪声，得到疑点信号的准确率；随机取“与文字层一致”的片段，对照原图，看是否漏掉错误。每类抽查篇数写进报告。
- [ ] **23.8 初稿与校订稿的文本（E2）**（G-model；原 21 的 11.3）
  - 对约 10 篇样本建档（含已建档的 3 篇），得到校订稿。发起前用 `usage-estimate` 给出调用数与 token 估算，Owner 定上限，超出即停。
  - 测量：两级文本逐片段的词级差异率；校订改字落在 `text-layer-differs`、`text-layer-match`、`no-text-layer` 片段中各多少；校订花费与估算对比。
- [ ] **23.9 评估报告**（原 21 的 11.5）：E1、E2 的数字、方法、样本清单（只写文献 ID 与书目，不含全文）、典型例子、未覆盖的范围。放 `sandbox/reports/`，摘要写进本块。交 Owner 决定：是否调整对比规则（升初稿方法版本）；是否另立“只校订疑点页”的工作。
- [ ] **23.10 Semantic Scholar 经代理**（G-sources；原 18 的残余）：2026-11-05 经代理 CONNECT 成功、目标返回 429（匿名额度）。在匿名额度恢复后于同一沙箱复测，或由 Owner 在正式配置下测试；结论写进本块。
