# 01 · 检索与固定来源导航

状态：Pending。Outcome：当前正式工作台的三种检索模式正常返回；从命中打开文献时保留固定来源身份，后续阅读器可以接收精确定位信息。

## 进入条件与责任

读取根计划、ADR 0028/0032/0033 和当前工作树。修改范围为 `workspace/retrieval.ts`、`workspace/app.ts`、`workspace/types.ts`、必要的文献导航及直接测试；知识用途和证据合同仍由 `packages/contracts` 拥有，不放宽校验绕过故障。

## Tasks

- [ ] **1.1 · 固定实施基线与场景。** 按处理器、Web 决策/计划和其它来源核对 tracked/untracked 改动，形成限定源码/文档清单及实际验证记录，不假定全部脏文件都属处理器。优先准备独立提交的精确范围，只有取得明确授权才暂存/提交；未提交时将 HEAD、相关 tracked patch、未跟踪源码副本及哈希保存到系统临时目录，并在临时副本验证可以重建，不能只有不含新文件的 git diff。不得复制用户凭据、catalog 或 ignored 资产；未知归属的重叠改动先保留。随后准备含原文、旧知识、旧综合、两个文档版本和缺材料条目的合成库，使用正式 `live.ts` 打包入口。记录现有日常业务测试入口，不把独立 query 页通过代替主工作台通过。
- [ ] **1.2 · 修复三种检索请求。** 依赖 1.1。按共享合同为“仅知识”和“原文与知识”提供明确、非空的用途选择；“仅原文”保持不带知识选择。以 UI 选择派生合法请求，不改变服务端用途语义。测试真实点击后三种模式都发送正确请求并返回相应结果，覆盖空结果、索引不可用、分页、取消及晚到响应；查询不能调用模型或写入业务事实。
- [ ] **1.3 · 固定来源与返回上下文。** 依赖 1.2。整理有类型的 Web 导航状态：文献、文档版本/hash 与 DocumentSelector、旧知识或新结果引用、来源页与必要查询参数。打开命中时使用其固定引用，不能只传文献 ID 后重新选择默认版本；URL/页面状态不携带整份正文或任意 JSON。验证默认版本更新后旧命中仍进入原版本，返回检索恢复问题、范围和结果选择，浏览器后退不会触发加工。输出供 03/04 使用的导航约定与测试，不新增持久业务事实。
- [ ] **1.4 · 保住既有业务入口。** 依赖 1.1–1.3。运行现有正式 Web 的库、解析/分析、配置和 Browser 定向回归，复核只读部署和缺能力提示。记录哪些高级功能已有入口而非再次实现；与本轮改动有关的回归在此修复，未相关的外部环境问题如实记录。
- [ ] **1.5 · 中文与跨语言检索提示。** 依赖 1.2。在检索页明确当前为词法关键词匹配；检测含汉字的输入时显示不阻断的提示，例如“当前不会自动跨语言匹配；检索英文原文可尝试原文关键词”。保留原始输入和正常检索，不能统一改写为英文、拒绝中文或把空结果解释成库中没有该知识。覆盖英文原文、连续中文字符串、可匹配的独立中文 token、中文生成知识及中英混合查询，记录实际 AND/分词语义；前端提示不改变合同。验证无隐式模型/翻译调用，英文关键词可找到对应英文材料，合法中文仍可命中。查询翻译/同义词生成作为后续显式辅助操作讨论，不在本任务自动启用。
