# 04 · 连续阅读与辅助核查

状态：Pending。Outcome：用户无需启动加工即可连续阅读已有 PDF 或解析文档，在多文献间切换保留位置，并从知识/记录证据往返原文。

## 进入条件与责任

1.3 提供固定来源导航约定；4.5 集成新记录证据时依赖 3.3。主要触达 `document-reading.ts`、`knowledge.ts`、`workspace/library.ts`、`app.ts`、`types.ts`、`public/workspace.css`；必要的依赖、worker 和离线资源经 `scripts/build-workbench-assets.mjs`、静态资产路由及正式安装包交付。Document/Storage 仍负责材料、版本、资源与证据读取，前端只负责渲染和 UI 状态。

## Tasks

- [ ] **4.1 · 阅读技术验证、样稿与 G3 确认。** 以下子任务完成并取得 Owner 确认后才关闭 4.1；技术选型通过不等于交互已确认。
  - [ ] **4.1.1 · 受控技术与性能验证。** 以 PDF.js 为可控 PDF 渲染候选，验证 Node 22 构建、模块/worker、文字层查找、页码/缩放控制和离线资源；验证安全 Markdown/数学排版组件。记录实际版本、许可、体积及 CSP/安装影响。在隔离验证入口上按下述口径测量合成 100 页 PDF 和全文样本，产出基线及可行方案；失败时记录替代与缺口，不将原生 iframe 回退写成目标已达标。
  - [ ] **4.1.2 · 阅读样稿与 Owner 讨论。** 依赖 4.1.1。沿原型的阅读标签和 PDF/全文/总结骨架，提供连续阅读与带问题核查的局部可点击样稿或关键状态截图，明确工具栏、目录、辅助知识、位置恢复、证据返回及窄屏收纳。把基准测量、建议的首屏/交互时间目标和仍有限制一起交给 Owner 讨论；记录确认版本、性能口径和反馈到 Web 专项设计说明并更新导航。保留附件原型，未确认不得开始生产阅读 UI，仍可推进不依赖该设计的接口/测试工作。
- [ ] **4.2 · 接入可控 PDF 阅读。** 依赖 4.1/G3。消费已按 asset_id/hash 验证的固定 PDF 字节；保留当前完整性和大小边界，不加载任意远程 URL。提供页码/翻页、缩放/适宽、可用目录与文档内查找，建立可保存的位置事件；只渲染可见及附近页面，关闭或换文献时释放不再使用的 worker、对象 URL、canvas 与监听器。扫描 PDF 无文字层、损坏/加密文件、缺目录和 worker 加载失败有明确反馈，可下载同一已核验原文件，但回退不算全部目标达标。
- [ ] **4.3 · 连续排版解析全文。** 依赖 4.1/G3，按以下三个可独立验证的子任务执行，全部完成才关闭 4.3。
  - [ ] **4.3.1 · 安全排版与资源。** 将原始 pre 文本转为章节、正文、列表、表格、公式及上下文图片；资源只走固定文档受控读取，不直接执行原始 HTML/脚本或自动请求外部资源。用静态合成全文验证渲染、无标题正文、缺图片及错误资源，不把缺失表示为完整成功。
  - [ ] **4.3.2 · 渐进装载与取消。** 依赖 4.3.1。沿片段/范围 continuation 有界读取，不一次拉取无限正文；目录和查找说明已加载范围。验证表格/公式/Unicode 跨分块仍完整、切换选择后旧响应不覆盖新内容、取消释放请求、加载更多不重复或遗漏正文。
  - [ ] **4.3.3 · 来源映射与定位。** 依赖 4.3.1 和 1.3，集成验证另需 4.3.2。保留 segment/range 对原 UTF-8 的映射，渲染后的 DOM 索引不能替代证据偏移。用包含数学式、链接、表格及多字节字符的样本验证引用进入正确原片段；无坐标时不猜 PDF 位置，能力缺口可辨。输出供 4.5 使用的定位接口。
- [ ] **4.4 · 多文献位置与返回状态。** 依赖 4.2/4.3 和 1.3。为每个打开标签保存阅读模式、PDF 页码/缩放、全文语义位置和滚动偏移、目录选择及来源页面上下文；键包含当前库身份、固定资产/文档版本与 hash。先保证同一工作区会话的内存状态与浏览器导航，主题等已有持久偏好继续保留，不新增永久阅读历史。修改当前重建 reader 的生命周期，返回标签时恢复状态，晚到请求不能覆盖新文献；同一论文不同版本不共用错误位置，关闭标签释放状态。
- [ ] **4.5 · 辅助知识与证据往返。** 依赖 3.3、4.3/4.4。在可收起的辅助区域读取已有摘要、分析和相关处理器结果；旧知识仍使用其 reader，新结果按 content.kind/引用读取。点击结论或字段证据打开固定解析文档并定位/标记相应片段或实际范围，保留上下文及返回检索/结果表的选择。只有合同确有 PDF 页码/区域时才在 PDF 精确定位；否则展示解析证据并可打开同一 PDF，明确没有坐标。打开辅助区不生成新总结、翻译或分析。
- [ ] **4.6 · 阅读舒适度与操作可达性。** 依赖 4.2–4.5，按 G3 确认的样稿和下述功能/性能口径验收。沿用现有字号与主题默认值，提供阅读字号/行宽及目录/辅助栏收放，控件可通过键盘到达且焦点可见，正文不被固定工具栏覆盖。表格在自身容器滚动；桌面和已有窄屏下主要操作可访问，不以扩展批注/翻译的无效按钮填充界面。
- [ ] **4.7 · 真实页面阅读验收。** 依赖 4.2–4.6。在断开外网的正式 Chromium 页面执行两种材料的完整旅程，按下述表格记录位置恢复、10 次切换、全部关闭、冷/热加载和交互指标。验证读取失败/取消/版本变化不混用来源，网络请求、任务数和模型调用不因阅读增加，并核对实际构建的 worker/字体/样式。与 G3 确认目标比较，未达到的项目保留未完成，截图或“感觉流畅”不能替代断言。

## 可观测验收口径

以下是测试场景和需记录的观察，不是未经确认的通用 CI 性能阈值。4.1 先固定 CPU/内存、浏览器版本、视口/缩放、合成文件 hash/大小/内容结构、冷/热缓存定义和重复测量方法；G3 根据基线确定该环境的首屏及交互目标，最终在相同条件复测。首屏应分别记录字节读取/完整性校验、PDF 解析和可见页绘制，避免把本地数据大小差异混为 renderer 性能。

| 场景                     | 明确观察与验收                                                                                                                                  |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 100 页合成 PDF 冷/热打开 | 记录首个可操作页面及页码/查找可用时间；不等待全部 100 页 canvas 绘制才允许阅读；时限按 G3 的固定环境目标                                        |
| 文献 A/B 来回切换 10 次  | 页码、缩放、全文片段及返回筛选保持正确；活 worker、canvas 和对象 URL 数量受当前打开/可见页面策略限制，不随切换次数累积                          |
| 关闭全部阅读标签         | 本阅读模块创建的 worker 已终止、对象 URL 已撤销、观察器/监听器/请求及渲染任务已释放；不要求浏览器进程 RSS 立即归零                              |
| 内存观察                 | 记录基线、切换后及全部关闭后的可用 heap/资源统计；缺少浏览器内存接口时明确缺测，至少直接验证模块持有引用和资源计数，不用一次 RSS 波动宣称无泄漏 |
| 桌面布局与控件           | 在 1280×800、1440×900 及已有窄屏用例中检查主操作可达、文字/按钮不重叠，固定控件不遮挡正文，宽表只在内容容器横向滚动；记录实际浏览器缩放         |
| 字号/行宽/主题/侧栏      | 每项控制实际改变对应阅读区域，切换后保留语义位置；所有主要控件键盘可达且有可见焦点，主题下提示和选中状态可辨                                    |
| 证据往返                 | 从字段或结论到正确版本的片段，再返回原记录/检索选择；定位缺口明确，不用后来默认版本补位                                                         |
