# 04 用词：文献库、候选、加入文献库

状态：Done（已部署，见计划 README“部署”）

## 输出

全站界面文字改成[页面规格“界面用词”](../../architecture/web/page-specs.md#界面用词)里新增的几行：文献库、候选、加入文献库 / 已加入、全部文献、找文献、批次与批次记录、最近读过。规格、使用指南与测试里的文字一起改。

## 判断

- “入库”只留在确实把文献放进文献库的地方：导入批次的“确认入库”“结束入库”“不入库”，设备连接的“入库”用途，浏览器下载的“PDF 已入库”。发现任务找到的是候选，所以同时管着发现与导入的东西不再叫“入库”：页面叫“找文献”，一次发现或导入叫“批次”，全部批次叫“批次记录”，排序“最近入库”改为“最近新增”，来源结果的“新入库”改为“新增”，批次状态“入库中”改为“进行中”。
- 洞察页的“全部文献库”原来读的是文献库加候选，名字和内容不符。现在它读的就是文献库，写“整个文献库”；候选只在地址自己带着条件时才进洞察。
- 候选行在书目末尾写“候选：来自引用扩展”，没有来历的只写“候选”；行上的动作是“加入文献库”，按过之后写“已加入”。
- 在文件夹等视图里搜索时，范围单选的第二项由“整个文献库”改为“全部文献”，因为它查的是文献库加候选。

## 没改的

命令行、MCP、接口字段与技术文档里的内部名（collected、discovered、intake）不变，照“界面用词”一节开头的规定。
