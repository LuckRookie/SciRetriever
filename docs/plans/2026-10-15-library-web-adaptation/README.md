# 定稿 Web 原型接入

状态：已完成现有 Web 能力适配与离线验收。授权：Owner 要求直接按当前定稿 HTML 适配现有 Web 及功能，不重新设计页面。

设计依据：[当前定稿原型](../../architecture/web/README.md)与 [ADR 0032](../../architecture/decisions/0032-library-centered-web-workspace.md)。原型保留为设计真相源，正式页面从其外框、样式和渲染结构适配；示例数据与模拟执行由真实应用服务替换。

## 工作切片与恢复入口

1. 接入原型外框、样式与导航；统一认证 transport，区分加载、空库和失败，保留查询无副作用。
2. 文献列表、分面筛选、选择范围、预览与阅读标签；PDF、文档、知识和证据来自同一库，上传与处理显式提交。
3. 发现/书目导入、检索与上下文、综合、洞察和提取交付；保留原 owner，未实现的原型扩展不伪装为成功。
4. 任务列表/详情、活动抽屉、Browser 会话画廊与真实画面直接交互；校验会话/文章/epoch/观察版本，交还确认后再关闭。
5. 配置与高级工具复用既有能力；同步使用文档和直接测试，完成浏览器旅程、Quick、Full 及构建资产核对。

各切片依次集成。测试只使用合成临时 home/数据库、fake 或 loopback；不读取真实用户配置/凭据或语料。原型中的批次历史、标签与统计只投影已有事实，不另建业务状态。保存视图和主题可作为有版本、按当前库隔离的浏览器 UI 偏好，不写 catalog。

## 完成条件

- 正式入口使用原型的资料/使用/运行导航、文献列表、按需预览、阅读标签和活动界面；样式与参考一致。
- 所有既有 Web 业务能力可访问，原型模拟数据、模拟 Browser、假成功与假计数不进入生产路径。
- 直接测试证明真实库读取、显式写入、结果回查与控制互斥；既有保护结果的测试继续有效。
- 相关测试、Quick、Full 通过，当前指南与实际行为一致；未实现的产品扩展如实说明。
