状态：Completed（2026-10-08）。Owner 于 2026-10-08 授权修复 DOI/API 路径问题，并优先实现功能审查中的第 4、6 项。

## 目标与依据

使合法 DOI 请求通过共享 Network；使下载后的文章身份有可追溯、非阻断的核验结果；
使外部 Agent 通过正式协议提交、查询和控制已有产品操作，并复用 durable 执行机制。
依据 R3/R4/R8/R11、ADR 0019/0025/0028/0029。下载不新增身份门槛，查询不隐式加工或扩库。
需要增加的身份结果和执行合同先同步所属技术文档，保持兼容读取和事实 owner。

## 范围和授权

- 修改源码、直接测试、生产组装、公开调用说明和必要合同；运行离线相关测试与 Full。
- 保留既有 `.gitignore`、文档索引及 Web 提案/原型改动，不处理 Web、解析科学质量、检索排序和额度持久化。
- 不访问个人配置、凭据、真实 catalog 或文献；不启动外部 Provider/模型测试，不执行 Git 写操作。
- 新持久化如需 schema 升级，提供显式升级、旧版读取和合成库验证；不迁移用户库。
