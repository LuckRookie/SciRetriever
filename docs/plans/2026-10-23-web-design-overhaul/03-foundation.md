# 03 · 视觉基础：字体、字号、颜色、间距与组件

## Outcome

[设计内核 · 改版草案](../../architecture/web/design-core.md#改版草案计划-14待审阅确认) §1–5 落地：中英文都有内置字体且离线可用；全站只用一套字号、间距与颜色角色；每种共享组件只有一种外观，组件画廊展示全部变体与状态。R1 获 Owner 确认后，草案 §1–5 并入设计内核正文。

## 进入条件

02 完成，改版前基线已截。

## 责任边界

- Claude：预审每个单元的截图与 diff；R1 后把草案 §1–5 并入设计内核正文。
- worker：3.1–3.6 实现。拥有 `apps/web/src/app/styles/`、`components/`、组件画廊、字体资产与生成脚本；页面文件只做因组件变化而必须的调整（逐页改版在 05）。

## Tasks

- [ ] **3.1 中文字体**〔worker〕：按草案 §1 取得字体、生成切片、在 `font-faces.css` 引入；生成脚本进仓库、生成物提交、构建不联网；许可证、来源、版本与校验值写入前端依赖说明（`docs/notes/web-frontend-dependencies.md`）。测量安装包体积差与首屏中文切片下载量，对照草案 §1 的预算。
- [ ] **3.2 令牌**〔worker〕：按草案 §2–4 落实 `tokens.css`（四个主题）；删除页面 CSS 中自带的字号、颜色与间距数值，改用令牌。输出“令牌外数值”清单，剩余项逐条说明原因。
- [ ] **3.3 组件**〔worker〕：按草案 §5 统一 `components/` 与 `styles/components.css`；页面里自绘的同类控件改用共享组件。
- [ ] **3.4 组件画廊**〔worker〕：按草案 §5 的组件表分节展示每个组件的全部变体与状态（默认、悬停、聚焦、按下、禁用、加载、错误），四个主题可切换；画廊加入设计样例库的页面清单。
- [ ] **3.5 设计审计规则**〔worker〕：扩展 `design-audit` 测试，在样例库上检查：只用草案 §2 的字号；字体族只来自令牌；每页主按钮不超过一个；不存在嵌套的标签栏；正文文字对比度不低于 4.5:1；可点击元素有悬停与焦点样式。
- [ ] **3.6 R1 审阅包**〔worker 产出，Claude 预审，Owner 确认〕：`capture --label r1`，含组件画廊、文献库、阅读页、任务三页（1440 与 390）；页标题衬线与无衬线各一套（临时 `data-title-face` 开关，R1 后删除）。Claude 预审通过后连同改版前截图一起交 Owner。
