# 04 · 信息架构、页面模板与任务页

## Outcome

[页面规格 · 改版草案](../../architecture/web/page-specs.md#改版草案计划-14待审阅确认) §1–3 与[设计内核 · 改版草案](../../architecture/web/design-core.md#改版草案计划-14待审阅确认) §6 落地：侧栏按人的工作重组、旧地址自动跳转；全部页面使用同一页头模板与空状态写法；任务改为表格加抽屉，Agent 会话从任务进入。R2 获 Owner 确认后，草案并入规格正文。

## 进入条件

03 的 R1 已确认。

## 责任边界

- Claude：预审；R2 后把页面规格草案 §1–3、设计内核草案 §6 并入正文，并同步 Web 指南的侧栏描述。
- worker：4.1–4.5 实现。拥有外壳（`shell/`）、路由、侧栏、页头与空状态组件；任务、Agent、建档问题三页的结构调整。各页内部的细节改版在 05。

## Tasks

- [ ] **4.1 侧栏与路由**〔worker〕：按页面规格草案 §1 调整侧栏、计数与“需处理”入口；旧地址重定向；键盘导航与当前项标记。
- [ ] **4.2 页头与空状态**〔worker〕：按页面规格草案 §2 改 `PageHeader` 与 `EmptyState`，全部页面换用；页头说明句逐条处理去向（删除、改为界面状态、移进提示），在交接记录列表说明。
- [ ] **4.3 需处理视图**〔worker〕：原建档问题页内容迁入文献库框架，形态不变。
- [ ] **4.4 任务表格与抽屉**〔worker〕：按页面规格草案 §3 与设计内核草案 §6 实现任务表、进度条、详情抽屉、任务内的 Agent 会话、“Agent 会话”分段视图与窄屏形态。
- [ ] **4.5 R2 审阅包**〔worker 产出，Claude 预审，Owner 确认〕：`capture --label r2`，全部页面清单。

## 集成与影响

URL 与导航结构变化；依赖旧入口名称的测试需改写。不改数据接口。

- 键盘：侧栏、任务表、抽屉均可只用键盘操作，抽屉关闭后焦点回到原行；
- 截图：R2 包。

## 退出条件
