# 11 Web 界面

状态：In progress（4/9；已有界面与离线旅程不等于第二版达标；11.3、11.4、11.7、11.8、11.9 待完成）。执行者：worker。

**Outcome**：

在 Web 上可以完成以下操作：
- 查看文献的建档状态，处理问题队列；
- 在阅读器中查看校订稿：显示核对依据与存疑，并可以对照初稿与矫正记录、高亮 PDF 上的区域、修正区块；
- 查看和修改元数据的字段来源、冲突与锁定；
- 管理标签：浏览词表、查看变更日志、撤销、回溯；
- 用筛选条件生成快照，比较快照，运行单篇或多篇算子，查看结果的四种状态和过时标记。

所有界面都使用已有的 React 前端、设计语言 v2 和组件库。CLI/MCP 中的每项能力，在 Web 上都有对应入口（ADR 0033）。

**进入条件**：
- 各页面所依赖的接口已经由对应的块交付；
- 可以逐页接入，但要在 10 完成后统一收口。

**责任边界**：
- 本块负责：
  - `apps/web/src/app/features/` 下的 `library`、`reader`、`processing`、`synthesis`、`tasks`、`settings`；
  - 新增的 `archive` 与 `tags` 功能目录；
  - 服务端 workbench 的 API 路由与视图事件，只做接线，不重复业务逻辑。
- 本块不负责：业务规则，这些属于 03–10。

- [x] **11.2 文献库**

  **状态列**：显示六种状态。`ASSET_READY` 同时显示下一步：待解析或待建档。`EXCLUDED` 显示排除原因（文章性质），可以人工改判。

  | 状态 | 附加显示 |
  | --- | --- |
  | `ARCHIVING` | 当前步骤 |
  | `ARCHIVE_FAILED` | 失败原因摘要，点击跳转到问题队列 |

  **筛选**：
  - 状态，默认只看 `READY`，可以切换；
  - 出版形式、文章性质；
  - 标签：可以选择“主标签”或“任一标签”；选择上级标签时提示“包含下级”；如果该标签有未回溯的文献，提示数量，并提供回溯入口（11.6）。

  **列表中的标签**：按顺序显示，主标签单独强调。

  **批量操作**：发起解析、发起建档、重试失败步骤、从当前筛选生成快照。解析与建档是两个独立按钮，都不会自动触发。

  删除 `document_type` 的筛选。旧的 URL 参数如果出现，忽略并提示一次。

> ADR 0037 第二版（2026-10-20）：校订改为“部署 profile 初稿 → 文字层找疑点 → DSH 看原图矫正 → 存疑不阻断就绪”。本块受影响的 Task 已取消勾选并写明调整内容；其余已完成项保留。

- [x] **11.3 问题队列**（第二版调整）（新页面，属于 `archive` 功能）

  - 按原因分组，显示条目数，支持批量处理。
  - 每类原因有对应的处理界面：

    | 原因 | 处理方式 |
    | --- | --- |
    | 校订未完成或失败 | 打开校订记录（11.4），逐页处置疑点、存疑，或继续校订 |
    | 需要重新解析 | 发起部署 profile 的解析 |
    | 参考文献缺失（不影响就绪） | 可忽略，或修正参考文献章节 |
    | 元数据缺失 | 内嵌字段编辑 |
    | 结构不满足 | 章节角色修正 |
    | 标签为空或无效 | 标签编辑 |
    | 解析失败 | 重试 |

  - 处理完成后，可以直接点击“继续建档”。
  - 显示建档统计：页数、耗时、模型调用（9.9）。

- [x] **11.4 阅读器**（第二版调整）

  - **部分切换**：正文和补充材料以标签页切换。没有补充材料时，不显示切换。
  - **校订稿视图**：
    - 存疑片段始终有轻量标记，悬停显示原因；
    - 打开“显示核对依据”后，用颜色或角标区分 `text-layer`、`image-only`、`uncertain`、`manual`；
    - 只能定位到页的区块，单独标注“仅页级定位”。
  - **校订记录**：点击区块，打开侧栏，内容包括：
    - 初稿原文；
    - 相关疑点及处置、矫正编辑记录；
    - 存疑说明（如有）；
    - 所在页的页面图像。

    侧栏中可以编辑文字、处置疑点或解除存疑，修改后的区块被锁定。修改会产生新的内容版本，所以要提示：读取该部分的结果将被标为过时。
  - **PDF 联动**：
    - 点击片段，PDF 视图跳到对应页，并高亮对应区域；
    - 从证据跳转时，同样会高亮。
  - **大纲**：显示章节角色。可以修正角色，修正后被锁定。
  - **图表清单**与**参考文献列表**：参考文献中已关联到库内的条目，可以跳转。
  - **总结**：显示 `summary` 算子的最新结果。结果过时时，标出“已过时”，并提供“重新生成”。

- [x] **11.5 元数据面板**

  - 每个字段显示取值、来源和锁定状态。
  - 有冲突时，展开显示双方的取值。
  - 编辑后的字段自动锁定，可以解锁。
  - 出版形式和文章性质使用下拉选择，选项是固定的枚举。

- [x] **11.6 标签**

  **文献的标签编辑**：
  - 用拖拽或上下移动调整顺序，第一个即主标签；
  - 达到上限后，不能继续添加；
  - 添加时先搜索已有标签，搜不到再新建，新建时必须填写定义；
  - 编辑后的标签被锁定。

  **词表页面**（新页面，属于 `tags` 功能）：
  - 按类别分组，并显示两层树；
  - 每个标签显示：名称、同义词、定义、使用数、示例文献、创建时的词表版本、回溯状态；
  - 可以手动合并、编辑和新建标签。

  **变更日志**：
  - 按时间列出变更，显示操作者（打标、整理、人工、回溯）、操作、理由和受影响的文献数；
  - 每条都可以撤销。撤销前列出依赖链，并要求确认。

  **回溯**：
  - 先选择标签，再点 dry-run，显示候选文献数和预计调用次数；
  - 确认后才执行，执行进度在任务页显示。

- [x] **11.7 快照与算子**（第二版调整：显示用时核对）

  **快照**：
  - 从文献库的当前筛选生成快照，生成时显示成员数，以及因未就绪而被排除的文献数；
  - 快照列表与详情：显示定义和成员；
  - 选择两个快照，比较差异。

  **运行**：
  - 先选择算子，再选快照或单篇文献；
  - 显示读取声明，例如“读取：正文 · 实验章节”；
  - 多篇算子同时显示它的 `map` 算子。

  **结果**：
  - 分别统计四种状态的数量，`part-absent` 和 `not-reported` 要分开显示；
  - 过时的结果显示过时原因，并提供“基于新快照重新运行”；
  - 报告类结果中的引用，可以一路点到片段和 PDF 区域；
  - 表格类结果中，每个单元格都可以跳转到证据；
  - 每个值显示核对标注（`text-layer`、`image-checked`、`uncertain`），`uncertain` 明显区分。

  “问答标注”（`labels`）的文案统一改为这个名称，不再叫“标签”。
