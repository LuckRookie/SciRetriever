# 18 · 入库页与批次页

类型：计划（结果块）
负责：ADR 0063 第 10 节的网页部分，以及设置页设备连接中的用途
状态：Pending

## Outcome

- 入库页按“文献从哪里来”排列，分为四个部分：从检索（主题发现、引用扩展）、从文件（放置区）、从 Zotero（需要扩展；没有连接扩展时，写明怎样安装和连接）、从网页（说明在文献页面上点扩展）。
- 一个放置区接受 PDF、文件夹与导出文件，并自动识别是哪一种。原来的“上传 PDF”标签页并入“从文件”。
- 入库记录列出全部批次，只有一种行，不论由谁发起。原来的“导入会话”列表并入其中。
- 每个批次一页：预览（含可能重复，以及“可能是这一篇”的选择）、确认、进度、报告（含全文取得情况）、接着做什么、撤回。
- 设置页的设备连接里，用途“收藏”“导入”合成“入库”。
- 界面上不出现“导入会话”。

## Tasks

- [ ] **18.1 现有入库页适配 14 的合同（计入 M1）**
  - 动作：不改界面结构，只把现有的“导入”、会话页、“上传 PDF”与设置页的用途改用 14 的接口与字段。
  - 验收：`next-intake-import.test.ts`、`next-settings-devices.test.ts` 对新合同的假服务端通过；用户可见的文案不再出现“导入会话”。
- [ ] **18.2 入库页的四个部分（等 12.22）**
  - 动作：按页面规格“入库”重排；从 Zotero 部分按扩展是否已连接显示不同内容；从网页部分是说明。
  - 验收：Web 定向测试断言四个部分与它们的空状态；主题发现与引用扩展的流程不变。
- [ ] **18.3 放置区（等 12.12、12.22，以及 15.2）**
  - 动作：接受 PDF、文件夹与导出文件，并自动识别；导出文件与同一次放进来的文件，按导出里写的路径配对；单独的 PDF 成为只有文件的条目；识别失败时按 12.22 提示。
  - 验收：在假服务端上测试四种情形：只放 PDF、只放导出文件、导出文件与文件夹一起放、放进无法识别的文件；断言交给服务端的清单与文件正确。
- [ ] **18.4 入库记录只有一种行（等 12.3、12.22）**
  - 动作：全部批次（检索、文件、扩展、Agent、CLI）用同一种行显示，字段按 12.22；移除原来单独的“导入会话”列表。
  - 验收：不同发起者的批次在列表中格式一致；状态包括“已撤回”。
- [ ] **18.5 批次页：预览、确认、进度、报告（等 12.22、14.6、15、16）**
  - 动作：
    - 预览显示新增、已在库、冲突、可能重复、不接纳、要补的文件、批注与不导入的内容；
    - “可能是这一篇”与可能重复的逐条决定；
    - 确认后显示后台进度；
    - 报告含全文取得情况。
  - 验收：
    - 假服务端给出各类计数，页面显示正确；
    - 逐条决定发出正确的请求；
    - 确认后页面不阻塞，进度随轮询更新；
    - 刷新页面后状态恢复。
- [ ] **18.6 批次页：接着做什么（等 12.19、14.11）**
  - 动作：对这一批获取全文、解析并形成初稿。按需求规2，由使用者发起，并写明会联网或花费。
  - 验收：入库完成后没有任何自动请求；点击后提交的范围是这一批。
- [ ] **18.7 批次页：撤回（等 12.20、12.22、17）**
  - 动作：撤回前显示将移除与将保留的数量与原因；确认后执行；显示撤回报告。
  - 验收：先显示预估，再执行撤回；撤回之后批次状态与报告正确；页面上没有绕过预估的入口。
- [ ] **18.8 设置页：用途“入库”（等 12.6、12.22）**
  - 动作：连接扩展与连接 Agent 时，用途的勾选改为“入库”“读取”“操作”，“操作”仍不默认勾选；扩展安装包与 skill 的下载入口保留。
  - 验收：`next-settings-devices.test.ts` 断言三种用途与默认勾选。
- [ ] **18.9 指南**
  - 动作：Web 指南按新的入库页、批次页与设备连接改写。
  - 验收：指南中不再出现“导入会话”，与页面规格一致。
