# 04 · Zotero 适配器

类型：计划（结果块）
负责：ADR 0058 第 6 节，以及 ADR 0057 第 3 节中书目、标签与首选附件的规则
状态：Pending（等 01、03）

## Outcome

- 适配器把 Zotero 接口返回的 JSON 转成导入记录。本地 API 与网络 API 交来的数据走同一段代码。
- 书目、标识、分组、标签、首选附件都能转换；不导入的内容（笔记、独立 PDF、非 PDF 附件、链接附件等）按种类计数。
- 批注在本块只计数，10 再导入。

## 进入条件

01 的结论与合成样本；03 完成。

## 责任边界

Codex：`apps/server`、`packages/contracts` 及测试，技术文档 03 中 Zotero 适配一节。不改 `apps/web/`、`docs/guides/` 与 skill。

## Tasks

- [ ] **4.1 规格**：Zotero 条目到导入记录的映射规则，写进技术文档 03。
- [ ] **4.2 书目与标识**：
  - 数据里带 Zotero 转换出的 CSL JSON 时用它，经现有的 CSL JSON 规则；没有时按 Zotero 字段映射；
  - 解析 Extra 字段里的 DOI、arXiv、PMID。
- [ ] **4.3 分组与标签**：
  - 分类转成带层级和外部编号的分组；
  - 自动标签转成作者关键词，手动标签转成用户标签。
- [ ] **4.4 文件**：
  - 首选附件：条目带 `links.attachment` 时用它；没有时按 01 的结论自行选取；
  - 引用名用附件编号，带上文件名与 Zotero 给出的 md5；
  - 同一条目的其他 PDF 只计数。
- [ ] **4.5 不导入的内容**：笔记、独立 PDF、非 PDF 附件、链接附件、回收站里的条目，按种类计数并进入预览与报告。
- [ ] **4.6 样本**：把 01 的合成样本移进测试 fixture。

## 验证

直接测试（01 的合成样本）：没有 DOI 的条目、Extra 里的 arXiv 号、多个 PDF、链接附件、独立 PDF、群组库、多级分类与多处归属、两种标签；本地 API 样本与网络 API 样本转换结果一致。定向测试与 `pnpm quick`。
