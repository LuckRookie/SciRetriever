# 06 · Skill 与给 Agent 的说明

类型：计划（结果块）
负责：ADR 0058 第 7 节
状态：In progress（2026-11-11：通用部分完成，6.7 试跑通过；Zotero 直接读取等 01、04）

## Outcome

- 仓库里有文献库自带的 skill：一组 Markdown 文件，随服务构建打包，经 02 的路由下载。
- skill 包含五篇：连接、导入、各来源的取数办法（首版写 Zotero）、使用文献库、失败与恢复。
- skill 不抄接口细节，只指向 03 由服务提供的接口说明。
- 设置页“连接 Agent”里那段可以直接复制给 Agent 的话定稿。
- 一个全新的 Agent 会话只凭这段话和 skill，能对合成数据完成一次导入。

## 进入条件

01 的结论（Zotero 本地 API 怎样读、文件路径怎样取）；03 的 `contract.md` 与 `curl` 脚本；04 完成。“使用文献库”一篇里的 MCP 配置等 07，07 没完成时先留空并在本块注明。

## 责任边界

Claude：skill 源文件与打包，[Agent 接口指南](../../guides/agent-interface.md)，[设计文档](../../architecture/design.md)与仓库 README 中的目录说明。不改服务端的接口。

## Tasks

- [x] **6.1 位置与打包**：skill 源文件放在仓库根下新的 `skills/sciretriever/`；构建时打包成 02 的下载路由读取的产物；目录说明写进 README 与设计文档。
- [x] **6.2 连接**：用连接码换令牌；令牌直接写进只有本人可读的文件，不进对话、不打印；连不上时检查地址与端口映射。
- [x] **6.3 导入**：
  - 会话的步骤，按 03 的 `curl` 脚本整理；
  - 哪一步要先问用户：范围不明确时，以及用户要求把关时的确认；
  - 只导入用户指定的范围；
  - 文件多时用循环批量上传，中断后按服务端的缺失清单继续。
- [ ] **6.4 Zotero 的取数办法**：
  - 在 Zotero 里开启本地 API；
  - 读库、分组、条目与子项；按附件编号取文件路径；
  - 库只在 Zotero 网站上时，用用户的只读 key 读网络 API，key 留在用户电脑上，不交给文献库；
  - 依据 01 的结论，未验证的地方写明。
- [x] **6.5 使用文献库**：怎样配置 HTTP 版 MCP（依据 07 的合同），以及常用的工作流程。
- [x] **6.6 失败与恢复**：重新读取当前状态再继续，不凭旧结果行动；各错误码该怎么办。
- [x] **6.7 试跑**：起一个全新的 Agent 会话（子代理），只给“复制给 Agent 的话”，让它对假的 Zotero 服务和测试用的文献库完成一次导入。记录它卡住和做错的地方，改 skill，直到一次通过。
- [x] **6.8 指南**：Agent 接口指南写设备连接、skill 与导入的入口。

## 验证

6.7 的试跑记录（Agent 的操作过程、导入报告、改了 skill 的哪些地方）记入本块。skill 里的每条命令都对测试服务实际执行过。

## 退出条件

全新的 Agent 会话一次通过导入；skill 里没有与服务端接口说明重复的接口细节。

## 恢复与交接

Agent 反复在同一步做错时，先判断是 skill 写得不清楚，还是接口本身不好用。后者写成对 03 的修改意见，交 Codex 处理。
