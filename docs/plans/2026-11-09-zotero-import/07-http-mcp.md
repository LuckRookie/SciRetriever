# 07 · HTTP 版 MCP

类型：计划（结果块）
负责：ADR 0058 第 8 节
状态：Done（2026-11-10，`bbbd8d5`）

## Outcome

- 文献库在同一个地址上提供 MCP（Streamable HTTP），凭设备连接令牌访问。
- 工具按令牌的用途给出：
  - 读取：stdio 版只读模式的工具，另加读导入会话的状态与报告；
  - 操作：stdio 版 `--maintenance` 模式的业务工具。
- 不经 HTTP 版提供：配置与凭据、设备连接管理、浏览器观看与控制。
- stdio 版 MCP 与 `--workbench-url` 的连接方式不变。
