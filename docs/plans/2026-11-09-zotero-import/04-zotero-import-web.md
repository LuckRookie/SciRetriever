# 04 · 入库页“从 Zotero 导入”与设置页“Zotero”分区

类型：计划（结果块）
负责：ADR 0057 第 2、7 节的 Zotero 界面，以及相应指南
状态：Pending（等 02 的 2.1）

## Outcome

- 入库页新增“从 Zotero 导入”标签页：选来源（本机 Zotero 或网络 API）与库，勾选分类树，看预览，确认导入。
- 不同机时，导入后可选择 Zotero 的 `storage` 文件夹，界面只上传还缺的文件，显示进度，可中断后继续。
- 入库记录显示 Zotero 导入批次与报告。
- 设置页新增“Zotero”分区：本机 Zotero 地址与“测试连接”；网络 API 用户编号、key 与“测试连接”。

## 进入条件

02 的 `contract.md`；上传部分依赖 03 的 3.1。

- [ ] **4.1 页面规格**：入库 · 从 Zotero 导入（三步、预览各项、上传进度、报告）；设置 · Zotero。先写规格再实现。
- [ ] **4.2 设置分区**：读写配置，key 只写不读（与现有凭据字段一致），测试连接结果。
