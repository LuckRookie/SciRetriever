# 06 · 浏览器扩展与设置页“浏览器扩展”分区

类型：计划（结果块）
负责：ADR 0057 第 5 节的扩展本体与第 7 节的设置分区
状态：Pending（等 05 的 5.1）

## Outcome

- 仓库新增 `apps/browser-extension/`：Chrome、Edge 用的 Manifest V3 扩展，构建出一个安装包。
- 用户点扩展按钮时：
  - 读当前页的标识与书目标签（`citation_*`、Dublin Core、`prism.*`，网址里的 DOI 或 arXiv 号）；
  - 显示是否已在库、是否已有 PDF；
  - 不在库时显示标题与作者，可选文件夹，点保存；
  - 读不到标识时请用户手动填写。
- PDF 由扩展在用户浏览器里下载（`citation_pdf_url`，或当前 PDF 页面的地址），再上传；访问 PDF 所在网站的权限在第一次用到时逐站请求。
- 设置页新增“浏览器扩展”分区：下载安装包、生成配对码、已配对设备列表与撤销。
