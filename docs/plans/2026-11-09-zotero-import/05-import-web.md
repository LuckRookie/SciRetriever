# 05 · 设置页“设备连接”与入库页“导入”

类型：计划（结果块）
负责：ADR 0058 第 9 节
状态：Done（2026-11-10，`8e174cb`；随书目上传的 PDF 文件夹等 03c）

## Outcome

- 设置页有“设备连接”分区：
  - 连接浏览器扩展、连接 Agent，勾选用途；
  - 显示连接码，以及一段可以直接复制给 Agent 的话；
  - 下载 skill；
  - 已连接设备的列表、改名与撤销。
- 入库页的“导入”取代现有的“导入书目”：
  - 上传导出文件，可以连同 PDF 文件夹；
  - 列出进行中和最近的会话，包括 Agent 发起的；
  - 会话页显示预览、进度、冲突与报告，有确认和取消按钮，状态实时更新。
- 入库记录里显示导入批次的名称、计数与报告。
- 网页不与 Zotero 通讯，设置页没有 Zotero 分区。

02 的 `contract.md`（设备连接分区）；03 的 `contract.md`（导入与会话页）。

## Tasks

- [x] **5.1 页面规格**：设置 · 设备连接；入库 · 导入（上传、会话列表、会话页的各状态与文案）。先写规格再实现。
- [x] **5.2 设备连接分区**：
  - 生成连接码时选名称与用途，“操作”不默认勾选，并说明它能发起会联网、会花费的任务；
  - 连接码只显示一次，带剩余有效时间；
  - “复制给 Agent 的话”的文本由 06 提供；
  - 设备列表显示名称、用途、创建时间与最近使用时间，可以改名与撤销。
- [x] **5.3 上传导入**：
  - 选择导出文件，格式自动识别，识别不了时请用户选择；
  - 可以再选一个文件夹，浏览器按会话给出的清单匹配文件并逐个上传；
  - 刷新页面后，从服务端的缺失清单继续。
- [x] **5.4 会话列表与会话页**：
  - 列表显示来源、发起者（网页或哪个设备连接）、状态与时间；
  - 会话页：预览各项、确认与取消、文件进度、冲突清单、报告；
  - 待确认的会话写明谁可以确认；Agent 已确认的会话照常显示进度。
- [x] **5.5 入库记录**：导入批次的名称、计数与报告入口。
- [x] **5.6 指南**：Web 指南写导入与设备连接的用法。
