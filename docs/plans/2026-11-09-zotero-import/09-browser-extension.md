# 09 · 浏览器扩展

类型：计划（结果块）
负责：ADR 0057 第 5 节的扩展本体，按 ADR 0058 第 1、2 节连接文献库
状态：Superseded（2026-11-14，由 [19](19-extension.md) 接续；9.1–9.6 的实现见 `d12cdb7`、`e9bdbee`）
ADR 0063 之后：扩展的外壳、连接、读页与 PDF 下载由 19 在原代码上继续。改用入库接口见 19.1；页面标签原样上交见 19.2；弹窗两项见 19.3；从 Zotero 导入见 19.4–19.6。未完成的 9.7（G4 的真实试用）并入 19.8。

## Outcome

- 仓库新增 `apps/browser-extension/`：Chrome、Edge 用的 Manifest V3 扩展，构建出一个安装包。
- 扩展用连接码连接文献库：粘贴一次，记住地址与令牌；地址可以修改；连不上时写明所连的地址，并提醒检查端口映射。
- 用户点扩展按钮时：
  - 读当前页的标识与书目标签（`citation_*`、Dublin Core、`prism.*`，网址里的 DOI 或 arXiv 号）；
  - 显示是否已在库、是否已有 PDF；
  - 不在库时显示标题与作者，可选文件夹，点保存；
  - 读不到标识时请用户手动填写。
- PDF 由扩展在用户浏览器里下载（`citation_pdf_url`，或当前 PDF 页面的地址），再上传。访问 PDF 所在网站和文献库地址的权限，在第一次用到时请求。
- 设置页“设备连接”分区里可以下载扩展安装包。
