# 05 · 网页收藏后端

类型：计划（结果块）
负责：ADR 0057 第 5 节的服务端部分与第 6 节的配对令牌
状态：Pending（等 02）

## Outcome

- 设置页可以生成一次性配对码；扩展用配对码换得长期令牌；服务端只存令牌的加盐派生值，列出设备与最近使用时间，可以撤销。
- 令牌只能调用收藏接口：
  - 按标识查询文献状态（是否在库、是否已有 PDF）；
  - 列出文件夹；
  - 保存书目：页面字段作为来源记录（来源名 `web-capture`），并用标识向元数据来源补全；
  - 上传 PDF。
- 收藏接口按令牌认证，不校验 Origin；其他接口按 ADR 0035 不变。
- 每台设备每天合成一个入库批次（如“网页收藏 2026-11-09”）。
- 服务端提供扩展安装包的下载。

## 进入条件

02 完成（批次、文件夹与来源记录的接口已定）。

## 责任边界

Codex：`apps/server`、`packages/contracts` 及测试，技术文档 01、03、06、07 的相应部分。不改 `apps/web/` 与扩展本体。

## Tasks

- [ ] **5.1 合同**：配对、令牌、收藏接口的请求与结果、错误码；`web-capture` 来源的字段；回执 `contract.md`，供 06 接扩展与设置分区。
- [ ] **5.2 配对与令牌**：一次性配对码（短时有效、限次尝试）、令牌派生值存储、撤销、最近使用时间；设备表并入 schema 16 或升 17（见计划 README）。
- [ ] **5.3 收藏接口**：令牌认证与范围检查；保存书目时读不到 DOI 或 arXiv 号就拒绝；PDF 按 ADR 0029 验收，已有主 PDF 不替换。
- [ ] **5.4 按日批次**：每台设备每天一个批次，可改名。
- [ ] **5.5 安装包下载**：提供 06 构建出的扩展包；没有构建产物时返回明确错误。

## 验证

直接测试：令牌只能调用收藏接口、撤销后立即失效、配对码过期与限次、跨站请求在其他接口上仍被拒、令牌不进日志、重复保存幂等、已有主 PDF 不替换、按日批次。另做一次安全自查，结论写进回执。

## 退出条件

回执给出提交与合同；06 可以接扩展。

## 恢复与交接

令牌机制有疑问时停在 5.2，写进回执交 Claude 与 Owner 讨论，不放宽认证规则。
