# 28 · 界面用词

类型：计划（结果块）
负责：把界面上的内部状态名换成大白话，全站同一个词
状态：Not started

来源：2026-11-19 前端审查两轮（`sandbox/reports/2026-11-19-frontend-audit/REPORT.md`，示意图 `seven-decisions.html`）与 Owner 同日的决定：方案全部同意，第二轮审查后“按照你的建议就全做了”。

## Outcome

- 文献状态、操作、任务状态、设置里的词都按“界面用词”表；快速筛选互不重叠，洞察页用同一组分类。
- 示意图与样例、测试里的旧词同步换掉。

规格：[页面规格](../../architecture/web/page-specs.md)“界面用词”。

## 进入条件

26 块的 26.1、26.2 已合入。

## 责任边界

- 前端实施者：全部任务。
- 不改：命令行、MCP、接口字段与技术文档里的内部名；“加工”组里的词。

## Tasks

- [ ] **28.1 词表落地**：`strings.ts` 与各页文案按“界面用词”表替换；同一含义只留一个词，删掉重复的映射。
- [ ] **28.2 快速筛选**：文献库的快速筛选改为互不重叠的分类（全部、有全文、有 PDF、只有书目，其余在“更多状态”），数量相加等于总数；洞察页“材料状态”用同一组。需要服务端计数口径配合时停下告诉总设计师。
- [ ] **28.3 设置与对话框**：Catalog、Provider、profile 等英文词换成中文；“建立文献档案”对话框改名“生成全文”。
- [ ] **28.4 样例与测试**：设计样例、测试断言里的旧词同步；`strings.test` 增加“同一含义只有一个词”的检查。
