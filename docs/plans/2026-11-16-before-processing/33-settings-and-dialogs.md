# 33 · 设置重组与对话框

类型：计划（结果块）
负责：设置按要做的事重新分区；对话框、表单、时间、可点文字的全站规则落地
状态：Not started

来源：2026-11-19 前端审查两轮（`sandbox/reports/2026-11-19-frontend-audit/REPORT.md`，示意图 `seven-decisions.html`）与 Owner 同日的决定：方案全部同意，第二轮审查后“按照你的建议就全做了”。

## Outcome

- 设置第一项是外观；配一个模型服务只在一处；高级里不再嵌别的页面。
- 每个对话框一个写着动作的主按钮，高级参数折叠；全站时间一种写法；能点的字是笔色。

规格：[页面规格](../../architecture/web/page-specs.md)“设置”“入库”的目标段落，[设计内核](../../architecture/web/design-core.md)规则 6、8 到 12。

## 进入条件

26 块已合入。

## 责任边界

- 前端实施者：全部任务。
- 不改：配置的保存接口与校验；密钥仍不回显。配置接口不支持“按服务保存密钥”时停下告诉总设计师。

## Tasks

- [ ] **33.1 设置分区**：按新顺序分区；模型服务一处配齐；来源的密钥在行内；“凭据”分区取消；“退出登录”移到页面最下方。
- [ ] **33.2 参数说明与保存**：每个参数一句说明；保存按钮位置统一；未保存提示在按钮旁。
- [ ] **33.3 高级**：只留维护工具；去掉嵌入的快照页与带边框的卡片；文件选择用本站样式；机器编号改为从文献库选择。
- [ ] **33.4 对话框**：获取 PDF、生成全文、发现文献、运行算子等对话框按规则 9：主按钮写动作与数量，高级参数折叠，内部数字进技术详情；发现文献列出来源名称。
- [ ] **33.5 全站规则**：时间写法一处实现、全站使用；行内文字操作改笔色，说明文字不再与操作同样式；状态不再用单选框样式；表单定义表的名称列宽；数字框的加减按钮只留在步进有意义处；禁用项说明原因。
- [ ] **33.6 零散修正**：设备连接表头对齐（B7）；浏览器页的卡片改为与全站一致的底块；Agent 会话记录的几种框统一；展开箭头统一用一种。

## 验证
