# 01 · 阅读页的键鼠交互

类型：计划（结果块）
负责：阅读页的缩放、右键菜单与其余键盘、鼠标操作
状态：Pending（规格待补：交互设计由 Fable 子代理提出，总设计师审定后写进阅读体验规格，再写本块的 Tasks）

来源：Owner 2026-11-16：“当前阅读界面键鼠交互还不是很多，可以丰富一些。”举例：按住 Ctrl 加滚轮线性调节阅读比例；在阅读区右键弹出功能栏，放常用操作，例如关闭所有文献。

## Outcome

- 在阅读区按住 Ctrl 滚动滚轮（或在触控板上捏合），阅读比例连续变化，阅读位置不丢。
- 在阅读区右键，按所在的对象弹出一份常用操作的菜单；标签页上右键可以关闭其他、关闭全部等。
- 其余常用操作有键盘与鼠标的快捷方式，并有一处列出全部快捷键。

具体行为以阅读体验规格为准（本块的 Tasks 在规格写好后补齐）。

## 进入条件

阅读体验规格中键鼠交互一节写好（总设计师）。

## 责任边界

- 负责：前端实施者。
- 不改：阅读位置的记录方式、PDF 的画布与文字层上限、批注的数据与对位。

## Tasks

规格写好后补齐。

## 验证

规格中每条行为对应一条可测的断言；扩展阅读页的定向测试与测量工具。

## 退出条件

规格中的键鼠交互全部可用，阅读页现有测试照常通过。

## 恢复与交接

规格与实现对不上时停下，交总设计师，不自行决定交互。
