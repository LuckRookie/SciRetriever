# 01 · 阅读页的键鼠交互

类型：计划（结果块）
负责：阅读页的操作登记表、阅读比例（Ctrl+滚轮、捏合、Ctrl+=/−/0）、右键菜单、标签页操作、键盘滚动与跳转、查找的上一处、快捷键一览
状态：Completed（2026-11-16；见“证据”）

来源：Owner 2026-11-16：“当前阅读界面键鼠交互还不是很多，可以丰富一些。”举例：按住 Ctrl 加滚轮线性调节阅读比例；在阅读区右键弹出功能栏，放常用操作，例如关闭所有文献。交互设计由 Fable 子代理提出（`sandbox/reports/2026-11-16-reader-interaction-design/DESIGN.md`，含 95 条验收断言），总设计师审定后写进规格；其中八个待定问题都按设计稿的推荐定下。

## Outcome

- 在案头内按住 Ctrl 滚动滚轮或在触控板上捏合，阅读比例线性变化（原文每格 5 个百分点，80%–160%；PDF 每格 10 个百分点，50%–300%），指针下的内容不动，阅读位置不丢；Ctrl+=、Ctrl+−、Ctrl+0 同样可用；当前比例写在页眉右侧。
- 原文的阅读比例是本机一个值，所有资料共用；PDF 缩放仍按资料记住。
- 在阅读区右键，按所在的对象出菜单；段落、图表公式、空白与 PDF 页面的菜单末尾有“关闭本文献”“关闭其他文献”“关闭所有文献”。图、表、公式可以复制图片、保存图片、复制表格、复制 LaTeX。
- 标签页：中键关闭；右键菜单；Alt+W 关闭、Alt+Shift+W 重新打开、Alt+PageUp/PageDown 换篇；关闭当前页后回到上一个使用的标签页，不再离开阅读页；刷新后已打开的标签页恢复。
- 不必先点击阅读区，空格与翻页键即可翻屏；Alt+↑/↓ 按节或页移动；`G` 跳到页码；查找有上一处；`?` 打开快捷键一览。

规格：[阅读体验 1.8 键盘与鼠标](../../architecture/web/reading-experience.md#18-键盘与鼠标)，以及第 1.2、1.3、3.5、4.2、4.4、4.5、5.3、6.1 节中随之改写的部分；[设计内核](../../architecture/web/design-core.md)的阅读正文字号与菜单两行。

## Tasks

- [x] **1.1 操作登记表**：阅读页的每个操作登记一次（名称、快捷键、是否可用、是否具备、执行）；把 `Reader.tsx`、`ReaderMarks.tsx` 里分散的键盘处理与菜单项收到这张表；“更多”“排版”菜单与提示从表里读。现有快捷键的行为不变。
- [x] **1.2 阅读比例**：规格第 1.8.1 节：取值、滚轮的换算与累加、捏合、键盘、PDF 对齐、边界、缩放后的滚动尾巴、拦截边界；缩放线与一次手势只测一次（第 4.2 节）；页眉右侧的比例与读屏播报（第 1.2 节）；“排版”菜单的比例组，放大、缩小按下后菜单不关闭（第 1.3 节）；原文比例改为本机一个值，设置页的默认阅读字号改为 16–32 px，旧的 18、20、22、24 仍有效；写入去抖（第 4.5 节）。捏合的换算系数在 Chromium 上实测校准，记入回执。
- [x] **1.3 右键菜单**：一个上下文菜单组件；目标的判定顺序；三段的组成与各对象的菜单；让出浏览器菜单的情形；Shift+F10 与菜单键；焦点、关闭与位置；与划词工具条、批注工具条的关系（规格第 1.8.2 节）。
- [x] **1.4 复制与保存**：复制本段、复制本段为引用、翻译本段；复制图片、保存图片（取已核验并已显示的图片资源，不重新下载）；复制表格（制表符分隔的文字与表格格式）；复制 LaTeX（取渲染公式用的源文字）。与 1.3 同批合入：图上接管了右键，就必须同时提供复制与保存。
- [x] **1.5 标签页**：中键关闭；标签页右键菜单；“另 n 篇”菜单末尾的批量关闭；Alt+W、Alt+Shift+W、Alt+PageUp/PageDown；关闭后激活上一个使用的标签页；批量关闭的“撤销”提示与跳过有未保存修改的标签页；关闭记录；已打开的标签页列表存进 `sessionStorage`，刷新后重建、只装载当前一篇（规格第 1.8.3 节）。
- [x] **1.6 键盘滚动与跳转**：规格第 1.8.4 节的表，不需要先点击阅读区；Home、End 与连按的 Alt+↑/↓ 记入跳转记录；鼠标后退键、前进键（先在 Chromium 与 Firefox 上验证能否拦住浏览器的后退，拦不住的浏览器上不提供，结果记入回执）。
- [x] **1.7 查找与 Esc**：查找的上一处与 F3、Ctrl+G 系列（第 1.8.5 节）；Esc 逐层关闭的顺序（第 1.8.6 节）。
- [x] **1.8 快捷键一览**：`?` 与“更多 → 键盘快捷键”打开的对话框，内容来自操作登记表（第 1.8.7 节）。

## 集成与影响

- 用户可见：两项现有行为改变：原文比例不再按资料记住，改为所有资料共用一个值；关闭当前标签页后留在阅读页，回到上一个使用的标签页。
- Ctrl+滚轮与 Ctrl+=/−/0 在案头内不再缩放整个页面；整页缩放用浏览器菜单，或把指针移到顶栏上。

- 审查退回两处并已修好：窗口上的非被动 wheel 监听改为只在有菜单或弹出层时挂（新增断言）；顶栏查找的名称改为“查找…”。
- 总设计师复跑：12 个定向文件 90 项通过、1 项跳过；修复后 5 个文件 56 项通过、1 项跳过（`sandbox/reports/2026-11-16-plan25-01/review/`）。`next-reader-boundaries` 的一次失败在复跑中未再出现，按偶发处理。
