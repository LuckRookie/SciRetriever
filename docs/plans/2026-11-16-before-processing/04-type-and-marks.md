# 04 · 排版与标记

类型：计划（结果块）
负责：阅读区的字号与段落、期刊排法、作者与机器的字体规则；读者的划线、页边批注、查找命中；PDF 上的批注
状态：Pending

来源：原计划 24 的 11（任务 11.1–11.4 改为 4.1–4.4，11.6 改为 4.5，11.8–11.10 改为 4.6–4.8；只为加工结果服务的 11.5 关键句竖线、11.7 证据与与原文不符的引用移入[知识加工提案](../../proposals/2026-11-16-knowledge-processing/README.md)）。

## Outcome

- 标题明显大于正文；中文与拉丁段落按规格排；摘要上下细线、三线表、编号的图表与公式。
- 作者的文字只有一种墨色。
- 读者的划线是该批注颜色的笔线；批注写在右页边，用细线连到被划线的那一行；窗口窄了落到段落下方。
- 查找只标命中的词，不再标整段。
- PDF 上：划线与框选画在页面上，批注在页面右边缘内侧用编号圆点表示。

规格：[2.1 字号](../../architecture/web/reading-experience.md#21-字号)、[2.2 段落](../../architecture/web/reading-experience.md#22-段落)、[2.3 期刊排法](../../architecture/web/reading-experience.md#23-期刊排法)、[2.4 作者与机器](../../architecture/web/reading-experience.md#24-作者与机器)、[2.5 标记](../../architecture/web/reading-experience.md#25-标记)（读者的批注、查找、疑点三行）、[3.4 原文](../../architecture/web/reading-experience.md#34-原文)（页边部分）、[3.5 PDF](../../architecture/web/reading-experience.md#35-pdf)（批注部分）。

## 进入条件

阅读页新版面的纸页几何（计划 24 的 08，已完成）。

## 责任边界

- 负责：前端实施者。
- 触达：`apps/web/src/reading/document.ts`（正文的元素与 `data-origin` 标记；查找现在给整个块加 `reading-match`）；`reading/markdown.ts`、`reading/table.ts`（表格、公式、图注）；`app/features/reader/marks/` 与 `reading/marks.ts`（划线与页边批注的画法）；`reading/pdf.ts`（PDF 上的批注画法）；`reading.css`；`apps/web/test/design-rules.test.ts`（为阅读区增加规则）。
- 不改：批注的数据、锚点与对位阈值；正文的结构读取与分组（ADR 0054）；全站的七种字号规则对阅读区以外的页面；初稿疑点的显示（已由计划 21 的 10.4 实现，本块只让它落在左页边的位置上）。

## Tasks

- [ ] **4.1 字号与段落**：规格第 2.1 节的表，全部以阅读字号的倍数表示；第 2.2 节的中文与拉丁段落设置与不可断开的单元。
- [ ] **4.2 期刊排法**：规格第 2.3 节：编号标题、摘要细线、文章信息收起、三线表、图与图注、组图、公式、页脚注。现有的表格与公式渲染只改样式。
- [ ] **4.3 作者与机器**：正文元素按来源标 `data-origin="author"` 或 `"machine"`；字体按规格第 2.4 节。
- [ ] **4.4 字号规则测试**：`design-rules.test.ts` 对阅读区（以容器标记识别）改为检查规格第 2.1 节的字号集合，阅读区以外照旧检查七种字号；增加“作者的文字用衬线、机器与界面用无衬线”的检查；`--reader-check-fail` 在两种主题纸页上的对比度 ≥ 4.5:1。
- [ ] **4.5 读者的划线与页边批注**：划线颜色取该批注颜色的标签文字色；近似位置用虚线；页边批注、颜色方块与引线；避让规则（相隔 10 px、挤离超过 120 px 时只显示第一行）；窄档落到段落下方。
- [ ] **4.6 查找只标命中的词**：替换 `document.ts` 中整块加 `reading-match` 的做法，命中用 `--hl`，当前命中用 `--hl-current`；PDF 照现有的词级高亮；查找栏打开时书脊刻度标出命中（03 的 3.4）。
- [ ] **4.7 PDF 上的批注**：划线与框选画在页面上；页面右边缘内侧的编号圆点，悬停或点击以浮层显示笔记。
- [ ] **4.8 左页边的位置**：段落编号“¶n”；初稿疑点（计划 21 的 10.4）移到左页边。
