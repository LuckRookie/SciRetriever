# 26 · 主风格与阅读主题

类型：计划（结果块）
负责：把“印的是墨，记号才有颜色”的主风格落到全站，并提供七套阅读主题
状态：Completed（2026-11-19）

来源：2026-11-19 前端审查（`sandbox/reports/2026-11-19-frontend-audit/REPORT.md` 的 C2–C9、U5）与 Owner 同日的决定：第三版定为主风格，另做几套适合阅读的主题放进设置。

## Outcome

- 主按钮是墨色底；蓝色只作笔迹（链接、勾选框、焦点环、当前标签下划线、阅读页的划线与批注）；选中行是墨色淡底。
- 状态色全站四种（绿、蓝、红、灰），进行中是灰底加转动的小环；黄色只用于证据与查找命中；淡紫不再使用；标签是灰底。同一状态在文献库、任务、浏览器、洞察各页同色。
- 按状态分类的图表与进度条用状态色的同色系。
- 停用的主按钮是灰底浅灰字。
- “设置 → 外观”可以选七套主题，并可跟随系统分别指定白天与夜里的主题；旧主题名自动换成对应的新主题。

规格：[设计内核](../../architecture/web/design-core.md)的“基调”、规则 4 与 5、“组件外观”、“主题”。色值的出处：`sandbox/reports/2026-11-19-frontend-audit/themes-gallery.py`（七套主题的纸、墨、笔与状态色，均已算过对比度）与同目录的 `themes.html`、`proposal-color-v3.html`。

## 进入条件

无。只改网页的样式、令牌与外观设置，不改服务端与文献库结构。

## 责任边界

- 前端实施者：全部任务。
- 不改：页面结构、文案与术语（“已就绪”“建档”等照旧，术语另议）、侧栏的入口（另议）、服务端。
- 色值可以为了对比度或观感在实现中微调，调了要在汇报里列出；四条舒适原则与规则 5 的含义不能动。

- [x] **26.1 令牌**：`tokens.css` 改为七套主题；新增主按钮、停用、选中行、标签、状态四色与进行中、图表同色系所需的令牌；去掉黄、紫两种状态色的使用。
- [x] **26.2 组件**：主按钮、停用态、选中行、勾选框、链接、标签、状态徽标（含进行中的小环，遵守减少动效偏好）按规格改；全站状态到颜色的映射收到一处。
- [x] **26.3 各页状态对齐**：文献库、任务、浏览器、需处理、洞察、算子、入库、设置的文献来源表，同一状态同色；设置里缺配置的行不再整行黄底。
- [x] **26.4 图表与进度条**：按状态分类的图与进度条用状态色的同色系。
- [x] **26.5 外观设置**：主题预览卡、跟随系统、白天与夜里分别指定、旧主题名迁移（蓝白与暖白换成纸墨，墨绿换成豆绿，深色换成夜读）。
