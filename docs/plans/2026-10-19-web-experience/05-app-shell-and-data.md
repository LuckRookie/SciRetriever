| 事件 | 缓存行为 |
| --- | --- |
| 同一 Browser 心跳、画面、控制权 epoch | 更新 Browser view；不失效材料或任务 |
| 候选 publication、会话结束 outcome、入库 report 改变 | 失效文献列表、详情、知识、处理器、任务 |

| 显式加工返回 | 由对应 mutation 刷新其资源 |
