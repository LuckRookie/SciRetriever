# 07 阅读器

状态：Completed。当前输入合同下的阅读、排版、证据往返与最终 Full/减少动效回归通过；无可靠结构的作者单位、图注归属和裸引用编号识别仍是后续内容能力。

**Outcome**：新界面的阅读器是一个安静、连续、可核对的阅读面，并达到功能对等。完成后可以观察到：

- PDF / 全文 / 总结三个视图的切换位于阅读区工具栏，信息栏收起后仍可切换。
- 工具栏控件同高同形，按用途分段。
- 信息栏依次显示：身份 → 摘要 → 可读材料 → 收起的技术详情。
- 日常操作和加工操作分开放置，加工操作需要确认。
- 全文按当前Markdown和可信结构排版；不从普通段落猜测作者单位、图注归属或引用编号。
- 总结按人能读的栏目呈现，每条结论可以就近查看原文并返回。
- G3 的性能与资源释放口径不退化。
