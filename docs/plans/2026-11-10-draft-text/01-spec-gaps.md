## Tasks

每项写清：要回答的问题，写进哪一节。规则的内容写在规格里，不写在本计划里。

- [x] **1.1 片段的核对依据由多个叶块组成时怎样取值**（04 §8.3）
  - 程序合并断段后，一个片段包含多个叶块，可能跨页。规格只说“程序逐个叶块对比”和“每个片段带一个核对依据”，没有合并规则。
  - 写明：片段内叶块取值不同时片段取哪个值；跨页片段怎样处理；差异记录按片段还是按叶块组织。
  - 已回答：[04 §8.3](../../architecture/technical/04-document-evidence.md#83-初稿的结构与核对依据)“片段与叶块”；片段的组成见 [§8.2](../../architecture/technical/04-document-evidence.md#82-初稿的形成)“渲染”。
- [x] **1.2 “找不到”和“全部出现在另一页”的判定**（04 §8.3）
  - 规格的 `text-layer-differs` 包含“叶块的词在本页文字层里找不到，却全部出现在另一个 `text-layer` 页上”。要写明：
    - “找不到”是否沿用 6.3 的图内文字判定（匹配不到 30%）；
    - “全部出现”是否沿用 6.2 页归属的条件（至少 4 个不同的词、含次数、只出现在另一页）；
    - 部分匹配（30% 以上）但仍有大量缺词的叶块，取 `text-layer-differs`。
  - 写明公式叶块（只有 LaTeX）怎样取词：归一化后没有可比文字时取 `no-text-layer`，还是照样对比。
  - 已回答：04 §8.3“对比规则（`draft-compare-v1`）”第 3、5、6 步与取值表。
- [x] **1.3 没有章节角色时的程序合并与标题层级**（04 §8.2）
  - 断段规则第 2 条要求“双方均为正文”，第 1 条的跳过依据“已归 end-matter”。代码里正文的判断就是“去向为正文类角色”（`archive/paragraph-breaks.ts` 的 `body`）。初稿没有角色。
  - 6.5 的标题层级排除了 title、authors、end-matter、references 角色的标题（`archive/source-layout.ts` 的 `headingLevels`）。
  - 写明初稿里“正文”与“可跳过的独立内容”按什么判定（只按解析类型与文字规则），论文题名是否参与层级统计。
  - 已回答：04 §8.2“没有章节角色时的判定”与“渲染”中的标题层级。
- [x] **1.4 初稿的 DocumentRef 与可读性校验**（04 §3.3.1、§8.2、§8.3）
  - 写明：
    - 初稿的 DocumentRef `schema_version`。建议取新值，使现有约 30 处“只接受 schema 2 校订稿”的检查默认拒绝初稿，而不是误收；
    - representation hash 覆盖哪些字段：资产、原始解析 ID 与 result hash、页面分类与文字层的 hash、初稿方法 hash、Markdown、结构、资源闭包、差异记录；
    - builder 名称与初稿方法 hash 的组成：规则版本、阅读顺序开关、对比规则版本、builder 版本；
    - verified reader 怎样重建并校验初稿。现有校订稿按 builder 从已保存的校订内容重建（`document/storage.ts`）。初稿若要在读取时重新跑 PDF 页面工具，读取会变慢。规格要定：形成时保存一份初稿内容（来源区块、程序操作、逐叶块核对结果），读取只从它重建；
    - 失败原因码：页面工具不可用、超过大小上限、`needs-parse`、来源完整性失败、取消。现有 Markdown 输入无法确定页归属时代码报 `input-missing`，要写明对外取 `needs-parse`；
    - 解析回执中初稿结果的字段；一次解析只请求了另一种 profile（不形成初稿）时，初稿结果怎样表达；解析在原始解析提交后被取消时，初稿结果怎样表达。
  - 已回答：04 §8.3“DocumentRef”“初稿内容”与 verified reader 一段；方法与页面 hash 见 §8.2“版本”；失败码与回执见 §8.2“失败”“回执”。
- [x] **1.5 差异记录的格式**（04 §8.3）
  - 写明每处差异的字段（片段、叶块、解析文字、文字层文字、页码）、大小上限、与 representation hash 的关系。
  - 已回答：04 §8.3“差异记录（`draft-differences-v1`）”。
- [x] **1.6 差异的有界读取**（04 §8.3、§3.4）
  - 规格只说“可以按片段有界读取”。写明操作名、请求与结果、`max_bytes` 上限、续读方式；在 HTTP、CLI、MCP 上都提供；设备连接的用途取 `read`。可以参照现有校订对照请求 `{document_version_id, segment_id, max_bytes, continuation}`。
  - 已回答：04 §8.3“差异的有界读取”。
- [x] **1.7 默认文本的边界情形**（04 §8.5）
  - 规格只有两条：有当前有效的校订稿就用它，否则用当前初稿。写明：
    - 重新解析后初稿形成失败、旧校订稿又不再有效时，默认关系怎样处理（删除，还是保持并在读取中标为过时）；
    - 部署 profile 改变后，旧 profile 的初稿与校订稿怎样处理；
    - 补充材料部分是否同样适用。
  - 已回答：[04 §8.5](../../architecture/technical/04-document-evidence.md#85-默认文本内容版本与证据)“默认文本”与“边界情形”。
- [x] **1.8 补形成初稿的维护操作**（04 §8.2“已有的原始解析”）
  - 写明：操作名；范围的写法（沿用获取 PDF 的 `{kind:"query",query,sort,limit}` 或 `{kind:"literatures",literature_ids}`）；提交前的预览计数（命中、要处理、已有初稿、没有原始解析、超出上限）；作为持久任务运行还是同步返回；单次上限；设备连接的用途；回执里逐篇的 `formed`、`reused`、`failed` 与原因。
  - 写明它的对象：只处理“没有初稿”的原始解析，还是也处理“没有当前方法的初稿”。规格同时说了“初稿方法改变时，只在使用者显式发起时重新形成”，两处要对上。
  - 已回答：[04 §8.11](../../architecture/technical/04-document-evidence.md#811-补形成初稿的维护操作)；§8.2“版本”的方法改变规则与它对上（`include_older_method`）。
- [x] **1.9 存储**（07 §2.3.4、§4.2）
  - 写明：初稿版本放在 `document_versions` 还是另一张表；初稿对原始解析的保护（现有 `raw_parse_pins` 只认校订稿，原始解析可在无 pin 时被退役）；初稿内容与差异记录作为不可变文件保存，catalog 只存引用、hash 与计数。
  - 已回答：[07 §2.3.4](../../architecture/technical/07-versioned-storage.md#234-asset原始解析与校订稿)“初稿的存储”，[07 §4.2](../../architecture/technical/07-versioned-storage.md#42-数据与写入所有权)“两级文本的写入所有权”。
- [x] **1.10 查询合同**（06 §2.1.1–2.1.3）
  - 06 还没有任何关于两级文本的内容。写明：
    - 文献库条目、`LiteratureDetail` 各部分、建档状态的 `text_level` 字段；
    - 查找命中的 `text_level` 字段；
    - `LibraryQuery` 的新筛选字段与 `LibrarySort` 的新排序键（疑点数、是否含扫描页、是否被结果引用、“找不到”的引用数，以及按文本等级筛选）；
    - 筛选与排序作用于哪个部分。04 §8.4 的文献行显示主 PDF，§8.7 的事实按部分给出；建议筛选只看主 PDF，要写明。
  - 已回答：[06 §2.1.7](../../architecture/technical/06-retrieval-context.md#217-文本等级与选择校订范围的事实)；describe 的字段见 [04 §8.4](../../architecture/technical/04-document-evidence.md#84-文本等级的标注)。
- [x] **1.11 四项事实的来源**（04 §8.7）
  - “是否被加工结果引用”：写明是否计入过时的结果（规格写“未过时”），以及只计读了该初稿内容版本的结果。
  - “找不到”的引用数：逐值核对的结果现在只在结果文件里，catalog 没有可查询的投影（`analysis/value-check.ts` 产生，`processor_record_projection` 不含核对状态）。写明由结果发布时写入的投影提供，归哪个模块写。
  - 已回答：[04 §8.7](../../architecture/technical/04-document-evidence.md#87-选择校订范围的事实)的计数口径；投影 `processor_unfound_citations` 的结构与写入方见 07 §4.2。
- [x] **1.12 哪些读取方接受初稿**（04 §6.5、§7、§8.8）

  - 已回答：[04 §8.10](../../architecture/technical/04-document-evidence.md#810-各读取方对初稿的处理)。
- [x] **1.13 长文档已发布的版本**（04 §8.3 的长文档例外）
  - 规格规定未逐页校订页的片段取初稿的取值。写明：只对新发布的长文档生效，还是对已发布的也重新发布；校订内容（`ArchiveTextBundleV2` 的叶块 `basis`）与结构的取值集合怎样扩展；是否需要新的 builder 版本，以免已发布版本按记录的 builder 重建时 hash 对不上。
  - 已回答：04 §8.3“长文档”。
