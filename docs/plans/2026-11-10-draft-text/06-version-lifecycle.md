# 06 · 版本生命周期：升级、重新解析、过时与引用保护

类型：计划（结果块）
负责：默认文本在初稿与校订稿之间切换时的内容版本、依据初稿的结果过时、证据固定与引用保护
状态：Completed（2026-11-15）

## Outcome

- 一个部分从初稿升级为校订稿后，默认文本改为校订稿；依据初稿的加工结果标为过时，不自动重算；这些结果仍可读，证据仍解析到原来那份初稿的片段。
- 重新解析形成新初稿时同样处理：默认关系先删除，形成新初稿后默认文本是新初稿；依据旧文本的结果过时。初稿形成失败时该部分没有默认文本。
- EvidenceRef 固定具体的初稿版本和片段 hash，即使校订稿里文字相同，也不改指校订稿。
- 被有效结果引用的初稿版本及其原始解析不被删除或退役；确需失效时明确报告。
- 默认关系的并发更新（初稿形成与校订稿发布同时发生）不丢失有效事实，最终符合 04 §8.5 的规则。

规格：[04 §8.5](../../architecture/technical/04-document-evidence.md#85-默认文本内容版本与证据)（默认文本、边界情形、内容版本、过时、证据）、[§4](../../architecture/technical/04-document-evidence.md#4-证据定位版本与生命周期)；保护见 [07 §4.2](../../architecture/technical/07-versioned-storage.md#42-数据与写入所有权)。

## Tasks

- [x] **6.1 初稿之上发布校订稿**
  - 默认文本是初稿时，建档的发布（`text-pipeline.ts` 读取当前默认 revision 后 CAS）与显式发布（`document publish-proofread`，调用方给出 `expected_default_revision`）都能把默认文本改为校订稿。
  - 建档自己的第一步解析会先形成初稿、把默认 revision 加一。确认发布时读到的是新的 revision，不报冲突。
- [x] **6.2 重新解析与 profile 改变**
  - 按 04 §8.5“边界情形”的前两条验收：重新解析、初稿形成失败、部署 profile 改变。
  - 现在重新解析后 `document_defaults` 仍指向旧校订稿，只靠视图判断它已失效；schema 17 起由原始解析当前指针切换的事务删除默认关系（03 的 3.3）。确认这一变化对已建档文献的读取方（阅读、查找、加工）表现为 `document-missing`，直到新初稿形成。
- [x] **6.3 并发**
  - 原始解析指针切换、初稿形成、校订稿发布三种写入交错时，每一方在自己的事务内重新求默认文本（04 §8.5），不覆盖另一方的有效结果；最终默认文本符合规则。
- [x] **6.4 过时**
  - 确认默认文本改变时，经现有触发器写出 `content-version-changed`，读取该部分内容版本的结果被标为过时，原因可读。
  - 确认初稿形成而默认文本不变（已有有效校订稿）时，不产生内容版本事件。
- [x] **6.5 证据固定**
  - 证据解析按 EvidenceRef 的版本读取，不跟随默认关系；初稿片段在升级之后仍能解析。
- [x] **6.6 引用保护**
  - 被结果引用的初稿版本：catalog 外键拒绝删除；它引用的原始解析退役返回 `raw-parse-in-use`。
  - 当前代码没有删除文档版本的路径。确认本计划没有增加这样的路径；若需要回收未被引用的旧初稿，另行设计，不在本计划。

## 验证

新增 `apps/server/test/draft-version-lifecycle.test.ts`（合成库、合成加工结果行），证明 04 §8.9 中的这几条：

- 只有初稿时默认文本是初稿；校订完成后改为校订稿；重新解析后回到新初稿；重新解析后初稿失败时读取返回 `document-missing`；部署 profile 改变后旧版本仍按 ID 可读，默认文本直到形成新初稿才变化。
- 默认关系被删除时内容版本为 null，依据旧版本的结果过时。
- 升级后依据初稿的结果为过时，原因是内容版本变化；结果仍可读；它的证据解析到初稿片段，文字与 hash 等于初稿原文，即使校订稿该处文字相同。
- 已有校订稿时再形成初稿，没有结果变为过时。
- 初稿形成与校订稿发布交错执行（用 checkpoint 注入顺序），最终默认文本正确，两边的版本都已登记。
- 删除被引用的初稿版本、退役它的原始解析都被拒绝。

扩展：`processor-freshness.test.ts`、`knowledge-stale-serving.test.ts`（过时结果的读取）、`proofread-document-publication.test.ts`（默认文本为初稿时的发布）、`raw-parsing-storage.test.ts`（退役保护）。
