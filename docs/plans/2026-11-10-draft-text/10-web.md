# 10 · Web：等级标注、初稿阅读与校订范围

类型：计划（结果块）
负责：页面规格中两级文本的排布，及其 Web 实现
状态：Pending

## Outcome

用户在 Web 上看到：

- 文献库的文献行：主 PDF 默认文本的等级；初稿的文献不再显得“没有全文”。
- 阅读页信息栏：各部分默认文本的等级；“档案”一项写明文本来自初稿还是校订稿。
- 全文视图顶部：当前所读版本的等级；初稿附固定说明文字“未经校订，文字可能含解析错误；以 PDF 为准”。长文档保留现有提示，等级显示为校订稿。
- 全文的“显示核对依据”能显示初稿的三种取值（显示文字见 04 §8.3 的取值表）；点疑点片段能看到差异，数据来自 `draft-differences`。
- 初稿不能编辑：全文的“编辑”在初稿上停用，并说明“初稿不接受改字，建档后在校订稿上修改”。
- 初稿上可以做批注；批注栏写明批注是在哪一级文本上做的；升级为校订稿后按现有规则重新定位（09 §9.2）。
- 全文检索的命中显示所在版本的等级。
- 文献库可按 06 §2.1.7 的新筛选与排序键筛选和排序，并把结果交给“建档”。
- 部分没有默认文本（例如重新解析后初稿失败）时，按现有“尚无已发布全文”处理（04 §8.5）。
- 打开、阅读、筛选都不发起加工。

规格：[04 §8.4](../../architecture/technical/04-document-evidence.md#84-文本等级的标注) 规定显示什么，[§8.10](../../architecture/technical/04-document-evidence.md#810-各读取方对初稿的处理) 规定哪些功能在初稿上可用；字段见 [06 §2.1.7](../../architecture/technical/06-retrieval-context.md#217-目标接口尚未实现文本等级与选择校订范围的事实)；**排布归[页面规格](../../architecture/web/page-specs.md)**，视觉规则归[设计内核](../../architecture/web/design-core.md)。用户整理一侧见 [09 §9.2](../../architecture/technical/09-user-organization.md#92-初稿上的批注)。

## 集成与影响

用户可见：大部分有全文的文献在建档前就能读全文。界面不能让初稿看起来和校订稿一样可靠：等级与说明文字必须出现在 04 §8.4 列出的每一处。
