# 06 · 读取与机器接口

状态：Pending。

## Outcome 与进入条件

04 已完成，05 可并行推进。人和 Agent 通过同一套应用操作使用资产与任务；按 ADR 0033，CLI 与 MCP 分别覆盖这些业务能力。

## 责任与 Tasks

- [ ] 6.1 应用操作：
  - 资产：列出、描述（schema、覆盖、版本）；
  - 记录：在服务端完成筛选、排序、分组与分页；
  - 检索：在资产的文本字段中检索；
  - 条目：读取条目及其证据和 lineage；从文献或 Unit 反查引用了它的结果；
  - 任务：提交（范围 + 规范或配方）、小样预览、查看运行、显式更新、人工修订、读取影响列表。
- [ ] 6.2 MCP：在 `apps/server/src/mcp/tools.ts` 增加对应工具，输入输出为结构化合同。区分只读工具与加工工具；查询未命中只报告缺口，不调用加工或探索。
- [ ] 6.3 CLI：在 `apps/server/src/cli/` 增加对应命令，支持非交互、结构化输出（JSON）、按 ID 恢复与诊断。
- [ ] 6.4 上下文读取：既有知识上下文接口能返回新资产类型（记录、论断），附带覆盖与截断说明，同一证据在摘要与综述中重复出现时不计为多份独立证据。
- [ ] 6.5 导出：记录表导出为 CSV / JSON，论断文档导出为 Markdown，均附结果卡；导出只交付文件，不修改库内事实。

## 验证与退出条件

- CLI 与 MCP 对同一合成场景得到一致结果，覆盖：只读与加工的区分、分页、反查、导出。
- MCP 工具描述与参数校验有直接测试。
- 定向测试与 Quick 通过。
