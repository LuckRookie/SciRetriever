## 范围与风险

- 静态定义归 configuration/生产组装；不新增核心业务模块、数据库表或插件框架。协议解析仍由所属 adapter 负责。
- 保留已支持的配置选择键；只提供 hints 的来源与真正 PDF API 明确区分，不伪造能力。不能按 publisher 字符串或 DOI 前缀决定权限。
- 普通 HTTP 每次真实请求与重定向重新选择访问政策；同额度组跨能力共享状态，不把同机构所有产品误合并。
- Browser 平台会话节奏独立于普通 API 请求节奏。本轮不重写 Browser 执行器，也不把 HTTPS 隧道数量冒充网页请求速率。
- 日/周额度以进程内保守窗口表达，不宣称跨重启账户余额；按 token/记录计费的未知余额不能伪装成请求计数。
- 当前验证以离线 fake/loopback 为准，不额外消耗真实 API 或模型额度。
