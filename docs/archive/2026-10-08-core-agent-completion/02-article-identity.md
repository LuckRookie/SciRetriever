# 02 · 解析后的非阻断文章身份核验

## Outcome 与责任

已有有效 PDF 在解析后可得到支持匹配、冲突或信息不足的有证据判断，并可再次读取。
判断绑定 Literature、asset hash、解析输入和元数据版本；没有核验保持 unverified。
Parsing 形成证据，Literature 接纳关联判断，Storage 只保存；不变更主 PDF、原始字节或文献身份。
进入条件：保持 ADR 0029，确定中性合同、算法适用范围和兼容策略。

## Tasks

- [x] 2.1 定义证据、判断、输入绑定及陈旧语义，同步已有设计下的技术合同；不把模型意见当权威元数据。
- [x] 2.2 实现通用核验、Literature 验收及必要存储，解析成功但证据不足也可正常完成。
- [x] 2.3 接通生产解析和公开读取；历史 unverified、已有 PDF 和旧解析可继续使用。
- [x] 2.4 覆盖不同排版、无 DOI、参考文献含目标 DOI、冲突、取消、重试与输入变化，验证判断有实际依据。

## 集成、验证与恢复

相关 Vitest 验证单一事实 owner、不可变证据与元数据/材料 stale；解析及 acquisition 回归证明无新增下载门槛。
若增加 schema，测试显式升级、备份、旧版本及重开读取，禁止隐式升级真实 catalog。
退出要求：通过正式解析/核验入口形成可读结果，失败不撤销已提交的 PDF/文档，不伪造“已验证”。
判断算法的真实文献准确率独立于合成测试，不能从流程测试推导。实现证据与残余限制回填本块。

## 实施与证据（2026-10-08）

正式入口为显式 `Application.articleIdentity.assess`，并接入加工任务。模型只看固定解析文本，
Parsing 检查实际片段/引文/hash，Literature 比较并接纳；没有隐式模型调用、下载门槛或 PDF 删除。
Catalog v9 保存不可变有限证据；v1–v8 显式升级及新库初始化复用已有 operator 备份/事务流程，未迁移用户库。

`article-identity.test.ts` 4 项通过：标识符匹配、冲突/不足、标题与作者及排版空白、虚构引文拒绝、
预算/取消/陈旧请求拒绝、元数据变化和重解析后当前标签失效、历史结果和重开复用。
参考文献场景只证明模型返回不足时不会强行匹配，不证明真实模型一定能分清引用。
日志 `/tmp/sciretriever-core-final-regression.log`；schema 直接验证及最终 Full 见根 README。

残余限制：证据字段需在一个文档片段内有连续引文，跨片段字段尚未支持；
真实模型语义准确率、所有排版覆盖和真实文章质量不在本轮离线验证中。
