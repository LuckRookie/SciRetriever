# 02 · 批量执行、结果存储与查询

状态：Completed（离线机制验收通过，2026-10-18 归档）。

## Outcome 与进入条件

01 的合同、适配与组合测试已完成。本块结束时：处理器可在冻结输入上运行，正确复用完整结果并隔离失败；恢复不改变原任务输入；结果长期保存、内容可检索、证据可展开。CLI 与 MCP 使用同一应用接口，旧入口与 Web 保持兼容。

## 责任边界

`application/jobs/` 拥有任务生命周期，`analysis/` 拥有结果接纳与适配，`extraction/` 拥有外部提交检查，`storage/` 执行不可变发布及依赖登记，`retrieval/` 拥有可重建索引。`bootstrap/` 完成生产接线，CLI/MCP 仅转换共同应用合同，不直接执行 SQL 或调用处理器内部实现。

## 责任与 Tasks

- [x] 2.1 结果持久化与 schema 升级：
  - 复用不可变 ArtifactStore 保存新结果正文；旧知识结果只登记稳定引用。SQL 保存 ID、类型/schema、内容引用/hash、输入/方法/规范/覆盖/来源及依赖。记录行与 FTS 是可重建投影，不成为第二份权威内容。
  - 结果集合保存名称、规范、冻结范围、精确成员结果引用与覆盖；支持逐篇结果及集合级产物，不强制每个结果只有一个 Literature ID。复用成员引用同一产物，不复制旧记录；旧集合成员不因新运行改变。
  - 在既有 Catalog writer 中按 create-if-absent 发布，事务复核输入并登记产物与材料/上游结果保护关系。同一比较身份允许保留多个 partial 尝试，只有完整、有效的结果进入自动复用选择；新完整结果不能被旧 partial 的唯一键拦住。外部候选的长期结果单独持有依赖，回执过期清理不得释放它；重复持久提交以完整内容与绑定 hash 判同/冲突。
  - 区分外部候选已交付与长期结果已发布，后一步失败保留前一步事实并允许幂等补存；禁止凭无正文的旧回执制造历史候选。索引失败不能回滚有效内容，发布后的取消不能误报未提交。
  - 新增明确 schema 版本和现有迁移/reader 接线，只用合成旧库验证升级、失败恢复与历史读取，不自动迁移用户库。文件与 catalog 责任、精确依赖保护沿用既有不变量。
- [x] 2.2 `runBatch` 输入冻结与复用：
  - 文献 ID、库查询或显式结果引用先经只读准备解析为固定 manifest；入队前保存成员、精确版本/hash、缺失项、规范及有效执行配置。结果子集按稳定记录引用冻结，运行中不重新执行查询或解析默认指针。
  - 逐篇比较身份为处理器 id@版本、规范 hash、完整输入指纹与方法执行配置指纹。命中后复核产物可读、hash/依赖有效及 coverage=complete，才复用 `ok/empty`；失败或 partial 不作为完整成功跳过。外部声明不冒充可自动复用的内部执行身份。
  - 集合处理绑定全部输入及顺序/选择政策；同输入且覆盖合格可复用旧综合，变化后整体生成。新运行、模型调用、新产物与复用数分别统计；首版不提供对完整成功结果的同身份强制重算，partial 按明确选择另起尝试。
  - 新集合只引用本次范围对应的结果；部分成功时逐项保存缺口，不能把没有产出的目标静默删掉以冒充完整集合。
- [x] 2.3 执行生命周期与生产组装：复用 `application/jobs/` 的持久队列、并发、取消与恢复，模型限速和计量继续走共享 Agents/Network。恢复使用原 manifest 与方法配置，配置已不可用时明确失败，不改用当前默认模型；单篇失败不影响其它篇。显式重试冻结原输入、保留成功结果，只重做失败目标；partial 的再次处理另行明确选择，首版整篇重跑。
  - 运行中进度与未完成项从 Jobs 读取，结果集合在明确发布时固定成员及缺口。完成/部分结束后再次重试可发布新的集合清单，不能修改已经对外交付的旧清单；任务恢复不重放已经确认的发布。
  - 复用现有任务幂等语义：同 key/同请求返回原运行，同 key/不同请求冲突。并发争用同一完整结果的发布复用实际赢家及其 provenance；partial 仍按独立尝试保存，不承诺远端模型恰好调用一次。
- [x] 2.4 集合描述与内容索引：
  - 集合名称、规范和范围生成可读模板描述，不调用模型；模板可有中英文固定词，用户提供的领域词保留原文，不声称模板能自动翻译任意术语。
  - FTS5 分别支持集合发现与内容命中；索引结果正文、既有知识 statements 和可检索记录字段，绑定结果 ID/hash、记录 ID/字段位置。重建不依赖模型或仍注册的处理器，索引过期/失败如实报告。
  - 字段 schema 驱动 JSON 查询投影，字段与类型在执行前确定。查询限制为受校验的筛选、排序和分页，不向调用方开放原始 SQL。
- [x] 2.5 应用操作：
  - 列出处理器及其规范/输入/输出描述，列出和检索结果集合与结果内容；
  - 描述一个集合：字段、冻结范围、覆盖、处理器与执行身份；
  - 查询记录：服务端完成筛选、排序和分页；
  - 读取逐篇/集合结果并展开原文或上游结果的字段证据；
  - 提交批量/集合任务、查看运行、重试失败项，以及显式接纳外部候选为长期结果。
- [x] 2.6 MCP 与 CLI：在 `apps/server/src/mcp/tools.ts` 和 `apps/server/src/cli/` 增加对应入口，并接入共同 Application/QueryApplication 和 bootstrap 生命周期。读写工具分开，按注册描述校验参数；字段名错误返回可用字段。检索可提示按原文语言尝试同义词，但不能把扩大词项后的未命中解释成不存在相关内容。
- [x] 2.7 导出：记录型结果支持 JSON 和可表示字段的 CSV，文本/知识结果支持 Markdown；保留结果 ID、方法/规范、输入及覆盖信息。JSON 保留完整字段证据，CSV/Markdown 用稳定引用及配套元数据保留追溯关系，不把有损导出当作权威存储。

## 验证与退出条件

- 合成批量场景：同输入全复用；100→120 且完全包含旧集合时执行 20；新 120 仅重叠 80 时执行 40，旧独有 20 不入新集合；若重叠部分 5 篇输入改变，则复用 75、执行 45。
- 处理器版本、规范、有效模型或输入 hash 改变时只重做受影响工作；损坏结果不能当作复用命中。集合输入相同可新建运行但复用产物，增加一篇则生成新综合且保留旧产物。
- 入队后默认文档/模型发生变化，再中断恢复，仍读取原绑定或明确报告不可用；不能悄悄换版本。单篇失败隔离、失败重试、partial 不自动跳过、取消及发布后取消均保持准确状态；同一输入先 partial 再完整成功时，两个结果均可读且后续复用完整结果。
- 真实合成存储验证：并发判同/冲突、发布失败恢复、外部回执过期后的长期证据、旧接口产物引用、集合成员隔离、重启读取，以及删除/重建查询投影不丢内容。
- 关键词仅在结果正文或记录值里时也能命中并展开证据；错误字段、错类型、索引缺失和分页均有明确结果。只读查询不调用模型或触发加工。
- CLI 与 MCP 对同一场景返回一致结果；字段名错误时提示可用字段。
- 现有任务、检索与 Web 回归测试通过；Quick 通过。
