# SciRetriever 文献知识加工平台：精简实施范围

Owner 于 2026-10-18 确认修订后的三块计划并授权实施。长期决定见 [ADR 0034](../../architecture/decisions/0034-unified-processors-and-results.md)，执行见[计划](README.md)。本文于 2026-10-18 与完成的计划一同归档；离线机制验收及真实质量边界见计划记录。原完整提案及九块设计保存在[参考目录](../../proposals/2026-10-17-knowledge-processing-full-design/README.md)。

## 产品承诺

从已有可核对文档出发，通过可信处理器生成标签、记录和综合结果。用户或 Agent 指定方法、规范与范围，系统固定输入、批量执行、复用适用成果，长期保存可查询和可继续加工的结果。领域含义与科学接纳仍由调用方负责。

## 首版架构

- Processor 声明身份、版本、文献/集合范围、输入和输出 schema；方法通过受控上下文读材料/结果、调用共享模型。
- 提交时冻结文档和上游结果版本、规范、有效模型与方法配置。复用核对完整输入与执行身份，完整结果和局部尝试分别处理。
- Result 保存内容类型、证据、实际来源、覆盖及稳定引用。结果集合组合已有结果，不复制正文；新运行不必生成重复产物。
- 旧知识产物保持原 owner；新结果由 Analysis 接纳，通过不可变文件和 catalog 依赖发布。记录查询与全文索引均为可重建投影。外部候选可经独立持久接口长期保存，旧回执仍保持原语义。
- 复用现有 Jobs、DSH、Storage、CLI/MCP；原文、标签、记录和旧知识能在固定范围内综合，保留证据与独立文献身份。

## 范围与验收

三个结果块分别完成合同与适配、批量与持久查询、标签/记录处理器及集成验收。不建设形状系统、配方、Unit 级依赖、版本差异、修订传播、修复 Agent、向量检索或新 Web 页面。

离线验收覆盖完整包含与部分重叠的集合更新、模型/规范变化、输入冻结恢复、partial 补全、长期证据、正文命中、索引重建、记录进入综合以及 CLI/MCP 一致性。新增处理器无需改动执行、存储或公共入口；不限制实现和测试文件数。真实语料质量仅准备评估方案，实际访问和执行另行授权。
