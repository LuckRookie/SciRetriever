# 27 · 侧栏与入口

类型：计划（结果块）
负责：侧栏只留主线（文献库、入库、全文检索、任务），加工收进折叠组；“需处理”“浏览器”并入任务页；菜单里加工相关的操作排到最后
状态：Completed（2026-11-19）

来源：2026-11-19 前端审查（`sandbox/reports/2026-11-19-frontend-audit/REPORT.md` 的 L1、L2、L5、C6）与 Owner 同日的决定“按方案改”。

## Outcome

- 侧栏是一列：搜索、文献库（最近阅读、文件夹）、入库（最近 5 个批次）、全文检索、任务、可折叠的“加工”（算子、快照、标签词表、洞察）、设置。
- 任务页有五个下划线式标签页：任务、需处理、浏览器、Agent 会话、来源统计；侧栏“任务”旁写“n 进行中 · m 需处理”。
- 文献库页头没有“入库”按钮；选择栏的主按钮是第一个能用的操作，停用的按钮不作主按钮；运行算子、生成快照排在“更多”与各菜单的最后一组。
- 旧地址（`view=archive`、`view=web`、`view=agent`）仍能打开对应的标签页。

规格：[页面规格“整体信息架构”](../../architecture/web/page-specs.md#整体信息架构)、“连续选择与选择栏”、“任务与 Agent 会话”。

## 进入条件

26 块的令牌与组件（26.1、26.2）已合入，避免两块同时改外壳样式。

## 责任边界

- 前端实施者：全部任务。
- 不改：各页的内容与文案（“需处理”“浏览器”页的内容原样搬进标签页）、服务端、文献库结构。
- 需处理的计数与任务的进行中计数各用现有接口，不新增接口。

## Tasks

- [x] **27.1 侧栏**：改成一列与一个可折叠的“加工”组（默认折叠、记在浏览器里、当前页在组内时自动展开）；“入库”进侧栏并下挂最近批次；去掉“最近入库”“需处理”“浏览器”三项与文献库页头的“入库”按钮；窄屏抽屉与阅读页抽屉同步。
- [x] **27.2 任务页**：五个下划线式标签页；“需处理”“浏览器”两页搬进来；快速筛选改名“有问题”；侧栏计数“n 进行中 · m 需处理”。
- [x] **27.3 旧地址**：`view=archive`、`view=web`、`view=agent` 以及已保存的链接都落到对应标签页；浏览器后退照常。
- [x] **27.4 菜单与选择栏**：选择栏主按钮规则；“更多”、文献行菜单、“用当前结果”菜单、阅读页“⋯”菜单里，运行算子与生成快照排到最后一组“加工”。
- [x] **27.5 一级切换统一**：全文检索页的一级切换改为下划线式标签页，与算子、洞察、入库、任务一致。

- `next-shell`、`next-tasks`、`next-archive`、`next-live-browser`、`next-library-workflows`、`next-navigation-height` 通过；`pnpm quick` 通过。
