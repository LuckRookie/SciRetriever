# 29 · 文献库：一屏看得更多

类型：计划（结果块）
负责：文献库的表格显示、顶部信息合并、筛选面板、行菜单、预览与空状态；去掉页面上方的栏与“活动”面板
状态：Completed（2026-11-19）

来源：2026-11-19 前端审查两轮（`sandbox/reports/2026-11-19-frontend-audit/REPORT.md`，示意图 `seven-decisions.html`）与 Owner 同日的决定：方案全部同意，第二轮审查后“按照你的建议就全做了”。

## Outcome

- 文献库有列表与表格两种显示；总数只写一次；筛选一点就开；行菜单只列用得上的操作；预览与书目页同内容、不带遮罩。
- 全站不再有只写页名的顶栏与“活动”面板。

规格：[页面规格](../../architecture/web/page-specs.md)“文献库”的目标一段，[设计内核](../../architecture/web/design-core.md)规则 8、12 与“页头”。

## 进入条件

27 块已合入（侧栏任务计数接住“活动”）。

## 责任边界

- 前端实施者：全部任务。
- 不改：文献库的查询接口与虚拟列表的分页方式；需要新的排序字段时只用服务端已有的。

## Tasks

- [x] **29.1 去掉顶栏与活动面板**：外壳去掉页名栏；窄屏的导航按钮并入页头；“活动”面板与入口移除。
- [x] **29.2 工具条与计数**：一行工具条；“排序”前缀；搜索词不计入筛选条件；总数与“符合 n / 共 m”；去掉全文取得一行与“已显示”计数；无结果时不显示全选。
- [x] **29.3 表格显示**：新增表格显示（标题、作者、期刊、年份、材料），点表头排序，行高 32，与列表共用选择、拖放、右键菜单；显示方式记在浏览器里。
- [x] **29.4 筛选面板**：点“筛选”直接开合；常用条件在第一行，其余在“更多条件”；保存与导出进面板右上角菜单；只留一个“清除”。
- [x] **29.5 行菜单与批量操作**：只列用得上的操作并按规格排序；不能用的项说明原因。
- [x] **29.6 预览**：不带遮罩，内容复用书目页组件（30 块提供；30 未合入时先用现有字段补齐期刊、年份、状态、标签），上下键切换。
- [x] **29.7 空状态**：居中一句话加“清除条件”。
