# 02 · 右侧面板

类型：计划（结果块）
负责：右侧面板的停靠与浮起，以及信息、批注、关联（引用数）、翻译四个标签页
状态：Completed（2026-11-16；见“证据”）

来源：原计划 24 的 09（任务 9.1–9.6 改为 2.1–2.6）。

## Outcome

- 侧栏按钮打开右侧面板，默认收起。窗口 ≥ 1440 px 时面板停靠在案头右侧，纸页和书脊重新居中、宽度不变；更窄时面板浮在案头上，不移动纸页。
- 四个标签页：信息（现有信息栏的内容，加“材料”一组）、批注（批注列表）、关联（资料之间的引用数）、翻译（现有翻译）。
- 打开状态与当前标签页按资料记住。

规格：[1.4 右侧面板](../../architecture/web/reading-experience.md#14-右侧面板)、[3.7 库内关联](../../architecture/web/reading-experience.md#37-库内关联)（只做引用数一组）。

## 进入条件

阅读页新版面的案头、纸页几何与顶栏（计划 24 的 08，已完成）。

## 责任边界

- 负责：前端实施者。
- 触达：`apps/web/src/app/features/reader/ReaderInformation.tsx`（现有信息栏的内容搬进“信息”）；`app/features/reader/marks/`（批注列表的显示位置）；`app/features/reader/translation/`（翻译放进标签页）。
- 不改：信息栏各项的数据来源与编辑功能；批注的数据、对位与编辑；翻译的服务端调用。

## Tasks

- [x] **2.1 面板的停靠与浮起**：按规格第 1.4 节；停靠时案头变窄，纸页与书脊重新居中（复用 `geometry.ts` 的几何函数）；浮起时带浮层阴影，不移动纸页；过渡按规格第 6.1 节；开合时锚点不动（计划 24 的 4.2）。
- [x] **2.2 信息标签页**：按规格列出的各组，内容与编辑沿用 `ReaderInformation.tsx`，现有信息栏上的每一项原样搬入；“材料”一组写文本等级（初稿或校订稿，数据来自 `document describe`）。
- [x] **2.3 批注标签页**：按阅读顺序列出批注，写颜色含义、原文摘录与笔记；“仅 PDF”“仅全文”“近似位置”照现有规则标注；点一条跳到位置并记入跳转记录（计划 24 的 4.4）；按颜色含义筛选。
- [x] **2.4 关联标签页（引用数）**：这个标签页始终存在（规格第 1.4 节）；规格第 3.7 节第一组“库内概况”中被引用与引用两行，数据用信息栏现有的“参考文献”“库内被引”。
- [x] **2.5 翻译标签页**：现有翻译功能放进标签页，翻译当前所在的节；译文用无衬线字（04 的作者与机器规则）。
- [x] **2.6 记住**：打开状态与当前标签页写入阅读状态的记录（计划 24 的 4.5）。

## 集成与影响

用户可见：信息栏变成可收起的面板；现有信息栏上的每一项仍然在“信息”标签页里。

## 验证

- 扩展 `next-reader-layout.test.ts`：1440 与 1439 px 两侧的停靠与浮起；停靠时纸页宽度不变；开合前后锚点移动在容差内。
- 扩展 `next-reader.test.ts`：信息标签页包含现有信息栏的全部字段与按钮；翻译可用。
- 扩展 `next-reader-marks.test.ts`：批注列表的顺序、标注与跳转；现有断言不变。
- 测量工具：“锚点保持”中侧栏开合的部分复跑。
- 截图：四个标签页，1440 与 1024 两种宽度。

## 证据

- 2026-11-16，前端实施者实现，总设计师审查后提交。三个决定写进规格第 1.4 节：拖动调宽保留（默认 352，250–520 px，按本机记住）；信息标签页不再重复参考文献与库内被引，“其他版本”“图表资源”并入“材料”；停靠后纸页按第 1.1 节重算，默认宽度下 ≥ 1600 px 时宽度不变。
- 总设计师复跑：改动涉及的 11 个 web 文件 74 项通过、2 项跳过；其余用到信息面板的 10 个文件 26 项通过、1 项跳过（`sandbox/reports/2026-11-16-plan25-02/review/`）。
- 面板默认收起后，后端实施者适配了两个服务端测试（`document-read`、`production-workbench-loopback`；后者另把阅读页去文献库改为经导航抽屉，原计划 24 的 08 之后的旧写法），断言不变；四个相关服务端文件全部通过（`sandbox/reports/2026-11-16-plan25-02-server-tests/`）。
- 现有信息栏字段的核对清单与 8 张截图在 `sandbox/reports/2026-11-16-plan25-02/`。

## 退出条件

四个标签页可用；停靠与浮起按规格；现有信息栏的功能没有丢。
