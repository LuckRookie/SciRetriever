# 30 · 阅读页：书目页、顶栏与排版

类型：计划（结果块）
负责：只有书目的文献的书目页，阅读页顶栏、更多菜单、排版面板、选区工具条、书脊与几处细节
状态：Completed（2026-11-19）

来源：2026-11-19 前端审查两轮（`sandbox/reports/2026-11-19-frontend-audit/REPORT.md`，示意图 `seven-decisions.html`）与 Owner 同日的决定：方案全部同意，第二轮审查后“按照你的建议就全做了”。

## Outcome

- 没有 PDF 的文献打开是一张排好的书目页；有 PDF 没有全文的默认打开 PDF。
- 常用阅读工具在顶栏上，“⋯”分组；总结与结果是视图切换里的一格。
- 排版面板可调字号、行宽、行距并就地换主题；翻译只在点了之后出现。

规格：[阅读体验第 9.0 节](../../architecture/web/reading-experience.md#9-尚未实现)。

## 进入条件

26 块已合入（主题色块、笔色）。

## 责任边界

- 前端实施者：全部任务。
- 不改：阅读引擎的加载与定位（阅读体验第 4、5 节）、批注的存储；PDF 页面保持原色。
- 翻译服务是否配置以现有的配置读取为准，不新增接口；读不到时停下告诉总设计师。

## Tasks

- [x] **30.1 书目页**：新的书目页组件（标题、作者、期刊卷期、DOI、摘要、关键词、取全文的一行）；没有 PDF 时作为阅读页内容；不显示视图切换与书脊。
- [x] **30.2 默认视图**：有 PDF 没有全文时默认 PDF，页眉下一行“还没有全文 · 生成全文”。
- [x] **30.3 顶栏与更多菜单**：目录、查找、高亮、排版、专注上顶栏，图标用次要色；“⋯”分三组；已有 PDF 时不出现“获取 PDF”；总结与结果作为视图切换的一格，都排在纸页上。
- [x] **30.4 排版面板**：字号、行宽、行距、主题色块与两个开关；行宽与行距记在浏览器里。
- [x] **30.5 选区工具条与翻译**：工具条改为浮层样式；翻译只在点击后出现，未配置时不显示入口（修 B8）。
- [x] **30.6 书脊与标记**：书脊改细改淡；未校对全文只标有差异或无可核对文字的段落；标题重复时只印一遍；窄纸页页眉只留右侧。
- [x] **30.7 无效地址与关联**：地址无效时的“找不到这个页面”；关联标签页没有数据时一句话。

## 验证

- `next-reader*`、`reader-*`、`design-rules`（阅读字号 16、20、32）与 `pnpm quick` 通过。
