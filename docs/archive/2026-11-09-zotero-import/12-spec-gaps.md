- [x] **12.1 HTTP 传输：上传与长请求的超时，JSON 的 Content-Type**（01 §2.4.1、§2.4.2、§7）
  - 已写入（2026-11-14，未提交）：产品接口 §2.4.3（传输：请求时长与 Content-Type；`/mcp` 请求正文也用空闲超时）；换令牌的 415 另见 §2.4.1“换令牌的限流”。
  - ADR 0063 第 4 节规定“不设大小上限，也不设时长上限”。现在整个服务的 `requestTimeout` 是 5 秒（审查 H1）。要回答：
