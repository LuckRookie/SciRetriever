# 02 · 设备连接

类型：计划（结果块）
负责：ADR 0058 第 1、2 节的服务端部分
状态：Done（2026-11-10，`2f4f5e7`）
ADR 0063 之后：由 14 修改以下三处：用途“收藏”“导入”合成“入库”（14.2）、凭令牌只能操作本设备发起的批次（14.5）、撤销时中断进行中的上传（14.7）。JSON 的 Content-Type 由 13.5 修改。配对、令牌与下载路由保留。

## Outcome

- 登录 Web 的用户可以生成连接码（文献库地址加一次性配对码），选择名称与用途。
- 客户端用连接码换得长期令牌。服务端只存令牌的派生值，记录名称、用途、创建时间与最近使用时间；可以列出、改名、撤销。
- 令牌按用途（收藏、导入、读取、操作）限定能调用的接口。凭令牌访问的接口不校验 Origin；其他接口按 ADR 0035 不变。
- 持任一有效令牌，可以下载文献库提供的接口说明与 skill 包（内容由 06 提供）。

## 进入条件

ADR 0058 Accepted。不依赖 01。

## 责任边界

Codex（`sciretriever-web`）：`packages/contracts`、`apps/server` 及测试，迁移脚本，[技术文档](../../architecture/technical.md) 01、06、07 中相应部分。不改 `apps/web/`、`docs/guides/`、页面规格与需求。

## Tasks

- [x] **2.1 合同与规格**：
  - 连接码的格式，换令牌的请求与结果，令牌所在的请求头；
  - 用途与接口范围的对应表（后续块只往表里登记接口）；
  - 管理接口（生成连接码、列出、改名、撤销）的请求与结果；
  - 错误码：配对码过期或已用、换令牌次数超限、令牌无效或已撤销、用途不足；
  - 写进技术文档；回执 `contract.md`，供 05、06、09 使用。
- [x] **2.2 配对**：配对码随机生成，10 分钟内有效，只能用一次；换令牌的接口限制次数。
- [x] **2.3 令牌认证**：
  - 令牌只接受请求头，放在地址或查询串里的一律拒绝；
  - 用途检查做成统一的一层，接口登记自己需要的用途；
  - 令牌请求不带来 Web 会话的权限：不能登录 Web，不能读写配置与凭据，不能调用管理接口；
  - 撤销立即生效；记录最近使用时间。
- [x] **2.4 管理接口**：只有登录 Web 的用户可以调用。
- [x] **2.5 schema 16**：设备连接表与离线迁移脚本 `scripts/migrate-import-v16.mjs`（按 `migrate-intake-v15.mjs` 的做法），打开旧库不自动迁移。03、08 在 M1 部署前新增的表并入同一个脚本。
- [x] **2.6 说明与 skill 的下载路由**：持任一有效令牌可以下载；内容来自 06 的构建产物，缺失时返回明确错误。

## 集成与影响

新增第二种认证方式；catalog schema 15 → 16；现有登录、会话与 Origin 校验不变。

## 验证

- 直接测试：
  - 配对码过期、重复使用、换令牌次数超限；
  - 令牌只能调用其用途允许的接口；
  - 撤销后立即失效；
  - 令牌不能登录 Web、不能读写配置与凭据、不能调用管理接口；
  - 其他接口上的跨站请求仍被拒；
  - 令牌放在查询串里被拒；
  - 令牌与配对码不出现在日志、事件与结果里。
- 迁移在合成库上测试。
- 另做一次安全自查，结论写进回执。
- 定向测试与 `pnpm quick`。
