# 16 · 可能重复

类型：计划（结果块）
负责：ADR 0063 第 8 节：来源没有库编号时，没有标识的条目是否与已在库的文献重复
状态：Completed（2026-11-16 16.1–16.5 完成；16.6 合成库误报、漏报各 1/21，正式库部分移入计划 25 的 23.4）

## Outcome

- 来源没有库编号（导出文件、单独的文件、网页）时，没有标识的条目按标题、第一作者和年份判断，是否可能与已在库的文献重复。
- 可能重复的条目，不自动合并，也不自动新增：预览里单独列出，由使用者逐条决定“并入已有的”还是“新增”。
- 没有人决定的条目不入库，写进报告；以后可以在批次页上处理。
- 审查 M4 的情形（一次性来源中没有标识的条目，改了标题后再导入，结果重复入库）不再发生：它会列为可能重复。
- 误报与漏报的程度有了数字。

## 进入条件

- 14 完成。
- 16.1 起等 12.18、12.23。
- 16.6 要 G-lib（只读副本）或使用合成库。

## 责任边界

- 负责：后端实施者。
- 拥有：可能重复的判断（新文件，放在 `apps/server/src/literature/`，与身份服务并列）；预览与报告中的“可能重复”分类；逐条决定的接口；本块的表结构。
- 触达：`import-sessions.ts` 的预览与入库流程；`packages/contracts` 的报告合同；身份服务（只读调用，不改现有的身份规则）。
- 不改：有标识或有来源库编号时的对应规则（ADR 0058 第 5 节不变）；网页（18 显示与操作）。

- [x] **16.2 判断（等 12.18）**
  - 动作：按 12.18 规范化标题、第一作者与年份，在 12.18 规定的范围里查找候选。
  - 验收：用合成库做纯函数与服务测试，覆盖以下情形：
