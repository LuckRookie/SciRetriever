# 02 · 全文增量渲染

类型：计划（结果块）
负责：全文视图在新正文到达时只处理新增部分
状态：Done

## Outcome

新正文到达时只切分和渲染新增部分，已渲染的块不再重算；标注定位只处理新增段落；滚动时按位置索引定位，不再遍历全部段落。

## 背景

`apps/web/src/reading/document.ts` 的 `paint()` 每批都把累计全文重新切块、重新解析和渲染公式；合成长文主线程长任务共 151 秒，KaTeX 被调用 62 万次。只解析新增部分的重放为 0.88 秒。

## 责任边界

Claude：`apps/web/`。

## Tasks

- [x] **2.1 增量切块与渲染**：只处理最后一个稳定块之后的内容。
- [x] **2.2 标注与链接**：标注定位、文档内链接只处理新增段落。
- [x] **2.3 滚动定位**：`capture`/`go` 不再遍历全部段落。
- [x] **2.4 测量**：用诊断用的合成长文复测，记录前后耗时。

## 验证

现有阅读器测试；新增一条长文增量渲染测试（批次到达后已渲染块不被重算，结果与一次性渲染一致）。

## 退出条件

合成长文主线程耗时降到诊断时的十分之一以内，阅读器测试通过。
