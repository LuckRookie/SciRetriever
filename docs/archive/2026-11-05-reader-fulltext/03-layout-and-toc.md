# 03 · 正文版式与目录

类型：计划（结果块）
负责：全文视图的版心、字体、公式与表格样式，以及目录
状态：Done

## Outcome

- 正文直接放在页面底色上，列宽随字号缩放，三档为舒适、宽、全宽；标题层级分明；公式无底无框，表格只用横线。
- 目录可调宽度、层级缩进清楚、长标题最多两行、标出当前阅读位置并随滚动同步、深层级可收起；放不下时变成浮层。

## 背景

调研见 `sandbox/reports/2026-11-05-reader-typography/research.md`：1440 宽时正文只剩约 490px；目录 220px、条目直接用按钮、没有当前项。
