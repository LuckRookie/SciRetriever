## 目标和边界

服务器运行同一个个人文献工作台，用户从自己的浏览器直接访问。只有一种启动与登录方式；默认对外监听，本机也必须认证。移除公开 origin 配置和交互式密码提问，统一使用指定密码或自动密钥。保留跨站防护、原有 tab CSRF、Browser 控制租约和同一业务 owner。没有多用户权限或新的文献事实，不访问真实 Provider、MinerU、DSH 或用户库。
