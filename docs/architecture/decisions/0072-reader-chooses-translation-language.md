# ADR 0072：读者在“更多”里选译文语言；没有的语言当场翻译这一篇

类型：决策（ADR）
负责：读译文时用哪种语言、在哪里选、一篇文献没有这种语言的译文时怎么办；PDF 与读本并排时“原/译”落在哪一边
状态：Accepted（2026-11-27，Owner 定方向，细节由总设计师补全）；已实现（2026-11-27）

- Date: 2026-11-27
- 修订：[ADR 0068](0068-stored-full-text-translation.md) 里“译文语言是部署的一项配置（`[translation].target_language`），所有文献共用”一句，改为“这一项是库的默认语言”；[ADR 0071](0071-pdf-first-reader-two-floating-balls.md) 第 2 节“PDF 一旦和读本并排，左页始终是原件，‘译’只管右边”一句。ADR 0068、0071 其余各节不变。
- 依据：
  - Owner 2026-11-27 的原话：

    > 这里的译文是不是可以换才对？不一定非要是中文，有可能是其他语言。这样子该如何设计？

    > 我建议是把这种语种的设置直接放入到右上角的下拉菜单选项，然后把常见的几个语种都放进去。小球的逻辑已经够多了，没必要再加了，你就按照游戏设计的思路来，怎么有趣怎么便捷怎么来。

  - 他在 PDF 与读本并排、两个小球都是并排时看到左页仍是原件、右页又是原文加译文，问“这里逻辑有点问题……就是这样子设计的吗？”
  - 库里的实情：译文按“文献、主 PDF、内容版本、语言”分开存（[文档与证据 9.4](../technical/04-document-evidence.md#94-译文的存放)），后端早已能存多种语言；只是读取一律用部署配置的那一种，建档也只翻这一种。

## 决定

### 1. 在哪里选

- 阅读页“更多”菜单里一项“译文语言”，打开一个子菜单，列出常用的九种：简体中文、繁體中文、English、日本語、한국어、Deutsch、Français、Español、Русский（合同 `TRANSLATION_LANGUAGES`）。
- 当前选中的一项打勾。每项后面一行小字说这一篇的情况：
  - 这一篇有这种语言的译文：“已有译文”，选了马上换。
  - 没有：“选了可以翻译这一篇”。
  - 这一篇本来就是这种语言：“原文就是这种语言”。
- 选择按本机记住，所有文献共用，和“原文 · 译文 · 对照”的选择一样。没有选过时用库的默认语言（部署配置 `[translation].target_language`）。
- 小球不加任何东西：“译”仍是单击换、双击并，只是“译”指的是这里选的语言。

### 2. 这一篇没有选中语言的译文时

- 选了一种这一篇没有的语言后，“译”球照常可以按，纸页上方一行说明：“这一篇还没有日本語译文。翻译这一篇”，后面那几个字是按钮。“更多 → 译文语言”的子菜单最下面同样有一项“把这一篇翻译成日本語…”。
- 按下后是与“解析全文”同一种确认对话框：写出要调用模型、预计的用量（按这一篇的页数与历史中位数），确认后作为一个任务运行。只翻译这一篇的这一种语言，不重做别的步骤。
- 翻译完成后这一篇就有了这种语言的译文，“译”球直接读它；PDF 的译文页、读本的译文都用它。
- 还没翻好时“译”球变淡，悬停说明原因；任务在进行时说“正在翻译成日本語”。
- 阅读层（批语、提要）的译文部分只做了库的默认语言。读者选了别的语言时，批语、提要显示原文，正文与原句用选中语言的译文。给阅读层补其他语言的译文是以后的事（见“还没有决定的事”）。

### 3. PDF 与读本并排时，“原/译”各占一边

两个小球都在用时（PDF 与读本并排，“译”也不是原文）：

| 译球  | 左页 PDF | 右页读本 |
| ----- | -------- | -------- |
| 原    | 原件     | 原文     |
| 译    | 译文页   | 译文     |
| 原/译 | 原件     | 只有译文 |

“原/译”在并排时就是字面意思：左边原文，右边译文。读本里不再一段原文一段译文，因为原文已经在左边。

## 后果

- 读取合同多一个可选项：`describe`、`translation`、`slice`、`layers` 与 PDF 的译文页接口都接受 `target_language`，不给时用库的默认语言；`describe` 多列出这一版已有哪些语言的译文。
- 多一种操作：把一篇文献翻译成指定语言，作为任务运行，调用模型。用量与模型名额同建档的翻译一步。
- 正式库上第一次真的翻译成另一种语言，要 Owner 授权调用模型（门槛 G-parse）。
- 库的默认语言仍在配置文件里，改了要重启；以后可以挪到设置页。

## 还没有决定的事

- 阅读层在库的默认语言之外的译文：要不要、何时做。做的话，每种语言另存一份阅读层的译文部分。
- 一次把整个文件夹翻译成某种语言（批量）。
- 库的默认语言挪到设置页。
