# ADR 0045：建档元数据读取整篇论文

类型：决策（ADR）
负责：建档元数据步骤读取的片段范围
状态：Accepted（2026-10-28，Owner 确认）

- Date: 2026-10-28
- 依据：Owner 2026-10-28：“元数据直接给他看全部区块就行了。简简单单。”
- 部分取代：[ADR 0041](0041-arrange-then-per-page-proofread.md) 第 5 节。
- Related: [计划 17](../../plans/2026-10-27-web-usage-review/README.md) P23；[文档与证据](../technical/04-document-evidence.md) 第 6.5 节

## 背景

按 ADR 0041 第 5 节，元数据步骤只读标题、作者、摘要、关键词章节和以“书目”理由删除的区块。真实样本中，一篇 Wiley 论文的文章类型只印在页眉里，页眉在整理时以“页眉”理由删除，元数据步骤看不到依据，文章类型这一必填项始终缺失，建档无法就绪。

## 决定

1. 元数据步骤读取整篇主文的全部内容：校订稿的全部保留片段，以及整理时删除的全部区块，不按章节或删除理由筛选。删除的区块标明删除理由，只作为元数据证据，不因此回到阅读视图、检索或算子输入。
2. 模型引用片段时使用本次输入内的短编号；宿主保存的证据仍是真实的片段与叶块身份。
3. ADR 0037 第 6 节的逐字段裁决、不猜测缺失值，以及必填字段，均不变。

## 后果

- 元数据步骤的输入随全文长度增长，仍是每篇一次调用。
- 页眉、页脚中的文章类型、期刊名等信息可以作为证据；书目行仍然可用。
