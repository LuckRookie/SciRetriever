# ADR 0051：PDF 全文对照翻译，译文放回原版面位置

类型：决策（ADR）
负责：阅读页全文翻译的视图、翻译范围、定位、请求、结果保存与批注显示
状态：Accepted（2026-10-30，Owner 确认：“接受并落地”）

- Date: 2026-10-30
- 依据：Owner 2026-10-30 的要求——“做一个翻译全文的功能，直接翻译PDF的全文……直接把翻译过后的问题放入原本的位置。最好还能附带我们的批注”；“这个功能你可以琢磨一下。看看能否实现”；随后决定“写 ADR”。
- Related: [ADR 0049](0049-reader-translation.md)、[ADR 0050](0050-translation-pane-and-movable-card.md)（划词翻译）；[ADR 0046](0046-reading-marks.md)（阅读批注）；[ADR 0048](0048-single-pass-arrangement.md)（整理与页归属）

## 背景

划词翻译（ADR 0049、0050）一次只翻一段。Owner 希望像沉浸式翻译那样翻译整篇 PDF，译文放回原文所在的位置，并带上自己的批注。

建档已经为每个保留的叶块记下所在页、在页面上的区域（0–1000 归一化坐标）和校订后的文字。2026-10-30 在 sandbox 用计划 17 的 01 篇第 1 页做了原型（`sandbox/cases/2026-10-30-reader-translation/fulltext-prototype.mjs`）：

- 按叶块区域用白底盖住原文、放上译文、字号自动缩到放得下，正文、标题、摘要都落在原位，字号 11.5–16 px，可以阅读；
- 公式用 KaTeX 渲染，`$\pm$`、上标显示正常；
- 摘要上的黄色高亮在译文侧显示为整块黄色底色和左侧色条；
- 这一页 6 个块，6 路并发逐块请求约 10 秒；
- 问题：解析器给图注的区域与图片完全重合，原位覆盖会盖住图（原型中跳过）；译文与原文没有逐词对应，批注只能标到整块。

## 决定

### 1. 视图

- PDF 视图增加“对照翻译”：左栏是原文 PDF，批注照常显示；右栏是同一页的译文版面；两栏同步滚动、同步缩放。可以切换为“只看译文”。
- 译文版面用与左栏相同的 PDF 渲染做底，在每个已翻译叶块的位置盖上不透明底色和译文；图、反应式、表格和未翻译的内容保持原样露出。
- 译文的字号在该块区域内自动缩小，下限 7 px；仍放不下时裁到区域内，悬停显示完整译文。数学按 KaTeX 渲染。

### 2. 翻译范围

- 翻译整理后**保留**的叶块中，类型为正文、标题、图注、列表、脚注的部分。
- 不翻译：图片、表格、公式块、参考文献、作者行，以及整理时删除的页眉、页脚、书目行和界面杂项；这些在译文版面中保持原样。

### 3. 定位

- 默认使用叶块记录的区域（ADR 0048 已按文字层纠正页归属）。
- 叶块区域与同页图片区域重叠超过一半时（典型是图注），改用 PDF 文字层：取该叶块文字在本页文字层中匹配到的文字片段，合并它们的外框作为区域。
- 文字层也定位不到时，该块不覆盖，保留原文，并在该位置标一个“未放置”记号，悬停可看译文。

### 4. 请求

- 由读者点击“翻译全文”开始，使用翻译页当前选定的模型和目标语言；开始前显示页数与预计请求次数。
- 每页一次请求：内置提示词加上本页待翻译叶块的列表（短编号与文字），强制以结构化结果返回每个编号的译文。提示词沿用 ADR 0049 的保留规则（数字、单位、化学式、公式、引用编号、人名与缩写保持原样），并要求逐条翻译、不合并、不拆分。
- 程序检查每个编号恰好返回一次；缺失的编号再请求一次；仍缺失的块保持原文并标“未翻译”。
- 页按顺序推进，同时最多 3 页在请求中；翻好的页立即显示。可以取消；失败的页可以单独重试。

### 5. 结果保存

- 每份文献、每个固定文档版本、每种目标语言的全文译文，保存为程序目录下的一个文件：`~/.sciretriever/cache/fulltext/<文档版本与语言的散列>.json`，不写进文献库。再次打开时直接显示，不再请求。
- 全文译文最多保留 50 篇，满了删除最久没有打开的一篇；它们不占 ADR 0049 的 1000 条句子缓存。
- 文档版本变化（重新建档、人工修改校订稿）后旧译文不再匹配，需要重新翻译；只改动了部分页时，只重翻内容变化的页。
- 每块译文同时写入句子缓存的键空间（规范化原文、目标语言、提示词版本），划词翻译过的句子可以直接复用；但全文翻译的结果不因句子缓存淘汰而丢失。

### 6. 批注

- 左栏批注照常，精确到字。
- 右栏：高亮批注所在的叶块（引文落在该块原文内）整块显示该批注颜色的浅底色和左侧色条；同一块有多条批注时显示最新一条的颜色和条数。框选批注在右栏按原区域显示同色边框。
- 点击右栏带色块，左栏滚动到并闪烁对应的批注；在右栏不能新建批注，避免批注锚到译文上。

### 7. 接口范围

全文翻译与划词翻译一样只供 Web 阅读页使用，不进入 CLI 与 MCP。

## 未采用的方案

| 方案 | 原因 |
| --- | --- |
| 生成一份译文 PDF 文件 | 需要重写 PDF 内容流与字体嵌入，复杂且难以随批注更新；对照视图已满足阅读 |
| 只替换、不对照 | 对照时左栏保留精确的批注和原文，替换式作为“只看译文”切换提供 |
| 逐块请求 | 原型可行，但请求次数随块数增长；按页一次请求次数等于页数 |
| 全文译文放进句子缓存 | 整篇的块数很多，会把 1000 条句子缓存冲掉，也会让整篇译文被逐条淘汰 |
| 全文译文存进文献库 | 译文可以重新生成，按 ADR 0049 的原则不混入用户资料 |
| 在译文上做批注 | 译文随模型与语言变化，批注锚点会失效 |

## 后果

- 读者可以对照阅读整篇译文，原文批注在两栏都能看到。
- 成本：每页一次模型请求；4 页的快报约 4 次，11 页的长文约 11 次。
- 残余风险如实承认：
  - 译文通常比原文短或长，自动缩放后字号可能偏小，极端情况需悬停查看；
  - 解析区域不准、文字层也定位不到的块只能保留原文；
  - 跨栏、跨页的段落按叶块分别翻译，句子可能在块边界被截断，译文因此不够通顺；
  - 批注在右栏只到块级。
- 以下内容需要在实施中确定并写入技术文档：每页请求的提示词与结构、文字层定位的匹配规则、50 篇上限的淘汰细节。
- 实施与验收另行排入计划。
