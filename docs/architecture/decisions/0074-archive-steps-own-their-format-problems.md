## 背景

benzothiadiazole 染料那篇重做阅读层之后，¶29 的依据是一整段核磁、红外与质谱数据。原因不在提示词：分句规则 `sentence-split-v1` 把从“柱层析得到产物”到质谱结束的五句当成了一句，模型只能挑这一整块。

2026-11-28 用正式库里全部 7 份 MinerU 原始解析（6 篇期刊论文、1 篇 294 页的博士论文）离线测试，没有调用模型：

- **v1 漏切的四类**。补上之后多切出 88 处，按原因分：句点后接方括号引用 `hydrogenation.[48] Among` 51 处；句点后接上标引用 `metals. $^{4}$ The` 15 处；下一句以公式开头 15 处；句点后没有空格 `yield).MP` 7 处。triptycene 那篇有一段 1281 字被当成一句。
- **只有约 8% 是格式错误**。句点后没有空格的 7 处里，benzothiadiazole 那篇的 4 处在 PDF 文字层里都有空格（`C1. Red`、`yield). MP`、`110.37. IR`、`825. LC`），是解析丢的；博士论文的 5 处文字层里本来就粘着（目录编号与代码），不该补。其余 92% 是论文本来的印刷样子：引用号放在句点后面、句子以公式开头。
- **校订不该改印刷样子**。ADR 0047 的规则是照印刷原样转录；把引用号挪到句点前面、或插入分句标记，都改动了原文。这几类无论放在哪一步，都只能靠规则去认，规则会漏冷门的体例；现成的分句库（`Intl.Segmenter`）多切的地方抽样多数是错的（`Dr.`、`Eq.`、`Fig.` 之后，`.[48]` 切在括号里）。
- **表注被当成页脚注**。MinerU 已经标出表格下面的注（类型 `footnote`、来源 `table`），渲染却按页脚注处理，放到首次引用它的段落后面；脉络里它脱离表格单独排出。
- **引用号的写法不一**。同一篇里 `$^{5}$` 与 `<sup>5</sup>` 并存（博士论文 17 与 11 处，photoredox 那篇 3 处 `<sup>`）；一处句点被解析进公式末尾（`$177 - 178^{\circ}C.$`）。

同日经 Owner 授权（“授权测试”），用阅读层的模型（terra）测“模型原样摘录依据、程序在段里找到它”：7 次调用，输入 20,154、输出 9,984 token。88 段、137 处摘录，原样找到 136 处（99.3%），没有一处不唯一；找不到的一处是原文把 photoredox 拼成 photaredox，模型改正了。摘录中位 172 字、最长 303 字；同一处按 v1 的句子取依据，中位 183 字、最长 1281 字。离线另测了定位程序对改动的容忍：空白不同、公式写成显示的文字、去掉引用号、破折号换成 ASCII、只摘半句，3588 句里找回 98.7% 到 100%。

## 决定

### 1. 各步的分工与约定

每一步只修它负责的那类问题，交给下一步的东西满足约定；下游信任约定，不替上游修。下游发现的问题，回到负责的那一步去修。

| 步骤 | 负责的问题 | 交给下一步的约定 |
| --- | --- | --- |
| 解析 | 把 PDF 变成区块：类型、页码、位置、文字或 LaTeX、表格、图片 | 区块可能类型不对、被页与栏截断、丢空格、粘词 |
| 整理 | 结构：内容与页眉页脚、章节与骨架角色、标题层级、图注与表注挂接、跨页跨栏的段合并、版权句拆分；以及第 2 节的写法统一 | 保留的每一块都有归属与角色；段落是完整的段落；图注、表注随它们的图表；引用号与上下标只有一种写法 |
| 校订 | 字：每个字符与印刷一致；以及第 3 节的句末空格 | 文字照印刷原样；句末标点之后，印刷有空白的地方文字里也有空白 |
| 渲染 | 阅读用的文档：片段、位置、结构与角色，不调用模型；公式与引用号的位置记进片段（借 TextFold 的原子） | 全文、段号与结构；表注在它的表下面 |
| 分层 | 原文语言的批语、节旨与全篇的总览；依据按第 4 节取 | 依据是段里的一段原文的位置 |
| 元数据、参考文献、标签 | 各自的内容，不变 | — |
| 翻译 | 逐段的译文，图表编号写法由提示词规定；阅读层的译文语言版本（第 5 节） | 每段一份译文；阅读层的译文版本 |

分句（`sentence-split`）不再承担约定：它只算显示用的句号（“¶13·2”），切错时只是句号不准，不影响任何依据。它照 TextFold 改为认渲染记下的公式与引用号位置：句末标点加空白之后是公式或引用号也断开，句点后紧跟的引用号归前一句。

### 2. 整理：程序统一写法，表注随表

整理请求之前，程序做两项写法统一，记在整理记录里，来源记为程序；人工可以撤销：

- **上下标一种写法**：叶块文字里的 `<sup>…</sup>`、`<sub>…</sub>` 改写成 `$^{…}$`、`$_{…}$`。这与 ADR 0047 第 1 节“上下标一律写 LaTeX”是同一条规则，提前由程序做到。
- **句点不在公式里**：行内公式以句点结尾、句点之后是空白、下一个公式或段末时，句点移到公式外面（`$177 - 178^{\circ}C.$` 写成 `$177 - 178^{\circ}C$.`）。

表注：解析类型为 `footnote`、来源为 `table` 的区块是它上方最近一张表的表注，与图注一样挂到这张表上，不是正文段，也不是页脚注。渲染把它排在表的下面，记进这张表的 `figure_groups`。翻译照常译它；阅读层不为它写批语，它随表出现在表所在的地方。来源不是 `table` 的 `footnote` 照旧是页脚注。

### 3. 校订：句末丢失的空格按文字层补回

校订的页请求之前，程序在文字层可信的页上检查每个保留叶块：

- 公式之外，“字母、数字、`)`、`]` 或 `%`，接句点，接大写字母加字母”（`yield).MP`）处，文字层在同一位置的这两个词之间是空格或换行时，补一个空格；文字层里也粘着的，不动。
- 补的空格记在校订记录里，来源为程序，与模型的改字分开列出。
- 没有文字层或文字层不可信的页不做。

ADR 0047 的差异仍然去掉其余的空格差异，模型不裁决空格。

### 4. 阅读层的依据：原文摘录，程序定位

- **模型给什么**：每条批语的依据是这一段里 1 到 2 处原文，每处是一段连续的文字（一句，或一句里承载要点的部分），不超过 300 字，逐字照抄，公式、数字、单位与标点照原样，不改写、不翻译、不拼接、不改正拼写。取舍规则不变：优先陈述结果、定义或决定的文字，不取主要是测量数据罗列的文字。
- **送给模型的段**：照原文写出，不再每句前写句号。
- **程序怎样找**：只在这一段里找。先逐字找；找不到时把两边的空白、TeX 记号、引用号、破折号与引号写法统一后再找，公式也按显示出来的文字再找一遍；仍找不到时，接受与原文只差一两个字符、且在段里唯一的一处（拼写被改正的情形）。找到两处以上的不取。找不到的这一处依据丢掉，记入 `dropped`；一条批语的依据全部丢掉时，这条批语没有（与 ADR 0073 第 7 节相同）。
- **存什么**：与现在相同，依据是段的 `unit_id` 加 UTF-8 半开区间。阅读页的划线、脉络里批语下的原文、原地展开都照旧，只是依据可以是一句的一部分。
- **译文语言的版本**：在翻译一步里写（第 5 节）。依据从这一段在库里的译文原样摘录，同样定位；不再报出译文里的句号。
- **版本**：阅读层文件的版本升为 4，分节与译文的提示词升版本；版本 3 的文件按[文档与证据 10.6](../technical/04-document-evidence.md#106-全文改动之后) 算过时。

### 5. 翻译放到最后

- 建档的步骤依次为：解析、整理、逐页校订、渲染、分层、元数据、参考文献、标签、**翻译**。前面各步都只用原文；翻译用到原文与原文语言的阅读层，排在最后。
- **分层**只写原文语言的版本。
- **翻译**先逐段译全文（与现在相同），再逐节写阅读层的译文语言版本（ADR 0073 第 5 节的写法，依据按第 4 节从译文摘录）。这篇没有阅读层时（短文、长文档、分层失败），只译全文。全文已经是译文语言时两样都不做（与现在相同）。
- **重做的范围**：`from_step: layers` 重做分层，以及翻译里的阅读层部分；全文的译文没有变，照旧复用。`from_step: translate` 重做全文的译文与阅读层的译文版本。元数据、参考文献与标签不受这两项影响（与现在相同）。
- **失败**：翻译失败照旧不影响全文就绪；阅读层的译文版本没写成，记为翻译一步的问题，恢复时只补没写成的节。
- **存放不变**：阅读层文件里的 `translation` 部分照旧，只是由翻译一步写入。
- 这样以后给阅读层补别的语言（ADR 0072“还没有决定的事”）时，就是对那种语言再走一次翻译这一步。

### 6. 已有文献

- 第 2、3 节改变整理与校订的结果。已建档的文献保持现状，照常阅读；用户重新建档（从整理一步开始）时按本决定处理。不自动重建。整理与校订的重做要调用模型，按建档的授权进行。
- 第 4 节只要求重做分层一步与翻译里的阅读层部分，前面各步与全文的译文复用。
- 第 5 节不改变已有的结果：已经写好的阅读层译文版本照常读取。

## 未采用的方案

| 方案 | 原因 |
| --- | --- |
| 只改分句规则（补四类） | 补上的只是碰到的几类；92% 的漏切来自印刷体例，下一种体例又会漏 |
| 改用现成的分句库 `Intl.Segmenter` | 同样要求句点后有空白、不认识公式；多切的地方抽样多数是错的 |
| 校订时把引用号挪到句点之前，或插入分句标记 | 改动了印刷原样，违反 ADR 0047 的转录规则 |
| 校订时让模型逐句标出句子边界 | 每页要多输出大量文字，回到 ADR 0047 否决的“让模型输出整页”；已校订的文献都要重校 |
| 最小的总结单位改为章节 | 各节长短悬殊，没有小标题的短文只剩几行；回到 ADR 0073 之前的做法 |
| 照 TextFold 仍报句号（上游约定好空格与原子，分句按原子切） | 我们的来源几乎都是 PDF，TextFold 的做法在 PDF 上同样漏切；上游没覆盖到的体例还会让依据变成一大段。原子的做法仍用于显示的句号（第 1 节） |
| 依据只到段 | 脉络里批语下面只能放整段，压缩不下来，也看不出批语凭的是哪句话 |
