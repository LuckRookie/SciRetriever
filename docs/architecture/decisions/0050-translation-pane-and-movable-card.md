# ADR 0050：翻译页改为原文与译文对照，划词浮框可拖动

类型：决策（ADR）
负责：阅读页“翻译”页的布局、划词浮框的显示与移动
状态：Accepted（2026-10-30，Owner 要求）

- Date: 2026-10-30
- 依据：Owner 2026-10-30 使用后的要求——“翻译的框无法拖动会挡着我看其他内容”；“划词翻译出现的时间太长了”；“改成类似于 zotero 那般，有一个巨大的翻译前与翻译后的对比……只不过要多出一个划词翻译的选框”。
- 部分取代：[ADR 0049](0049-reader-translation.md) 第 1 节第一条中“下方列出本篇最近的翻译”，第 2 节第一、三条中浮框的位置与“开关关闭时结果显示在翻译标签里”的说法。ADR 0049 其余各节（请求、内置提示词、缓存、浏览器偏好、接口范围）不变。

## 背景

ADR 0049 的翻译页上方是设置，下方是最近的翻译列表；划词浮框固定在选区下方，不能移动，会挡住后面的正文。浮框要等选区停下 350 毫秒才出现，没命中缓存时还要等模型返回。2026-10-30 实测：缓存命中 8–22 毫秒，模型请求约 3 秒，思考强度从 medium 降到 none 并不明显变快（2.4–3.9 秒），时间主要在模型服务的往返上。

## 决定

### 1. 翻译页

翻译页改为上下对照，从上到下依次是：
- **模型**与**译成**两个选择；
- **原文框**：可编辑，选中正文文字时自动填入，也可以粘贴；
- **翻译**按钮；
- **译文区**：显示译文、所用模型和是否来自缓存；
- 两个选项：**选中文字后自动翻译**、**在选区旁显示划词翻译**；
- 复制：**原文**、**译文**、**两者**。

不再列出最近的翻译。两个选项与模型、语言一样存为浏览器偏好，默认都开启。

### 2. 选区与浮框

- 用选择工具选中文字时，原文框总是填入这段文字；开启“自动翻译”时随即翻译，关闭时由读者点“翻译”。
- 开启“划词翻译”时，选中文字后浮框立即出现并显示“翻译中”，选区停下 150 毫秒后才发请求；新选区取消上一个还没完成的请求。
- 浮框可以按住标题栏拖到别处，不会移出窗口；之后的划词翻译出现在拖到的位置，点浮框的 × 后恢复为跟随选区。
- 关闭“划词翻译”时不弹出浮框，选区工具条提供“翻译”按钮，点击后打开翻译页。
- 高亮笔仍然不翻译。

## 未采用的方案

| 方案 | 原因 |
| --- | --- |
| 保留最近的翻译列表 | Owner 要求按原文与译文对照的样子做，列表让对照区变小 |
| 降低翻译的思考强度来提速 | 实测从 medium 降到 none 并不明显变快；Owner 已定所有模型调用用 medium |
| 浮框固定在侧栏，不再浮在正文上 | 浮框的价值是不离开正文；可拖动已能避开要看的内容 |

## 后果

- 选中文字后立刻有反馈；命中缓存时译文在半秒内出现，没命中仍需约 3 秒。
- 残余风险：模型返回前只能显示“翻译中”，逐字显示译文需要模型调用支持流式返回，本 ADR 不包含。
