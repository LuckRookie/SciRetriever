## 背景

ADR 0061 接受时附带的效果图，阅读模式是本项目自己的，样子却仍是参考对象的：底部浮动的胶囊条，左侧的图标窄栏，暖色的无边画布，颜色加深的关键句，右上角一排小按钮，完全不用线。Owner 指出这是照抄。

本项目已经有自己的东西：墨水蓝，只用于证据的荧光黄，期刊式的排版，按文献打开的标签页，右侧带标签页的面板，批注刻度条。阅读页的样子应当从这些出发。

## 决定

1. **形象。** 一份排好版的文稿，放在案头，用蓝笔和荧光笔批过。
2. **案头与纸页。**
   - 阅读区是案头，用 PDF 视图现有的背景色。
   - 案头中间是一张白色的纸页，带现有的页面阴影。
   - 窗口 1440 宽时，纸页宽约 1040：正文栏 680，左页边约 150，右页边约 210。
   - 左页边放要点编号、段落编号和读者画的线；右页边放批注和证据标记。
   - PDF 视图用同一个案头，纸页的位置和宽度相同。从原文切到 PDF，是同一页换了排版。
   - 窗口变窄时纸页占满宽度，页边缩小。
3. **页眉。** 纸页顶部一行小字，下面一条细线。左边是出处；右边写明当前看的是什么、基于哪一版文本。滚动时页眉固定在纸页顶部。
4. **顶栏。** 只有一行，页面上没有任何浮动的控件。
   - 最左是打开全站导航的按钮。阅读时导航隐藏，不设图标窄栏。
   - 然后是按文献打开的标签页。
   - 中间偏右是四个并列的视图：概览、脉络、原文、PDF。资料没有 PDF 时不显示这一项。
   - 接着是提问框：“向这份资料提问”。
   - 最右是查找、排版、侧栏、更多，都是同一种形状的图标按钮。
   - 窗口变窄时，标签页收成当前一篇加其余的数目，提问框收成一个按钮。
5. **右侧面板。** 默认收起，四个标签页：信息、批注、关联、翻译。它放在案头上；窗口 1440 宽时不挤纸页。
6. **书脊。** 挂在纸页右边缘外侧的一条细条，宽约 16 像素，是整份资料的缩略。
   - 章节是一段一段的；当前屏幕上的范围用墨水蓝框出。
   - 刻度标出位置：蓝色是批注和库内关联，黄色是证据，红色是与原文不符的引用。
   - 指针停在一段上时显示章节名。
   - 侧栏打开时，书脊跟着纸页。
   - 它取代原来的批注刻度条。
7. **排版用期刊的排法。** 章节标题带编号；摘要上下各一条细线；表格用三线表；图和表有编号。线少而有用，不给区域画框。标题明显大于正文。
8. **标记。**
   - 作者的文字只有一种墨色。关键句不加深，而是在左页边画一条细的墨水蓝竖线。
   - 读者的划线是蓝色的下划线。批注是右页边的蓝色小字，用一条细线连到被划线的文字。
   - 证据用荧光黄。黄色只用于证据和查找命中。
9. **概览排成结构化的摘要。** 关键数据是一张三线表，列是量、数值、出处，不用大号数字的方块。关键的图表放在纸页右侧较窄的一栏。
10. **脉络排成悬挂式的提纲。** 要点编号在左页边；每条依据前面有一栏很窄的类别。
11. **两个镜头的位置。**
    - 按问题阅读：问题在顶栏的提问框里输入；回答放在纸页顶部，上下各一条细线；下面只留有关的要点，并用一行说明隐藏了几项。
    - 库内关联：放在右侧面板的“关联”标签页；纸页上有关的要点旁边有蓝色的记号。

## 后果

- [设计内核](../web/design-core.md)、页面规格和阅读体验规格按本决定写明具体的数值。本决定只定形象和构件。
- 项目 README 借鉴表里 TextFold 一行去掉“加深关键句”。
- 效果图放在不入库的 `sandbox/` 里，只作参考；以规格的文字为准。
- 三处细节留给规格决定：深色主题下红色刻度偏淡；窗口很窄时书脊的悬停提示放在哪里；概览只有一屏时书脊显示什么。

## 考虑过但没有采用的方案

| 方案                               | 没有采用的原因                                                        |
| ---------------------------------- | --------------------------------------------------------------------- |
| 沿用参考对象的框架，只换颜色和字体 | 骨架仍是别人的；本项目已有的标签页、面板和刻度条反而没有用上          |
| 阅读面不设纸页，正文直接铺满       | 和 PDF 视图成了两种样子，切换时像换了页面；页边的批注也没有明确的归属 |
| 用加深的墨色标出关键句             | 作者的文字被分成了两种颜色；用页边的竖线标记，文字本身不动            |
