# ADR 0047：校订改为每页一次裁决，由程序防护把关

类型：决策（ADR）
负责：建档中校订一步的输入、输出、程序防护与失败处理
状态：Accepted（2026-10-30，Owner 确认：“接受并落地”）；部分被取代：长文档不逐页校订，见 [ADR 0055](0055-long-document-simplified-archive.md)；第 1 节第 2 条“差异去掉空格”：句末丢失的空格由程序按文字层补回，见 [ADR 0074](0074-archive-steps-own-their-format-problems.md) 第 3 节

- Date: 2026-10-30
- 依据：Owner 2026-10-29/30 的讨论与决定——“目标是内容正确、格式干净的校订稿”；“以 PDF 为准”，不设可信度分级，拿不准的地方保持原样；模型调用统一用 medium 强度，主模型为 terra（配置事项，不在本 ADR 固定）；“补齐后写 ADR”。
- 部分取代：[ADR 0041](0041-arrange-then-per-page-proofread.md) 第 3 节第 1、2、3、4 条，第 6 节中针对校订的“无意义消耗”停止条件与“只保留最新一张页面图”。ADR 0041 其余各节（整理、渲染与结构注释、元数据读取范围、已有建档结果）不变，第 3 节第 5、6 条（原图为准、人工锁定、按叶块坐标保存、失败只重跑该页）不变。
- Related: [计划 17](../../archive/2026-10-27-web-usage-review/README.md) P28；[文档与证据](../technical/04-document-evidence.md) 第 6 节

## 背景

ADR 0041 的校订是每页一个多轮会话：模型用工具逐块读叶块、处置每条疑点、提交改字、再读回确认。实际运行中，一页往往要十几到二十轮调用，上下文随轮数增长，成本和耗时都集中在这一步。

2026-10-29/30 在 sandbox 用计划 17 的同一批 5 篇（ACS 2 篇、Elsevier、Wiley 长文、RSC，共 34 页）做了对比，数据在本机 `sandbox/reports/2026-10-29-light-proofread/` 与 `sandbox/reports/2026-10-30-flow-medium-vs-light/`：

- **同样的叶块、同样的模型与强度（terra、medium）下**，ADR 0041 的校订用 299 次调用、284 万输入 token；每页一次裁决用 28 次调用、16 万输入 token，整轮约 110 秒。
- **改对的更多。** 两边同改 115 处。只有一次裁决改对的，包括表格里重复 13 次的 `Pd2(dbab)3` 与 `CsOPIv`、photoredox、υ、`Cl2C6H4`、经文字层核实的 77 处连接号、单位拆分；只有 ADR 0041 流程改对的，主要是 phosphonylation 两处与少量单位拆分。
- **不加程序防护是危险的。** 无防护时，模型会把作者原文“纠正”成别的词、把结构式里的原子标签转写进正文、插入版权行、把图里的文字塞进表格。加了下面的程序防护后，最终一轮没有发现改错的地方。
- **思考强度越高，模型越爱“改进”文字。** max 强度一轮耗时是 medium 的 13 倍，多出的改动里有往图例加符号、补页末连字符这类不该改的内容；low 比 medium 快得不多，却漏掉一批真错。

## 决定

### 1. 每页一次裁决

校订仍只处理整理后保留的叶块，目标仍是抄录保真（ADR 0037 第 3 节、ADR 0041 第 3 节）。每个有保留叶块的页发**一次**模型请求：

1. **输入**：本页页面图；本页保留叶块（短编号、类型与文字）；程序算出的本页差异；本页的图内文字叶块清单。
2. **差异**由程序计算：把每个叶块的解析文字与 PDF 文字层逐块对齐，去掉只是写法不同的地方（LaTeX 记号、连字、空格），剩下的交给模型裁决。
   - 文字层可信的页，差异只是提示，模型按页面图判断哪边对；
   - 没有文字层或文字层不可信的页，没有差异清单，模型对照页面图校整页。
3. **输出**：一次提交，包括改字列表（叶块、原文片段、改成什么、一句理由）与拿不准的地方列表。不再逐条处置疑点，也不要求读回确认。
4. **规则**写在请求说明里，具体措辞由技术文档维护，至少包括：
   - 照印刷原样转录，作者的拼写与前后不一致都保留；
   - 不删内容；
   - 不转写化学结构图里的原子、基团标签；
   - 上下标一律写 LaTeX；
   - 破折号和引号按印刷；
   - 印刷上分开、解析粘在一起的单位或名称要拆开；
   - 图或反应式里的文字（分图字母、轴标、反应条件）不进图注、表格和正文。

### 2. 程序防护

模型的每处改字都要先经程序检查，未通过的**不应用**，原文保持不变。具体判定由技术文档维护，至少包括：

- **G1 按位置核对文字层**：文字层可信的页上，改字新增的每个词、字母或数字，必须是文字层在同一位置印的；上下标里的内容只要求出现在该叶块对应的文字层里。
- **G1b 近似拼写**：任何页上，文字层在该位置印的是一个与新词相近但不同的词时，拒收。
- **G2 不删内容**：原文较长而改后不到一半，或改后少了数字，拒收。
- **G3 结构式标签**：连续插入三个以上原子或基团标签，拒收。
- **G4 标识符**：DOI、网址、邮箱与文字层只差几个字符时，按文字层改正。
- **G5 凭空插入**：原文片段为空的插入，拒收。
- **G6 版权声明**：插入版权或许可声明，拒收。
- **G7 破折号与引号**：文字层可信的页上，新增的连接号、破折号或弯引号必须是文字层在该位置印的；部分出版社用减号 U+2212 存连接号，视为同一符号。位置找不到时保持原样。

被拒的改字和模型拿不准的地方只记录在校订记录里，供诊断与人工查看，不在阅读视图里另做标记，也不形成可信度分级。

### 3. 改字的应用

- 原文片段必须出现在指定叶块里，否则不应用。
- 同一叶块里原文片段出现多次时，全部替换。
- 改字仍按叶块坐标保存，并映射回原始区块坐标（ADR 0041 第 3 节第 6 条不变）。

### 4. 失败与重试

- 一页请求因网络、服务或格式问题失败时，自动重发该页一次；仍失败时该页校订失败，建档不进入就绪，可以只重试该页。
- 校订不再需要“无意义消耗”的停止条件：每页的调用次数天然有上限。
- 发起建档前的用量预估（ADR 0041 第 6 节）按每页一次请求计算。

### 5. 已有建档结果

已按 ADR 0041 校订的文献保持现状，可以照常阅读和被算子选中。用户重新发起建档时按本 ADR 校订；不自动重建。

## 未采用的方案

| 方案 | 原因 |
| --- | --- |
| 保留 ADR 0041 的逐页多轮校订 | 同样的模型与强度下，调用约 10 倍、输入约 18 倍，改对的反而更少 |
| 让模型直接输出整页或整篇校订后的全文 | 无法审查改动范围，会悄悄改字，长文受输出上限限制 |
| 只靠提示词约束，不做程序防护 | 实验中模型会把作者原文改成别的词、插入版权行和结构式标签 |
| 给每段内容标可信度，交给下游判断 | Owner 决定以 PDF 为准、不设可信度分级；拿不准就不改 |
| 用 max 强度换质量 | 耗时为 medium 的 13 倍，而且更爱改不该改的地方 |

## 后果

- 同样的模型与强度下，校订一步的输入 token 降到原来的约十八分之一，调用约十分之一，每页耗时约从 27 秒降到 13 秒；整理成为建档中最大的一块成本。
- 残余风险如实承认：
  - 同样的输入，两次运行改出的内容会有出入，例如表格里重复的错字有一轮只放进了“拿不准”；
  - 文字层不可信的页，G1 与 G7 不生效，主要靠模型和其余防护；
  - 正确但文字层里没有的改动会被 G1 拒收（实验中的 Hämäläinen），这类地方保持解析原文；
  - 图内文字仍可能被写进正文，只能靠规则和人工发现；
  - 跨页问题仍由整理阶段负责。
- 以下合同有变化，不做兼容：校订记录的格式（不再有逐条疑点处置，新增被拒改字与拿不准的列表）、校订的进度事件。
