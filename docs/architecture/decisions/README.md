# 架构决策索引

类型：导航
负责：架构决策索引
状态：现行

ADR 记录已经接受并会长期约束后续设计的重要选择。ADR 不替代产品需求、设计文档或当前实现文档，也不保存实施进度。

## 权威顺序

1. [产品需求](../requirements.md)定义用户问题、核心流程、产品结果和验收标准。
2. 本目录的 ADR 在各自适用范围内约束后续设计，不得反向修改产品需求。
3. [设计文档](../design.md)在需求和已接受 ADR 的边界内推导系统架构、模块命名、数据流、所有权和设计取舍。
4. [技术文档](../technical.md)把设计映射为代码目录、依赖、端口、持久化和运行技术。
5. 项目 [README](../../../README.md)、源码和测试说明当前实现。

当这些文档发生冲突时，先按主题找到唯一责任文档，而不是让更具体的技术细节反向覆盖产品需求。

## 当前 ADR

- [ADR 0066：构建交付完整的程序，缺少部件即失败](0066-complete-program-or-failed-build.md)：**Accepted**，2026-11-25（Owner 决定）；主线功能需要的本机部件（MuPDF、检查 PDF 的工具、Xvfb、受控浏览器 runtime）由构建取得，取不到就让构建失败，不以提示代替；服务启动时核对同一份清单，缺部件拒绝启动；外部服务不算程序的部件；部分取代 ADR 0016“安装包不携带 vendor binary”；MinerU 作为可选包尚未决定。
- [ADR 0065：文献库按千万篇设计，耗时不随总篇数增长](0065-scale-rules.md)：**Proposed**，2026-11-21；书目按一千万篇、全文按一百万篇设计；交互操作只与本次的量有关，常驻内存不随总篇数增长，后台维护与变化量成正比，截断的数如实标明，结构变化不停服，长任务的进度在库里；继续使用 SQLite，写明重新评估的条件。
- [ADR 0064：引用扩展以层数为界，数量上限可以不填](0064-citation-expansion-bounded-by-depth.md)：**Accepted**，2026-11-19（Owner 决定）；引用扩展以层数为主参数，不写时取 1；结果上限和每个来源的扫描上限都可以不填，不填即不限，填写时仍按整个 Run 计；主题发现不变；部分取代 ADR 0013 第 3 节。
- [ADR 0063：统一的入库：一种条目、一个过程、三种载体](0063-unified-intake.md)：**Accepted**，2026-11-14（Owner 确认）；所有入库都是同一种条目走同一个过程，结果是一个入库批次；人以浏览器扩展为主（收藏网页、从 Zotero 导入），网页接收本机文件，Agent 用同一组接口；只有文件、没有标识的资料可以入库；批次可以撤回；HTTP 版 MCP 保留；部分取代 ADR 0052、0057、0058。
- [ADR 0062：阅读页的样子：案头的文稿](0062-reader-visual-manuscript-on-a-desk.md)：**Accepted**，2026-11-13（Owner 确认）；阅读页的形象是一份排好版、放在案头、用蓝笔和荧光笔批过的文稿：浅灰案头上的白色纸页，与 PDF 视图同一种样子；纸页有页眉和左右页边；顶栏一行，四个并列的视图和提问框，没有浮动的控件；纸页右边缘有书脊；期刊的排法；关键句用页边的蓝色竖线标出，不加深；部分取代 ADR 0061 的视觉条目。
- [ADR 0061：阅读优先的阅读页，按理解的过程读文献](0061-reading-first-reader-and-layered-reading.md)：**Accepted**，2026-11-13（Owner 确认）；视觉条目部分被 ADR 0062 取代；阅读页以正文为先，导航和侧栏默认收起；任何版面变化都固定阅读位置，PDF 与全文位置互通；结构变化有过渡，切换不清空画面；一份资料按远（概览）、中（脉络：要点与依据）、近（原文）三个距离阅读，并有“按问题阅读”和“库内关联”两个镜头；概览固定给出性质与范围、要点、依据、局限与未决事项，一种格式通用于各类资料；提示词分为固定的核心、模型自拟的阅读提示和使用者的说明，按类型的提示只作有证据的补丁；不新增产出类型。
- [ADR 0060：全文文本分两级：初稿可读、可加工，校订按需进行；建档规则不预设学科](0060-two-level-full-text.md)：**Accepted**，2026-11-10（Owner 确认）；解析后由程序形成初稿，不调用模型，可以阅读、查找和加工，并标明文本等级与核对依据；校订只在使用者选定的范围内按需进行；标签规则中的“主要化合物”改为“主要研究对象”；部分取代 ADR 0037 第 1、7、10 节和 ADR 0034 的相关表述。
- [ADR 0059：通用的文献知识库：人和 Agent 并列，蓝图按五件事组织](0059-general-literature-knowledge-base.md)：**Accepted**，2026-11-10（Owner 确认）；产品是通用的文献知识库，人和 Agent 是并列的服务对象；蓝图按收、读、理、炼、用五件事组织，需求只写目的；新增“用户整理”模块；知识来源不以文献为界（方向）；部分取代 ADR 0001、0011、0019、0026、0032 中的产品定位表述。
- [ADR 0058：文献库的导入系统，以及 Agent 怎样接入文献库](0058-import-system-and-agent-access.md)：**Accepted**，2026-11-10（Owner 确认）；部分被 ADR 0063 取代；文献库对外只有用户在浏览器里打开它的那个地址，扩展与 Agent 用设置页生成的连接码换取按用途（收藏、导入、读取、操作）限权的设备连接令牌；导入改为与来源无关的导入模型加服务端适配器，所有导入经同一组 HTTP 接口的导入会话（交数据、预览、确认、交文件），可由 Agent 确认，再次导入即同步，PDF 不设大小上限；Zotero 是第一个适配器，数据由桌面一侧取得后交来，服务端不连 Zotero；另提供文献库自带的 skill 与同一地址上的 HTTP 版 MCP；部分取代 ADR 0057 第 1、2、3、6、7 节与 ADR 0035 的相应部分，并与需求 R7 的修订同时生效。
- [ADR 0057：从 Zotero 导入，以及在浏览网页时收藏文献](0057-zotero-import-and-browser-capture.md)：**Accepted**，2026-11-09（Owner 确认）；部分被 ADR 0058、0063 取代；同机用 Zotero 本地 API、不同机用网络 API（兜底为 RDF 导出），经选择、预览、导入形成入库批次；书目、分类（导为文件夹）、PDF、标签导入，批注仅在主 PDF 与 Zotero 附件逐字节相同时导入；保存 Zotero 编号以便再次导入，只单向导入；另做 Chromium 浏览器扩展，在用户自己的浏览器里读页面标识、下载 PDF 后收进文献库，扩展用配对令牌只调用收藏接口；部分取代 ADR 0035、0046 的相应部分，并与需求 R7 的修订同时生效。第 1、2、6、7 节与第 3 节的“Zotero 编号”被 ADR 0058 取代。
- [ADR 0056：出网代理，按发起方逐项选择](0056-outbound-proxy-by-requester.md)：**Accepted**，2026-11-05（Owner 确认）；普通配置加一个 HTTP CONNECT 代理，认证存 `credentials.toml`，不读环境代理变量；按发起方分文献来源、模型、解析服务、浏览器四组逐项选择直连或经代理，默认全部直连；经代理时本机仍做地址检查，隧道内自己完成 TLS，代理不可用报 `proxy-unavailable`、不回退直连；部分取代 ADR 0015、0016 第 4 节的“原始出口”表述，并与需求 Sci-Hub 条目的修订同时生效。
- [ADR 0055：长文档自动走简化建档流程](0055-long-document-simplified-archive.md)：**Accepted**，2026-11-05（Owner 确认）；超过 50 页或整理输入超过单次上限时自动判为长文档：整理按整页分段，校订不调用模型，元数据只读前 20 页与最后 5 页；状态仍为 READY，在阅读页、文献库、任务详情与机器接口注明长文档及“未逐页校订，以 PDF 为准”；部分取代 ADR 0045、0047 第 1 节与 0048 第 5 节的相应部分。
- [ADR 0054：整理前的规则预处理，校订稿按原文排版](0054-rule-preprocessing-and-source-order-layout.md)：**Accepted**，2026-11-03（Owner 确认）；整理前由程序删除页眉页脚、按版面证据先判断断段（确定的直接合并，断在句号处的跨页跨栏补为候选，候选不再限同一章节），分栏阅读顺序纠正待样本验证后启用；校订稿按原文章节顺序与原文标题排版，标题层级优先按编号与字号，首页文章信息默认收起，分图合成一张图，页脚注随引用段落；部分取代 ADR 0041 第 2、4 节与 ADR 0048 第 1、3 节的相应部分。

- [ADR 0047：校订改为每页一次裁决，由程序防护把关](0047-single-pass-page-proofread.md)：**Accepted**，2026-10-30（Owner 确认）；每页一次请求，模型按页面图裁决解析与文字层的差异，一次提交改字；改字经程序防护（按位置核对文字层、近似拼写、不删内容、结构式标签、标识符、凭空插入、版权、破折号与引号）后才应用，拿不准就保持原样；部分取代 ADR 0041 第 3 节第 1–4 条与第 6 节的校订部分。

## 阅读方法

1. 所有产品或架构讨论先读[产品需求](../requirements.md)。
2. 检查是否存在约束当前问题的 Accepted ADR。
3. 讨论系统架构、整体数据流和模块责任时读[设计文档](../design.md)。当前 ADR 的主题为：
   - 领域边界、资产证据或下游集成：ADR 0001；
   - 文献身份、版本和增量补全：ADR 0002；
   - MinerU parser service：ADR 0003；
   - 文档责任和需求/设计分离：ADR 0004；
   - 已归档的 ADR 0005、0006、0008、0009、0010、0020、0024 只用于理解被替代的历史合同，见下方“已归档的 ADR”；
   - 参考文献解析、目标接纳与权威引用关系：ADR 0007。
   - 文献数据库中心、当前事实驱动的增量维护和恢复：ADR 0011。
   - Provider/API/网页访问限速、进程内共享准入和内存运行状态：ADR 0012。
   - 外部发现、进程内数据库补全、多版本选择、自动 PDF 获取耗尽、运行报告边界、Logging 公用基础模块、手动 PDF 接纳和当前不建立 Collection：ADR 0013。

   - CloakBrowser 固定身份、binary/Profile 生命周期、受限验证资源和统一 Challenge 页面合同：ADR 0016。
   - 共享单次 Agents Runtime 与消费模块边界：ADR 0017；DSH 受控执行基础及多轮历史修订：ADR 0031；唯一通用 Browser 路线结合 ADR 0023。
   - 唯一用户级普通配置文件、配置路径所有权和旧配置迁移：ADR 0018。
   - 外部 Agent 编排、Entry/MCP/Skill、解析目标、SDK 驱动模型运行时和 Network transport gate：ADR 0019。
   - Provider/Model 注册表、Model 自有 reasoning/image/stream、Analyze/Download 直接选择、模块派生调用合同、自动模型目录与旧 schema 严格拒绝：ADR 0021。
   - Source Auto/Custom、默认安全 catalog、Custom 冻结列表、逐 Source metadata limit 与旧 `[discovery]` 删除：ADR 0022。
   - 唯一通用 Browser Agent、单步worker/文章session、5秒节奏与300秒/30次模型调用累计预算：ADR 0023；下载取消身份门、PDF 未验证标签：ADR 0029；后台transfer、平台网络资格与candidate/publication交接：ADR 0030。
   - 文献库中心的 Web、日常加工与阅读服务、可选直接操作和无默认人工待办：ADR 0032。
