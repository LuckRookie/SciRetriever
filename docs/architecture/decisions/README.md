# 架构决策索引

类型：导航
负责：架构决策索引
状态：现行

ADR 记录已经接受并会长期约束后续设计的重要选择。ADR 不替代产品需求、设计文档或当前实现文档，也不保存实施进度。

## 权威顺序

1. [产品需求](../requirements.md)定义用户问题、核心流程、产品结果和验收标准。
2. 本目录的 ADR 在各自适用范围内约束后续设计，不得反向修改产品需求。
3. [设计文档](../design.md)在需求和已接受 ADR 的边界内推导系统架构、模块命名、数据流、所有权和设计取舍。
4. [技术文档](../technical.md)把设计映射为代码目录、依赖、端口、持久化和运行技术。
5. 项目 [README](../../../README.md)、源码和测试说明当前实现。

当这些文档发生冲突时，先按主题找到唯一责任文档，而不是让更具体的技术细节反向覆盖产品需求。

## 当前 ADR

- [ADR 0038：Web 的定位与设计依据](0038-web-design-basis.md)：**Accepted**，2026-10-23；Web 为人设计、CLI/MCP 为 Agent 设计；设计依据为设计内核、页面规格、组件画廊与设计样例库截图，不再维护独立 HTML 原型；部分取代 ADR 0032。

- [ADR 0037：文献建档、校订稿与算子输入](0037-literature-archive-and-proofread-text.md)：**Accepted**，2026-10-20；获取、解析、建档分为三个手动阶段，MinerU 初稿经 PDF 文字层找疑点、DSH 看原图矫正形成校订稿（2026-10-20 第二版，替代双解析对齐与仲裁），存疑不阻断就绪，算子证据用时核对，元数据拆分出版形式与文章性质，领域级标签自然增长，算子只读就绪文献的校订稿。取代 ADR 0008、0010，修订 ADR 0002、0003、0007、0026、0034。实施见[文献建档计划](../../archive/2026-10-20-literature-archive/README.md)。

- [ADR 0036：Web 前端采用 React 重建](0036-react-web-frontend.md)：Accepted，2026-10-19；React 19、React Aria Components、Motion、TanStack、Vite，不放宽 CSP；旧前端已删除。

- [ADR 0031](0031-dsh-backed-agent-capabilities.md) 于 2026-10-19 修订：移除旧 Agents 兼容入口，单篇/长文与综合采用 DSH 阅读工具会话；材料、证据与发布仍由业务 owner 验收。

- [ADR 0035：统一登录的单用户 Web 服务](0035-authenticated-remote-web-access.md)：Accepted，2026-10-19；默认 IP/端口直连、统一登录与自动启动密钥，保留同源和业务授权边界。

## 阅读方法

1. 所有产品或架构讨论先读[产品需求](../requirements.md)。
2. 检查是否存在约束当前问题的 Accepted ADR。
3. 讨论系统架构、整体数据流和模块责任时读[设计文档](../design.md)。当前 ADR 的主题为：
   - 领域边界、资产证据或下游集成：ADR 0001；
   - 文献身份、版本和增量补全：ADR 0002；
   - MinerU parser service：ADR 0003；
   - 文档责任和需求/设计分离：ADR 0004；
   - 已归档的 ADR 0005、0006、0008、0009、0010、0020、0024 只用于理解被替代的历史合同，见下方“已归档的 ADR”；
   - 参考文献解析、目标接纳与权威引用关系：ADR 0007。
   - 文献数据库中心、当前事实驱动的增量维护和恢复：ADR 0011。
   - Provider/API/网页访问限速、进程内共享准入和内存运行状态：ADR 0012。
   - 外部发现、进程内数据库补全、多版本选择、自动 PDF 获取耗尽、运行报告边界、Logging 公用基础模块、手动 PDF 接纳和当前不建立 Collection：ADR 0013。
   - Provider 能力分类、全面 adapter 目标、出版社与聚合来源解耦、本地凭据文件和配置/连通性命令：ADR 0014。
   - 访问方画像与运行时计划、五层获取与认证独立的执行顺序、官方 API policy 和 Provider-scoped Browser 调度：ADR 0015。
   - CloakBrowser 固定身份、binary/Profile 生命周期、受限验证资源和统一 Challenge 页面合同：ADR 0016。
   - 共享单次 Agents Runtime 与消费模块边界：ADR 0017；DSH 受控执行基础及多轮历史修订：ADR 0031；唯一通用 Browser 路线结合 ADR 0023。
   - 唯一用户级普通配置文件、配置路径所有权和旧配置迁移：ADR 0018。
   - 外部 Agent 编排、Entry/MCP/Skill、解析目标、SDK 驱动模型运行时和 Network transport gate：ADR 0019。
   - Provider/Model 注册表、Model 自有 reasoning/image/stream、Analyze/Download 直接选择、模块派生调用合同、自动模型目录与旧 schema 严格拒绝：ADR 0021。
   - Source Auto/Custom、默认安全 catalog、Custom 冻结列表、逐 Source metadata limit 与旧 `[discovery]` 删除：ADR 0022。
   - 唯一通用 Browser Agent、单步worker/文章session、5秒节奏与300秒/30次模型调用累计预算：ADR 0023；下载取消身份门、PDF 未验证标签：ADR 0029；后台transfer、平台网络资格与candidate/publication交接：ADR 0030。
   - 文献库中心的 Web、日常加工与阅读服务、可选直接操作和无默认人工待办：ADR 0032。
   - CLI/MCP 分别覆盖 Web 业务、Web 专有视觉交互及维护诊断分工：ADR 0033。
   - 统一处理器、默认标签/记录提取、长期结果及输入复用：ADR 0034。
   - 原始解析、校订稿、文献建档、元数据字段、标签词表、就绪状态与算子输入：ADR 0037。
4. 讨论代码组织、持久化、外部访问和具体运行机制时再读[技术文档](../technical.md)。

尚未接受的设计放在讨论或活动提案中，不得提前写成 Accepted ADR。完成、拒绝或被替代的讨论材料进入 `docs/archive/`，不参与当前架构解释。
