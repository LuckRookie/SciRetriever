# ADR 0046：阅读批注作为用户数据保存在 catalog

类型：决策（ADR）
负责：阅读批注（高亮、框选与笔记）的归属、锚点、保存与机器访问
状态：Accepted（2026-10-29，Owner 确认：“1、存进去 2、可以 3、排在之前那批问题之后吧”）

- Date: 2026-10-29
- 依据：Owner 2026-10-29 要求在阅读中加入高亮、笔记、标签和框选，做法交给 Claude；评审过的方案见[历史提案](../../archive/2026-10-29-reading-annotations/README.md)。
- 约束来源：[需求](../requirements.md)“阅读”一节；[ADR 0032](0032-library-centered-web-workspace.md) 第 114–115 行；[ADR 0033](0033-machine-interfaces-cover-web-capabilities.md) 第 9 条。

## 背景

需求与 ADR 0032 都规定：批注、笔记属于用户数据，引入时须写明业务 owner、来源绑定、持久化、保留与导出，并在同等授权下可以由机器访问。

批注同时落在两种材料上：
- PDF 文字层；
- 建档后的校订稿全文。

两者文字不完全相同。2026-10-29 在 5 篇真实建档文献上只读实测：
- 校订稿里存在的选段，先按区块的页码与区域缩小范围，再统一写法比对文字，全部能对上；
- 整理时删掉的内容全部如实标为对不上，没有一次被放到错误位置。

## 决定

1. **归属**：批注由新的 `marks` 业务 owner 负责，界面上叫“批注”。
   - 它是用户对一篇文献的标记，不是文献事实，不改变元数据、状态、标签或检索。
   - 代码里不用 annotation 一词，避免和建档的结构注释混淆。
2. **存储**：保存在 catalog 的 `reading_marks` 表，随现有备份一起保存。
   - 这次表结构升到 schema 14。
   - 已有正式库需要用 `scripts/migrate-reading-marks-v14.mjs` 显式离线迁移；打开库时不会自动迁移。
   - 文献删除时，它的批注一起删除。
3. **种类与颜色**：
   - 两种批注：高亮，必须有原文；框选，必须落在 PDF 的某一页上。
   - 五种颜色，默认含义为“重点、方法、结论、疑问、待查”。保存的是颜色本身，含义只是标签。
4. **锚点**：每条批注至少有一个锚点，锚点要么完整，要么没有。
   - PDF 锚点：PDF 的 sha256、页码、页面矩形。矩形用缩放为 1 的 PDF 页面单位，原点在左上角。
   - 全文锚点：校订稿的文档版本和 UTF-8 范围。
   - 每条批注还保存原文和前后各一小段文字，材料换了版本时用它们重新定位。
   - 锚点只能指向这篇文献自己的 PDF 或文档版本。
5. **两种材料之间对位**：第二个锚点在对位成功后补存，不在打开文献时重算。对位分两步：先按区块的页码与区域缩小范围，再统一写法比对文字。结果按相似度分三档：
   - 不低于 0.85：按位置显示；
   - 0.7 到 0.85 之间：显示为“近似位置”；
   - 低于 0.7：标为“仅 PDF”或“仅全文”。

   页码与区域只是定位提示（ADR 0037），最终以文字比对为准；对不上时如实标明，不编造位置。
6. **笔记与标签**：
   - 笔记是纯文本，最多 20,000 字符。
   - 笔记里的 `#标签` 由笔记文字推出，不另外存。它们与 [ADR 0034](0034-unified-processors-and-results.md) 的派生标签互不写入。
7. **删除**：删除只做标记，30 天内可以恢复；到期后，下一次写批注时清除。
8. **机器访问**：与 Web 使用同一套合同。
   - CLI：`marks list|export|create|update|delete|restore --request FILE`；
   - MCP：`marks_query`（列出、导出）与 `marks_manage`（写入）；
   - 查询入口：`/api/v1/query/marks`；
   - 导出格式为 Markdown 和 JSON。Markdown 按页分组，写出颜色含义、原文与笔记。

## 不在本决定内

- 跨文献的批注总览页；
- 整篇笔记、引用悬停预览；
- 需要调用模型的选段翻译、术语解释、对选段提问；
- 与 Zotero 等外部工具同步；
- 多人共享批注、手写笔迹。

以上另行决定。阅读器里的交互规则遵循[设计内核](../web/design-core.md)。
