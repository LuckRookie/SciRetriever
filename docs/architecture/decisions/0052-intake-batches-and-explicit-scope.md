# ADR 0052：入库批次、写明范围的 PDF 获取与关键词分层

类型：决策（ADR）
负责：元数据入库的批次记录、批量获取 PDF 的范围、作者关键词与主题词的区分
状态：Accepted（2026-11-01，Owner 确认：“按设计做”）；部分被取代：第 2 节“范围内的词”的层次与排列见 [ADR 0053](0053-scope-terms-led-by-tags.md)；第 1 节的入库方式、批次完成之前的状态与撤回见 [ADR 0063](0063-unified-intake.md)

## 背景

- **入库记录**：
  - 主题发现和引用扩展已经在 catalog 里记有发现运行与结果，书目导入没有任何记录；
  - Web 入库页只在当前会话里保留 30 条回执，关掉页面就看不到了；
  - 文献库能按发现运行筛选，但筛选标签显示的是内部 ID。
- **PDF 获取的范围**：Web 端只能对勾选的文献获取，“全选符合条件的”最多 1,000 篇。用户没有办法表达“这次入库带进来的那一批里、某个方向的、还没有 PDF 的”。
- **关键词**（2026-11-01 对真实库只读核查）：
  - OpenAlex 适配器把学科分类（concepts）同时写进了作者关键词和声明关键词。平均每篇 23 个，没有按相关度过滤，里面有与文章无关的分类。
  - 文献当前的关键词只取人工填写的。库里 30,111 篇的来源记录带关键词，实际显示出来的是 0 篇，与 ADR 0037 规定的“人工 > 校订稿 > 来源”不一致。

## 决定

### 1. 入库批次

- 每次元数据入库都形成一个持久的入库批次，无论从 Web、CLI 还是 MCP 发起。入库方式包括主题发现、引用扩展和书目导入。
- 批次记录这些内容：
  - 方式、发起入口、时间、状态；
  - 用户的输入，例如检索式、年份、种子文献、文件名；
  - 命中篇数：本批之前不存在的、已存在但补充了元数据的、已存在没变的；书目中未接纳的条数。
- 批次的成员是这次命中的全部文献，包括原来已经在库的。“本次获得的 1000 篇”指的就是这 1000 篇。
- 每个批次的 PDF 状态（已有、无法获取、待获取）按当前库现算，不另存。
- 批次有默认名称，用户可以改名。
- 引入批次之前已经在库的文献，合成一个“早期入库”批次，保证每篇文献都能查到来历。

### 2. 范围只有一种表达：文献库筛选

- 入库批次、作者关键词和主题词都作为文献库的筛选条件。
- 文献库提供“范围内的词”：在当前筛选结果里统计最常见的作者关键词和主题词，以便在还没有 PDF 时，按方向逐步缩小范围。
- 不为获取 PDF、建档另设选择器。这些批量操作的范围，就是一组勾选的文献或一组筛选条件。

### 3. 获取 PDF 先看清范围再提交

- 提交之前，界面写明范围的来历和条件、实际处理多少篇、跳过多少篇以及原因（已有 PDF、已标记无法获取、超出本次上限）。
- 范围可以按筛选条件整体提交，由服务端解析，不受前端已加载行数的限制。
- 成员在创建任务时固定，之后新入库的文献不会加进来。
- 可以限定“本次最多 N 篇”。超出时按文献库当前的排序取前 N 篇，不随机挑选。
- 任务保存这段范围说明，任务页和入库记录都能看到。

### 4. 三种词分开

- **作者关键词**：论文自己给出的关键词。当前值的优先级按 ADR 0037：人工 > 校订稿 > 来源。来源中只有真正提供作者关键词的才计入，例如 Europe PMC、Elsevier 和书目文件。
- **主题词**：数据库给的学科分类，例如 OpenAlex concepts、Crossref subject。
  - 单独保存与显示，不混入作者关键词，也不进入书目导出的关键词字段。
  - 新取得的数据按相关度过滤，每篇最多保留 8 个。
- **标签**：建档时按受控词表给出，需要全文，规则仍按 ADR 0037。

## 后果

- catalog 表结构升一版，用来保存批次及其成员和主题词；迁移时要建“早期入库”批次、把已有的 OpenAlex 分类改归主题词，并重新投影全部文献。旧数据没有相关度，迁移时无法按相关度过滤。
- 真实库的文献大多来自 OpenAlex，而 OpenAlex 不提供作者关键词。所以在获取 PDF 之前，主要靠主题词来粗筛；作者关键词要等建档以后才逐渐补全。
- 入库页的会话回执改为持久的入库记录。阅读页信息栏分三行显示作者关键词、主题词和标签，并显示文献所属的批次。
- 规格写在 [technical/06](../technical/06-retrieval-context.md) 的文献库查询部分，以及[页面规格](../web/page-specs.md)的入库、文献库与阅读页部分。
