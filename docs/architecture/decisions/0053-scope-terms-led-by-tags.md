# ADR 0053：范围内的词以标签为主

类型：决策（ADR）
负责：文献库“范围内的词”统计哪几层词、怎样排列与提示

## 背景

- ADR 0052 的“范围内的词”只统计作者关键词和主题词，服务于还没有 PDF 时的粗筛。
- 建档会补上两种词：元数据步骤从论文正文摘出作者关键词，标签步骤按受控词表给出标签。建档的文献多起来以后，筛选主要靠这两种词。
- 作者关键词是各篇论文自己写的，同一概念有多种写法，篇数会被拆散。真实库里已经出现“AI”与“Artificial intelligence”、“Sodium‐ion Batteries”与“Sodium-ion battery”分成不同项的情况。标签一个概念只有一个，同义写法记为别名，按标签筛选得到的篇数准、范围完整。

## 决定

1. **三层词，固定顺序**：“范围内的词”依次列出标签、作者关键词、主题词。标签按出现在当前结果里的篇数统计，不区分主次；点一个标签即加为标签筛选条件（任一标签即可）。
2. **写明覆盖篇数**：每层写出当前结果里有这一层词的篇数，与结果总篇数并列。各层篇数只在本层内比较，不能读作整个范围。
3. **主题词让位**：当前结果里有标签的篇数达到一半时，主题词一层默认收起，需要时再展开。
4. **关键词指向标签**：作者关键词恰好是某个标签的名称或别名时，界面指出对应的标签；已选的作者关键词有对应标签时，提示可以改用该标签筛选。
5. 获取 PDF 之前的粗筛仍靠主题词和来源给的作者关键词，这一层不删除。

## 后果

- 范围词频的返回增加标签一层、各层覆盖篇数，以及作者关键词对应的标签；规格在 [technical/06](../technical/06-retrieval-context.md) 2.1.6，页面表现在[页面规格](../web/page-specs.md)的文献库部分。
- 不改 catalog 表结构；标签与别名读取已有的标签表。
