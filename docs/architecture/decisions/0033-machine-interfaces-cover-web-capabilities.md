# ADR 0033：CLI 与 MCP 分别覆盖 Web 业务能力

- Status: Accepted（Owner 已确认；实施状态见当前指南和计划）
- Date: 2026-10-15
- Amends: [ADR 0019](0019-agent-operable-application-and-sdk-model-runtime.md)、[ADR 0032](0032-library-centered-web-workspace.md)
- Related: [R11/R12](../requirements.md#r11-科研-agent-产品接口)、[统一产品接口](../technical/01-product-interface.md)

## 背景

Owner 明确 Web 面向人、CLI/MCP 面向 Agent。Web 覆盖大部分常用业务，复杂诊断与维护可以交给 Agent；同时 CLI 和 MCP 必须分别是 Web 业务能力的超集，不能靠两者并集补齐，也不能产生只有点击页面才能调用的业务。

## 决策

1. 同一授权、配置与运行条件下，Web 业务能力包含于 CLI，亦包含于 MCP。比较可完成的操作、可读取的信息与结果，不要求复制主题、标签布局或面板开关。当前只读 MCP 保持只读；相应显式授权模式下才开放写入和外部请求。
2. 三端调用共同 Application/Entry 与既有业务 owner。页面和协议适配器负责交互、参数转换、有界传输、取消和错误映射，不另建业务状态、编排、身份决定或存储写入所有者。
3. CLI 必须支持非交互输入、结构化结果和稳定错误；MCP 按可理解的业务能力提供工具与明确 schema。通用 JSON 传输不等于任意内部方法调用权限。保留已支持命令、工具及请求格式，不以替换旧接口获得覆盖率。
4. 操作范围、缺省语义、固定 ID/hash、任务结果、幂等、失败、取消和重试保持一致；长操作报告已接收不等于结果成功。执行寿命可以随进程模型不同，但必须明确，不虚构 CLI 退出后仍运行或跨进程 Browser 自动共享。
5. 配置管理也是产品能力。修订 ADR 0019 的 MCP 普通配置编辑禁令：允许通过唯一 Configuration owner 读取、预览、按 revision 发布受支持配置并显式测试，遵守与 Web 相同的冲突、生效和访问规则。凭据允许通过专用受控输入设置/移除，不提供读取秘密值、任意配置文件或任意服务器文件路径的工具。
6. Browser 业务协作采用既有 observation、session、epoch 和控制租约合同。允许机器入口获得受控观察、指导和动作能力；不开放任意 Page/CDP、JavaScript、Cookie、Profile 或不受控 URL。操作活会话须连接持有会话的 runtime，不能从共享 catalog 推导跨进程控制权。
7. 大文件按受控资源、稳定引用和有界读取交付，不默认塞入模型文本。传输形式可以不同，但都必须经过相同资产/证据校验、写入 owner 和不可变发布。
8. Web 的完备性按日常业务闭环评价。普通失败提供可理解结果与恢复入口；深入故障可以交给 Agent。三端通过稳定任务/文献/产物引用衔接，不引入第二份诊断或任务事实。

## 影响与验证

新增或调整 Web 业务时同步审查两个机器入口，按能力矩阵核对实际生产路径。验证应通过真实 CLI 参数和 MCP 客户端，检查结果、失败与权限；不以按钮、工具数量或一份映射表代替验证，不新增机械数量门禁。

本决定不要求 Web 承载全部运维命令，不新增自动提取算法、迁移、领域数据或批注等业务事实，不自动授权真实数据操作。实施与覆盖核对见[三端能力计划](../../plans/2026-10-15-interface-capability-parity/README.md)。
