# ADR 0049：阅读页划词翻译与服务端翻译缓存

类型：决策（ADR）
负责：阅读页翻译的入口、请求、内置提示词、缓存与设置的存放
状态：Accepted（2026-10-30，Owner 确认：“我同意你的做法。然后写ADR。然后就可以开始干活了”）

- Date: 2026-10-30
- 依据：Owner 2026-10-30 的需求——在批注旁加翻译选项，可选模型、翻译语言、是否开启悬浮框；划哪些词就翻译哪些词；内置提示词，请求时把提示词和语句一起送出；缓存最多 1000 道翻译，先匹配已翻译的语句，匹配到就直接显示、不发请求；同意缓存放在服务端程序目录、不进文献库。
- Related: [ADR 0046](0046-reading-marks.md)（阅读批注）；[需求](../requirements.md) 阅读部分

## 背景

阅读页已有 PDF、全文两种视图和阅读批注（ADR 0046），没有翻译。Owner 要求在批注旁加翻译：选择模型与目标语言，划词后在悬浮框里看到译文，重复的语句不再请求模型。

## 决定

### 1. 入口与设置

- 阅读页右侧面板在“信息、批注”之后加“翻译”标签。标签里有三项设置：**模型**、**目标语言**、**划词翻译**开关；下方列出本篇最近的翻译，可复制、可回到原文位置。
- **模型**从服务启动时已登记的模型中选，默认沿用 `analyze.model`；新登记的模型在服务重启后出现在列表里。**目标语言**默认简体中文，提供常用语言的封闭列表。**划词翻译**默认开启。
- 三项设置是**浏览器偏好**，与主题一样保存在浏览器本地，随点随生效。不写入用户配置文件：普通配置的任何改动都会让服务提示“需重启后应用”，翻译开关不应如此。每次请求带上模型与目标语言，由服务端校验。

### 2. 划词翻译

- 划词开关开启、且当前是选择工具时，在 PDF 或全文中选中文字，选区旁弹出悬浮框显示译文：命中缓存立即显示，否则先显示“翻译中”。悬浮框标明翻译所用的模型，提供“复制”和“重新翻译”；重新翻译跳过缓存，新结果覆盖旧的。
- 使用高亮笔时选中文字是做批注，不触发翻译。
- 开关关闭时，选区工具条提供“翻译”按钮，结果显示在翻译标签里。
- 一次最多翻译 4000 个字符，超出时提示缩小选区；连续划选只翻译最后停下的那一次。

### 3. 请求与内置提示词

- 服务端提供翻译接口：入参为原文、目标语言、模型、是否跳过缓存；先查缓存，没命中再调用模型，结果写回缓存。只在用户划词或点“翻译”时发送文字。
- 每次请求只发一次模型调用：内置提示词加原文，以结构化结果返回译文，不用工具。提示词由程序内置并带版本号，具体措辞由技术文档维护，至少要求：数字、单位、化学式、公式（LaTeX）、引用编号、人名与缩写保持原样；只输出译文。
- 模型调用沿用已登记的 Provider、模型设置与凭据，不新增凭据。

### 4. 缓存

- 缓存放在服务所在机器的程序目录：`~/.sciretriever/cache/translations.sqlite`，单独一个文件，不写进文献库（catalog）；删除这个文件即清空缓存，不影响任何资料。
- 最多 1000 条，满了淘汰最久没有用到的一条。
- 匹配：原文先规范化（Unicode NFKC、连续空白合为一个空格、去掉首尾空白）再精确匹配。缓存的键是“规范化原文、目标语言、提示词版本”，**不含模型**；换模型仍可命中，每条缓存记录所用模型，需要时手动“重新翻译”。
- 翻译请求不进入文献库的操作记录与活动流，也不记录原文与译文。

### 5. 接口范围

翻译接口只供 Web 阅读页使用，不进入 CLI 与 MCP：翻译是给人看的阅读辅助，Agent 直接读取原文即可。

## 未采用的方案

| 方案 | 原因 |
| --- | --- |
| 设置写入用户配置 `[translate]` | 普通配置改动会要求重启服务，划词开关、换语言都要重启 |
| 缓存放在浏览器本地 | 换浏览器或清理网站数据后失效，服务重启前后也无法共享 |
| 缓存写进文献库 | 翻译缓存可以随时丢弃，混进 catalog 会让备份、迁移和版本管理带上无用数据 |
| 缓存键包含模型 | 换模型后同一句话要重新请求；需要新模型的结果时可以手动重新翻译 |
| 作为维护操作，进入 CLI/MCP | 维护操作会写入文献库的操作记录，原文会因此进库；Agent 不需要翻译 |

## 后果

- 同一句话第二次翻译不调用模型，立即显示。
- 残余风险如实承认：
  - 只有完全相同的语句（规范化后）才命中，改动一个词就重新请求；
  - 不同模型的译文共用一条缓存，显示的是最后一次翻译所用的模型；
  - 浏览器偏好只在当前浏览器有效，换浏览器需要重新选择。
