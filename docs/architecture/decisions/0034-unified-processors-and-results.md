## 决定

Owner 已确认精简的文献知识加工服务：可信仓库处理器（算子）共用 DSH、受控读取、持久任务与存储。范围为文献级（单篇）和集合级（多篇）处理，不建立通用算子形状、配方或用户代码沙箱。按 ADR 0037，单篇算子只读取就绪文献的校订稿，按声明的部分与章节角色读取，单篇算子之间不互相依赖；多篇算子以冻结的快照为输入，先用声明的单篇算子逐篇读取，再只基于单篇结果汇总。

处理器声明版本、输入与输出类型、规范和执行方法。提交时固定材料/结果版本、规范、方法以及有效模型配置；复用同时比较这些身份并核查内容完整性与覆盖；单篇结果的复用键使用被读取部分的内容版本，描述版本（元数据与标签）不参与。恢复不重新选取默认文档或模型。版本变化只把相关结果标记为过时，不自动重算；是否基于新快照或当前版本重新运行由人决定。新运行可以复用旧产物，不承诺每次运行都调用模型。

处理执行状态与覆盖分别记录。零命中、未读取和不支持的能力不能代表原文未报告；只有声明范围完整处理且无记录才是“原文未报告”。文献缺少声明要读的部分时记为“无该部分”，补充材料不可用时记为“读取不完整”，三者不能混同。partial 可保存、引用和重新处理，不能阻止后续完整产物，也不能自动作为完整成功复用。

Analysis 拥有通用结果接纳与处理器，Extraction 保留外部候选校验责任；默认标签与记录提取可替换。领域 schema、科学含义、单位领域规则和最终数据集接纳仍由调用方拥有。旧分析产物及外部提交协议保持可读可用，外部回执不自动升级为长期候选正文。

发布结果和集合清单不可变，成员通过稳定引用组合。旧内容保持原 owner，新结果的大内容存入不可变文件；catalog 保存目录、精确依赖和可重建记录/检索投影。长期结果独立保护其证据，不受外部回执过期影响。索引失败不撤销有效发布，查询不触发加工或补库。

结果具有规范、内容类型、证据、来源和覆盖合同，可作为多篇算子的输入。综合必须保留记录字段到原文的引用链并去重实际文献来源；多个结果不能伪装为多篇独立证据。CLI/MCP 使用共同应用边界，按字段查询、内容检索和导出不泄露内部 SQL、绝对路径或凭据。

## 取舍与验收

选择精简处理器而非完整形状/配方/Unit 依赖体系，先验证新增方法无需改动执行、存储及机器入口。完整版保留为[参考设计](../../proposals/2026-10-17-knowledge-processing-full-design/README.md)，实际重复工作或重算成本出现后再决定扩展；不要求外部框架或向量库。文档校订（区块级仲裁）后来按 ADR 0037 作为建档的一部分引入，不属于处理器。

验收包括重叠集合复用、模型与输入变化、恢复固定输入、部分结果补全、记录进入综合、长期证据和索引重建。合成 fixture 与 fake 模型验证机制，真实语料准确率与真实 Agent 自主行为另行授权评估。Accepted 不表示实现或质量已验收。
