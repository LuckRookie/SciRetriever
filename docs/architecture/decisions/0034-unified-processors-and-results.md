# ADR 0034：统一处理器接口与结果格式

- Status: Accepted
- Date: 2026-10-18
- Amends: [ADR 0027](0027-extraction-capabilities-and-caller-defined-records.md)
- Related: [产品需求](../requirements.md)、[精简实施计划](../../archive/2026-10-18-knowledge-processing-platform/README.md)

## 决定

Owner 已确认精简的文献知识加工服务：可信仓库处理器只消费已有材料和显式上游结果，共用 DSH、受控读取、持久任务与存储。首版范围为文献级和集合级处理，不建立通用算子形状、配方或用户代码沙箱。

处理器声明版本、输入与输出类型、规范和执行方法。提交时固定材料/结果版本、规范、方法以及有效模型配置；复用同时比较这些身份并核查内容完整性与覆盖。恢复不重新选取默认文档或模型。文献级处理独立复用；集合输入变化后整体综合。新运行可以复用旧产物，不承诺每次运行都调用模型。

处理执行状态与覆盖分别记录。零命中、未读取和不支持的能力不能代表原文未报告；只有声明范围完整处理且无记录才是 empty。partial 可保存、引用和重新处理，不能阻止后续完整产物，也不能自动作为完整成功复用。

Analysis 拥有通用结果接纳与处理器，Extraction 保留外部候选校验责任；默认标签与记录提取可替换。领域 schema、科学含义、单位领域规则和最终数据集接纳仍由调用方拥有。旧分析产物及外部提交协议保持可读可用，外部回执不自动升级为长期候选正文。

发布结果和集合清单不可变，成员通过稳定引用组合。旧内容保持原 owner，新结果的大内容存入不可变文件；catalog 保存目录、精确依赖和可重建记录/检索投影。长期结果独立保护其证据，不受外部回执过期影响。索引失败不撤销有效发布，查询不触发加工或补库。

结果具有规范、内容类型、证据、来源和覆盖合同，可作为后续处理输入。综合必须保留记录字段到原文的引用链并去重实际文献来源；多个结果不能伪装为多篇独立证据。CLI/MCP 使用共同应用边界，按字段查询、内容检索和导出不泄露内部 SQL、绝对路径或凭据。

## 取舍与验收

选择精简处理器而非完整形状/配方/Unit 依赖体系，先验证新增方法无需改动执行、存储及机器入口。完整版保留为[参考设计](../../proposals/2026-10-17-knowledge-processing-full-design/README.md)，实际重复工作或重算成本出现后再决定扩展；不要求外部框架、向量库、文档修复 Agent 或新 Web 页面。

验收包括重叠集合复用、模型与输入变化、恢复固定输入、部分结果补全、记录进入综合、长期证据和索引重建。合成 fixture 与 fake 模型验证机制，真实语料准确率与真实 Agent 自主行为另行授权评估。Accepted 不表示实现或质量已验收。
