# ADR 0071：阅读页以 PDF 为主角；两个悬浮小球管译文与读本

类型：决策（ADR）
负责：打开一篇文献看到什么；原件、译文、读本怎样换、怎样并排；这些开关放在哪里、按什么规则变化；导图从哪里进

  - TextFold 的做法（`textfold/web/reader.js`、`reader.css`，只取道理）：只有读到多细这一件事有显眼的控件，是文本下方的一条，滑块跟着手势走；其余每样只占一个按钮；只在某一层才有的选择只在那一层出现。

## 决定

### 1. 主角与配角

- 打开一篇有 PDF 的文献，看到的是 PDF 原件，别的什么都没有。
- 从 PDF 加工出来的东西是配角，要的时候才出现，只有两样：**译文**，和**读本**。读本是重排的文本，有三档深浅：概览、脉络、全文（样子与换层见 ADR 0070）。
- 界面上不再有“视图”“材料”“读法”这些分组的词。

### 2. 两个悬浮小球

案头右下角有两个小球，“读”在上，“译”在下。各管一对东西：“译”管原文与译文，“读”管原件（PDF）与读本。规则只有两条：

1. **单击是换**：换成这一对里的另一样。球上写的是点一下会去的地方：看原文时写“译”，看译文时写“原”；看 PDF 时写“读”，看读本时写“看”。
2. **双击是并**：两样并排。球上写两样：“原/译”“看/读”。并排时再点一下，收回到并排之前看的那一样。

- 单击立即生效，不等着分辨是不是双击；紧接着的第二下把它变成并排。
- 指针停在小球上时，旁边伸出一个小签“并排”（并排时写“收回”），点它等于双击。
- 两个小球叠起来共九种情形：

  |                   | 原文                   | 译文（单击“译”）   | 原/译（双击“译”）          |
  | ----------------- | ---------------------- | ------------------ | -------------------------- |
  | 看 PDF            | PDF 原件               | 整份换成译文页     | 左原件页，右译文页         |
  | 读本（单击“读”）  | 读本原文，下方有程度条 | 读本译文           | 读本里一段原文一段译文     |
  | 看/读（双击“读”） | 左 PDF，右读本         | 左 PDF，右读本译文 | 左 PDF，右读本原文译文对照 |

- **PDF 一旦和读本并排，左页始终是原件，“译”只管右边的读本。**
- 缺什么就没有什么：没有全文的文献没有“读”球；只有全文没有 PDF 的文献也没有“读”球，页面就是读本；没有译文的文献“译”球变淡，指针停上去说明原因。窗口窄到放不下两页时不并排，小签上写明原因。
- 每种情形在“更多”菜单与快捷键里都有一项，不依赖双击。

### 3. 程度条

- 读本在场时，它的正下方有一条：概览 › 脉络 › 全文。读本不在场时没有这一条。
- 滑块跟着换层的进度连续移动；可以点一档，可以拖滑块，可以在条上滚轮，也可以在读本上按住 `Alt` 滚动。
- 单击“读”第一次到全文，以后回到这篇文献上次停的那一档。
- 没有阅读层的文献，读本只有全文一档，没有这一条。

### 4. 导图

- 顶栏原来放视图切换的位置只留一个“导图”按钮，只在文献有阅读层时出现。
- 按下后导图占满整个案头，是单独的一页，用来看整篇文章的脉络；再按一次或按 `Esc` 回到原来的地方。
- 导图这一页上只有“译”球，并且只有单击。

### 5. 其余跟着改的

- 顶栏的视图切换与读法切换去掉；顶栏只有标签页、“导图”按钮与工具。
- 右侧面板“翻译”标签页里的对照翻译开关去掉，那一页只留划词翻译与粘贴翻译。
- “译”的状态按本机记住，所有文献共用；“读”的状态与程度条停在哪一档按文献记住。
- 专注模式下小球与程度条淡出，指针靠近才出现。

## 后果

- 顶栏上与阅读方式有关的词由十几个减为一个。
- 第一次打开有阅读层的文献不再先到概览（阅读体验 6.4 原来的规定），而是 PDF。概览要点一下“读”再点程度条。
- PDF 与读本要能同时在案头上，各自滚动、互相跟随。现在的引擎同一时刻只显示一个视图，这是最大的一处改动。
- 读本三层、批语与换层（ADR 0070，已实现）原样用在读本里。
- 双击是藏着的手势，靠悬停的小签、菜单与快捷键补足。

## 还没有决定的事

- 被批的句子要不要直接画在 PDF 上（原件上压一道朱线，点了对上右边的批语）。位置数据是有的；倾向做，放在这次之后。
- 屏幕足够宽时，原件、译文页、读本三页并排。先把两页的规则做稳。
- 译文正文用黑体还是宋体（现在是黑体）。
- 书眉的一粗一细线（ADR 0070 的目标，尚未实现）与这次的关系：读本整页时照 ADR 0070；并排时读本的页眉从简。
