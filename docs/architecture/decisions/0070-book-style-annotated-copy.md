# ADR 0070：书本风格以批校本为核心；阅读层的样子、换层与各页面按它定

类型：决策（ADR）
负责：书本这一套风格的核心是什么；作者、机器、读者三种话怎样区分；全文、脉络、概览、导图各是什么样子；层与层之间怎样换；外壳各页面怎样与阅读页成为一个东西；一套风格管哪些东西
状态：Proposed（等 Owner 审定）

## 背景

分层阅读做过五版样稿。前四版按“折”做，第五版回到字的移动，并参照 TextFold 加了导图。Owner 每次都认可局部，但指出整体割裂。原因是页面说着几种话：阅读页是纸与墨，换层借的是 TextFold 的做法，导图是白板工具的样子，到处的小标签（“要点 1”“原句”“图”）是后台界面的写法。每一块都是就近借来的，没有一个共同的来处。

Owner 一直说产品的特点是书本。设计内核里也早已写着“印的是墨，记号才有颜色”。缺的是把这条原则落到一个具体的、读书人认得的东西上，再让每个细节从它出来。

## 决定

### 1. 核心是批校本

一本带批注的书：作者的话是印出来的正文；别人加在上面的话是批语和记号，用另一种墨、另一种字，放在正文之外的位置。我们的阅读页就是这样一本书，批的人是机器，读者自己也可以批。

谁的话，由墨色、字体和位置说明，不由标签说明。页面上不出现“要点”“原句”“图”这类给界面的部件起名字的文字；记号怎样读，在卷首的凡例里说一次。

界面文字用简明的现代书面语，只借书里的名目（凡例、提要），不用文言虚词。

### 2. 三种话的写法

| 谁的话                                                     | 字体                     | 颜色                             |
| ---------------------------------------------------------- | ------------------------ | -------------------------------- |
| 作者（正文、标题、图题、书目）                             | 宋体，拉丁字母用衬线体   | 墨                               |
| 机器，批在作者文字旁边                                     | 楷体，拉丁字母用衬线斜体 | 朱                               |
| 机器，自己成文（提要、局限、精读建议，以及作了正文的批语） | 同上                     | 墨                               |
| 读者（划线、批注）                                         | 批注用楷体               | 划线是黄色涂抹，批注是笔色（蓝） |
| 界面的控件                                                 | 无衬线体                 | 墨                               |

- **朱色只表示机器加在作者文字上的东西**：页边的批语、批语的编号、被批句子旁栏线上的一笔、重点词。它不表示界面状态（当前视图、选中），那是读者的笔色。朱色只在阅读页出现。
- **批语**是原来说的“要点”在界面上的名字；数据与接口里的名字不变。每条批语有全篇唯一的编号，写在圈里；全篇主干的几条是实心的圈。被批的句子末尾有同一个带圈编号，和作者自己的引文号分得开。
- **重点词**是朱色加粗。在本身是朱色的页边批语里，重点词反过来用墨色加粗。不靠颜色的主题里是加粗加下划线。字下加点的做法不用：它只有读到那一行才看得见。
- 每个阅读主题给朱色一个取值，对纸的对比度不低于 4.5。
- 楷体随产品自带（霞鹜文楷，SIL OFL），安装包因此增加约 10 MB，做法与现在自带的宋体、黑体相同。

### 3. 四个视图

- **全文**：正文在版框里，段首缩进、段间不空行。正文与页边之间一条栏线。批语在页边，对着它所批的第一句；开头是编号与这一条的类别，下面一行淡墨小字写去处与关系（“见图 3”“承接 7”“依据 11”）。指针移到批语、编号或被批的句子上，三者一起亮。
- **脉络**：批语成了正文。每条批语用楷体墨字大字排出，下面低两格、小一号是它所批的原句，再下面是它的图。它和原句靠字号、缩进与字体区分，不靠颜色。作者写了而没有批语的文字不出现。页边放类别与关系。
- **概览**：卷首的东西。提要（研究对象、方法、结论，两三句）；主干批语，各带一行所据（原句的摘录，或它的图是什么）；主干所据的图在页边，大到看得清；数据（量、数值、出处，三线表）；局限；精读建议。栏目名在左页边。
- **导图**：独立的视图，不是第四层。全书的纲目画成一棵树，占和窗口一样宽的一张拉页。题名在一粗一细的框里，章节是带底线的宋体字，批语是带圈编号加短标签，细墨线相连。树按窗口自动缩放并居中；可缩放、拖动、收起章节（写明余下几条）、按类别标出一类；指针移到一条批语上，右栏显示它的全文、被批的句子和图，不必离开导图。
- 每页顶上是书眉：刊名、当前章节、页码，下面一粗一细的线；卷末相反。
- 批语的**类别**取自固定的几种：背景、问题、方法、结果、分析、结论、局限。**关系**指向另一条批语或一件图表，写法取自固定的几种：见、承接、依据、解释、总结、引申自。

### 4. 换层

- 新的一页照常排好；两页上都有的东西（批语、编号、被批的句子、标题）从旧位置走到新位置；只在旧页上的先淡去，只在新页上的最后浓起来。
- 全文到脉络：没有批语的文字先淡去；被批的句子收拢，给每条批语留出位置；批语带着编号在页边移到那个高度，再横着进到正文里，由朱变墨、由小变大。反方向相反：批语先退到页边，句子回到段落里，正文的墨最后在它们周围浓起来。
- 概览与脉络之间：主干批语保持上下次序一起移动，其余淡出或淡入。
- 为了不让东西互相压住：批语在页边与正文之间走直角，不走斜线；图不移动，随页淡出淡入；页边的类别与关系在全文与其他层之间不移动。
- 整个变化是一个 0 到 1 的值的函数。点击由时间推动；手势直接推动这个值，可以停在半途，停手后落到较近的一层。正在读的那条批语在换层前后停在屏幕上的同一高度。
- 使用者选择减少动效时直接换层。导图与三层之间直接切换。

### 5. 外壳各页面

离书越近越像书，分三层：

- **阅读页**就是那本书，按第 1 至 4 节。视图的切换（导图、概览、脉络、全文、PDF）与读法的切换放在产品顶栏，用现有的分段控件；书眉只留刊名、章节、页码。
- **讲文献内容的页面**（文献库、右侧详情、检索结果、找文献）是书目。版式不变，只用两条规矩：来自文献的文字（标题、作者、刊名、年卷期、作者摘要）用宋体，书目行按引文的写法；页头与列表之间是一粗一细的线。
- **工具页与外壳**（侧栏、顶栏、任务、设置、入库）是书房里的工具，只跟着改共用的变量。
- 每一页只放回答这一页的问题的东西。文献库回答“这是哪一篇、它的材料到了哪一步”，不显示批语的条数、读者批注的数目，也不设“有批语”的筛选。
- **文献库里材料的状态各有颜色**，圆点与文字同色，不带底色：已就绪为绿，有 PDF 为蓝，需要留意（没找到 PDF、未校对）为琥珀，失败为红，进行中不占颜色、用一个转动的小环。只有书目的不挂标记。

### 6. 一套风格管什么

书本是默认的一套风格；现有七个主题是它的变奏。一套风格决定：颜色、字体与字色、三种话的写法、重点词与批语怎样标、基础组件的外观。版式与行为各风格共用。实现时把这一层与版式、行为分开放。其他风格（Owner 提过现代、古风、像素、科技）另行决定。

### 7. 模型要多给的内容

在分层这一步里，除 ADR 0069 已有的要点、依据、重点词之外，另给：

- 哪几条是全篇主干（四五条）；每条批语的短标签（导图用，两种语言）；每条的类别；每条的关系。
- 提要（两种语言）；数据表的各行（量、数值、出处）；每条主干的所据（一句原句里的一段摘录，或一件图表）；局限与精读建议各条的出处。
- 程序核对：类别与关系的写法不在固定取值里的丢掉；关系指向的批语或图表不存在的丢掉；数据表的数值与摘录在全文里逐字找不到的丢掉；主干不足三条时这一步按 ADR 0069 的规则算失败。丢掉了多少记录在案。

## 还没有验证的前提

- 模型能挑对主干，给对类别与关系，短标签写得短而准。要在真实文献上跑过才知道。
- 换层在很长的文献上不卡。样稿只在一篇九页的文献上看过。
- 楷体切片后首屏不明显变慢。
- 墨水屏主题里朱色退为墨色之后，批语只靠楷体与位置仍然分得清。

## 还没有决定的事

- 对照读法在各视图里的排法；窄屏时批语落在哪里。
- 读者自己的批注在脉络与概览里放在哪里；导图里有批注的批语要不要带记号。
- 导图与三层之间要不要有过渡。
- 其他风格；长资料（ADR 0069 的同名一项）。

## 后果

- 规格要改：文档与证据第 10 节（第 7 节的内容与核对）、阅读体验第 3 节等（第 1 至 4 节）、设计内核（三种话的写法、朱色、楷体、状态颜色、风格的定义）、页面规格（文献行的材料标记、阅读页顶栏）。
- 后端：提示词与阅读层文件的版本上调，已有的阅读层标为过时，重新解析全文时重新产生。读取操作多出这几样内容。
- 前端：阅读页按样稿重写；分支 `layers-frontend` 上“折”的引擎不合入。文献库的材料标记换成有颜色的写法。字体包增加楷体。
- 设计内核里“状态色只有四种”改为五种（多一种琥珀），“文献的材料标记只有圆点和次要色文字”作废。

## 考虑过但没有采用的方案

| 方案                                  | 没有采用的原因                                                           |
| ------------------------------------- | ------------------------------------------------------------------------ |
| 折（ADR 0069 第 4 节）                | 是给机制起的名字，不是读书的人认得的东西；Owner 认为不是合适的表现方式   |
| 字在两层之间自由飞（TextFold 的做法） | 它来自 TextFold 自己的核心；搬过来没有理由，而且字会互相压住             |
| 重点词用字下加点                      | 只有读到那一行才看得见，扫一眼找不到                                     |
| 脉络里批语仍用朱色                    | 颜色说“我是批注”，字号说“我是标题”，两个信号相反；整页成了大片红字       |
| 批语用宋体加粗                        | 机器的概括与作者原话只剩编号可分，容易被当成作者的话引用；Owner 选了楷体 |
| 导图用彩色分支与类别圆点              | 在纸、墨、朱之外另起一套颜色；类别改用淡墨小字与“标出”                   |
| 在文献库显示批语条数与读者批注数      | 这一页的人只关心这条数据的状态；Owner 否定                               |
| 把侧栏、按钮、设置页也做成古书的样子  | 外壳是工具不是书页，做成古书是生搬硬套                                   |
