# Web 设计改动记录

类型：记录
负责：Web 设计每一次改动的时间、内容、原因、由谁决定、对应的提交
状态：现行

设计文档只写现在的规定，看不出它改过没有、为什么改。这份记录补上这一点：**凡是改了看得见的设计（颜色、字体、组件外观、排版、某一页呈现什么），在同一次提交里在这里加一行。** 一次大改动里顺带改掉的旧规定，各占一行，不并在大改动里。

- “由谁决定”写清是 Owner 的原话，还是总设计师自己的判断；后者要让 Owner 事后看得见。
- 被撤销的改动不删，另加一行写明撤销。
- 新的记录写在最上面。2026-11-26 之前的各行是从提交历史补记的，只收影响大的。
