# Web 风格

类型：导航
负责：什么是一套风格、现有哪几套、每一套的记录写在哪里
状态：现行（风格的定义待 [ADR 0070](../../decisions/0070-book-style-annotated-copy.md) 审定）

## 一套风格是什么

一套风格决定界面看上去是什么：颜色、字体与字色、作者、机器、读者三种话各怎样写、重点字词与批语怎样标、基础组件的外观。同一套风格里，所有这些围绕同一个核心。

风格不决定：页面有哪些内容、怎样排布、怎样操作。这些各风格共用，写在[排版](../layout.md)、[页面规格](../page-specs.md)与[阅读体验](../reading-experience.md)里。

**主题**是一套风格之内的变奏：只换纸、墨、笔与状态色的色调，别的不变。

## 每一套风格的记录写什么

每套一个文件，按同样的顺序：

1. 核心：这套风格是什么，一句话。
2. 元素：这套风格用到的每一样东西（纸、墨、笔、记号、线、徽标……），各是什么样子、表示什么。
3. 字体：每种文字用什么字体、字重。
4. 配色：每个主题的取值。取值以 `apps/web/src/app/styles/tokens.css` 为准；改取值时在同一次提交里改这张表，并在[改动记录](../changelog.md)里加一行。
5. 组件的外观：与别的风格不同的地方。
6. 还没有实现的部分。
