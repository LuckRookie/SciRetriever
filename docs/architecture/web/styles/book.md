# 书本风格

类型：规格
负责：书本这一套风格用到的元素、字体与七个主题的配色取值
状态：现行（标“待 ADR 0070”的各项尚未实现）

规则写在[设计内核](../design-core.md)，本文不重复规则，只列这套风格由哪些东西组成、各取什么值。取值以 `apps/web/src/app/styles/tokens.css` 为准；本文的表取自提交 `e8597daa` 时的内容。改取值时在同一次提交里改这里，并在[改动记录](../changelog.md)里加一行。

## 1. 核心

界面像印出来的书页：只有纸和墨，颜色只属于记号（[设计内核“基调”](../design-core.md#基调)）。

待 ADR 0070：核心落到“批校本”，一本带批注的书。作者的话是印出来的正文，机器的话是批语，读者自己也可以批；谁的话由墨色、字体和位置说明。

| 朱           | 每个主题一种朱色                                                                       | 机器加在作者文字上的批语、编号、重点词 | ADR 0070 第 2 节                                                                      | 待 ADR 0070 |

## 3. 字体

| 来自文献的一切（作者、刊名、摘要） | Source Serif 4      | 思源宋体             | 待 ADR 0070 |
