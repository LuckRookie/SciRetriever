# Web 页面规格

类型：规格（前端页面）
负责：信息架构、侧栏、页面模板与逐页排布
状态：现行

视觉规则见[设计内核](design-core.md)；当前已实现的操作见 [Web 指南](../../guides/web-workbench.md)。

## 整体信息架构

产品围绕一条主线组织：**找到文献 → 阅读与核对 → 在一批文献上运行算子 → 查看结果**，另有一组页面观看后台运行。

```
SciRetriever
搜索 ⌘K
资料
  文献库            35,177
    最近阅读             6
    需处理              12
    文件夹…
  快照
  词表
加工
  算子
  全文检索
  洞察
运行
  任务          2 进行中
  浏览器
────────
设置
```

| 侧栏分组 | 页面     | 在主线中的位置                                      |
| -------- | -------- | --------------------------------------------------- |
| 资料     | 文献库   | 找到文献、选择一批；下挂最近阅读、需处理与文件夹    |
|          | 快照     | 把一批文献及其版本固定下来，作为范围                |
|          | 词表     | 管理标签                                            |
| 加工     | 算子     | 运行算子、回看运行记录与结果                        |
|          | 全文检索 | 在已建档全文中找片段                                |
|          | 洞察     | 看分布与引用关系                                    |
| 运行     | 任务     | 后台任务的进度与失败；切换到“Agent 会话”看 DSH 会话 |
|          | 浏览器   | 观看与接管下载                                      |
| 底部     | 设置     |                                                     |

- “需处理”是需要人处理的建档问题，在文献库框架内显示；计数为 0 时显示为灰色。
- Agent 会话都由任务发起，因此并入任务页；任务项旁显示进行中的数量，没有进行中时不显示。
- 旧地址照常可用：`view=agent` 打开任务页的“Agent 会话”，`view=archive` 打开文献库的“需处理”。
- 阅读页不在侧栏：从任何文献标题打开，以顶部标签页的形式存在。
- 结果有两个入口：算子页按运行记录看，阅读页“结果”标签按单篇看。
- 运行算子只有一种入口形式：四步对话框（范围 → 算子 → 规范 → 确认），可从文献库、阅读页、快照页、算子页打开；已有范围时跳过“范围”一步。
- 入库不在侧栏：文献库页头的“入库”按钮进入入库页。

## 页面模板

```
页标题  上下文数字                                   [主操作]
工具条（一行；必要时第二行放快速筛选）
内容
```

- 页头不放说明系统行为的句子；对用户有用的信息改为界面状态、按钮文案、字段旁的提示，或页面底部的页注。
- 上下文数字示例：文献库“35,177 篇”、快照“3 个”、任务“2 个进行中”、需处理“12 项”。
- 空状态：一句话加至多一个动作，例如快照为空时“还没有快照。在文献库筛选后，可以把结果生成快照。”
- 没有数据时隐藏分页与批量操作。

每页按“用户来做什么 → 要呈现的信息（按优先级）→ 排布”说明。

## 文献库

**用户来做什么**：找到文献，看清它的材料状态，选一批去做事。

**信息优先级**：

1. 文献行：标题、书目（作者 · _期刊_ · 年份）、标签、状态；
2. 当前检索与筛选：检索词、状态、已应用的筛选条件；
3. 结果数量：已显示 / 共几篇；
4. 批量操作。

**排布**：

```
文献库  35,177 篇                                              [＋ 入库]
┌ 工具条（吸顶）────────────────────────────────────────────────────┐
│ [搜索：标题、作者、期刊                ] [筛选·2▾] [最近入库▾] [用当前结果▾] │
│ 全部 · 已就绪 · 有 PDF · 建档中 · 建档失败 · 无法获取 · 仅元数据 · 更多状态▾ │
│ （有筛选条件时）年份 2020– ✕  期刊 ACS Catalysis ✕                      │
├ 表头（吸顶）：□ 全选已加载                     已显示 50 / 共 35,177 篇 ┤
│ 文献行 …                                                            │
└────────────────────────────────────────────────────────────────────┘
（勾选后浮出）已选 3 篇  [运行算子…] [建档] [加入文件夹…] [更多▾]      取消选择
```

- 整页一个滚动容器；标题随内容滚走，工具条与表头吸顶。
- 输入框、下拉框不带上方标签（保留无障碍名称）。“入库”是次按钮，勾选后浮出的“运行算子”是这页唯一的主按钮。
- “筛选”是一个菜单：展开或收起筛选条件、应用已保存的筛选、保存当前筛选、删除当前筛选。
- 快速筛选显示当前检索下的数量，计数为 0 的项不显示（当前选中的除外）；“已排除”收在“更多状态”里；默认显示全部状态，按最近入库排序。窄屏时快速筛选横向滑动。
- 文献行：第一行衬线标题，最多两行；第二行书目，作者超过 3 位显示“等”，中文期刊名不用斜体；第三行（有才显示）标签最多 3 个，多出显示 +N；右侧为非默认状态的徽标；悬停或聚焦时出现“预览”与“文献操作”菜单（运行算子、加入文件夹、获取 PDF、建档）；最小行高 56，上下内边距 12。
- 文件夹：侧栏“文献库”下展开为目录树（最近阅读、需处理、文件夹），点文件夹即在本页按文件夹筛选；文件夹视图有“只看本层”开关与“移出文件夹”；文献行可拖到文件夹，文件夹可拖进别的文件夹。文件夹、最近阅读、需处理共用页头模板，标题即视图名。

## 阅读页

**用户来做什么**：读原文或全文，核对证据，必要时改校订稿，查看这篇的结果。

**工具栏**：

```
[PDF | 全文 | 结果] [目录]        上下文控件          [运行算子] [查找] [信息栏] [⋯]
```

- 分三组，组间 16：左为视图分段控件与目录；中为当前视图的上下文控件；右为“运行算子”次按钮、查找与信息栏两个图标按钮、“更多”菜单。窄屏时查找与信息栏收进“更多”。
- 上下文控件：PDF 为页码与缩放；全文为“阅读 / 编辑”切换、字号（18/20/22/24）、行宽与“显示核对依据”；结果无。
- 全文的“编辑”为左 PDF、右校订稿的编辑视图。
- 未建档文献的全文标签：一句说明加“建立文献档案”按钮。
- “更多”：阅读设置、查找、信息栏、获取 PDF、上传 PDF、解析、核验身份、导出书目、下载原始 PDF。
- 目录与信息栏都可收起；窄屏时信息区排在正文之后，目录为可收起的覆盖层。
- 阅读标签页：标题单行省略，悬停显示全文；关闭按钮悬停出现。
- 阅读位置、缩放、字号与栏宽是会话内状态，关闭标签即释放，不持久化。

**信息栏**（自上而下，每节为节标题加定义表；不重复页面已显示的标题）：

1. **状态**：建档状态徽标；原始 PDF、文章身份、全文、文字来源块数、文字层、最后人工修改、图表资源；单步处理。
2. **书目**：作者、期刊、年份、DOI（可打开，旁边复制）；摘要默认收起为三行。
3. **标签**：当前标签与编辑入口。
4. **元数据**：字段、来源与锁定；身份核验证据；其他版本。默认收起。
5. **参考文献**：参考文献、库内被引、图表资源。

**结果标签**：一个列表，每行为算子名、时间、完整性与参与篇数，过时用徽标；全文总结置顶，行内“阅读总结”为次按钮，“结果详情”为文字按钮。总结只把已有的发现、方法、结果、局限、分歧映射为栏目；证据编号就近预览，并可跳到固定版本的原文；没有可靠依据时不补背景、不改写来源、不编造 PDF 页码。

**性能目标**（本机 100 页合成文本 PDF）：冷开 ≤ 2 s，热开 ≤ 1 s，翻页、缩放、查找 ≤ 500 ms；切换十次后关闭，释放 worker、canvas 与对象 URL。

## 命令面板

- `⌘K` / `Ctrl+K` 或侧栏“搜索”打开；靠上居中的浮层，宽 640。
- 一个大输入框，无标签无按钮；实时显示前 8 条文献（标题、书目、状态）；空输入显示最近阅读的 8 篇。
- ↑↓ 选择，回车打开阅读，`⌘回车` 在文献库中查看全部；底部一行“在文献库中查看全部 N 条”。
- 复用文献库检索接口；输入停顿 150 ms 后请求，新请求中止仍未返回的上一个请求。

## 算子

**用户来做什么**：在一批文献上运行算子；回看运行记录，打开结果。

**排布**：

```
算子                                                         [运行算子]
[运行记录 | 算子与规范]
运行记录：
  [全部算子▾] [来源文献，或选择快照                ] ○ 只看过时
  全文总结 · 规范名  ● 已过时                          查看结果  运行过程
  快照或首篇来源 · 等 N 个输入 · 10/22 14:02 · 网页登录
  有结果 120  结果为空 6  读取不完整 2  未形成结果 1
算子与规范：
  内置算子（全文总结、记录提取、问答标注、多篇综合）各一块：做什么、读取范围、输出；
  已保存的规范列表；外部交付作为次级入口。
```

- 只有一级标签；运行记录的筛选为一行无标签工具条。来源只有一个输入框：输入文字按来源文献筛选，聚焦或输入时下拉列出匹配的快照，选中后按该快照筛选。
- 运行记录是一个列表，不用卡片：第一行为算子名与规范名，过时用徽标，当前版本不加标签；第二行为来源、时间、发起方；第三行为按篇计数，数字加重，未形成结果用失败色。“查看结果”“运行过程”为文字按钮。

**结果详情**：顶部“← 全部结果”、标题与一行说明；结果集合列表、字段表、分页与跨页选择、字段证据侧栏、确认后继续综合、按明确范围完整导出。字段取值在悬停或键盘聚焦约半秒后预览第一段原文（最多 6 行，注明 PDF 页码与原文处数），只读不可交互；点击仍打开证据侧栏核对全部来源。筛选工具条无标签；只有应用筛选后才显示筛选状态。六种核对状态在单元格内用同色小徽标；部分结果与未知值保留原义。

**四步对话框**：步骤条（范围 → 算子 → 规范 → 确认）；底部“上一步 / 下一步”，最后一步为“开始运行”。每一步高度相同，步骤条与底部按钮位置固定。确认页用定义表列出范围、算子、规范、输入与缺口，下面是复用与 token 预估。已有范围时步骤条只显示三步。提交以当次范围和规范为准，重复点击不重复建任务，失败保留草稿。

## 快照

**用户来做什么**：把一批文献及其版本固定下来，命名、比较，并在上面运行算子。

**排布**：列表页加详情页（对象页）。

- 列表页为表格：名称、篇数、创建时排除、创建时间，数字右对齐，点行进入详情；窄屏隐藏“创建时排除”。页头右上“从当前筛选生成快照”。没有快照时只显示一句说明。
- 详情页：顶部“返回快照列表”，标题为快照名称（可改名、可恢复默认名称）；内容按节往下排：成员与版本（生成条件、成员）、与另一快照对比、运行算子（打开四步对话框并跳过范围）、基于此快照的运行记录。打开的快照记在 URL 中，可后退。

## 全文检索

**用户来做什么**：在已建档全文与算子结果中找片段，挑出来交给 Agent。

```
全文检索
[全文 | 算子结果]
[ 输入要查找的问题或关键词                              ] [检索]
▸ 高级检索选项
10 条结果 · 当前结果包含部分片段，可以继续读取。
文献标题（衬线）
  │ 命中片段，检索词用证据黄标出……
  │ 原文  在原文中查看  固定来源  加入上下文
```

- 全文：大搜索框；命中按文献分组，组标题为文献标题；片段最多四行，去掉 Markdown 标题符号；右侧为“上下文”栏，可复制为 Markdown 或导出 JSON。
- 算子结果：一行无标签工具条（检索范围、只看过时结果、关键词），列表行为集合或结果名、算子、过时徽标与“打开”。地址为 `view=ask&results=all`。

## 任务与 Agent 会话

**用户来做什么**：看后台在跑什么、跑到哪一步、哪里失败；必要时查看任务发起的 Agent 会话原样记录。

**排布**：

```
任务  2 个进行中
[任务 | Agent 会话]
[全部 · 进行中 · 待处理 · 已结束]  [搜索任务]               运行中 2 · 失败 1
任务        发起方      进度            状态        开始
获取 PDF    网页登录    ███████░░ 8/12  ● 运行中    14:28
解析 PDF    CLI         ██████████ 1/1  ● 已完成    09:46
```

- 点行从右侧打开详情面板：运行过程、逐篇结果与失败原因、该任务发起的 Agent 会话。获取 PDF 任务的逐篇结果带一行获取经过，按实际尝试顺序列出来源与结果，例如“Elsevier API 未命中 · 公开网站未命中 → Browser Agent · 已入库”；没有发起网络请求的来源写“未启用”或“冷却中”，不写成未命中。面板不遮挡列表，可以直接点另一行切换；Esc 或关闭按钮收起，焦点回到原行；地址记录打开的任务，可后退。面板打开时表格隐藏发起方与开始两列。
- 进度条只在有总数时显示，否则显示已处理数。
- 窄屏：表格改为卡片式列表，详情面板占满全屏。
- **Agent 会话**（主从容器）：左为会话列表（算子或校订、文献标题、状态、已用时间、token），状态筛选在列表上方；右为原样的 DSH 会话记录。列表包括没有对应任务的直接调用。

## 需处理

处理型清单。没有问题时只显示一句空状态；有问题时按可读原因分组，每行显示文献、步骤与是否影响就绪，操作放在行内，编辑在该行下方展开；勾选后才出现“确认已处理”。

## 设置

对象为配置，形态为“左侧分区导航 + 定义表”。

- 桌面：页内左侧为竖排分区导航（文献库位置、文献来源、模型、解析与 Browser、建档、凭据、运行状态、外观、高级），宽 180；窄屏改为页头下方的下拉菜单。
- 每个分区由若干节组成，每节为节标题、可选的一句说明和一张定义表：左列为名称加一句说明，右列为控件，能给出当前生效值时写在控件下方。
- 路径用等宽字体单行省略，旁边一个复制图标按钮。
- 保存按钮放在节标题右侧，只在这一节有未保存的改动时出现；数字框输入一个范围内的新值即算作改动，不必先离开输入框。切换分区保留草稿；离开设置页时提示是否放弃。
- Provider 与 Model 在“模型服务”节内逐条列出，下方有“添加”；角色绑定为单独一节。
- 文献来源 · PDF 获取：先写“当前获取顺序”，一张按执行顺序排列的表（直链 → 出版社 API → 通用 API → 公开网站 → Browser Agent），每行为来源名、阶段与状态：“已启用（默认）”“已启用（已配凭据）”“已启用（自定义）”“未启用：缺凭据”“不可用：原因”。自动模式下配好凭据的来源默认加入；已保存但要重启才生效的选择单独标出“重启后生效”。顺序表下方才是自动/自定义的选择控件。

## 洞察

- 每幅图配图注：图号、标题，样本数靠右；图表用图表令牌，只有需要强调的一组用强调色。
- 年份横轴每隔几列显示一个完整年份，不截断；“以表格查看”在页面层级提供。
- 页面底部的页注说明范围与未计入的数据。

## 词表

- 工具条：搜索名称与同义词、“整理词表”文字按钮、“新建标签”次按钮。
- 一张按分类分组的表格：标签、同义词、使用篇数（右对齐）；子标签缩进并用次要色。使用篇数只计直接赋给该标签的文献。
- 点标签在该行下方展开详情：定义、同义词、使用情况、编辑、合并与回溯；再点一次收起。
- 词表变更日志收在表格下方的折叠区中。

## 浏览器

**用户来做什么**：看 Agent 获取 PDF 的过程，监督它干活；想点就直接在它的画面上点。Agent 是一套固定能力的获取流程，不是万能助手；流程失败就由 Owner 自己获取 PDF，页面不暗示“人帮一把就能成功”，也不出现“人工接管”“需要你帮忙”一类说法。

**排布**：

```
浏览器                                                         [刷新会话]
进行中
  本次获取 · 10 篇 · 14:02 开始 · 3 进行中 · 2 等待 · 5 已结束
    [卡] 衬线标题                      ● 推理中            观看 Agent
    [卡] 衬线标题                      ● 等待执行          观看 Agent
已结束
  › 本次获取 · 14:02 · 已入库 4 · 未获取 1        （展开为紧凑行）
  › 10/25 21:30 · 10 篇 · 已入库 7 · 未获取 3
      标题 · ✓ 已入库
      标题 · ● 未获取 · Agent 停止原因一句
```

- 每篇会话（卡片与已结束的行）显示一行小字“已尝试：Elsevier API 未命中 · 公开网站未命中 → 交给 Agent”，说明为什么轮到 Agent；没有记录时不显示。
- 会话按获取任务归组，组标题写开始时间、篇数与各状态计数；进行中的组在上，用浮起白卡；已结束的组在下，默认折叠，展开后每篇一行。
- 只列当前服务持有的会话（服务重启后清空）；更早的记录看任务页。
- 阶段颜色：推理、下载、验收等进行中为绿色；等待执行为灰色；已入库为中性灰带勾；未获取为红色，并原样显示 Agent 的停止原因。
- 没有会话时只显示一句空状态。

**观看**：

- 画面占主要宽度。Agent 的鼠标指针叠在画面上，随每次动作移到目标位置；点击时出现一圈波纹，指针旁写一句动作，例如“点击 View PDF”。指针位置来自 Agent 实际动作的坐标或元素位置，不推测。
- 右栏是动作记录：按时间往下列 Agent 实际做过的动作（点击的元素或位置、滚动、输入、新页签、进入的页面标题）和平台事件（开始下载、验收通过或失败）；流程停止时把停止原因放在末尾。不预设步骤，不替 Agent 编写理由。
- 画面可以直接点击、滚动、输入：第一次操作时 Agent 暂停，顶部写“你在操作 · Agent 已暂停 · 停手 10 秒后继续”，旁边一个“现在继续”；停手满 10 秒自动交还。不显示页面元素按钮墙。
- 剩余模型调用与时间以一行小字显示。“更多操作”折叠在动作记录下方：“暂停 Agent”、暂停或继续会话、页面上的链接与按钮列表（画面是图片，键盘用户靠它操作页面）、页面文字、给 Agent 的可选指导、取消会话。

## 入库

- 顶部标签页：主题发现、引用扩展、导入书目、上传 PDF。
- 表单为定义表；数字框按内容取宽，年份起止合成一行；主按钮为“开始发现”或“导入”，提交前确认范围与所用服务。
- 本次会话的运行结果按条列出：名称、状态徽标、摘要，技术明细可展开。

## 登录

- 暖白页面上居中的一张白卡，宽 448；标题为衬线页标题，下面一句说明；输入框与主按钮按组件规范，主按钮占满卡片宽度。
- 登录页与工作台使用同一套随包字体。
