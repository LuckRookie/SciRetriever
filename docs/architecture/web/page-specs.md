# Web 页面规格

类型：规格（前端页面）。负责：信息架构、侧栏、页面模板与逐页排布。状态：现行；文末“改版草案”一节为[计划 14](../../plans/2026-10-23-web-design-overhaul/README.md)的待确认内容。

视觉规则见[设计内核](design-core.md)；当前已实现的操作见 [Web 指南](../../guides/web-workbench.md)。

## 整体信息架构

产品围绕一条主线组织：**找到文献 → 阅读与核对 → 在一批文献上运行算子 → 查看结果**，另有一组页面观看后台运行。

| 侧栏分组 | 页面                           | 在主线中的位置                       |
| -------- | ------------------------------ | ------------------------------------ |
| 资料     | 文献库（下挂最近阅读与文件夹） | 找到文献、选择一批                   |
|          | 快照                           | 把一批文献及其版本固定下来，作为范围 |
|          | 词表                           | 管理标签                             |
| 加工     | 算子                           | 运行算子、回看运行记录与结果         |
|          | 全文检索                       | 在已建档全文中找片段                 |
|          | 洞察                           | 看分布与引用关系                     |
| 运行     | 任务                           | 后台任务的进度与失败                 |
|          | 浏览器                         | 观看与接管下载                       |
|          | Agent                          | 原样查看 DSH 会话                    |
|          | 建档问题                       | 需要人处理的建档失败                 |
| 底部     | 设置                           |                                      |

- 阅读页不在侧栏：从任何文献标题打开，以顶部标签页的形式存在。
- 结果有两个入口：算子页按运行记录看，阅读页“结果”标签按单篇看。
- 运行算子只有一种入口形式：四步对话框（范围 → 算子 → 规范 → 确认），可从文献库、阅读页、快照页、算子页打开；已有范围时跳过“范围”一步。
- 入库不在侧栏：文献库页头的“入库”按钮进入入库页。

每页按“用户来做什么 → 要呈现的信息（按优先级）→ 排布”说明。

## 文献库

**用户来做什么**：找到文献，看清它的材料状态，选一批去做事。

**信息优先级**：

1. 文献行：标题、书目（作者 · _期刊_ · 年份）、标签、状态；
2. 当前检索与筛选：检索词、状态、已应用的筛选条件；
3. 结果数量：已显示 / 共几篇；
4. 批量操作。

**排布**：

```
文献库                                                        [入库]
┌ 工具条（吸顶）────────────────────────────────────────────────────┐
│ [搜索：标题、作者、期刊          ] [筛选·2] [排序：最近入库▾] [用当前结果▾] │
│ 全部 · 已就绪 · 有 PDF · 建档中 · 建档失败 · 无法获取 · 仅元数据 · 更多▾  已保存筛选▾ │
│ （有筛选条件时）年份 2020– ✕  期刊 ACS Catalysis ✕                      │
├ 表头（吸顶）：□ 全选已加载   已显示 50 / 共 35,177 篇 ───────────────────┤
│ 文献行 …                                                            │
└────────────────────────────────────────────────────────────────────┘
（勾选后浮出）已选 3 篇  [运行算子…] [加入文件夹…] [建档] [更多▾]      取消选择
```

- 整页一个滚动容器；标题随内容滚走，工具条与表头吸顶。
- 输入框、下拉框不带上方标签（保留无障碍名称）。
- 快速筛选按钮显示当前检索下的数量；默认显示全部状态，按最近入库排序。
- “已保存筛选”收在一个菜单里：应用、保存当前筛选、删除。
- 文件夹：侧栏“文献库”下展开为目录树（最近阅读、文件夹），点文件夹即在本页按文件夹筛选；文件夹视图有“只看本层”开关与“移出文件夹”；文献行可拖到文件夹，文件夹可拖进别的文件夹。

## 阅读页

**用户来做什么**：读原文或全文，核对证据，必要时改校订稿，查看这篇的结果。

**工具栏**：

```
[PDF | 全文 | 结果] [目录]   上下文控件                [运行算子] [查找] [信息栏] [更多▾]
```

- 上下文控件：PDF 为页码与缩放；全文为“阅读 / 编辑”切换、字号（18/20/22/24）与行宽；结果无。
- 全文的“编辑”为左 PDF、右校订稿的编辑视图。
- 未建档文献的全文标签：一句说明加“建立文献档案”按钮。
- “更多”：获取 PDF、上传 PDF、解析、核验身份、导出书目、下载原始 PDF、阅读设置。
- 目录与信息栏都可收起；窄屏时信息区排在正文之后，目录为可收起的覆盖层。
- 阅读位置、缩放、字号与栏宽是会话内状态，关闭标签即释放，不持久化。

**信息栏**（自上而下）：

1. **状态**：建档状态标签；PDF 是否保存；文章身份核验结果；全文版本；文字来源块数；最后人工修改；单步处理。
2. **书目**：标题、作者、期刊与年份、DOI（可复制、可打开）、摘要（默认收起）。
3. **标签**：当前标签与编辑入口。
4. **元数据**：字段、来源与锁定；身份核验证据；其他版本。默认收起。
5. **参考文献**：参考文献、库内被引、图表资源。

**结果标签**：总结置顶。总结只把已有的发现、方法、结果、局限、分歧映射为栏目；证据编号就近预览，并可跳到固定版本的原文；没有可靠依据时不补背景、不改写来源、不编造 PDF 页码。

**性能目标**（本机 100 页合成文本 PDF）：冷开 ≤ 2 s，热开 ≤ 1 s，翻页、缩放、查找 ≤ 500 ms；切换十次后关闭，释放 worker、canvas 与对象 URL。

## 算子

**用户来做什么**：在一批文献上运行算子；回看运行记录，打开结果。

**排布**：

```
算子                                                     [运行算子]
[运行记录 | 算子与规范]
运行记录：
  [算子▾] [来源：快照或文献      ] [只看过时 ○]
  ┌ 全文总结 · 规范名                                     过时 ┐
  │ 快照「标签 Spectroscopy · 2020 年起」· 128 篇 · 10月22日 14:02 · 网页登录 │
  │ 有结果 120 · 结果为空 6 · 读取不完整 2       [查看结果] [运行过程] │
  └──────────────────────────────────────────────────────────┘
算子与规范：
  内置算子（全文总结、记录提取、问答标注、多篇综合）各一块：做什么、读取范围、输出；
  已保存的规范列表；外部交付作为次级入口。
```

**结果详情**：结果集合列表、字段表、分页与跨页选择、字段证据侧栏、确认后继续综合、按明确范围完整导出；六种核对状态用统一徽标；部分结果与未知值保留原义。

**四步对话框**：步骤条（范围 → 算子 → 规范 → 确认）；底部“上一步 / 下一步”，最后一步为“开始运行”。确认页显示范围、算子、规范摘要、复用篇数、缺口与 token 预估。已有范围时步骤条只显示三步。提交以当次范围和规范为准，重复点击不重复建任务，失败保留草稿。

## 快照

**用户来做什么**：把一批文献及其版本固定下来，命名、比较，并在上面运行算子。

**排布**：列表页加详情页（对象页）。

- 列表页：每行为名称、篇数、创建时排除的篇数、本地时间；页头右上“从当前筛选生成快照”。没有快照时只显示一句说明。
- 详情页：顶部“返回快照列表”，标题为快照名称（可改名、可恢复默认名称）；内容按节往下排：成员与版本（生成条件、成员）、与另一快照对比、运行算子（打开四步对话框并跳过范围）、基于此快照的运行记录。打开的快照记在 URL 中，可后退。

## 任务、Agent、建档问题

- **任务**（监视页，左右两栏）：左为任务列表（名称、状态标签、本地时间），上方为状态标签与筛选；右为运行过程。
- **Agent**（监视页，左右两栏）：左为会话列表（算子或校订、文献标题、状态、已用时间、token），状态筛选在列表上方；右为原样的 DSH 会话记录。
- **建档问题**（处理型清单）：没有问题时只显示一句空状态；有问题时为按原因分组的单列清单，每行显示文献、步骤与是否影响就绪，操作放在行内，编辑在该行下方展开；勾选后才出现“确认已处理”。

## 其余页面

全文检索、词表、浏览器、入库与设置的其余分区，按设计内核套用页面模板。

- “需处理”替代“建档问题”页，在文献库框架内显示，形态仍是处理型清单；计数为 0 时显示为灰色。

- 旧地址：`agent` → 任务页“Agent 会话”；`archive` → 文献库“需处理”；算子页“结果检索” → 全文检索“算子结果”。

### 2. 页面模板

```
页标题  上下文数字                                   [主操作]
工具条（一行；必要时第二行放快速筛选）
内容
```

- 不放说明系统行为的句子；对用户有用的信息改为界面状态、按钮文案或字段旁的提示。
- 上下文数字示例：文献库“35,177 篇”、快照“3 个”、任务“2 个进行中”。
- 空状态：一句话 + 一个动作。例如快照为空：“还没有快照。在文献库筛选后，可以把结果生成快照。”加按钮“去文献库”。
- 没有数据时隐藏分页与批量操作。

### 3. 任务

```
任务  2 个进行中                                      [刷新]
[任务 | Agent 会话]   [全部 · 进行中 · 待处理 · 已结束]  [搜索任务]
任务        范围             发起方      进度            状态        开始
获取 PDF    快照「…」12 篇    网页登录    ███████░░ 8/12  ● 运行中    14:28
解析 PDF    1 篇              CLI         ██████████ 1/1  ● 已完成    09:46
```

- 点行从右侧抽屉看详情：运行过程、逐篇结果与失败原因、发起的 Agent 会话；地址记录打开的任务，可后退；抽屉关闭后焦点回到原行。
- 进度条只在有总数时显示，否则显示已处理数。
- 窄屏：表格改为两行卡片式列表，抽屉改为全屏。

### 4. 批次 A：文献库、阅读页、命令面板

**文献库**

- 工具条第一行：搜索（占满剩余宽度）、筛选、排序、用当前结果；第二行：快速筛选，计数为 0 的项不显示，“更多状态”收进菜单；已保存筛选并入筛选菜单。
- 表头与计数合成一行：全选框、“已显示 50 / 共 35,177 篇”。
- 文献行：第一行衬线标题；第二行书目，作者超过 3 位显示“等”；第三行（有才显示）标签最多 3 个，多出显示 +N；右侧为非默认状态的徽标；悬停或聚焦时出现预览与更多操作；最小行高 56，上下内边距 12。
- 文件夹、最近阅读、需处理三种视图共用页头模板，标题即视图名。

**阅读页**

- 工具栏分三组，组间 16：左为视图分段控件与目录；中为当前视图的上下文控件；右为查找、信息栏两个图标按钮，“运行算子”次按钮与“更多”菜单。
- 信息栏统一为“节标题 + 定义表”；不重复显示页面已显示的标题；摘要默认三行收起。
- 阅读标签页：标题单行省略，悬停显示全文；关闭按钮悬停出现。

**命令面板**（替代搜索对话框）

- `⌘K` / `Ctrl+K` 或侧栏“搜索”打开；居中浮层，宽 640。
- 一个大输入框，无标签无按钮；实时显示前 8 条文献（标题、书目、状态）；空输入显示最近阅读的 8 篇。
- ↑↓ 选择，回车打开阅读，`⌘回车` 在文献库中查看全部；底部一行“在文献库中查看全部 N 条”。
- 复用文献库检索接口；输入停顿 150 ms 后请求，前一请求可取消。

### 5. 批次 B：算子、快照、全文检索

- **算子页**只保留一级标签 [运行记录 | 算子与规范]；运行记录的筛选为一行无标签工具条：算子、来源、只看过时。
- **运行记录行**：算子名与规范名、范围、时间、发起方；三种按篇计数用小号数字；过时用状态徽标；“查看结果”“运行过程”为文字按钮。
- **结果详情**：表格按设计内核；证据编号悬停预览。
- **四步对话框**：步骤条与底部按钮位置固定；确认页用定义表。
- **快照**：列表为表格（名称、篇数、排除、创建时间）。
- **全文检索**：顶部大搜索框，下方分段控件 [全文 | 算子结果]；结果按文献分组，命中词用证据黄标出。

### 6. 批次 C：设置、洞察、词表、浏览器、入库、登录

- **设置**：桌面为页内左侧竖排分区导航，右侧为定义表；路径用等宽字体单行省略，旁边“复制”；只在有改动时显示“保存”；窄屏分区导航改为下拉。
- **洞察**：图表用图表令牌；图注统一为“图 N 标题 · 样本数”；年份横轴标签隔几个显示一个完整年份，不截断。
- **词表**：词表与标签用表格，计数右对齐；编辑在行内展开。
- **浏览器**：会话画廊卡片为浮起白卡，状态徽标统一。
- **入库**：表单分节；回执用定义表显示数量与状态，技术回执可展开。
- **登录**：居中单卡，产品名用衬线，输入框与主按钮按组件规范。
