# Web 页面规格

类型：规格（前端页面）
负责：信息架构、侧栏、页面模板与逐页排布
状态：现行

视觉规则见[设计内核](design-core.md)；当前已实现的操作见 [Web 指南](../../guides/web-workbench.md)。

## 整体信息架构

产品围绕一条主线组织：**找到文献 → 阅读与核对 → 在一批文献上运行算子 → 查看结果**，另有一组页面观看后台运行。

```
SciRetriever
搜索 ⌘K
资料
  文献库            35,177
    最近阅读             6
    需处理              12
    文件夹…
  快照
  词表
加工
  算子
  全文检索
  洞察
运行
  任务          2 进行中
  浏览器
────────
设置
```

| 侧栏分组 | 页面     | 在主线中的位置                                      |
| -------- | -------- | --------------------------------------------------- |
| 资料     | 文献库   | 找到文献、选择一批；下挂最近阅读、需处理与文件夹    |
|          | 快照     | 把一批文献及其版本固定下来，作为范围                |
|          | 词表     | 管理标签                                            |
| 加工     | 算子     | 运行算子、回看运行记录与结果                        |
|          | 全文检索 | 在已建档全文中找片段                                |
|          | 洞察     | 看分布与引用关系                                    |
| 运行     | 任务     | 后台任务的进度与失败；切换到“Agent 会话”看 DSH 会话 |
|          | 浏览器   | 观看与接管下载                                      |
| 底部     | 设置     |                                                     |

- “需处理”是需要人处理的建档问题，在文献库框架内显示；计数为 0 时显示为灰色。
- Agent 会话都由任务发起，因此并入任务页；任务项旁显示进行中的数量，没有进行中时不显示。
- 旧地址照常可用：`view=agent` 打开任务页的“Agent 会话”，`view=archive` 打开文献库的“需处理”。
- 阅读页不在侧栏：从任何文献标题打开，以顶部标签页的形式存在。
- 结果有两个入口：算子页按运行记录看，阅读页“结果”标签按单篇看。
- 运行算子只有一种入口形式：四步对话框（范围 → 算子 → 规范 → 确认），可从文献库、阅读页、快照页、算子页打开；已有范围时跳过“范围”一步。
- 入库不在侧栏：文献库页头的“入库”按钮进入入库页。

## 页面模板

```
页标题  上下文数字                                   [主操作]
工具条（一行；必要时第二行放快速筛选）
内容
```

- 页头不放说明系统行为的句子；对用户有用的信息改为界面状态、按钮文案、字段旁的提示，或页面底部的页注。
- 上下文数字示例：文献库“35,177 篇”、快照“3 个”、任务“2 个进行中”、需处理“12 项”。
- 空状态：一句话加至多一个动作，例如快照为空时“还没有快照。在文献库筛选后，可以把结果生成快照。”
- 没有数据时隐藏分页与批量操作。

每页按“用户来做什么 → 要呈现的信息（按优先级）→ 排布”说明。

## 文献库

**用户来做什么**：找到文献，看清它的材料状态，选一批去做事。

**信息优先级**：

1. 文献行：标题、书目（作者 · _期刊_ · 年份）、标签、状态；
2. 当前检索与筛选：检索词、状态、已应用的筛选条件；
3. 结果数量：已显示 / 共几篇；
4. 批量操作。

**排布**：

```
文献库  35,177 篇                                              [＋ 入库]
┌ 工具条（吸顶）────────────────────────────────────────────────────┐
│ [搜索：标题、作者、期刊                ] [筛选·2▾] [最近入库▾] [用当前结果▾] │
│ 全部 · 已就绪 · 有 PDF · 建档中 · 建档失败 · 无法获取 · 仅元数据 · 更多状态▾ │
│ （有筛选条件时）年份 2020– ✕  期刊 ACS Catalysis ✕                      │
├ 表头（吸顶）：□ 全选已加载                     已显示 50 / 共 35,177 篇 ┤
│ 文献行 …                                                            │
└────────────────────────────────────────────────────────────────────┘
（勾选后浮出）已选 3 篇  [运行算子…] [建档] [加入文件夹…] [更多▾]      取消选择
```

- 整页一个滚动容器；标题随内容滚走，工具条与表头吸顶。
- 输入框、下拉框不带上方标签（保留无障碍名称）。“入库”是次按钮，勾选后浮出的“运行算子”是这页唯一的主按钮。
- “筛选”是一个菜单：展开或收起筛选条件、应用已保存的筛选、保存当前筛选、删除当前筛选。
- 快速筛选显示当前检索下的数量，计数为 0 的项不显示（当前选中的除外）；“已排除”收在“更多状态”里；默认显示全部状态，按最近入库排序。窄屏时快速筛选横向滑动。
- 文献行：第一行衬线标题，最多两行；第二行书目，作者超过 3 位显示“等”，中文期刊名不用斜体；第三行（有才显示）标签最多 3 个，多出显示 +N，没有标签时改用浅色字列出最多 3 个作者关键词，再没有就列主题词；右侧为非默认状态的徽标；悬停或聚焦时出现“预览”与“文献操作”菜单（运行算子、加入文件夹、获取 PDF、建档）；最小行高 56，上下内边距 12。
- 入库批次：侧栏“文献库”下有“最近入库”分区，列出最近 5 个入库批次和各自篇数，最后一行“全部入库记录”进入入库页。点批次即把文献库限定到这一批，页头标题为批次名；筛选条件里批次显示名称，不显示内部 ID。
- 范围内的词：有筛选条件时，筛选条件下方一块浅底区域按标签、作者关键词、主题词的顺序分行列出当前结果里最常见的词，各取前 8 个，带篇数，末尾“更多”展开到 30 个。每行名称后用浅色字写覆盖篇数，如“1,200 / 17,010 篇”。点一个词即加为筛选条件（标签取“任一”，作者关键词与主题词各自取“同时具有”），已选的词用荧光黄底。有标签的篇数达到结果的一半时，主题词一行只显示名称和“展开”。作者关键词对应某个标签时，词后带一个小标签记号；已选的作者关键词有对应标签而该标签未选时，这块末尾提示“‘词’对应标签‘名称’”，旁边按钮“改用标签筛选”，按下即去掉该关键词、加上该标签。三层都没有词时不显示这块。
- 获取 PDF 的范围：选择栏的“获取 PDF”和批次的“获取 PDF”都先打开对话框，对话框第一块写明范围：来历（勾选的 n 篇，或批次名与筛选条件）、处理多少篇、跳过多少篇及原因（已有 PDF、已标记无法获取、超出本次上限）。下面是“本次最多 N 篇”，超出时按文献库当前排序取前 N 篇，并写出排序名称。主按钮写“获取 n 篇”。选择了“全部 N 篇符合条件的文献”时按筛选条件整体提交，不受已加载行数限制，篇数来自服务端预览。
- 文件夹：侧栏“文献库”下展开为目录树（最近阅读、最近入库、需处理、文件夹），点文件夹即在本页按文件夹筛选；文件夹视图有“只看本层”开关与“移出文件夹”；文献行可拖到文件夹，文件夹可拖进别的文件夹。文件夹、最近阅读、需处理共用页头模板，标题即视图名。

## 阅读页

**用户来做什么**：读原文或全文，核对证据，必要时改校订稿，查看这篇的结果。

**工具栏**：

```
[PDF | 全文 | 结果] [目录]        上下文控件          [运行算子] [查找] [信息栏] [⋯]
```

- 分三组，组间 16：左为视图分段控件与目录；中为当前视图的上下文控件；右为“运行算子”次按钮、查找与信息栏两个图标按钮、“更多”菜单。窄屏时查找与信息栏收进“更多”。
- 上下文控件：PDF 为页码与缩放；全文为“阅读 / 编辑”切换、字号（18/20/22/24）、行宽与“显示核对依据”；结果无。
- 全文的“编辑”为左 PDF、右校订稿的编辑视图。
- 未建档文献的全文标签：一句说明加“建立文献档案”按钮。
- “更多”：阅读设置、查找、信息栏、获取 PDF、上传 PDF、解析、核验身份、导出书目、下载原始 PDF。
- 目录与信息栏都可收起；窄屏时信息区排在正文之后，目录为可收起的覆盖层。
- 阅读标签页：标题单行省略，悬停显示全文；关闭按钮悬停出现。
- 阅读位置、缩放、字号与栏宽是会话内状态，关闭标签即释放，不持久化。

**全文的排版**（[ADR 0054](../decisions/0054-rule-preprocessing-and-source-order-layout.md)；分组与目录取自文档结构读取，不读 Markdown 里的标记）：

- 章节按原文顺序，标题只显示原文自己的标题。
- 目录列出原文标题，按层级缩进；原文没有标题的部分以角色名（引言、方法、结果与讨论、结论等）列出，用次级文字色，表示这是归类而不是原文标题。
- 文章信息（单位、通讯作者、注释、收稿与发表日期）排在作者之后，默认收起为一行“文章信息”，点开展开；收起状态是会话内状态。
- 组图：同一组的图片按结构给出的行列排成网格，图注在网格下方，每张图可单独点开放大。续表紧跟前表，组内不重复表题。
- 页脚注排在引用它的段落之后，字号小一级，左侧细线与正文区分。

**信息栏**（自上而下；不重复页面已显示的标题；字段为左侧标签列加左对齐的值，长值在值列内换行）：

1. **元数据**（无节标题）：作者、期刊、发表日期或年份、卷期、页码、出版方、类型、语言、DOI（可打开，旁边复制）、其他标识符、作者关键词、主题词、入库；元数据里没有的字段不显示。作者关键词与主题词显示为词块，主题词用更浅的颜色；点词在文献库按这个词筛选。“入库”列出这篇所属的入库批次名称，点开在文献库查看这一批。下面是“复制引用”“导出书目”“编辑元数据”三个文字按钮，编辑展开字段、来源与锁定。
2. **摘要**：默认收起为三行；没有摘要时一句说明（未建档时说明建档会补全）。
3. **标签**：直接显示已有标签，主标签加重；“编辑标签”展开编辑。
4. **文件夹**：这篇所在的文件夹路径，点开在文献库中查看；不在任何文件夹时不显示。
5. **关联**：参考文献、库内被引、其他版本、图表资源各一行，右侧为数量；有内容的行可展开列表，数量为零显示“无”，没有图表资源时不显示该行。
6. **档案**：原始 PDF、PDF 与文章是否相符、全文建档三项，每项前为完成 / 进行中 / 需处理 / 未做的标记；身份核对依据挂在第二项下，未确认时给“核对身份”。已建档时列文字来源、文字层与人工修改；可建档时一句说明建档后能做什么、会调用什么，再给“建档”和“单步处理”。
7. **技术详情**：默认收起，含标识、指纹与各元数据来源。

**结果标签**：一个列表，每行为算子名、时间、完整性与参与篇数，过时用徽标；全文总结置顶，行内“阅读总结”为次按钮，“结果详情”为文字按钮。总结只把已有的发现、方法、结果、局限、分歧映射为栏目；证据编号就近预览，并可跳到固定版本的原文；没有可靠依据时不补背景、不改写来源、不编造 PDF 页码。

**性能目标**（本机 100 页合成文本 PDF）：冷开 ≤ 2 s，热开 ≤ 1 s，翻页、缩放、查找 ≤ 500 ms；切换十次后关闭，释放 worker、canvas 与对象 URL。

## 命令面板

- `⌘K` / `Ctrl+K` 或侧栏“搜索”打开；靠上居中的浮层，宽 640。
- 一个大输入框，无标签无按钮；实时显示前 8 条文献（标题、书目、状态）；空输入显示最近阅读的 8 篇。
- ↑↓ 选择，回车打开阅读，`⌘回车` 在文献库中查看全部；底部一行“在文献库中查看全部 N 条”。
- 复用文献库检索接口；输入停顿 150 ms 后请求，新请求中止仍未返回的上一个请求。

## 算子

**用户来做什么**：在一批文献上运行算子；回看运行记录，打开结果。

**排布**：

```
算子                                                         [运行算子]
[运行记录 | 算子与规范]
运行记录：
  [全部算子▾] [来源文献，或选择快照                ] ○ 只看过时
  全文总结 · 规范名  ● 已过时                          查看结果  运行过程
  快照或首篇来源 · 等 N 个输入 · 10/22 14:02 · 网页登录
  有结果 120  结果为空 6  读取不完整 2  未形成结果 1
算子与规范：
  内置算子（全文总结、记录提取、问答标注、多篇综合）各一块：做什么、读取范围、输出；
  已保存的规范列表；外部交付作为次级入口。
```

- 只有一级标签；运行记录的筛选为一行无标签工具条。来源只有一个输入框：输入文字按来源文献筛选，聚焦或输入时下拉列出匹配的快照，选中后按该快照筛选。
- 运行记录是一个列表，不用卡片：第一行为算子名与规范名，过时用徽标，当前版本不加标签；第二行为来源、时间、发起方；第三行为按篇计数，数字加重，未形成结果用失败色。“查看结果”“运行过程”为文字按钮。

**结果详情**：顶部“← 全部结果”、标题与一行说明；结果集合列表、字段表、分页与跨页选择、字段证据侧栏、确认后继续综合、按明确范围完整导出。字段取值在悬停或键盘聚焦约半秒后预览第一段原文（最多 6 行，注明 PDF 页码与原文处数），只读不可交互；点击仍打开证据侧栏核对全部来源。筛选工具条无标签；只有应用筛选后才显示筛选状态。六种核对状态在单元格内用同色小徽标；部分结果与未知值保留原义。

**四步对话框**：步骤条（范围 → 算子 → 规范 → 确认）；底部“上一步 / 下一步”，最后一步为“开始运行”。每一步高度相同，步骤条与底部按钮位置固定。确认页用定义表列出范围、算子、规范、输入与缺口，下面是复用与 token 预估。已有范围时步骤条只显示三步。提交以当次范围和规范为准，重复点击不重复建任务，失败保留草稿。

## 快照

**用户来做什么**：把一批文献及其版本固定下来，命名、比较，并在上面运行算子。

**排布**：列表页加详情页（对象页）。

- 列表页为表格：名称、篇数、创建时排除、创建时间，数字右对齐，点行进入详情；窄屏隐藏“创建时排除”。页头右上“从当前筛选生成快照”。没有快照时只显示一句说明。
- 详情页：顶部“返回快照列表”，标题为快照名称（可改名、可恢复默认名称）；内容按节往下排：成员与版本（生成条件、成员）、与另一快照对比、运行算子（打开四步对话框并跳过范围）、基于此快照的运行记录。打开的快照记在 URL 中，可后退。

## 全文检索

**用户来做什么**：在已建档全文与算子结果中找片段，挑出来交给 Agent。

```
全文检索
[全文 | 算子结果]
[ 输入要查找的问题或关键词                              ] [检索]
▸ 高级检索选项
10 条结果 · 当前结果包含部分片段，可以继续读取。
文献标题（衬线）
  │ 命中片段，检索词用证据黄标出……
  │ 原文  在原文中查看  固定来源  加入上下文
```

- 全文：大搜索框；命中按文献分组，组标题为文献标题；片段最多四行，去掉 Markdown 标题符号；右侧为“上下文”栏，可复制为 Markdown 或导出 JSON。
- 算子结果：一行无标签工具条（检索范围、只看过时结果、关键词），列表行为集合或结果名、算子、过时徽标与“打开”。地址为 `view=ask&results=all`。
- 索引状态：搜索框下方一行，只在索引不是最新时出现，与结果状态行分开。状态取自索引状态读取，更新中每 2 秒刷新一次，离开本页即停止。

  | 状态        | 显示                                                                                        | 操作                                                         |
  | ----------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
  | 最新        | 不显示                                                                                      | —                                                            |
  | 更新中      | “全文索引正在更新，还有 N 篇的最新内容暂时搜不到。”（拿不到篇数时省略“还有 N 篇”）          | 无；完成后若当前结果来自旧索引，显示“索引已更新”和“重新检索” |
  | 更新失败    | “全文索引上次更新没有完成，最近变化的文献暂时搜不到最新内容；其余内容照常可搜。”            | “重试更新”；原因码放在技术详情                               |
  | 尚未建立    | “还没有全文索引，原文和元数据都搜不到。”                                                    | “建立索引”，说明约需几分钟、可以离开本页                     |
  | 已损坏      | “全文索引已损坏，需要重建后才能检索。”                                                      | “重建索引”，先确认                                           |
  | 建立/重建中 | “正在建立全文索引，已处理 X / Y 篇。可以离开本页，完成后自动生效。”（重建时旧索引照常可搜） | 无                                                           |

### 错误的呈现

真实网络中的错误无法穷举，界面不对错误分类：凡请求失败一律显示为“错误”。只有三种用户能直接处理的情况单独写出名称：**未配置**、**凭据无效**（API Key / Token 被拒）、**无全文权限**（出版社认证通过但无订阅）。没拿到结果（无全文、未收录、0 条）是正常结果，不算错误。具体原因码只出现在“技术详情”里，供排查。

- PDF：尝试 = 进入该来源并实际发出请求的篇数（未启用、冷却中不计）；拿到 = 由该来源拿到 PDF 的篇数；比例条统一用强调色，不因比例低改成失败色——低比例可能是来源本身覆盖面窄。没拿到不等于错误：没有全文、未收录是正常结果。错误 = 请求本身失败的比例。
- 元数据只用比例，不用累计条数：累计条数和“新入库”都随文献库变大而变化（库越全，新入库越少），不能说明来源好坏。按三种用途各一个比例，分母写在比例下方：
  - 检索覆盖：每次主题检索合并去重后的结果中，有多少是这个来源找到的，取各次检索的平均。说明它“找得全不全”，与库里已有多少无关。
  - 补全命中：请它补全的文献中，它查到匹配记录的比例。
  - 引用命中：请它查引用的文献中，它给出引用列表的比例。
  - 错误：失败请求占全部请求的比例。
  - 不提供该用途的格子写“—”；缺配置的来源整行“—”。
- 错误比例不小于 5% 时用失败色。错误不分类，只在出现下面三种时于行尾加一个失败色小标签；行不可展开。
- 数字全部取自各任务的逐来源记录，与任务详情一致，不另算一套；历史任务没有逐来源记录的不计入，表头下注明统计起点一次。
- 窄屏：每个来源两行，第一行名称与阶段，第二行比例条（附“拿到 / 尝试”）与主要原因。

## 草案：文献库的连续选择与批量操作（计划 17，待确认）

本节待 Owner 确认，尚未实现；确认并实现后并入“文献库”节并删除本节。

**用户来做什么**：一次选中一批文献，给它们获取 PDF 或运行算子；选中的文献状态不一，系统替用户分好哪些能做什么。

**连续选择**

- 在勾选框一列按住拖动，经过的行连续选中；从已选的行开始拖动则连续取消。拖到列表上下边缘时自动滚动。
- Shift + 点击勾选框，选中上次点击的行到当前行之间的整段。
- 在未选中的行上按下并移动超过 4 px，拉出选框，经过的行被选中；按住 Shift、⌘ 或 Ctrl 时追加。已选中的行按下即拖起，可放到侧栏文件夹（计划 17 · P29、P30）。
- Esc 取消全部选择。“全选已加载”选满后，列表上方出现一行“选择全部 N 篇符合条件的文献”，可切换到服务端范围（批量获取 PDF 常用）。

**选择栏**

```
已选 8 篇   (无 PDF 3) (待解析 1) (待建档 1) (已就绪 3)   [获取 PDF 3]  解析 PDF 1  [运行算子 3]  建档 1  加入文件夹…  更多▾  取消选择
```

- 左侧写选中篇数，紧跟按状态的组成，每类一个小标签；点标签把选择缩小到这一类。
- 按钮写“对几篇生效”，数字就是实际会被处理的篇数，系统只处理满足前提的那部分：获取 PDF → 无 PDF 的；解析 PDF → 有 PDF 还没有解析的；建档 → 已解析未建档或建档失败的；运行算子 → 已就绪的。数字为 0 时按钮停用，悬停说明原因（例如“所选文献都已有 PDF”；只选了待解析的文献时，建档说明“请先解析 PDF”）。
- “获取 PDF”与“运行算子”是选择栏的两个主按钮；解析 PDF、建档、加入文件夹为次按钮；导出书目、生成快照、核验文章身份收进“更多”。行菜单同样有获取 PDF、解析 PDF、建档，不满足前提的一项停用并写明缺什么。
- 选择“全部 N 篇”时组成与数字来自服务端计数。

**运行算子遇到混合选择**

- 对话框“范围”一步先给出两格：可以运行 x 篇；还不能运行 y 篇（写明几篇无 PDF、几篇未建档）。
- 两个选项：
  1. 只对可以运行的 x 篇运行（默认）；
  2. 同时为其余 y 篇补齐材料：另建一个任务，无 PDF 的先获取、再建档。补齐任务完成后，任务详情里有“对这些文献运行同一算子”一键继续。系统不自动串联运行，避免一次操作在背后跑出多段任务。
- 全部都能运行时不显示这一步的分组与选项；全部都不能运行时“运行算子”按钮停用。
- “能运行”的判定目前沿用“已就绪”；计划 16 把算子门槛改为按算子声明的材料后，按新判定计数，界面不变。
