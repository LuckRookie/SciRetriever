## 已确认的界面基准

- 左侧导航按“资料 / 使用 / 运行”分组：文献库与发现；洞察、检索、综合与提取；任务与浏览器；设置固定在侧栏底部。
- 顶部为工作区/阅读标签与全局活动入口；任务有独立页面，活动抽屉用于快速查看。
- 库以文献列表为主，标题、参考文献式书目信息、标签及紧凑状态有明确层级。点击文献打开阅读标签，预览按钮才展开右侧面板；选择后浮出批量操作条，“用这些文献做…”复用当前范围。
- 阅读标签默认显示已有 PDF，右侧提供文献信息；按 G5，PDF / 全文 / 总结切换移至阅读区工具栏，即使信息栏收起也可切换。证据标记指向原文位置。正式证据定位仍须以实际材料与 locator 能力为准。
- 白色内容面、浅灰侧栏、墨蓝主要操作、黄色证据标记；标题/阅读与界面控件区分字体，分隔线轻，悬停不改变行尺寸。原型包含浅色与深色样式。
- 默认尺寸按 Owner 后续试用反馈调大：界面正文 18px、文献标题与全文正文 20px、书目信息 17px、常规按钮高 40px（浏览器默认根字号 16px 时）。生产样式以集中定义的 `rem` 字号和控件尺寸适配，原型附件保持原始字节，布局与配色继续以它为准。
- Browser 以会话画廊进入观看，直接点击画面表达介入，交还恢复 Agent；具体控制生命周期继续按 ADR 0032 的服务端边界落实。

## 2026-10-18 确认的功能与阅读目标

沿用上述原型与尺寸基准，后续分别完善并验收日常加工和阅读服务。日常业务应能仅用 Web 从文献选择、标签或记录规范配置，到任务执行、结果查询、证据核对、再次综合及导出，并处理普通失败和配置问题；不以 CLI 或底层 JSON 作为必经步骤。

阅读支持连续阅读与带问题核查：PDF 导航、缩放和查找，解析全文与资源呈现，多文献切换保留位置，以及从检索、综合或提取字段往返正确版本的原文。实际证据能力不足时明确提示；字号、行宽、主题和侧栏收放服务于阅读舒适度。具体阅读交互继续专项设计，批注、笔记、翻译和术语解释等扩展范围尚未在本次落实。

这些是已接受的目标，不表示现有页面已经全部实现。精确职责与验收以 ADR 0032/0033 和产品需求 R12 为准；维护、迁移和特殊操作可留在 CLI，机器入口复用全部 Web 业务能力，无需复刻视觉交互。

## 原型与实现的边界

### 标签与提取表单（G1，2026-10-18 确认）

Owner 在本会话查看局部可点击样稿后明确回复“按这版表单继续（推荐）”。该确认扩展“提取”入口，沿用现有外框、字号与配色；原附件 HTML 字节保持不变。

- 左侧配置规范，右侧显示文献范围、输入说明及主操作。桌面保持双栏，窄屏顺序堆叠；新建处理可切换“记录提取”和“文献标签”，已有低层交付工具保留为次级入口。
- 记录提取先说明记录含义与可选纳入条件，再增删字段、填写字段名/说明/类型及数值的单位说明。标签使用问题、答案类型和枚举选项；证据不足明确为无法判断，不默认判否。初始内容使用空表单和提示，不把合成示例变成产品领域默认值。
- 范围区区分单篇/已选文献和全部当前筛选结果；输入缺口按真实材料显示。全文为默认，也可显式选择匹配片段并说明部分覆盖；不隐式补解析或获取。
- 提交使用当次范围和规范快照，重复点击不重复建任务；失败保留草稿，已保存任务的回执与入口不会随表单范围变化而改义。首屏显示新生成/复用与缺口，真实 token 信息另行展开。

本次确认覆盖表单与提交/任务反馈。结果表、筛选/证据侧栏为 G2，阅读器为 G3，已于 2026-10-19 分别确认；样稿和批准不证明生产链路已经完成，实施状态见活动计划与当前指南。

原型使用内嵌示例文献、模拟任务、模拟 PDF 和 Browser 画面。入口和交互作为设计依据；示例中的业务数值、`ready` 标记、数据结构、执行算法、持久化和定时器不构成生产合同，也不证明现有后端已实现相应能力。统一处理器与默认提取边界已由 [ADR 0034](../decisions/0034-unified-processors-and-results.md)明确，Web 接入仍须单独验证；统计/地图的数据支持、批次与保存视图持久化、跨入口会话可见性等逐项衔接，不从原型推导新的领域事实所有权。

HTML 的“讨论点”是原型内的说明内容；具体功能边界以用户后续决定及对应需求/ADR 为准。正常点击关闭时交还 Agent 是原型展示的目标体验，意外断线、切换文章和交还失败不能仅靠前端关闭回调处理。

原型HTML引用了Google Fonts，离线时使用系统回退，不影响内嵌示例交互。正式React界面内置Source Sans 3 / Source Serif 4拉丁woff2字体，中文保留系统回退，不加载外部字体。合成库的浏览器验证阻断外部请求；不据此声称访问了真实服务或用户数据库。

### G2 / G3 专项确认（2026-10-19）

Owner 对两份可点击样稿分别回复“按这版结果页继续（推荐）”和“按这版阅读布局和验收范围继续（推荐）”。布局沿用定稿库界面，不修改 prototype.html 原字节。

- G2：集合/结果列表、schema 字段表、分页/跨页选择、字段证据侧栏、确认后继续综合、明确范围的单份完整导出；partial 和未知值保留原义。
- G3：中间连续阅读 PDF/全文/总结，目录与文献信息栏可收起；页码、适宽/缩放、查找、正文 18/20/22/24 px 和行宽控制；证据可进入固定全文并返回结果/检索/总结。桌面双栏，窄屏信息区在正文后可滚动，目录为可收起覆盖层。
- 基础 UI/正文仍为 18/20 px、普通控件 40 px。阅读位置为会话状态，关闭标签释放；没有新增持久文献事实、批注或翻译。
- 性能验收限本机 100 页、每页两行的 36,419 字节合成文本 PDF：冷开 ≤2 s、热开 ≤1 s、翻页/缩放/查找 ≤500 ms；十次切换后关闭释放 worker、canvas、对象 URL。该口径不代表扫描文件或所有部署环境。

### 设计语言 v2（G4）与阅读方向（G5，2026-10-19）

Owner 对当前设计语言和 Motion 手感的原话是「目前就挺好的，加了motion之后手感好多了」；对阅读与总结回复「按这个阅读与总结方向继续（推荐）」。这些确认扩展原型的组件与阅读呈现，原始 HTML SHA-256 不变。2026-10-19的GB确认进一步确定沿用当前整体版本，检查通过后切换默认并删除旧前端；实际切换和全量测试仍须分别验证。

- 四主题是蓝白、深色、墨绿与暖白；表面、文字、边线、焦点、状态和证据颜色集中于 `apps/web/src/app/styles/tokens.css`，四主题不另写各页组件分支。
- 控件使用同一 React Aria 原语：普通高 40 px、紧凑 36 px、行内 28 px；圆角基准 4/6/8/12 px，胶囊只用于明确的圆形/标识用途。阅读正文默认20 px，支持18/20/22/24；信息18 px、辅助17 px、说明16 px。字体离线交付，许可与实际版本不在这里重复维护。
- 主要操作、次要操作、文字操作与加工动作分层；加工先确认范围和服务影响。技术 ID/hash/机器错误保留在技术详情中，重要失败用人的语言说明，不能为了干净而隐藏数据校验失败。
- 默认动效参数：按下缩放0.98；spring stiffness520/damping38/mass0.7；短120 ms、标准180 ms、面板240 ms、证据标记900 ms，退出约进入时长的2/3。CSS负责颜色与按下反馈，Motion负责指示滑动、内容进入和可打断过渡。关闭面板先提交真实布局，PDF不随动画逐帧重建。
- 续读插入、路由、PDF翻页、栏宽拖动、数字变化和普通虚拟列表行不做动效。系统或本机“减少动效”偏好统一传播到CSS和Motion，业务请求不等待动画完成。
- 阅读工具栏承载视图切换、目录、页码/缩放或字号/行宽、查找、信息栏和更多操作；信息栏按身份、摘要、可读材料、操作与收起的技术详情组织，窄屏在正文后可达。
- 总结仅把现有 finding/method/result/limitation/disagreement 映射成人类栏目；短证据编号就近预览，并跳转到固定原文版本。无可靠语义时不新增背景、不改写来源、不编造PDF页码。正文显式片段链接仅在已加载目标可匹配时预览，裸引用编号不猜测。

组件层以 v2 为准，整体导航、列表、预览和标签布局继续以原型为准。实测只覆盖本机合成材料；用户确认不代替功能对等、生产对象图与 Full。本轮完成证据见[Web 体验归档记录](../../archive/2026-10-19-web-experience/README.md)。
