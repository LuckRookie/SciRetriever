## 设计原型

不维护独立的 HTML 原型。设计在三层中进行，全部与生产代码同源：

1. **规则**：设计内核与页面规格，只写规则和意图。
2. **组件**：应用内的组件画廊（`gallery` 入口）展示每个共享组件的全部变体与状态。新增或修改组件先在画廊里出现。
3. **页面**：设计样例库。用真实服务端加合成样例文献库启动正式应用，样例覆盖每一种状态；截图脚本按固定页面清单在 1440×900 与 390 宽度下截图。这组截图就是每一轮设计的“原型”，交 Owner 审阅，也作为视觉回归的对照。样例库由[计划 14](../../plans/2026-10-23-web-design-overhaul/02-design-samples.md)建立，建成后在此写明启动与截图命令。

尚不存在的新页面、或需要比较几个方向时，可在 `sandbox/` 下做临时静态样稿，只用于当次决定，定下后删除或归档。

样例库中的文献、数值和会话都是合成内容，截图只说明界面，不代表真实数据、科学结论或已实现的能力。
