# Web 排版

类型：导航
负责：Web 的排版由哪几样东西组成、每一样写在哪里；还没有写进规格的排版事实
状态：现行

排版是各风格共用的：换一套风格，页面的内容、位置和尺寸不变。排版的规定分散在几份文档里，这里把它们列全，改排版时先从这里找到该改的地方，改完在[改动记录](changelog.md)里加一行。

## 还没有写进规格的排版事实

下面这些只存在于样式代码里，文档里查不到。数值是 2026-11-26 在 1440×900 的截图上量的，不是规定；写规格时要按代码核对后挪到上表所指的文档里。

| 哪里                 | 量到的值                               |
| -------------------- | -------------------------------------- |
| 顶栏的高             | 48 px                                  |
| 侧栏的宽             | 244 px                                 |
| 文献库右栏的宽       | 约 404 px                              |
| 文献库列表的宽       | 占满侧栏与右栏之间；宽屏下没有上限     |
| 阅读页纸页的宽与位置 | 纸宽约 1040 px，居中；正文栏在纸内偏左 |

带批语的纸页（[ADR 0070](../decisions/0070-book-style-annotated-copy.md)，文献有阅读层时）：正文栏、栏线、页边三栏，由 `apps/web/src/app/features/reader/geometry.ts` 的 `sheetGeometry(…, annotated)` 算出，只在案头不窄于 1088 px 时这样排。

| 案头宽度        | 左页边 | 栏线所在的间隔 | 页边（批语的宽） | 页边外的纸 |
| --------------- | ------ | -------------- | ---------------- | ---------- |
| 不窄于 1560 px  | 110 px | 46 px          | 350 px           | 48 px      |
| 1240 至 1560 px | 96 px  | 46 px          | 310 px           | 48 px      |
| 1088 至 1240 px | 72 px  | 38 px          | 250 px           | 28 px      |

阅读页上浮着的控件（[ADR 0071](../decisions/0071-pdf-first-reader-two-floating-balls.md)，尺寸见[阅读体验 1.9](reading-experience.md#19-小球与程度条)）：案头右下角的“读”“译”两个小球；读本下方的程度条；两页并排时案头分左右两页，中间 16 px 是可拖的分界（左页占 30% 到 70%，默认一半，`apps/web/src/app/features/reader/layers.css` 的 `.reader-pair-handle`）；案头窄于 1100 px 时不并排。除此之外阅读页没有常驻的浮动控件。

正文栏仍由“排版 → 行宽”决定，放不下时先收窄正文栏。案头窄于 1088 px 时没有栏线与页边，批语排在它第一句所在段落的下方。导图是一张与案头同宽的拉页，不用这套尺寸。书眉的一粗一细线尚未实现。
