# Web 排版

类型：导航
负责：Web 的排版由哪几样东西组成、每一样写在哪里；还没有写进规格的排版事实
状态：现行

排版是各风格共用的：换一套风格，页面的内容、位置和尺寸不变。排版的规定分散在几份文档里，这里把它们列全，改排版时先从这里找到该改的地方，改完在[改动记录](changelog.md)里加一行。

## 排版由什么组成，各写在哪里

| 排版的哪一样                                               | 写在哪里                                               |
| ---------------------------------------------------------- | ------------------------------------------------------ |
| 字号与行高（全站只有七种）                                 | [设计内核“字号与行高”](design-core.md#字号与行高)      |
| 间距（4 px 基准的七个值）                                  | [设计内核“间距”](design-core.md#间距)                  |
| 页面怎样分块、控件怎样取宽                                 | [设计内核“规则”](design-core.md#规则)第 1、2、3、11 条 |
| 页面的几种形态                                             | [设计内核“三种页面形态”](design-core.md#三种页面形态)  |
| 顶栏、侧栏、整体信息架构                                   | [页面规格“整体信息架构”](page-specs.md#整体信息架构)   |
| 页面模板                                                   | [页面规格“页面模板”](page-specs.md#页面模板)           |
| 每一页的排布                                               | [页面规格](page-specs.md)的各页一节                    |
| 阅读页的版面：案头、纸页、页眉、顶栏、右侧面板、书脊、目录 | [阅读体验第 1 节](reading-experience.md#1-版面与构件)  |
| 阅读页的排版：字号、段落、期刊排法、标记                   | [阅读体验第 2 节](reading-experience.md#2-排版与标记)  |
| 阅读页的各视图                                             | [阅读体验第 3 节](reading-experience.md#3-视图)        |
