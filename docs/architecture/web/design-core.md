# Web 设计内核

类型：规格（前端视觉）
负责：全站视觉与组织规则：字体、字号、颜色、间距、组件、页面形态与动效
状态：现行

定位与设计依据的决定见 [ADR 0038](../decisions/0038-web-design-basis.md)；逐页排布见[页面规格](page-specs.md)。颜色、字体与尺寸的数值集中在 `apps/web/src/app/styles/tokens.css`，本文只写规则。全部组件及其状态在应用内的组件画廊中展示。

## 基调

文献与数据是主角，控件保持安静；颜色用得很少，每种颜色都有固定含义。质感概括为：**暖纸软墨，轻笔少框，平时安静，碰到才出现。**

- **暖纸软墨**：正文为暖深灰（`--fg`），不用近黑；侧栏与底块为暖白（`--side`）。
- **文字三级灰**：正文 `--fg`、次要 `--fg2`、再次 `--fg3`；三级在白底、侧栏与浅灰底上都满足 4.5:1 文本对比度。更浅的 `--fg-quiet` 只用于图标与装饰。
- **轻笔**：页标题、节标题用 600；导航当前项、按钮用 500；文献标题衬线 500，不加粗。
- **少框**：分组靠浅灰底块，不靠边框；浮起的东西用白底加阴影；交互靠底色变化（悬停 `--hover`，选中 `--sel`）。
- **碰到才出现**：列表行里的复选框、预览等行内操作只在悬停、键盘聚焦或已进入选择状态时显示；触屏设备始终显示。占全库绝大多数的默认状态（仅元数据）不挂标签。
- **书卷气**：衬线的页标题与文献标题，引文格式的书目行，淡色标签，黄色荧光笔式的证据标记，墨蓝实心主按钮。
- **不使用**：档案夹索引签、实体按键等拟物质感（试过，与现有风格不符）。

## 字体

| 用途                       | 拉丁           | 中文                   | 字重            |
| -------------------------- | -------------- | ---------------------- | --------------- |
| 界面、正文                 | IBM Plex Sans  | 思源黑体 Noto Sans SC  | 400 / 500 / 600 |
| 页标题、文献标题、阅读正文 | Source Serif 4 | 思源宋体 Noto Serif SC | 500 / 600       |
| 代码、技术详情             | 系统等宽       | 跟随界面               | —               |

- 全部为可变字体，按 `unicode-range` 切片的 woff2 随包离线发布（OFL）；来源、版本与校验值记在 `apps/web/src/app/styles/fonts/README.md`。
- 安装包因中文字体增加约 10.5 MB。浏览器只下载用到的切片；带 hash 的静态资源长期缓存，只在首次访问或升级后下载。
- 每到一个新切片，浏览器都要把整页文字重新排一遍。所以首屏之后趁空闲，一次性载入界面文案用到的切片：构建时从源码收集文案里的汉字，每种字体约 20 片。之后切换页面不会再触发重排；文献内容里的生僻字仍按需下载。

## 字号与行高

| 级别     | 用途                       | 规格                                                  |
| -------- | -------------------------- | ----------------------------------------------------- |
| 页标题   | 每页一个                   | 衬线 28 px / 1.3 / 600                                |
| 节标题   | 页内一级分组、对话框标题   | 无衬线 17 px / 1.4 / 600                              |
| 正文     | 内容与表单                 | 无衬线 15 px / 1.6 / 400                              |
| 控件     | 按钮、导航、标签页、工具条 | 无衬线 14 px / 1.4 / 400，当前项 500                  |
| 辅助     | 书目、说明、计数           | 无衬线 13 px / 1.5，次要色                            |
| 文献标题 | 列表与信息栏中的文献标题   | 衬线 16 px / 1.4 / 500                                |
| 阅读正文 | 全文                       | 衬线 20 px，中文行高 1.85、拉丁 1.7，可调 18/20/22/24 |

除以上七种外不出现其它字号；阅读页内的标题、注释与机器写的内容按阅读字号的倍数缩放，倍数见[阅读体验](reading-experience.md#21-字号)。数字一律 `tabular-nums`。控件高：常规 34 px、紧凑 30 px、行内 26 px。

## 间距

4 px 基准，只用 4、8、12、16、24、32、48：页面左右内边距桌面 32、窄屏 16；页头与内容之间 24；节与节之间 32；底块内边距 16；列表行上下 12；工具条控件间距 8、控件组之间 16；侧栏项高 30、组间距 16。

## 规则

1. **结构靠“节”来划分。** 一节是节标题（可带一句说明）加下方一个浅灰底块，内容放在底块里。白底加阴影只用于浮起的元素：弹出层、选择栏、对话框、选中项。不用边框画框，不在底块里再套卡片。

2. **控件按内容宽度。** 下拉框、数字框按内容取宽，不拉满整行。两到三个互斥选项用分段控件，更多选项才用下拉框。

3. **设置用定义表。** 每行左列是名称加一句说明，右列是控件；能给出当前生效的值时写在控件旁。行与行之间用最轻的细线（`--line`）。

4. **数据像论文里的图表。**
   - 每组数据只选一种形式：时间序列用柱状，排名用横条，占比用一条比例条加图例；
   - 图表默认用墨色（`--chart-ink`），底轨用 `--chart-muted`，只有需要强调的一组用 `--chart-accent`；
   - 每幅图配图注：图号、标题、样本数；
   - 需要看原始数字时，在页面层级统一提供“以表格查看”；
   - 没有数据的图不画，在页面注释里写一句。

5. **颜色各有专用含义。**
   - 墨蓝（`--blue`）：主按钮、链接、焦点环、选中项、当前标签下划线；
   - 黄色（`--mark`、`--hl`）：只用于证据与查找命中；
   - 阅读页的红色（`--reader-check-fail`）：只用于与原文不符的引用；
   - 状态色全站一套：已就绪绿、有 PDF 蓝、建档中黄、建档失败红、无法获取紫、仅元数据灰、已排除灰；
   - 其余用灰阶。
   - 四个主题（蓝白、深色、墨绿、暖白）共用同一套组件，只换令牌值。

6. **书目与数字有固定格式。** 书目为“作者 · _期刊_ · 年份”。数字用等宽字形、加千分位，在表格中右对齐。时间一律为本地时间。

7. **空状态一句话。** 用辅助级文字，留在它所属的区域里；不使用大号居中标题。

8. **只展示人能理解的事实。** 机器 ID、hash 与原始错误收进可展开的技术详情；操作者显示可读名称；重要失败用人的语言说明原因，不为了界面干净隐藏数据校验失败。

## 组件外观

每种组件只有一种外观。

| 组件     | 外观                                                                                               |
| -------- | -------------------------------------------------------------------------------------------------- |
| 主按钮   | 墨蓝实心；每页、每个对话框最多一个                                                                 |
| 次按钮   | 白底、一圈淡边、6 px 圆角                                                                          |
| 文字按钮 | 无底无边，悬停浅底；低频与内联操作                                                                 |
| 图标按钮 | 无底无边，悬停浅底，30×30，图标 16；成组时组内间距 4                                               |
| 输入类   | 文本框、搜索框、下拉框、数字框同一外观：白底、淡边、6 px 圆角，聚焦时墨蓝边与焦点环                |
| 标签页   | 下划线式，一页最多一级；需要第二级时用分段控件。分区很多的设置页用竖排标签：左侧一列，当前项浅灰底 |
| 分段控件 | 浅灰底槽，选中格白底浮起                                                                           |
| 快速筛选 | 胶囊形，选中为浅灰底                                                                               |
| 状态徽标 | 圆点 + 文字 + 浅色底；附带原因写在同一徽标里（“有 PDF · 待建档”）                                  |
| 标签     | 淡色小签，4 px 圆角，13 px                                                                         |
| 浮层     | 白底、12 px 圆角、`--shadow-pop`：菜单、弹出、选择栏、对话框、抽屉、命令面板、登录卡片             |
| 菜单     | 菜单项可分组，组间一条最淡细线；只有图标的“更多”用 ⋯ 图标按钮                                      |
| 表格     | 表头 13 px 次要色、无底；行上下内边距 12；行间最淡分隔线；数字列右对齐                             |
| 页头     | 页标题 + 上下文数字 + 至多一个主操作；不放说明系统行为的句子                                       |
| 空状态   | 一句话 + 至多一个动作，辅助级文字，留在所属区域内                                                  |

| -------- | ------------------- | -------------------------- |
| 节       | `.ui-section`       | 页内一级分组               |
| 底块     | `.ui-block`         | 节与图的内容区（浅灰底）   |
| 定义表   | `.ui-definitions`   | 设置与属性                 |
| 图       | `.ui-figure`        | 统计图与其图注             |

### 三种页面形态

按用户在页面上做什么来选：

- **监视页用表格加右侧详情面板**：一串同类条目，点行从右侧滑出详情（宽 560）；面板不遮挡列表，可以直接点另一行切换；Esc 或关闭按钮收起，焦点回到原行；不常驻空白的详情栏；窄屏时面板占满全屏。
- **需要并排对照时用主从容器**：在同类条目之间频繁切换，并且右侧是实时或很长的详情（例如 Agent 会话记录）。
- **处理型清单用单列列表、操作放在行内**：一条一条处理，可多选批量处理；编辑在该行下方展开。
- **对象页用列表加详情页**：条目不多但每个内容丰富，点开进入详情页，顶部有返回，内容按节往下排。

主从容器：列表和详情装在同一个外框里（`--line2` 细边、12 px 圆角）；左栏浅灰底列表，上方筛选工具条，底部分页；右栏白底详情，两栏之间一条竖线。列表项悬停浅灰，选中项白底加轻阴影浮起。

侧栏文字与图标用专用颜色（`--side-fg`、`--side-icon`），图标线宽 1.75；悬停用 `--hover-soft`，当前项用 `--active` 加 500 字重。

## 交互反馈与动效

可操作的东西被指到、按下、聚焦时都要立刻回应；只有“出现、移动、消失”才用动画，颜色变化不当作表演。数值在 `tokens.css`：`--feedback` 加在控件上，悬停时换成 `--feedback-hot`。

| 时刻 | 规则                                                                                                                                                                 |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 悬停 | 底色或边色在指针进入的同一帧出现，离开时 140 ms 淡出。次按钮边色加深一级并带极浅阴影；文字按钮、图标按钮只换浅底；行与卡片只换底色或边色，不放大、不上浮             |
| 按下 | 按钮缩到 0.98、图标按钮 0.92、筛选胶囊 0.96，90 ms 内到位，松开后略带回弹；菜单项与行按下时底色加深一级（`--active`）；复选框按下缩到 0.88                           |
| 焦点 | 键盘焦点为 2 px 墨蓝环，即时出现；鼠标点击不显示焦点环                                                                                                               |
| 切换 | 标签与分段控件的指示块在切换时滑过去（220 ms），只在切换那一刻测量一次；复选框打勾带一点弹性，取消即时；开关滑块略带回弹                                             |
| 浮层 | 菜单、弹出层、提示从触发点方向偏移 4 px 并从锚点缩放进场（180 ms），退场 120 ms；对话框与抽屉进场 240 ms，遮罩随之淡入；关闭即时移除，避免淡出中的旧对话框仍可被点到 |
| 提示 | 第一次指到后 500 ms 出现；随后在其他控件上立即出现；能显示快捷键的写上快捷键                                                                                         |
| 加载 | 骨架屏延迟出现，快速返回的请求不闪骨架；业务请求不等待动画完成                                                                                                       |
| 增删 | 用户操作新增的条目（新文件夹、新批注）以 200 ms 淡入并下展；删除先淡出再收起，并提供撤销                                                                             |
| 拖放 | 拖起的东西跟手显示数量；经过的落点即时高亮，停留片刻自动展开；放下后落点闪一次                                                                                       |

不做动效：路由切换、续读插入、PDF 翻页、栏宽拖动、数字变化和普通虚拟列表行。

实现约束：

- 动画只改 `transform`、`opacity`、`clip-path`；
- 不对大区域做布局投影动画；
- 测量只在状态改变时做一次；
- 悬停判断交给 CSS，或单个监听加逐帧节流；
- 系统或本机“减少动效”偏好统一传到 CSS 与 Motion，此时所有动画改为即时，只保留颜色变化。

## 阅读页

阅读页的形象是“案头的文稿”（[ADR 0062](../decisions/0062-reader-visual-manuscript-on-a-desk.md)）：案头上一张白色纸页，期刊式排版，用蓝笔和荧光笔批过。它是第 1 条规则的例外：纸页上用有含义的细线分隔（页眉线、摘要上下线、三线表、脉络的章节线），不用浅灰底块分组，也不给区域画框。版面、标记与视图的规则见[阅读体验](reading-experience.md)。

阅读页的令牌（目标；其中 `--reader-skeleton` 已随计划 24 的 05 块加入 `tokens.css`，其余尚未加入）：

| 令牌                     | 浅色                    | 深色                      | 用途                                                                     |
| ------------------------ | ----------------------- | ------------------------- | ------------------------------------------------------------------------ |
| `--reader-desk`          | 同 `--pdfbg`（#efeeeb） | 同 `--pdfbg`（#111315）   | 案头，原文与 PDF 视图共用                                                |
| `--reader-sheet`         | 同 `--bg`（#fff）       | #1f2226                   | 纸页与书脊的底色；阴影用 `--shadow-1`                                    |
| `--reader-pen`           | 同 `--blue`             | 同 `--blue`               | 读者的划线、批注文字、框选、书脊视窗                                     |
| `--reader-pen-soft`      | rgba(47, 75, 168, 0.55) | rgba(142, 162, 240, 0.6)  | 关键句竖线、批注引线、PDF 定位线                                         |
| `--reader-spine-a`       | rgba(55, 53, 47, 0.16)  | rgba(255, 255, 255, 0.16) | 书脊章节段（单数段）                                                     |
| `--reader-spine-b`       | rgba(55, 53, 47, 0.30)  | rgba(255, 255, 255, 0.30) | 书脊章节段（双数段）                                                     |
| `--reader-tick-evidence` | #f0c41e                 | #e6c34a                   | 证据与查找命中的刻度                                                     |
| `--reader-check-fail`    | #a03a33                 | #f2726a                   | 与原文不符的引用：波浪线、说明文字、刻度；两种主题在纸页上对比度 ≥ 4.5:1 |
| `--reader-skeleton`      | rgba(55, 53, 47, 0.07)  | rgba(255, 255, 255, 0.06) | 骨架条与图片、PDF 页的占位                                               |

页眉用“辅助”级字（13 px）加一条 `--line2` 细线；顶栏 48 px，白底，一条 `--line2` 细线；阅读页的按钮、标签页、分段控件和输入框沿用本文的组件外观。

## 检查
