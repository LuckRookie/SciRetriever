# Web 设计内核

类型：规格（前端视觉）。负责：全站视觉与组织规则，包括字体、字号、颜色、间距、组件、页面形态与动效。状态：现行；文末“改版草案”一节为[计划 14](../../plans/2026-10-23-web-design-overhaul/README.md)的待确认内容。

定位与设计依据的决定见 [ADR 0038](../decisions/0038-web-design-basis.md)；逐页排布见[页面规格](page-specs.md)。颜色、字体与尺寸的数值集中在 `apps/web/src/app/styles/tokens.css`，本文只写规则。

## 基调

文献与数据是主角，控件保持安静；颜色用得很少，每种颜色都有固定含义。质感概括为：**暖纸软墨，轻笔少框，平时安静，碰到才出现。**

- **暖纸软墨**：正文为暖深灰（`--fg`），不用近黑；侧栏与底块为暖白（`--side`）。
- **文字三级灰**：正文 `--fg`、次要 `--fg2`、再次 `--fg3`，三级都满足 4.5:1 文本对比度；更浅的 `--fg-quiet` 只用于图标与装饰。
- **轻笔**：只有页标题、节标题用 600；导航当前项、按钮用 500；文献标题衬线 500，不加粗。
- **少框**：分组靠浅灰底块，不靠边框；浮起的东西用白底加阴影；交互靠底色变化（悬停 `--hover`，选中 `--sel`）。
- **碰到才出现**：列表行里的复选框、预览等行内操作只在悬停、键盘聚焦或已进入选择状态时显示；触屏设备始终显示。占全库绝大多数的默认状态（仅元数据）不挂标签。
- **书卷气**：衬线的文献标题，引文格式的书目行，淡色标签，黄色荧光笔式的证据标记，墨蓝实心主按钮。
- **不使用**：档案夹索引签、实体按键等拟物质感（试过，与现有风格不符）。

## 规则

1. **字号只有五级。**

   | 级别   | 用途                         | 规格               |
   | ------ | ---------------------------- | ------------------ |
   | 页标题 | 每页一个                     | 无衬线 32 px，700  |
   | 节标题 | 页内一级分组                 | 无衬线 17 px，600  |
   | 正文   | 内容与表单                   | 无衬线 15 px       |
   | 控件   | 按钮、导航、标签页、工具条   | 无衬线 14 px，常规 |
   | 辅助   | 书目、说明 14 px；计数 13 px | 无衬线，次要色     |

   文献标题为 16 px 衬线；阅读正文默认 20 px 衬线，可选 18/20/22/24。控件高：常规 34 px。

2. **结构靠“节”来划分。** 一节是节标题（可带一句说明）加下方一个浅灰底块，内容放在底块里。白底加阴影只用于浮起的元素：弹出层、选择栏、对话框、选中项。不用边框画框，不在底块里再套卡片。

3. **控件按内容宽度。** 下拉框、数字框按内容取宽，不拉满整行。两到三个互斥选项用分段控件，更多选项才用下拉框。

4. **设置用定义表。** 每行左列是名称加一句说明，右列是控件；能给出当前生效的值时写在控件旁。行与行之间用最轻的细线（`--line`）。

5. **数据像论文里的图表。**
   - 每组数据只选一种形式：时间序列用柱状，排名用横条，占比用一条比例条加图例；
   - 每幅图配图注：图号、标题、样本数；
   - 需要看原始数字时，在页面层级统一提供“以表格查看”；
   - 没有数据的图不画，在页面注释里写一句。

6. **颜色各有专用含义。**
   - 墨蓝（`--blue`）：操作、链接、选中；
   - 黄色（`--mark`、`--hl`）：只用于证据；
   - 状态色全站一套：已就绪绿、有 PDF 蓝、建档中黄、建档失败红、无法获取紫、仅元数据灰、已排除浅灰；
   - 其余用灰阶。
   - 四个主题（蓝白、深色、墨绿、暖白）共用同一套组件，只换令牌值。

7. **书目与数字有固定格式。** 书目为“作者 · _期刊_ · 年份”。数字用等宽字形、加千分位，在表格中右对齐。时间一律为本地时间。

8. **空状态一句话。** 用辅助级文字，留在它所属的区域里；不使用大号居中标题。

9. **只展示人能理解的事实。** 机器 ID、hash 与原始错误收进可展开的技术详情；操作者显示可读名称；重要失败用人的语言说明原因，不为了界面干净隐藏数据校验失败。

## 按钮分级

| 级别   | 用途                 | 样式                      |
| ------ | -------------------- | ------------------------- |
| 主操作 | 每页或每个对话框一个 | 墨蓝实心                  |
| 次操作 | 一般操作             | 白底、一圈淡边、6 px 圆角 |
| 文字   | 低频、内联操作       | 无底无边，悬停浅底        |

输入框保留淡灰边框，聚焦时以墨蓝边框标示。固定在页面里的小控件用 6 px 圆角，快速筛选为胶囊形，浮起的选择栏、弹出层用 12 px。

| ------ | ------------------- | -------------------------------- |
| 节     | `.ui-section`       | 页内一级分组                     |
| 底块   | `.ui-block`         | 节与图的内容区（浅灰底）         |
| 定义表 | `.ui-definitions`   | 设置与属性                       |
| 图     | `.ui-figure`        | 统计图与其图注                   |

| 主从   | `.ui-master-detail` | 需要在同类条目间频繁切换的监视页 |

### 三种页面形态

按用户在页面上做什么来选：

- **监视页用主从容器**：在一串同类条目之间频繁切换，右侧是实时或较长的详情。
- **处理型清单用单列列表、操作放在行内**：一条一条处理，可多选批量处理；编辑在该行下方展开。
- **对象页用列表加详情页**：条目不多但每个内容丰富，点开进入详情页，顶部有返回，内容按节往下排。

主从容器：列表和详情装在同一个外框里（`--line2` 细边、12 px 圆角）；左栏浅灰底列表，上方筛选工具条，底部分页；右栏白底详情，两栏之间一条竖线。列表项悬停浅灰，选中项白底加轻阴影浮起。

侧栏文字与图标用专用颜色（`--side-fg`、`--side-icon`），图标线宽 1.75；悬停用 `--hover-soft`，当前项用 `--active` 加 500 字重。

## 动效

- 按下缩放 0.98；弹簧参数 stiffness 520、damping 38、mass 0.7；时长：短 120 ms、标准 180 ms、面板 240 ms、证据标记 900 ms；退出约为进入时长的 2/3。
- CSS 负责颜色与按下反馈，Motion 负责指示滑动、内容进入和可打断的过渡。关闭面板先提交真实布局，PDF 不随动画逐帧重建。
- 续读插入、路由切换、PDF 翻页、栏宽拖动、数字变化和普通虚拟列表行不做动效。
- 系统或本机“减少动效”偏好统一传到 CSS 与 Motion；业务请求不等待动画完成。

## 改版草案（计划 14，待审阅确认）

以下内容在计划 14 的审阅点确认后并入上文对应位置，并删除本节。R1 确认 1–5，R2 确认 6。

### 1. 字体

| 用途                       | 拉丁           | 中文                   | 字重            |
| -------------------------- | -------------- | ---------------------- | --------------- |
| 界面、正文                 | Source Sans 3  | 思源黑体 Noto Sans SC  | 400 / 500 / 600 |
| 页标题、文献标题、阅读正文 | Source Serif 4 | 思源宋体 Noto Serif SC | 500 / 600       |
| 代码、技术详情             | 系统等宽       | 跟随界面               | —               |

- 优先用可变字体，按 `unicode-range` 切片为 woff2 随包离线发布，许可证 OFL；字体来源、版本与校验值记在前端依赖说明。
- 体积预算：安装包新增不超过 10 MB；打开文献库首屏下载的中文切片不超过 400 KB。超出时改用“GB 2312 常用字 + 标点”子集。

### 2. 字号与行高

| 级别     | 规格                                                                 |
| -------- | -------------------------------------------------------------------- |
| 页标题   | 衬线 28 px / 1.3 / 600（R1 同时给出无衬线 26 px / 600 对照，二选一） |
| 节标题   | 无衬线 17 px / 1.4 / 600                                             |
| 正文     | 无衬线 15 px / 1.6 / 400                                             |
| 控件     | 无衬线 14 px / 1.4 / 400，当前项 500                                 |
| 辅助     | 无衬线 13 px / 1.5，次要色                                           |
| 文献标题 | 衬线 16 px / 1.4 / 500                                               |
| 阅读正文 | 衬线 20 px / 1.75（可调 18–24）                                      |

除以上七种外不再出现其它字号；数字一律 `tabular-nums`。书目行由 14 px 改为辅助级 13 px。

### 3. 间距

4 px 基准，只用 4、8、12、16、24、32、48：页面左右内边距桌面 32、窄屏 16；页头与内容之间 24；节与节之间 32；底块内边距 16；列表行上下 12；工具条控件间距 8、控件组之间 16；侧栏项高 30、组间距 16。

### 4. 颜色角色

- 墨蓝只用于主按钮、链接、焦点环、选中项和当前标签下划线；
- 新增图表令牌 `--chart-ink`、`--chart-muted`、`--chart-accent`：图表默认用墨色，只有需要强调的一组用强调色；四个主题都要给值。

### 5. 组件外观

| 组件     | 唯一外观                                                                                                  |
| -------- | --------------------------------------------------------------------------------------------------------- |
| 按钮     | 同“按钮分级”；高 34、紧凑 30、行内 26；每页、每个对话框最多一个主按钮                                     |
| 图标按钮 | 无底无边，悬停浅底，30×30，图标 16；成组时组内间距 4                                                      |
| 输入类   | 文本框、搜索框、下拉框、数字框同一外观：白底、淡边、6 px 圆角，聚焦时墨蓝边与焦点环；搜索框不再单独用灰底 |
| 标签页   | 下划线式，一页最多一级；需要第二级时用分段控件                                                            |
| 状态徽标 | 圆点 + 文字 + 浅色底，七种状态固定配色                                                                    |
| 标签     | 淡色胶囊，13 px                                                                                           |
| 浮层     | 白底、12 px 圆角、`--shadow-pop`：菜单、弹出、选择栏、对话框、抽屉                                        |
| 表格     | 表头 13 px 次要色、无底；行上下内边距 12；行间最淡分隔线；数字列右对齐                                    |
| 空状态   | 一句话 + 至多一个动作按钮，辅助级文字，留在所属区域内                                                     |
| 页头     | 标题 + 上下文数字 + 至多一个主操作；不放说明系统行为的句子                                                |

### 6. 页面形态调整

监视页（任务）由主从容器改为“表格 + 右侧抽屉”：点行从右侧滑出详情，宽 560，Esc 或点外部关闭；不再常驻空白的详情栏。主从容器保留给确实需要并排对照的场景。
