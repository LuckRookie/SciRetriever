## 共享内容怎样查

公共能力只有一个详细说明位置，其他消费者通过链接引用：

- **配置、凭据与中性合同**：见①。配置仍由 Configuration owner 管理；文献、文档、知识和查询的具体对象字段归其所属模块。
- **网络访问与安全日志**：见②。它们由所有运行模块共享，文档归档位置不把供应商规则或事实判断交给任务协调器。
- **共享模型与受控 Agent 执行基础**：见⑤。单次模型层与 ADR 0031 的进程内 DSH 执行基础共享配置和 Network；Browser 的业务动作与控制仍见⑧。
- **跨模块版本、依赖和发布**：接口版本见①；业务产物合同见③④⑤；持久化和回收一致性见⑦。

这些是八篇正文内部的共享支撑章节，不新增顶层模块，也不要求调整当前源码目录。
